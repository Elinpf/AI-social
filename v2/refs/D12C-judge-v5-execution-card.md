## 0. 前置定义

| 符号 | 定义 | 怎么数 |
|---|---|---|
| **R** | **回合数 = 该线程内唯一 `turn_index` 的个数**（**不是台词行数**；群聊里同一回合多人各说一句仍算 1 回合） | 按 `turn_index` 去重计数 |
| **R_lines** | 台词行数（含同回合多人发言） | 仅记录，**不参与判档** |
| **锚点** | 可指名的具体物 / 数 / 人名 / 待办事由。**"东西""事"不算；地点不算** | |
| **P（推进计数）** | 满足 P1–P4 任一**回合对**的数量 | 见下 |

**P1–P4**

| 代号 | 判定问句 | 是 ⇒ |
|---|---|---|
| P1 | 后一句是否给前一句某个锚点**新增状态或量化**？ | +1 |
| P2 | 后一句是否给出**决定 / 承诺 / 带理由的拒绝**？ | +1 |
| P3 | 后一句是否引入**此前未出现的第三方或新待办**并与当前锚点挂接？ | +1 |
| P4 | 前一句提出**需要对方回答的具体问题**，且后一句**回答了它**？ | +1 |

⚠ P4 须**闭合**才算；未答 = 悬空，记入 Q2，**不计 P4**。同一锚点反复挪动但状态意义不变只算 1 次 P1；反复推迟不算推进；提问不计推进、被回答才计。

## 1. 计数项

### 1.1 Q1 内部 token 泄漏
- **问**：是否出现非中文标识符 / 英文 `snake_case` / 内部枚举名？
- **是** ⇒ **C，终止全流程**。**否** ⇒ 继续。

### 1.2 Q2 悬空提问
- **问**：是否存在一句含**直接疑问**（`？` 或 `成不/咋样/顺不顺/没/要不要/在不在` 等），指向对方或第三方的**具体事由**，而该事由在**此后至少一个对方回合**里**既未被回答、也未被同义追问**？
- **是** ⇒ 每处 **Q2+1**（按处计）。**否** ⇒ +0。
- **★ 末轮提问一律不计悬空**（其后无对方回合，"此后至少一个回合"字面不成立；否则等于系统性惩罚自然收尾征询）。**无例外**：末轮提问若真为缺陷，由 Q4/Q6 承接。
- **★ 不重复计数**：同事由已被非末轮提问计过悬空，末轮再问不额外计。
- **落到**：`Q2≥1 ⇒ 不得 A`；`Q2≥2 ⇒ C`。

### 1.3 Q3 光杆收束公式
**闭集（不得外延）**：`先这样`／`就这样吧`／`先这么着`／`先这么办`／`先这么定`／`就先这样`／`先到这儿`／`先搁着吧`／`先搁这儿`／`先搁那儿`／`先搁下`／`先放着`／`先放着吧`／`先摆着`／`先放放`／`先不急`

- **问**：某句的**最后一个分句**是否**仅由**表内短语构成（无物、无动作、无事由），且该句**不是**线程末句？
- **是** ⇒ **Q3+1**。**否** ⇒ +0。
- **事由归属**：事由在短语**内部**（`那件事先放放，我…`）⇒ 不计；只能靠**上文回指**（`…有点闷。先这样。`）⇒ 计。
- **闭集纪律**：不在表内一律计 0，并在证据栏注 `闭集未收录`。不得按"类似/同族"外延。
- **落到**：`Q3≥1 ⇒ 不得 A`；`Q3≥2 ⇒ C`。

### 1.4 Q3b 句尾标签复现
- **问**：是否存在一个 **≤6 字**短语，在同一线程内出现 **≥2 次**，且**每一次都在句末**？
- **是** ⇒ **Q3b+1**（每短语 1 次）。**否** ⇒ +0。
- **落到**：`Q3b≥1 ⇒ 不得 A`；`Q3b≥2 ⇒ C`。
- ⚠ 只认**句末**标签；句首/句中复述是正常接话。
- ⚠ **必须同时通过 §2 的「复现三门」**，否则不得命中。

### 1.5 Q4 镜像问答
- **问**：相邻回合是否出现「乙回答甲的提问 → 随即提出同型提问 → 甲照此回答并再反问」这一 **≥3 步**循环？
- **是** ⇒ **Q4+1**。**否** ⇒ +0。
- **落到**：`Q4=1 ⇒ 不得 A`；`Q4≥2 且 P=0 ⇒ C`。

### 1.6 Q5 槽位填装（**v5 新增 P0 排除项**）
**三条件同时成立才算 1 处**：
- (a) 由 **≥3 个短句**并列构成（逗号/句号分隔）？
- (b) 短句之间**零连接词**（无 `就/倒/可/不过/所以/要不/回头/等/才/便`）？
- (c) 至少一个短句是 **≤5 字纯状态标签**（只有状态，无物无动作，如 `手都酸了。`／`饿得慌。`）？

**★ P0 排除项（先判这一步）**
> **问**：该条台词（**去句首语气词后**）的**第一个短句**，是否为对**紧邻上一句直接提问**的**应答语**？三条须同时成立：
> - (a') 上一句是**直接提问**（含 `？`，或含 `成不/咋样/顺不顺/没/要不要/在不在/还…吧`）；
> - (b') 首短句在**应答闭集**内：`稳当`／`还行`／`差不多`／`好`／`成`／`行`／`可以`／`是`／`对`／`是的`／`没`／`没有`／`忙`／`挺好`（**闭集，不得外延**）；
> - (c') 去语气词后长度 **≤3 字**。语气词闭集：`哎/哟/唉/喂/嗯/啊/哦/啧`。
>
> **是** ⇒ **该句不计 Q5**，证据栏注 `P0 排除` 并抄录"上一句提问片段"+"本句首短句"。**否** ⇒ 按三条件照常计。

- **落到**：`R ≤ 3 且 Q5 ≥ 1 ⇒ C`；`R ≥ 4 且 Q5 ≥ 2 ⇒ C`；`R ≥ 4 且 Q5 = 1 ⇒ 不得 A`。（**此路径 v5 未改**）

### 1.7 Q6 回合失接
- **问**：后一句对前一句的**核心请求/提议**是否出现 ——
  - (i) **否定性误读**：回答了一件对方**并未提出**的请求；
  - (ii) **完全无响应**：既不接受、不拒绝、不替代，且直接另起完全无关话头。
- **是** ⇒ **Q6+1**。**否** ⇒ +0。
- **★ 截断线程不计**：若线程已贴到 run 末尾（`min_round + T − 1 ≥ maxround`，`T`=线程实际轮数）⇒ 后续回合**没机会出现**，Q6 计 0，注 `尾截断，不计`。
- **★ 旁白豁免（amendment2）**：旁白中的动作可视为回应的一部分；**若台词另有间接回应，不记 Q6**。
  - **旁白唯一承载且台词零回应 ⇒ 不豁免**，照判。
  - 旁白是**无关动作**、不承载回应 ⇒ 不影响判定。
- **落到**：`Q6≥1 ⇒ C`；`Q6=1` 须按 §4 三项标注（amendment1/2）。

### 1.8 Q7 句骨架复现（**v5 新增复现三门**）

**骨架抽取**：抹去专名（人名/地名/店名/称呼）与具体物/数量；保留人称、**分句数**、各分句**谓词类型**（陈述/疑问/祈使）、**动词**（同义视为相同）、句末语气。**副词与体标记不属骨架。**

| 等级 | 定义 | 该回合计 |
|---|---|---|
| R1 逐字复现 | 抹去专名与具体物后字面完全一致 | 1 |
| R2 换皮复现 | 骨架相同，具体物/数量/宾语被替换或扩展，**分句数与谓词类型不变** | 1 |
| 非复现 | 骨架不同；或分句数/谓词类型改变 | 0 |

- **计数**：同骨架族回合数 `n`（含首现）。
- **豁免（仅一条）**：族内某复现回合**首次引入**新锚点（新对象/新第三方/新待办）或新分工 ⇒ 该族不计 Q7。**回指族外已有对象不算豁免；地点不算锚点。**
- **同人/跨人**：**不区分、等权计 1**；但证据栏须注明 `同人/跨人`。
- **落到**：**`Q7≥1 ⇒ C`（无条件）**。
- ⚠ **必须同时通过 §2 的「复现三门」**，否则不得命中。

## 2. 复现三门（Q3b / Q7 命中的前置门，**v5 新增**）

对每个候选字符串 `s`（Q3b 用 ≤6 字短语；Q7 用骨架串）：

| 门 | 判定问句 | 不通过时 |
|---|---|---|
| **门 1 语气词剥离** | 是否已把句首 `哎/哟/唉/喂/嗯/啊/哦/啧` 剥离后再取 `s`？剥离后 `s` 是否非空？ | 剥离后为空 ⇒ **不得命中** |
| **门 2 基线可算** | 能否算出 `base(s)` = 本臂中出现 `s` 的**不同 thread_id 数 ÷ 本臂线程总数**？（需本臂全库） | 算不出 ⇒ **不得命中**，注 `基线不可算，不判` |
| **门 3 固定句名单** | `s` 是否落在闭集名单内：`这日子过得真快`／`日子过得真快`／`这炉桃酥刚出炉`／`这雨下得人心慌`？ | 在名单内 ⇒ **一律不得命中**（跨臂共用模板，不是本线程内部生成） |

**命中后强制披露（缺项即不合规）**：
```
s = <字符串> ；in(s) = <次数> ；base(s) = <线程数>/<总数> = <比值> ；语气词剥离：已做 / 不适用
```

**关于 `n≥3`**：**它是「临时护栏，非校准阈值」。** 降阈值须同时满足：① 基线分母已生效并随命中披露；② 语气词剥离与固定句名单已执行；③ 显著性阈值**另走预登记**。执行者**不得自行降阈值或改名单**。

## 5. 执行步骤

1. 抄录每条 `thread_id`、`R`（唯一 `turn_index`）与 `R_lines`。
2. 逐条填计数表（Q1/Q2/Q3/Q3b/Q4/Q5/Q6/Q7/P 共 9 项）。
3. 按 §3 走，**命中即停**，记命中步与档位。
4. 凡 Q3b/Q7 命中，必须填 §2 的四个披露字段；凡 Q6=1，必须填 §4 三项。
5. 落盘：**计数表**与**档位表分开放**（便于先对计数、再对档位）。
6. 交卷只报：路径 + sha256（全 64 位）+ `wc -l <` + 条数自证（输入 `grep -c "^\[#"`、矩阵行 `grep -cE '^\| *[0-9]+ *\|'`）。**正文不贴档位理由。**

## 6. 已知局限（不读会误用）

1. **v5 未经验证**：两处修订只针对**已观测到的假阳性**（正常短答语、跨臂固定模板），**无任何新语料验证过**。
2. **阈值仍待校准**：`Q3≥2`、`Q4≥2 且 P=0`、`Q5≥1 且 R≤3`、`P≥2`、`Q7 的 n≥3` 均无数据支撑。
3. **A 档可能不可达**：若本批 `R` 多为 2，`A1（R≥3）` 会使 A 档**结构性为 0**——这是结构后果，**不是文本质量结论**。
4. **新增项可能引入假阴性**：P0 会让"应答＋填装"混合句逃过 Q5；门 3 会让"真复读但恰在固定句名单内"逃过 Q3b/Q7。**两方向均未测。**
5. **闭集必有漏**：应答闭集、语气词闭集、固定句名单都是闭集，遇漏项记 `闭集未收录`，**不得就地扩表**。
6. **Q6/Q7 命中率极低时**：写「未触发、无法评价」——**零命中既非通过也非失败**。
