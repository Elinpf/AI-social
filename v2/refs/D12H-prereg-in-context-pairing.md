# D12-H 预登记 · **v3（定稿候选）** run 内真配对：ON/OFF 各 3 采，判定用 `overlap_frac`

> 立此存照：**2026-10-23 22:05（v3，采纳 eval 两轮实测与口径确认）**，在任何 D12-H 跑批之前。
> v1（用 `L-7`/`pair_delta`）与 v2（用 `recent16` argmin 差）**均已作废**，原因见 §8。
> 依据：`v2/evidence/d12g_result.md`、`v2/evidence/d12g_pairing_feasibility.md`、eval 的 `overlap_frac` 实测（T4 >0 占 34.1%、T5 32.2%）与口径确认。

## 0. v3 的核心：**判定指标与选优指标必须分开，且分开的代价要写死**

- **选优指标**（run 内实时）：`recent16_scores[c]` = 候选与该 agent 可见最近 16 条台词的 8-gram **交集条数**；两组各自 argmin（平局取组内最小 index）。
- **判定指标**（出数时用日志全局重算）：`overlap_frac(c) = |shingles(c) ∩ H| / |shingles(c)|`，`H` = **全批中 `(round, seq)` 严格小于该消息的所有 MSG 的 shingle 并集**。

> **④ 的关键限制（必须写进结论）**：被选候是**按 `recent16_scores` 选的，不是按 `overlap_frac` 选的** ⇒ 本设计只能回答
> **「在 `recent16` 择优规则下，ON 组产出的被选候在**全局交集率**上是否更低」**，
> **不能**回答「开头约束能否降低全局交集率」。
> ⇒ 若效应偏小，**不得**据此判「机制未生效」，只能报「**本设计下不可分辨**」（这是 floor effect 的第 5 种预防形态）。

## 1. 设计（一个 run、60 轮不变）

每一处对话生成**采 6 次**：

| 组 | 3 条候选 prompt | `sample_index` | 落库 |
|---|---|---|---|
| **ON** | 全部 = T1 + 「开口先叫对方一声，别用你上一句或对方上一句的前四个字。」 | 0/1/2 | **是**（落选中那条） |
| **OFF** | 全部 = T1 基础 prompt（逐字节） | 3/4/5 | **否** |

- **只开一个结构位**（开头约束）⇒ ON/OFF 唯一差别是这一行提示词；
- 两组**各自** 3 选 1（用 `recent16_scores` argmin，平局取组内最小 index）。

## 2. 判据（**只有一条主判据**）

| # | 判据 | 阈值 |
|---|---|---|
| **1（主）** | **`overlap_frac` 配对差**：`d = off.overlap_frac[off.picked] − on.overlap_frac[on.picked]`；**在全部有效对上取均值（含 `d = 0`）** | **`mean(d) > 0` 且配对 CI 不含 0**（slot 级配对重采样 B=2000/seed42；另报线程级，两者**不得互代**） |
| 2（描述，**非判据**） | **三分比**（`d>0 / =0 / <0`）+ **非零对的均值与 CI** | **只描述**，且必须标注「**条件于 `d≠0`，含选择性偏差，不得作效应量**」 |

> **⚠ 为什么主判据必须用"全部对（含 0）"（`eval` 22:00 校正，采纳）**：`d≠0` 是**结果变量**，条件在它上面取均值 = **按结果筛样本（选择性偏差）**。三个具体坏处：
> 1. **均值会崩**：若 ON 把少量对从 0 推成正、同时把另一批从 0 推成负，非零对均值可能强正而**全对均值接近 0**；而 `L-7` 只对"全对均值"敏感 ⇒ **判据与目标脱节**；
> 2. **CI 分母虚小**：非零对约 1/3（约 170 对）⇒ 半宽被压窄 ⇒ 会被误读成"精度很高"；
> 3. **不可复算对齐**：换一批数据非零对集合会变，跨臂不可比。
>
> ⇒ **若全对均值被 0 稀释到看不出东西，那正是 §0 的结论（如实报"不可分辨"），不得靠换分母造精度。**
| 3（机制闸） | `ctx.d12h` 六采齐 `m=6` 命中率 | = 100% |
| 4（机制闸） | ON/OFF 两组**各自** argmin 命中（按 `recent16_scores`） | 各 = 100% |
| 5（代价闸） | **`L-3` 含括号块率**（按落库 body） | **≥55%** |
| 6（效果层，仅记录） | `L-7` norm8/raw8、`P1`、`F-2'`、`L-15 strong`（ON 语料） | 沿用 T5 阈值，**只报点估计，明写"本设计不判效果显著性"** |

## 3. 中途自检闸（**性质：实现自检闸，不是分辨力闸**）

预期**有效对（`d ≠ 0`）占比 ≈1/3**（`eval` 实测 `overlap_frac` 非零率 T4 34.1%、T5 32.2%）。
**跑到 1/3（约 20 轮）时同时核 4 项**（都可一行命令）：

| # | 自检项 | 异常含义 |
|---|---|---|
| 1 | `N/A`（`\|shingles\|=0`）占比 | 过高 ⇒ 候选过短/归一化错 |
| 2 | `overlap_frac` 是否**退化为全 0** | 全 0 ⇒ 历史并集没算进来 |
| 3 | `cand_shingle_counts` 是否**全 >0** | 有 0 ⇒ 空串/切分错 |
| 4 | **ON 与 OFF 的 `cand_shingle_hashes` 是否 100% 相同** | 相同 ⇒ **两组候选是同一份、机制没接上** |

**判据（`eval` 22:00 校正，采纳）**：
- **若有效对占比 <5%** ⇒ 判「**实现层可疑，先查接线**」，**不要**写成"本设计无分辨力"（3.5–4.6% 正是**旧 `recent16`+argmin 口径的特征值**，说明落盘/重算用的是错的指标）；
- 若 ≥5% 继续跑；报告须给**有效对条数**并据此说明 CI 现实半宽；
- **本条闸只检测"实现是否接对"，不承担"能否分辨效应"的判断**（后者由 §0 的 ④ 限制承担）。

## 4. 落盘字段（**判定可复算的唯一依据**）

```
ctx.d12h = {m:6, group,
  on:  {picked, recent16_scores[3], cand_shingle_hashes[3], cand_shingle_counts[3]},
  off: {picked, recent16_scores[3], cand_shingle_hashes[3], cand_shingle_counts[3]},
  resampled}
```
- `cand_shingle_hashes[k]`：**排序后的 blake2b-8B hash 列表**（**不是集合 sha**——摘要算不出交集）；
- **`cand_shingle_counts[k] = |shingles(cand)|`（每候选一个整数）**：出数时作为 `overlap_frac` 的**分母**，同时用于发现"空串/过短"；
- **不落 `pair_delta` / `overlap_frac`**（出数时算，避免自证）；
- 组内候选 sha 重复 ⇒ **重采该候选（上限 2 次）**，记 `resampled`。

## 5. `overlap_frac` 的口径（**5 条钉死，采纳 eval 确认**）

1. **历史范围** = 全批、`(round, seq)` **严格小于**本消息的**所有 MSG**（不看 agent 可见性）；
   - **披露**：这是**批序**而非"该 agent 实际看到的上下文"（同轮并发消息也计入、模型当时未必看见）；因两组共享同一历史，**配对仍然公平**；
2. **必须严格小于（不能用 `≤`）**：否则 ON 组被选候若已落库会**把自己算进去**（自比 ⇒ 虚高）；
3. **分母 = `|shingles(cand)|`**；**`|shingles| = 0`（过短候选）记 `N/A` 并单独计数，不得记 0**（否则又是地板效应）；
4. 归一化：`normalize_body` 后 8-window（与 `L-7` 同源）；
5. **本指标与 `L-7` 同族但不可互代**：`L-7` 是"消息级 dup 率"（全局索引 + 任一 shingle 重合即计），`overlap_frac` 是"候选级交集占比"。

## 6. 出数必须给（防止"只看均值"）

- `overlap_frac` 在 ON / OFF 两组**各自的分布**（均值 / 中位 / p90 / >0 占比）；
- **非零对的均值 + 配对 CI**（slot 级 + 线程级，双口径）；
- **三分比**（>0 / =0 / <0）；
- **按 10 轮分层的趋势**：历史越长 `overlap_frac` **自然越高** ⇒ 必须展示配对差**不是时间趋势驱动**（配对按 slot 对齐已消掉趋势，但要展示出来）；
- `|shingles| = 0` 的 `N/A` 条数与占比。

## 8. v1/v2 作废原因（两个都被实测推翻）

| 版本 | 指标 | 为什么废 |
|---|---|---|
| **v1** | `L-7` 配对差 | **OFF 组 3 条候选永不落库** ⇒ `L-7` 的 dup 是**全局 shingle 索引**，OFF 组**没有 `L-7` 读数**；判定只能用候选级指标 |
| **v2** | `recent16` 交集 + argmin 配对差 | **floor effect**：`scores[picked] = 0` 占 **98.8%(T4)/97.6%(T5)** ⇒ `pair_delta ≠ 0` 实际只有 **3.5–4.6%**，20% 停手闸必然触发；且方差小是**被 0 截断**、不是精度（放大 n 无效） |
| **v3（本版）** | `overlap_frac`（全局累计交集率） | 实测非零率 **34.1%/32.2%**、20 个不同取值 ⇒ 方差非退化、与 `L-7` 同族 |

**另**：v2 里"2.1 分效应量"是**口径混用**（2.463 是首条候选均值、0.357 是被选候均值 ⇒ 那是**选择规则本身的效果**），已删除。
