## 2. 判定标准（预登记，判定者逐条套用）

一条 `landed=true` 的 tag 追加事件被判为 **真展开（true）** 当且仅当：

1. 该条台词**接着同线程上一句**在说事（不是答非所问、不是复述提示词、不是把内部 token 念出来）；**且**
2. 在原话题之外**自然**带出了第二个话题线索（`shift` 话题以动作/对象形式出现在语义主位，而不是只当修饰语或与动作矛盾）。

否则判 **假展开（false）**。若信息不足以判（如本线程首条无上文、正文截断），判 **存疑（undecidable）**，存疑**计入分母、不计入真展开**（更严一侧）。

**达标线**：真展开数 / 30 **≥ 20** ⇒ 达标；**< 20** ⇒ 未达标；判定样本不足 30 条 ⇒ 不可判（样本不足）；守卫任一被击穿 ⇒ 主判定降为不可判（见 §4）。

### R-1 · 2026-10-23T14:45+08:00｜抽样起点改为固定种子系统抽样（确认人：team-leader，书面消息 `0b96afdb`）

- **原文（§3）**：`step = N // 30，取 appends[0::step][:30]`。
- **修订**：`N ≥ 60`（即 `step = N//30 ≥ 2`）时，起点 `start = Random(SAMPLING_SEED).randrange(step)`，
  取 `index = start + i*step`（`i = 0..29`），**`SAMPLING_SEED = 20261023`** 写死可复现；
  `30 ≤ N < 60`（`step == 1`）无法等间隔覆盖 30 条 ⇒ **退回首段方案**（seq 升序前 30 条）并在判定件**披露前段偏置**；
  `N < 30` 仍判「样本不足」。
- **为什么改**：原式在 `30 ≤ N < 60` 时 `step=1`，等价于「只判最早 30 条」，存在早期轮次偏置（dry-run 已发现并披露）。
  Leader 指示用固定种子系统抽样消偏。
- **不变项（硬）**：判定样本量 **固定 30**、达标线 **≥20 条真展开**、主判据分母对象（`landed=true` 事件）、不回溯。
  **分母没有被改大或改小**，只改了「从 N 条里挑哪 30 条」的取点方式。
- **证据**：`v2/evidence/f2b_v2_n16r60_seed42/dryrun/sample_rule_selftest.txt`（N=10…247 全档自测 + 同 seed 可复现性断言）。
