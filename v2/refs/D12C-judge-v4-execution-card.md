## 0. 前置定义（全部可数，不用形容词）

| 符号 | 定义 | 怎么数 |
|---|---|---|
| **R** | 线程回合数（台词条数） | 该线程内台词行计数（每行一个 `turn`） |
| **锚点** | 一个**可指名的**具体物 / 数 / 人名 / 待办事由 | 如某具体货物名、某具体数字、某人名、某件待办。**"东西""事"不算锚点；地点（窗台/灶边/后院）不算锚点** |
| **接物** | 后一句对前一句的锚点**指名复述并做动作** | 构造例：`半块薯`→`那块薯皮皱了`→`薯给我` |
| **P（推进计数）** | 满足 P1/P2/P3/P4 **任一**的**回合对**数量 | 见下 |

**P1–P4（逐对判，满足一种即 +1）**

| 代号 | 判定问句 | 是 ⇒ |
|---|---|---|
| **P1** | 后一句是否给前一句的某个锚点**新增了状态或量化**？ | +1 |
| **P2** | 后一句是否给出**决定 / 承诺 / 带理由的拒绝**（不是"嗯""是啊"）？ | +1 |
| **P3** | 后一句是否引入**一个此前未出现的第三方或新待办**，并与当前锚点挂接？ | +1 |
| **P4** | 前一句提出**需要对方回答的具体问题**，且后一句**回答了它**（不接受"另起话头"）？ | +1 |

⚠ **P4 必须"闭合"才算**。提问未被回答 = 悬空，记入 Q2，**不计 P4**。
⚠ **同一锚点被反复挪动**、若只换动作不换状态意义（可用性／位置／归属未变），**只算 1 次 P1**。**反复推迟不算推进**。**提问不计推进，提问被回答才计。**

## 1. 计数项（逐条填整数，不填形容词）

### 1.1 Q1 内部 token 泄漏

- **判定问句**：台词中是否出现非中文的标识符 / 英文 `snake_case` / 内部枚举名？
- **是** ⇒ **C，终止全流程**。**否** ⇒ 继续。

### 1.2 Q2 悬空提问

- **判定问句**：线程内是否存在这样一句——它含**直接疑问**（`？` 或 `成不/咋样/顺不顺/没/要不要/在不在` 等疑问式），指向**对方或第三方的一个具体事由**，而该事由在**此后至少一个对方回合**里**既未被回答、也未被同义追问**？
- **是** ⇒ 计 **Q2 +1**（按处计，不按措辞去重）。**否** ⇒ +0。
- **★ 末轮提问一律不计悬空**：线程最后一回合的提问之后**不存在对方回合**，"此后至少一个对方回合未答"字面不成立。
  - 理由：否则**任何线程末轮只要提问就必然判悬空**（对话窗口总在某处截断），等于系统性惩罚"自然收尾征询"（`你说这样成不成？` 这类是正常口语）。
  - **无例外**：若末轮提问确实构成缺陷，由 Q4 或 Q6 承接，**不由 Q2 承接**。
- **★ 不重复计数**：同一事由若已被此前某个非末轮提问计过悬空，末轮再问**不额外计**（也不撤销前一次）。
- **落到哪一档**：`Q2 ≥ 1 ⇒ 不得判 A`；`Q2 ≥ 2 ⇒ 判 C`。

### 1.3 Q3 光杆收束公式

**闭集词表 v4（16 词，不得外延）**：
`先这样`／`就这样吧`／`先这么着`／`先这么办`／`先这么定`／`就先这样`／`先到这儿`／`先搁着吧`／`先搁这儿`／`先搁那儿`／`先搁下`／`先放着`／`先放着吧`／`先摆着`／`先放放`／`先不急`

- **判定问句**：某句台词的**最后一个分句**是否**仅由**上表中的一个短语构成（前后无具体物、无具体动作、无事由），且该句**不是线程最后一句**？
- **是** ⇒ **Q3 +1**。**否** ⇒ +0。
- **事由归属的分辨**：事由在短语**内部**（`那件事先放放，我这就去…`）＝ 有指向的推迟 ⇒ **不计**；短语内部什么也没有、只能靠上文回指（`…是不是有点闷。先这样。`）＝ **光杆，计 1**。
- **★ 闭集纪律**：**不在表内的短语一律计 0**。不得按"类似/同族/意思一样"外延；遇到"像但不在表内"的，计 0 并在证据栏注明 **`闭集未收录`**（供下一版扩表）。
- ⚠ 本项会**误伤合法口语**（`先搁着吧` 常是人对自己的活说的）。误伤最坏后果是 **A→B 一格**，不制造 C。**照规则数，不得用"我觉得这句挺自然"豁免。**
- **落到哪一档**：`Q3 ≥ 1 ⇒ 不得判 A`；`Q3 ≥ 2 ⇒ 判 C`。

### 1.4 Q3b 句尾标签复现

- **判定问句**：是否存在一个 **≤6 字**的短语，在同一线程内出现 **≥2 次**，且**每一次都处于句末位置**（后接 `。！？` 或台词结束）？
- **是** ⇒ **Q3b +1**（每短语 1 次）。**否** ⇒ +0。
- **落到哪一档**：`Q3b ≥ 1 ⇒ 不得判 A`；`Q3b ≥ 2 ⇒ 判 C`。
- ⚠ 只认"句末"标签；句首/句中的复述是**正常接话**，不算缺陷。

### 1.5 Q4 镜像问答

- **判定问句**：抽取相邻两回合的**句式骨架**，是否出现「**乙回答甲的提问 → 随即提出同型提问 → 甲照此回答并再反问**」这一 **≥3 步**的循环？
- **是** ⇒ 计 **Q4 +1**。**否** ⇒ +0。
- **落到哪一档**：`Q4 = 1 ⇒ 不得判 A`；`Q4 ≥ 2 且 P = 0 ⇒ 判 C`。

### 1.6 Q5 槽位填装

**三个条件同时成立才算 1 处**：

| 条件 | 判定问句 |
|---|---|
| (a) | 该句是否由 **≥3 个短句**并列构成（逗号或句号分隔）？ |
| (b) | 这些短句之间是否**零连接词**（无 `就/倒/可/不过/所以/要不/回头/等/才/便` 等衔接成分）？ |
| (c) | 是否至少有一个短句是 **≤5 字的纯状态标签**（只有状态、没有物、没有动作，如 `手都酸了。`／`饿得慌。`）？ |

- **三条件全"是"** ⇒ **Q5 +1**。任一"否" ⇒ +0。
- **落到哪一档**：`R ≤ 3 且 Q5 ≥ 1 ⇒ 判 C`；`R ≥ 4 且 Q5 ≥ 2 ⇒ 判 C`；`R ≥ 4 且 Q5 = 1 ⇒ 不得判 A`。

### 1.7 Q6 回合失接

- **判定问句**：后一句对前一句的**核心请求 / 提议**（形如 `成不？``要不…？``得空来坐坐``你帮我…`）是否出现下列任一 ——
  - **(i) 否定性误读**：回答了一件**对方并未提出**的请求。
    构造例：甲说「要不先搁一搁，等我把手上这点活弄完再喊你」，乙答「你先别急着喊我」——甲并未要求乙现在来。
  - **(ii) 完全无响应**：既不接受、不拒绝、不替代，且直接另起完全无关的话头。
- **是** ⇒ **Q6 +1**。**否** ⇒ +0。
- **★ 截断线程的未接上，不得判为缺陷（执行前必读）**：若该线程是**尾截断线程**——即它在 run 的末尾才开始（本臂判定线：`min(round) > 36`，因 `max_turns=6`、run 到 41 轮结束）——则"没接上"极可能只是**后续回合没机会出现**，而非生成缺陷。
  - 操作性判据：线程最后一句之后**是否还存在后续回合的位置**？若线程已贴到 run 末尾（无后续位置）⇒ **Q6 计 0**，并在证据栏注明 `尾截断，不计`。
  - 同理**倒推**：若"回答方似乎拒绝了一件没被提出的请求"，先检查是不是因为该提议的展开发生在**被截断掉的后续回合**里。
  - ⚠ 这一条**只影响截断件**；非截断线程里出现否定性误读或零响应，照常计 1。
- **落到哪一档**：`Q6 ≥ 1 ⇒ 判 C（任何 R）`。失接是**功能性断裂**，一句就够，**不需累积**（与 Q3/Q4/Q5 属不同阈值族）。
- **效力等级（务必与档位一起引用）**：Q6 的**实证支撑仅 1 例**（非截断样本），属**单例规则**。⇒ 评审方引用本判据时，不得把"Q6 单独致 C"当作已充分验证的稳定结论；**这是样本不足，不是规则错误**。

### 1.8 Q7 句骨架复现（v4 新增）

**(A) 骨架抽取（三步）**

1. **抹去专名**：人名、地名、店名、亲缘称呼与称谓（某个"某婶""某先生""某家小子"）。
2. **抹去具体物与数量**：可指名的物品名、数量词与量词。（代指性的 `这/那/它` **不抹**。）
3. **保留为骨架**：人称；**分句数**（按句号/逗号切分的谓词性分句数）；每个分句的**谓词类型**（陈述/疑问/祈使）；每个分句的**动词**（同义替换视为相同，如 `钉` 与 `钉完`）；句末语气（`呢/吧/了` 的有无）。

⚠ **副词与体标记的增删不影响骨架**（`正`、`还`、`这儿`、`着`、`没…完` 等属骨架之外）。理由：复读机的形态特征是**句法框架重复**，若把副词算进骨架，"同模板换副词"会逃逸。

**(B) 三种等级与单回合计数**

| 等级 | 定义 | 该回合计 |
|---|---|---|
| **R1 逐字复现** | 抹去专名与具体物后，两处**字面完全一致**（仅标点/句末语气词差异不计） | **1** |
| **R2 换皮复现** | 骨架相同，但具体物/数量/宾语被替换或扩展，**分句数与谓词类型不变** | **1** |
| **非复现** | 骨架不同；或骨架相同但**分句数改变／谓词类型改变** | **0** |

若原文**含具体物层面就已逐字相同**，按 R1 计 1（不因更严重而计 2）。

构造例（同一骨架族）：`我正钉着木箱呢`（R1 首次）／`我正钉着木箱呢`（R1 逐字）／`我这儿还搁着半筐木钉没钉完呢`（R2 换皮：动词与宾语槽未变，副词与体标记增删属骨架之外）。

**(C) 计数单位与阈值**

- 以**回合**为单位；同一**骨架族**的回合收集成族，**n = 族内回合数（含首现那一回合）**。
- **n ≥ 3 ⇒ 进入 (D)；否则 Q7 = 0。**

**(D) 豁免（仅一条，必须窄）**

- **新锚点豁免**：若族内**某个复现回合首次引入**了线程中此前未出现的**锚点**（新对象/新第三方/新待办），**或**产生了**新分工**（"你做 X 我做 Y"的明确指派），该族**不计 Q7**。
- **★ 只认"由族内复现回合首次引入"的锚点**；**回指族外已出现过的对象不算豁免**（否则前文提过任意新物，复读即可逃逸）。
- **地点不算锚点**，不触发豁免。

**(E) 同一人 / 不同人**

- **不区分，等权计数**（跨人复现同样计 1）。理由：Q7 判的是**文本形态**，不是某人的口癖；跨人逐字复现反而更难由口癖解释。
- **但必须记录**"同人/跨人"于证据栏（属证据列，**不进计数**）。

**(F) 落档点**：**Q7 ≥ 1 ⇒ C（无条件）**。

## 4. 已知局限（不读会误用）

1. **阈值全部待校准**：`Q3≥2`、`Q4≥2 且 P=0`、`Q5≥1 且 R≤3`、`P≥2`、`Q7` 的 `n≥3` —— 均无数据支撑，是设计选择。
2. **Q6 是单例规则**：`Q6 ≥ 1 ⇒ C` 只有 **1 个干净（非截断）样本**支撑。样本不足 ≠ 规则错误：**照规则判**，但引用结论时须说明其效力等级。**截断线程的未接上不得判为缺陷**（见 §1.7）。
3. **Q7 只在 1 条样本上被演示过** ⇒ "3 回合"这个门槛可能偏松或偏严。
4. **Q7 仍有裁量**：同义动词判定（`钉` vs `钉完`）、长句的分句切分，仍需人读。
5. **Q3 闭集无论多长都会有漏项**：本版只补了已知漏项，不保证穷尽；遇到漏项请记 `闭集未收录`。
6. **A 档可能偏紧**（具体性只是必要条件）⇒ 执行时**不许因为"A 太少了"而自行放宽规则**。
