# 架构立项备忘：**时序才是"不像生活"的最后一层**（A 对端计划期锁定 / B 轮内零往返）

> 日期：2026-10-24。状态：**立项备忘，不是预登记**，不含可跑臂；两份预登记待本备忘评审后再写。
> 依据：`d23_mock_verdict.md`（A）、`d26_perception_lag.md`（B）、`d24_flow_limits.md` + `d25_quota_bottleneck.md`（配额，已可测）。

## 0. 为什么要把两件事放在一起看

D2.2/D2.3 的失败、D2.6 的发现，表面是三个问题，根子是**同一层**：**时序**。
再调权重、再调措辞都不会动到它。

| 缺陷 | 量化事实 | 后果 |
|---|---|---|
| **A 对端在计划期一次抽定** | 一周 84 轮，基线 60 轮不足一周；PLAN 只在 `round=0` 一次且当时无历史 ⇒ `w≡1` | 任何"周内累积"机制（近因/共现/关系强度）**在 ≤84 轮不可测** |
| **B 轮内闭环 + 轮末提交** | 341 个相邻消息对里 **gap=0 占 0.0%**；gap=1 62.8%、gap≥2 37.2%；每轮消息中位 9 | **同轮零往返**，对话像留言而非当面说话 |

## 1. A：`participants` 从计划期推迟到**发起时刻**

**改动**：`plan_slot` 只定 `tid`/`place`；`participants` 在 `_initiate` 时按**当时**历史抽。
**收益**：地点亲和（D2.3 已实现、`c2512ce` 分支现成）、近因（D2.2）、关系强度**全部变得可测**，且 60 轮即可测。
**代价**：
- `thread_id` 生成时机改变（`DT.thread_id_dm(agent, to, round)` 现在要带真实 `to`）⇒ 线程命名/回放口径要重新对齐；
- 计划期"可复现"变成"发起期可复现"——仍确定性（同样的历史 + 同样的 seed ⇒ 同样结果），但**对历史基线的可比性为零**；
- 必须**新跑 C 臂**，不能拿 T0 日志对照。

**最小可测规模**：60 轮即可（不再需要 144 轮）⇒ 两臂 ≈1.8h。**这比"扩大规模到 144 轮"便宜得多，是更优解。**

## 2. B：轮内**两阶段**（phase A 全员决策 → phase B 待回者再决策一次）

**改动面最小方案**（推荐，先评审再动手）：
- **不改** `visible_events` 的 `upto_round` 口径（保持 `state.round` 语义不变）；
- 只改**调度次序**：一个 round 内跑两遍决策——第一遍全员照旧；第二遍只让"有可回入站且未达上限"的 agent 再决策一次；
- 复用现成的 `max_turns_per_round=2` 作为**轮内上限**，防"同轮无限互回"。

**收益**：同轮往返成为可能（上限估算：62.8% 的回复延迟可压到 0，即 214/341 个相邻对）。
**代价与风险**：
- `mono_ts` 顺序、`prev_hash` 链、`events` 计数都会变 ⇒ **与全部历史基线不可比**，须新跑 C 臂（60 轮，≈52min）；
- 轮内两遍 ⇒ **calls 上升**（估计 +20~40%），需代价闸；
- 「同轮可见」会放大**回声效应**（A 说 B 立刻接，可能产生短促互怼/复读）⇒ 判据必须带 Q1 复述 / Q2 重复闸；
- `_round_replies`（单回合回复计数）语义需重新定义（否则 K 上限失效）。

**最小可测规模**：60 轮（不需要扩大）。两臂 ≈1.8h（单变量 A/B 两档）。

## 3. 优先级：**B 先于 A**

| 维度 | A（对端推迟） | B（轮内两阶段） |
|---|---|---|
| 贴北极星 | 中（"认识谁"） | **高**（"当面说话"的节奏） |
| 可测成本 | 两臂 1.8h | 两臂 1.8h |
| 对历史基线 | 破坏（须重跑 C） | 破坏（须重跑 C） |
| 复现风险 | 中（线程命名） | **中高**（事件链、计数、K 上限） |
| 已备实现 | 有（`c2512ce`，需改取点） | 无（需新写调度） |

**建议顺序**：先 B（更贴题、且能把"隔轮"这个最刺眼的机械感消掉），A 随后（正好给 B 的基线复用）。
