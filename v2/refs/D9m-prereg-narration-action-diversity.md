## 2. 量定义（**原样嵌入，不写文字描述**）

```python
import json, re
PAIR = re.compile(r"[（(][^（）()]*[）)]")   # 全角/半角都算，要求成对、不嵌套

def narration_rate(run_jsonl: str) -> tuple[int, int, float]:
    """旁白率 = 含≥1个成对括号块的 MSG 条数 / MSG 总数（分母不筛）。"""
    hit = tot = 0
    with open(run_jsonl, encoding="utf-8") as fh:
        for line in fh:
            if '"MSG' not in line: continue
            r = json.loads(line)
            if not str(r.get("type","")).startswith("MSG"): continue
            body = (r.get("payload") or {}).get("body") or ""
            tot += 1
            if PAIR.search(body): hit += 1
    return hit, tot, (hit/tot if tot else 0.0)

def narration_counts(run_jsonl: str) -> tuple[int, int]:
    """接线门槛用：含旁白的 MSG 条数 / 旁白片段总数（绝对量，非比率）。"""
    msg = frag = 0
    for line in open(run_jsonl, encoding="utf-8"):
        if '"MSG' not in line: continue
        r = json.loads(line)
        if not str(r.get("type","")).startswith("MSG"): continue
        hits = PAIR.findall((r.get("payload") or {}).get("body") or "")
        frag += len(hits); msg += 1 if hits else 0
    return msg, frag
```

**强度均值**：`旁白片段总数 / 线程数`（均值，不是比率；小样本更稳，**不随 body 长度虚高**）。

## 4. 五条边界（与代码同嵌，不可省）

1. **仅 ON 臂**适用旁白率下界（OFF 按定义 0%，不适用）；
2. **分母不筛**（排除 0 旁白的 MSG 会把下界推到 100%，属 R-6 稀释路径，禁止）；
3. **与"片段数"口径不同源**：`205/191`（片段/MSG）、`197/205`（去重率）**都不可与 86.01% 比**；
4. **不处理嵌套**；全角半角同等；改嵌套感知须重算所有历史锚；
5. **跨批比较前必须用本段代码自跑一次**，不引他人报的百分比。
