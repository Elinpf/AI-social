# 恒真清单：「这个数在什么情况下必然是这样？」

> 立件：Leader（team-leader）｜2026-10-29
> 用途：**任何新指标 / 新判据 / 新验收在写进预登记之前，先过一遍这张表。**
> 由来：2026-10-29 一天之内，团队（含 Leader 本人）**连续犯了 7 次同一族错误**——把"结构性必真"当成"观测到的证据"。逐条记录，因为**每一条都曾差点变成结论**。

## 0. 一句话

> **在问"这个数是多少"之前，先问"它在什么情况下必然是这个数"。若答案是"always"，那它就不是证据。**

## 1. 七例（按发生顺序）

| # | 现象 | 恒真机制 | 正确表述 | 当时差点写成的错话 |
|---|---|---|---|---|
| 1 | `lag ≤ window` 覆盖率 = **100%** | `lag` 上界 2 ⇒ 任何 `window ≥ 2` 都给 100% | 「`window=2` 已覆盖全部**观测** lag，本批对该变量**无区分力**」 | 「窗口 4 覆盖更完整」 |
| 2 | `M-1-a` 的 `OFF 臂 = 0` | OFF 时 `_meal_place()` 不被调用 ⇒ 事件**不可能**产生 | 「机制触发：ON 臂 = n（对照离线预算）」 | 「ON/OFF 双通道验证通过，OFF=0 证明对照有效」 |
| 3 | 「同回合只能一个发言者」43/43 | `MSG_DM/GROUP` 无 `author` 字段 ⇒ `len({None})==1` **恒真** | 「同回合**多人发言可能**（用 `from` 重算 43/43 均 ≥2 人）」 | 「结构不变量：同回合单发言者」 |
| 4 | `lag = 0` 在四臂都是 0 | 冻结为"结构宿命"的解释 | 「同回合消息对当事人**不可见**（`turn_index` 全同值 43/43、27/27）」 | 「`lag` 上界由结构决定，参数无用」 |

## 2. 自检三问（写进每份预登记的必填栏）

1. **这个量在 H0（变量无效）下取什么值？**（`hit-metric-h0-baseline-rule.md` 已立）
2. **这个字段在每种事件类型里都有值吗？没有的话我的判定退化成什么？**（防 #1 #3）
3. **这个结论是"观测"还是"对我所理解机制的复述"？** 若机制本身没被独立验证 ⇒ 只能是假设（防 #2 #4 #5）

## 3. 三条通用退化形态（比单例更有用）

| 形态 | 特征 | 例子 |
|---|---|---|
| **恒真比例** | 分子恒等于分母，或恒为端值 | #1 #6 |
| **构造性为零** | 该分支代码路径不可能产生事件 | #2 #5 |
| **空值/缺字段致判定退化** | `len({None})==1`、`all(x is None)`、`set()` 为空 | #3 |
| **状态越证** | 用"当前状态 + 零痕迹"推"当时状态" | #5 #7 |
| **瞬时帧当稳态** | 单次快照推持续状态 | #7 |

## 4.5 第 8 类：**比率类指标的分母/暴露面效应**（2026-10-30 新增，当日第三次同族）

> **R-1｜凡"重复率 / 命中率 / 覆盖率"类指标，必须同时报"暴露面"**：body 平均长度、n-gram/token 总数、候选池大小。暴露面变化会使该指标**失去可比性**。
>
> **R-2｜跨臂比较前必须"同口径重算"一次**。对"与任一其他条目共享 n-gram"这类**双向碰撞**指标，**对方变长也会抬高己方命中率** ⇒ 单边协变量校正**不够**，须统一载体口径重算（本例：全体剥旁白），或按长度分桶比较同桶命中率。

**当日实例（`D9i`）**：`L-7` 8-gram 重复率 OFF `0.125654` → ON `0.198953`（+7.33pp），**初判为"有代价"**。
**剥掉旁白后重算：ON `0.052356` < OFF `0.125654`** ⇒ 恶化 100% 是暴露面效应（body 42.26→59.79 字符、8-gram 5,906→8,588），**台词层反而更好**。裁定由 **P 档更正为 N 档**。

**同族三次**：
| 次数 | 现象 | 混淆源 |
|---|---|---|
| 1 | `lag ≤ window` 覆盖率恒 100% | `window ≥ 2` 时分子恒等分母 |
| 2 | `P ≤ R − 1` 的 `P` 分母 99→100 | "未定值→定值"同时移动分母 |
| 3 | `L-7` +7.33pp 当质量下降 | **body 变长 ⇒ 碰撞概率升高**（本次） |

**自检句（新增）**：**"这个比率的分子分母，会不会因为实验本身而变？"**

## 5. 使用方式

- **写预登记时**：§"必报量"表里每一行加一列「**恒真风险**」，取值 `无 / 恒真比例 / 构造为零 / 空值退化 / 越证 / 瞬时帧`；
- **写证据件时**：若某条结论的"恒真风险"不是 `无`，**必须与结论同屏写出该风险**，不得只在附注里提；
- **复核时**：`repro-verifier` 的复核件首项即检查此项，缺列视为不合格。

## 6. 一句总结

**今天这七次没有一次是"算错"，全部是"算对了但解读错了"。** 所以防线不在算术，在**"这个数有没有可能永远是这么大"**这一问。
