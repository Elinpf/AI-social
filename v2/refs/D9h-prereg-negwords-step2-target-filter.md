> 上游：`v2/evidence/d9g_judgement_F_severe.md`（`31ba154d…` / 89 行 / `12211eb`）—— 判定 **F-确认严重**（假阳性 33/33 = 100%）

## 0. 本件承诺什么、不承诺什么（**先划边界，防止"改进判定器"这种含糊承诺**）

| 项 | 承诺 | 依据 |
|---|---|---|
| **降假阳性** | ✅ **可验证**（33 条抽样 + 锚样本） | 有语料 |
| **提灵敏度**（能识别更多真冲突） | ❌ **CANNOT-VERIFY** | 两臂 **11/18 词零命中**、33/33 抽样全否 ⇒ **无真负向话可用** |

> **只测假阳性率，一定可以做到 0%——把词表删空就行。** 所以本件必须同时报灵敏度状态，且**在没有锚样本时，只能写「消除了假阳性，但灵敏度未知」，不得写「判定器改善」。**

## 1. 第一条改动：**加"指向性"前置筛（先于词表）**

**现有缺陷**：`NEG_WORDS` 只判断"正文里有没有这个字"，**完全不建模"对谁说"**。`pl` 的判断我采纳：

> 问题不在词，在"指向性"根本没被建模。只调词表，下一批仍会得到"全否"。

**新增前置筛 `has_target(body, from, participants)`**：

| 情形 | 判定 |
|---|---|
| 第二人称指向（`你`/`您`）且上下文有具体对象 | **通过**（进入词表判断） |
| 第三人称指名（人名/称谓，如 `老周`/`王婶`/`陈医`） | **通过** |
| **群体指称**（`他们`/`镇上人`/`你们这些人`/`大伙儿`/`评委`/`关系户`） | **直接否**（不进词表） |
| **无对象自述**（`我累了一天`、`这日子真苦`） | **直接否** |
| **转述/引述**（见 §2.3） | **直接否** |

⇒ 只有通过前置筛的句子才进入词表判断。**这一层单独报计数**（进入筛的条数 / 被筛掉的原因分布），否则无法知道筛子干了什么。

## 2. 词表改法：**按形态分层，不删词**

来自 `d9g` 的形态分解（33 条，两级都 100% 假阳性）：

| 形态 | 涉及 | 改法 | 可验证性 |
|---|---|---|---|
| **2.1 对他人关切/共情** | `累` 5/5、`心疼`、`我怕你顾不过来` | **删词或加排除式**（`别累着`/`替你们累`/`心疼`/`我怕你…） | 可验 |
| **2.2 生理/味觉** | `疼` 3（刺疼/一沾水就疼/腰疼）、`苦` 3（苦味/发苦） | **词组级排除**，不整词删（整词删会误伤"我疼得睡不着"这类） | 可验 |
| **2.3 转述他人冲突** | `吵` 3/6（`喊他爹跟人吵起来`/`吵到村委去了`/`两家媳妇…吵得凶`） | **引述标记正则**：`听说`/`喊他`/`说他`/`说…去了`/`跟人吵` + **主语既非说话人也非听话人** | 可验（**正则优先，不做代词消解**） |
| **2.4 顾虑/推测句式** | `怕` 5/6（`怕是`/`怕它散开`/`怕磕了`/`最怕的`） | **排除模式**；**不得整词删 `怕`**（会丢"我怕你不高兴了"这类真指责） | 可验 |
| **2.5 客套/事态** | `烦` 4/4（`不烦不烦`/`别嫌我烦`/`这雨下得人心烦`/`不惹麻烦`） | 排除式 | 可验 |

**实现约束（写死）**：
1. **能用正则稳定抓的线索优先**；需要**代词消解**的线索**不作为 v1 判据**（否则判定依赖未验证的消解器，制造新的不可判环节）；
2. **不改** `window_msgs` / `max_open` / `max_age_rounds` / `context_max_age_rounds` 任何阈值；
3. **不改** `dialogue_repair.py` 之外的文件；diff 只碰该模块的判定函数 + 新增前置筛；
4. **默认关**（`enabled=false`）时行为**逐字节不变**（与现状等价）。

## 3. 词表重估：**新增词必须带实证出处**

> 每个新增词必须附 **≥1 条原文出处**（`msg_uid` + 原文片段）；**无出处不得入表**。

理由（`pl` 原话）：新词在旧语料里**零命中 ⇒ 加进去不可验证**，等于把不可判的东西混进判定器。

**已知待考察方向**（不得直接入表，须先找出处）：`你别太过分` / `凭什么你说了算` / `你什么意思`（已在表但零命中）/ `说话不算数` / `翻脸`。

## 4. 验收：**双向 + 退化条款**

| 项 | 门槛 | 语料 |
|---|---|---|
| **A. 假阳性率** | **≤ 20%**（`d9g` 的 O 档门槛） | 33 条抽样（重判） |
| **B. 锚样本召回** | **≥ 50%**（`ANCHOR-POSITIVE`：人工从两臂挑 10–20 条"像真冲突"的，逐条标 `msg_uid` + 判定理由） | 人工筛出 |

**退化条款（先写死，不得事后放宽）**：

| 情形 | 判定 | 禁止写法 |
|---|---|---|
| A 达标 **且** 锚样本存在且 B 达标 | **P-双向改善** | — |
| A 达标 **但** 找不到任何锚样本 | **O-仅降假阳性（灵敏度未知 / CANNOT-VERIFY）** | 「判定器改善」「识别更准」 |
| A 未达标 | **F2-仍不达标** | 「有改善但…」 |
| 锚样本存在但 B < 50% | **S-灵敏度不足**（须报漏了什么） | 「已达可用」 |

**若找不到锚样本（我预期很可能），本步只能记 O 档**——这是诚实的上限，不是失败。
