> 旧结论（须并读，不得覆盖）：D9 在**旧结构**（回复被 `max_messages_per_slot` 卡死）下判该参数「惰性」。
> **本件只回答一个问题：回复预算被打开后，这个窗口是否第一次变成活的约束。**

## 0. 为什么现在做（三条理由必须同时成立才算值得跑）

1. **A2 已判无效**：`d2_trigA2_result.md` 记 A2 vs A1 = MSG −0.6%、发起 −0.8%、转化率 −0.29pp、p50 不动，**only 2 次发起被抑制**（266→264）⇒ 「对未回对端不发起」不是瓶颈。
2. **A2 的诊断第 3 条直接指向本参数**：`reply_window_rounds=2` 让跨 slot 的未回入站很快过期，到下一个 slot 想接也接不上。
3. **旧 D9 结论的前提已改变**：当时回复被 slot 配额吃掉，窗口放宽也没人有力气接话；A1 打开回复预算后，「想接却被窗口卡掉」才第一次成为可能。

## 2. mock 的性质：**确定性，因此差异即机制效应**

同参数同 seed 的 MockProvider 是确定性的 ⇒ 两臂任何差异**不来自采样噪声**，不设显著性与 MDE。
**但这条优势同时是硬局限**：mock 下没有语言生成，本批**只能看结构量**（条数/轮数/滞后分布），**不得**据此对该参数是否改善「生活气息」下任何结论；语言侧必须另由真 LLM 批回答。

## 3. 必报量（缺任一即视为本件不合格）

### 3.1 结构量（沿用 D2.1 四列，口径不变）
- MSG 总数、发起条数、回复条数、线程数
- 轮数分布：p50 / p90 / max / mean
- **≥3 轮占比** 与 **≥3 轮绝对条数**（两列必须同时报：占比可被分母稀释）

### 3.2 分母（**没有分母的转化率不得引用**）
- `有未回入站的 agent-slot` 数
- 转化率 = 该分母中最终发出回复的 slot 占比
- **新起线程数**（防"用少说话换比值"）

### 3.3 机制命中量（本件的核心证据，事后从日志算，不插桩）
**`reply_lag` 分布** = 每条「回复」的 `回复所在 round − 父消息 round`。
- ctrl（window=2）**理论上不应出现 lag ≥ 3**；若出现即为口径异常，须先排查再判。
- treat（window=4）**出现 lag=3、4 的回复**⇒ 窗口确实曾是约束（机制触达）。
- treat 臂 lag 分布与 ctrl **完全无差异** ⇒ 窗口从未卡掉任何接话（该参数在当前结构下仍惰性）。

## 4. 判定五档（**按特异性排序，命中即停**，不得并列调和）

| 序 | 档位 | 成立条件（全部成立） |
|---|---|---|
| 1 | **V-有效** | `(p50 ≥ 2 或 ≥3轮占比相对 ctrl ≥ +5.00pp)` **且** `≥3轮绝对条数 > ctrl` **且** `MSG ≤ ctrl × 1.10` |
| 2 | **W-用少说话换比值** | `新起线程数 ≤ ctrl × 0.85` **且** `≥3轮绝对条数 ≤ ctrl` |
| 3 | **I+-无效但成本上升** | `p50 不动` **且** `≥3轮绝对条数 ≤ ctrl` **且** `MSG ≥ ctrl × 1.10` |
| 4 | **T-不可判（机制未触达）** | `分母（有未回入站 agent-slot）相对 ctrl 变动 < 5%` **且** `treat 臂 lag≥3 的回复数 = 0` ⇒ 窗口放宽没有改变任何候选池 |
| 5 | **I-无效（结构量不变）** | 以上均不命中，且所有结构量相对 ctrl 变动 ≤ 2% |

- 命中 4 ⇒ **只许写「不可判（机制未触达）」**，**禁止写「无效」**（这是 D5-09 的同类错误：把"参数没被用到"说成"参数没用"）。
- 命中 5 ⇒ 可写「无效（结构量不变）」，但必须附 lag 分布，证明"不是没触发"与"触发了但没效果"的区别：**lag 有变化而结构量不变 = 触发但无收益；lag 无变化 = 未触发**，两者分开表述。
- **任一非零的 lag≥3 计数都必须单独报绝对值**（不接受只报百分比）。

## 5. 三条反事实（每条都要给数值，不得只写方向）

1. 若 treat 臂里 `lag≥3` 回复数 = 0 ⇒ 本参数是**惰性参数**，与 A2 同类，从此不再单独复测。
2. 若 treat 臂 MSG 显著上升而 ≥3 轮绝对条数不升 ⇒ 只是**话变多**，不是**对话变长**，不得报为改进。
3. 若 ctrl 臂出现 `lag ≥ 3` ⇒ **先停判**，说明 `reply_window_rounds` 不是唯一约束（另有路径绕过窗口），本预登记的"单变量"前提作废。
