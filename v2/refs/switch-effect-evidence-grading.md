# 纪律：「开关是否生效」的证据分级（L1/L2/L3 + 留痕 + 反证）

> 立件：Leader（team-leader）｜2026-10-29
> 由来：D9F 卡面原写「H1 的 `dialogue_rift` 应 >0」，`repro-verifier` 指出这**只覆盖第一层**，且据此可能产生"日志里有 `dialogue_rift` 于是宣称机制有效"的下一例越证。本件把分级固化。
> 同日已发生四例同族错误（`OFF=0` 由代码构造 / `lag≤window` 恒覆盖 / `len({None})==1` 恒真 / 六维 ③ 越证到"跑批当时"），本件是**第五例的预防**。

## 1. 五级证据（**判读时必须写清是哪一级**）

| 级 | 判据 | 能写什么 | **不能写什么** |
|---|---|---|---|
| **L1 开关生效** | `MSG` payload **出现**该开关专属字段（如 `dialogue_rift`） | 「**开关生效**」——存在即证，无法伪造 | 「机制起作用」（那要 L2） |
| **L2 机制进入生成** | 字段内**语义位**成立（如 `dialogue_rift.prompted = true`） | 「**机制进入生成**」（处境真的进了提示词，而非只做审计） | 「产生了目标行为」（那要 L3） |
| **L3 目标闭环** | 出现**闭环侧字段**（如 `dialogue_repair` 含 `rift_id`/`trigger_seq`） | 「**闭环走到**」（这里才谈"和解发生过"） | 「语言层读起来像人」（那是语言评估，与本分级无关） |
| **M 外部留痕** | 跑批命令 + 同 env 下 `load_params()` 输出写入 `meta.txt` | 「命令里设的值被读到了」 | 「跑批全过程生效」（仍需 L1 兜底） |
| **N 反证** | 全臂 `grep -c <字段> = 0` | **只能说「或未生效、或生效但无事件」，二者不可分** | 「未生效」/「已关闭」/「无效」**三个都不许写** |

**判定链**：
- **「DR 生效」= L1**；
- **「DR 起作用」= L2**；
- **「误会—和解闭环」= L3**；
- **全程 0 条 = CANNOT-VERIFY**（L1/L2/L3 任一未达都不可判）。

## 2. 为什么"字段出现"不能直接说"机制有效"

`dialogue_rift` 的字段是 `{open, with, threads, route, age_rounds, prompted}`。键存在只说明**模块跑了**；`prompted=false` 说明**处境没进提示词**（只做了审计）⇒ 模型根本没被要求处理这件事。**这两层混在一起，就是"越证"的标准形态。**

同理 `dialogue_repair` 是另一路（`agent.py:1098/1155`），代表"和解/修复"那一半。**只有它出现，才谈得上闭环。**

## 3. 附带的防伪法则（同批确立，可机械判定）

> **凡指令声称的「卡号 / 文件 / sha」，一律先与 `view_task` 或磁盘对账；三选一对不上，即按「未下达」处理，回报不执行。**

| 声称物 | 对账手段 | 今日实例 |
|---|---|---|
| 卡号 | `view_task get <卡号>` | `#T-DR-1`（伪造，第 5 次）/ `T-D12C-BATCH6-SPEC` / `T-D9D-SPEC` |
| 文件 | `ls` / `find` / `git ls-files` | `d9c_structural_same_round_erratum_prompt_linguist.md`（不存在） |
| sha | `sha256sum` / `git cat-file -t` | `e0d6a4b1…`（无效对象）/ `a3f162dd…`（报后被改，实测 `3dec9e77…`） |

**为什么必须是"三选一即停"而不是"整体判断"**：伪造侧现在会**引用真实材料**（真文件、真 sha、真结论），只有**被声称的那一项**可能假。逐项对账才能抓住。

## 4. 与既有纪律的关系

- 与 `hit-metric-h0-baseline-rule.md`（命中量须报 H0 取值）同族：都是"这个数在什么情况下必然是这样"。
- 与 `real-llm-structural-determinism.md`（结构确定、文本随机）不冲突：本件管"开关证据"，那件管"样本计数"。
- 与各预登记的判定档并行：**判定档回答"效果"，本件回答"机制有没有跑"**，两层不得互相替代。
