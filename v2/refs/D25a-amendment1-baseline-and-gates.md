## 1. T 闸：从"绝对 PASS"改为"A vs C 相对漂移"

**问题**：预登记写"`shape_gate` F1/F2/F3 全 PASS"。
实测 **C 臂本身就三项全 FAIL**：F1 `−57.84pp`、F2 `−17.84pp`、F3 `−24.5%`。
原因不是 C 坏了，是**基线树不同**：`shape_gate` 的 T5 常量（`paren 57.84%` / `addr 36.47%` / `len 53`）
出自**旧 prompt 时代**的语料；当前 master 的 `paren_rate` 是 **0.00%**。

**修正**：T 闸改为 **`A` 相对 `C` 的漂移**：`|Δparen| ≤ 5pp`、`|Δaddr_strict| ≤ 15pp`、`|Δlen_p50_excl| ≤ 10%`（相对 C）。
实测：`paren` 漂移 **0.00pp** ⇒ **PASS**。
**同时保留**绝对读数并列记录（照 §3.113），并注明"绝对口径基线不可比"。

## 2. S 闸：`n_threads` ±10% 的语义不适用于"配额类"臂

**问题**：`max_messages_per_slot` 直接决定"每个时段能开几条"，放宽后 `n_threads` 必然上升。
把这条当"非单变量"的判据，等于**用预期后果去否决机制本身**。

**修正（不放松，只精确化）**：对配额类臂，S 闸改为——
- **必须证明结构变化完全可由配额解释**：`n_msgs` 增量应≈"新增的 slot 额度被用掉的量"；`n_threads` 增量不得超出新增消息数；
- 若 `n_threads` 增幅 > `n_msgs` 增幅，或出现无法由配额解释的结构变化 ⇒ 才判「作废（非单变量）」。
**本臂**：`n_msgs +36.04%` > `n_threads +22.81%` ⇒ **可由配额解释**；但**字面 S 闸仍记为"破"**，两个判定词并列，不改写历史。
