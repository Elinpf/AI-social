## C-2 冻结件：`tools/d9m/narration_family_lexicon.json`（已落盘，本件的规范来源）

| 项 | 内容（**有序，顺序即优先级**） | 出处 |
|---|---|---|
| `verbs_closed_8` | 蹭 / 搓 / 抹 / 擦 / 拂 / 拍 / 抿 / 揉 | D9j §3（原表，不改） |
| `verbs_rotation_13` | 别 / 挽 / 拢 / 让 / 靠 / 挪 / 望 / 扇 / 撤 / 抬 / 低 / 伸 / 侧 | 由 D9m 旋转词表 9 句提取（首次冻结） |
| `parts_6` | **手背 / 指腹 / 指头 / 手指 / 手 / 肩** | D9j 只给「6」；**内容为 D9m 首次冻结** |
| `objs_13` | **围裙 / 锉刀 / 木屑 / 木花 / 袖口 / 袖子 / 衣襟 / 竹篮 / 碗 / 壶 / 锅 / 凳 / 门槛** | D9j 只给「13」；**内容为 D9m 首次冻结** |

**选词原则（人为，须声明）**：`parts_6` 取「更具体者前置」的身体部位谱（手背 > 指腹 > 指头 > 手指 > 手 > 肩）；`objs_13` = 基线 top 器物 ∪ 旋转词表出现的器物（`袖口/衣襟/竹篮/凳/门槛` 来自 9 句词表，`围裙/锉刀/木屑/木花/碗/壶/锅` 来自基线）。
**明确登记**：这两份内容**不是 D9j 原文**（D9j 只给数量），是 D9m 首次冻结；报告不得表述为「按 D9j 的部位/器物表」。

**归族算法（7 条，唯一实现须逐条对应）**：
1. 单位：一片段恰好归一族。
2. 动词：`V_judge = verbs_closed_8 ∪ verbs_rotation_13`，**按并集顺序**取首个命中 → `v`；全不命中 ⇒ `unassigned`。
3. 附属：先按 `parts_6` 顺序取首个命中 → `p`；无则按 `objs_13` 顺序取首个 → `o`；皆无 ⇒ `null`。
4. 族键：`f"{v}|{p if p else o if o else 'null'}"`。
5. **部位优先于器物**（同片段含「手」与「围裙」⇒ 取 `蹭|手`）。
6. 不做同义归并（8 个闭表动词各自成族）。
7. **介词不入表**（`把/往` 不算动词；基线「把」128 次，入表即尺子失效）。

**基线参考值（本词表口径，已实测；实现件必须逐一复现）**：`blocks_total=205`、`msgs_total=191`、`coverage = 40/205 = 19.512%`、动词计数 `蹭31/搓5/抹3/擦0/拂0/拍0/抿0/揉1`、spot check `蹭|手 8 (P004 5)`、`蹭|锉刀 9 (P014 3/P013 3/P011 2/P002 1, n_ge2=3)`、`蹭|指腹 4`、`蹭|手背 2`、`蹭|指头 1`。

**复算入口（脚本待实现，属 run-1 前置）**：
