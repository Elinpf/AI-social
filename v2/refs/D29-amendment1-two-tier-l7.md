# D2.9 预登记 · 修正案 1：`L-7` 判据分**两层**（机制层 + 效果层），只加严不放宽

> 日期：2026-10-25，**在 D2.9 任何代码改动与跑批之前**。修正对象：`v2/refs/D29-prereg-syntax-diversity.md`（`009e953`，写得比我预想的细，**采纳**）。
> **本件只增加一条判据，不改任何已有阈值。**

## 1. 问题：现有 Q2 只测"方向"，不测"够不够"

预登记 Q2 写：「`L-7` 相对 **D2.8 的 B 臂** 下降 **≥5.0pp**，两 seed 同向」。
但：D2.8 的 B 臂是 **32.75% / 32.55%**，C 是 **25.49% / 23.14%**。
⇒ 降 5pp 后约 **27.75% / 27.55%**，**仍高于 C 2.3–4.6pp**。

这意味着：Q2 达标只能证明"**骨架是真因**"（机制层），**不能**说明"旁白不再伤重复"（效果层）。
若只判 Q2，一个"恢复了 5pp 但仍比无旁白基线差"的结果会被写成"有效"。

## 2. 修正：拆成两层，两层含义不同，**并列报告**

| 层 | 指标 | 达标线 | 含义 |
|---|---|---|---|
| **L1 机制层** | `L-7` 相对 D2.8 的 B 臂 | **降 ≥5.0pp**，两 seed 同向 | 证明**骨架多样化确实起作用**（否则判「无效（骨架不是真因）」） |
| **L2 效果层（新增）** | `L-7` 相对 **同 seed 的 C** | **≤ +0.0pp**（即**不高于** C：≤25.49% / ≤23.14%） | 证明**旁白不再伤重复**；未达则判「不足以下结论（重复仍高于无旁白基线）」 |

**判定合成**：
- L1 过 + L2 过 + 其余全过 ⇒ **「有效」**；
- L1 过、L2 未达 ⇒ **「不足以下结论（重复仍高于基线）」**——机制成立但未完全抵消代价，**不得写成"有效"**，也不得写成"无效"；
- L1 未达 ⇒ **「无效（骨架不是真因）」**（这是最有信息量的失败，说明要另找重复来源）。

## 3. 随之需要写进预登记的两条（不改阈值，只明确口径）

1. **`L-2`（效果层）与 `L-1`（机制层）禁止互相替代**（§3.113）：报告必须两行并列，各自带"相对谁"的后缀
   （`dL7_vs_D2.8B` / `dL7_vs_C`）。
2. 若 L1 过而 L2 未达，**不得**回头调 `para_on` 比例或台词长度去凑 L2——那会动 D2.8 已成立的两个收益（`len_p50_excl`、`P1_count_mean`），
   重犯 D2.7 的"替换而非并存"。
