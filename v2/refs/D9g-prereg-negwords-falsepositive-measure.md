## 0. 为什么不能直接改码

现在的"假阳性"判断只有 **抽样 6 条全假** 这一个证据。**拿它当依据去改判定，就是重演"D12-C 判据未定型就上马"**。所以先做一件更便宜的事：**把假阳性率量出来**（人工判读，零改码、零跑批）。

## 1. 两个必须写死的定义（否则判读无法收敛）

### 1.1 "负向话"的二值操作定义（**不做三档**）

> **一条 MSG 的正文，是否在表达「对某个具体人的不满 / 抱怨 / 指责 / 失望」？** 是 / 否。

明确排除（都算"否"）：
- 生理疼痛（"手背刺疼"）、味觉（"苦味"）、恐惧的口语用法（"怕是""最怕"）、客套（"别嫌我烦"）；
- 自述状态但**不指向任何人**（"我累了一天"——无对象，不算"对谁不满"）；
- 旁白（`（）` 内）**不参与判定**，只看台词。

### 1.2 "对端"口径（**不得按地点推断**）

> **对端 = `participants − {from}`**（DM 与 GROUP 通用）；`PUBLIC` 的 `participants` 只有发言人自己 ⇒ 天然无对端，不参与。

**严禁**按 `msg.place` 推对端 —— 这是 **R1 边界 12 的已知坑**：`msg.place` 是"发言人此刻所在地"（人可以在家/公园插话），实测与 group 地点相符仅 **13/126 = 10.3%**；若需地点必须用 `group_id`（`place:<place>`）。**本预登记口径直接绕开地点，不用任何推断。**

## 2. 步骤 1（本件批准）：人工判读 30 条，量出假阳性率

### 2.1 抽样口径（写死，不得临场改）

- **分层抽样**：按命中**词**分层，词频 ≥6 的（`怕` 38 / `烦` 7 / `疼` 7 / `苦` 5）各抽 **6 条**；其余词（`吵` 3 / `累` 3 / `委屈` 1）**全抽**；
- **跨臂**：A1 与 F6off **各抽一半**（同词在每臂各抽 3 条，不足则全取）；
- 目标样本量 **≈30 条**，实际条数以脚本输出为准并写进件；
- **随机性**：按 `msg_uid` 升序取前 k 条（确定性，可复算），**不得人工挑选**。

### 2.2 两人独立判读 + 一致性门槛

- 判读者：`prompt-linguist` 与 `repro-verifier`，**各自先判、后对账**（不得先看对方结果）；
- 每人每条只给 **是 / 否** + **一句理由**（必须引原文片段）；
- **一致性门槛**：两条二值序列的**一致率 ≥ 0.80** 才可合并；不足则**不合并**，须逐条由第三人（Leader）裁，并记录分歧性质；
- **禁止**报 κ 点估计（本批 n 太小，且今天已因"n=12 报 κ"栽过两次）。

### 2.3 产出

| 量 | 说明 |
|---|---|
| **现判定假阳性率** = （人工判"否"的条数）/（抽样总条数） | **带分子/分母** |
| 按词分列假阳性率 | 识别哪些词最糟（预期 `怕`/`疼`/`苦` 最差） |
| 两人一致率与分歧条目 | 一致率 <0.80 时须列出全部分歧 |

## 3. 步骤 1 的判定（**先写死，跑完不改**）

| 序 | 档 | 条件 | 后果 |
|---|---|---|---|
| 1 | **F-确认严重** | 假阳性率 **≥ 50%** | 现判定不可用，**必须改**（进入步骤 2） |
| 2 | **P-部分可用** | 20% ≤ 假阳性率 < 50% | 改判定可带来实质改善，**建议改** |

## 4. 局限（必须随结论引用）

1. **"负向话"仍是主观判断**，二值化只是收窄，不是消除；一致率 <0.80 时结论强度自动降级。
2. 抽样 ≈30 条，**不足以给出窄置信区间**；本批只回答"是 ≥50% 还是 <20%"这个量级问题，**不报精确率**。
3. 只在 **2 条真 LLM 臂**上抽（`run_d9_a1` / `run_d1_f6off`），**不外推到其它配置**。
4. 本件**不改任何 code**，不动 `dialogue_repair.py`；步骤 2 须另批。
