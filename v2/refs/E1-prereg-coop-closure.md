## 1. 一句话假设（可被指标反驳）

> 在对话提示词里只加**一行**「别人托你办事时，说清你手上正替他做的那一下；应下的事下回先交代做到哪一步」，
> 居民台词里**替对方动手**的比例（`F-9m`）会上升。
> 读者读到的差别是：**从前是「好」「行」「没问题」这类空应一声，现在变成「我这就把门口那筐艾草给你挪进来，顺手把秤搁你柜边」这类带活儿的回话。**

**反驳方式（写死）**：
- `F-9m` 的 `Δ = 100×(ON − OFF)` **未达 §6 判定线** ⇒ 假设为假，判 `未达标` 或 `不可判（功效不足）`；
- `F-9m` 上升但 `F-9a`（请求提出率）掉 >3.0pp ⇒ 判 **`无效（空转）`**（没人真托事，居民自己加戏）；
- `F-9m` 上升但 `L-15 restate_strong` / `L-7` 击穿代价闸 ⇒ 判 **`无效（套话）`**。

**写作纪律（硬）**：本维度禁写 `更有生活气息` / `更自然` / `更像过日子` / `改善` / `提升` / `显著`。
只允许判定词：**`有效` / `无效（空转）` / `无效（套话）` / `未达标` / `不可判（功效不足）` / `机制未生效` / `批次无效`**。

> **「功效不足也是合法结论」（写进判定词表，防止被当成失败而事后回调阈值）**：本臂在 `n=686`、基线 `p≈5%` 下只能检出 `Δ ≳ +3.6pp`（§6.4）。真实效应若只有 +1.5~+3.6pp，本臂**注定**给出 `不可判（功效不足）`——这是**预期内的诚实结论**，与 `未达标`、`有效` 并列合法，**不构成失败**，也**不得**触发任何阈值/口径调整（唯一允许的动作是 §9 的 seed=7 复制支路，判据不变）。
