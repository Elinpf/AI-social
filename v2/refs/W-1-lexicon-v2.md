v1 的严格词表里 26 个词元中有 **5 个是单字弱词**：`晒 / 湿 / 云 / 风 / 霜`。
这 5 个词同时是**天气词**与**非天气复合词的构词成分**：

| 词 | 天气义（真阳性） | 非天气义（假阳性） | 本批实例 |
|---|---|---|---|
| 晒 | 日头晒、晒得人发懒 | 晒干/晒场/晒谷场/晒盐/晒网（工艺）、晒好的陈皮/晒的艾草（工序状态） | **14 条**（ON 9 / OFF 5） |
| 湿 | 湿气重、潮湿 | 湿布/湿泥（物件、泥土） | **5 条**（ON 3 / OFF 2） |
| 云 | 云彩、云压得低 | 云手（太极招式） | **2 条**（ON 2 / OFF 0） |
| 风 | 风大、风往领口里钻 | 风箱（器具）、防风（药材名）、风湿（病） | **6 条**（ON 3 / OFF 3） |
| 霜 | 霜（地面结霜） | 糖霜（食材） | **1 条**（ON 0 / OFF 1） |

v1 用 `word in body` 判，必然全收。**这不是"LLM 说话不自然"，是尺子会把工艺词当成天气词。**

**Newcombe95 实现**（两独立比例差值，Newcombe 1998 method 10，脚本 `newcombe95()`）：

```
d = p1 - p2
CI = ( d - sqrt((p1-l1)^2 + (u2-p2)^2),  d + sqrt((u1-p1)^2 + (p2-l2)^2) )
其中 (l1,u1),(l2,u2) = 各自的 Wilson95
```

## 5. 判定：W-1-a 在 v2 下重算

**规则（来自 `v2/refs/W-1-weather-prereg.md:83`，一个字未改）**：
`ON 臂 weather_mention_strict 的 Wilson95 下界 > 1.5 × H0 点估计`。

| H0 候选 | H0 取值 | ×1.5 阈值 | ON v2 Wilson 下界 6.46% | 判 |
|---|---:|---:|---:|---|
| **同参（v2）**：本批 OFF `10/191` | 5.24% | **7.85%** | 6.46% < 7.85% | **否** |
| 原卡（跨配置，v1）：`69/1188` | 5.81% | 8.72% | 6.46% < 8.72% | **否** |
| 同参（v1）：本批 OFF `20/191` | 10.47% | 15.71% | 6.46% < 15.71% | **否** |

**三个 H0 候选全部判「否」** ⇒ v2 下 W-1-a **不再随口径翻转**。
（对照：v1 下 ON 下界 13.48% 对 8.72% 判"是"、对 15.71% 判"否"，这正是"口径敏感"的来源。）

### 结论句（三选一 ⇒ **不达标**）

> **新口径（v2）下，W-1（天气/季节感知臂）的主判据 W-1-a 判「不达标」。**
> 依据：ON 臂天气提及率 19/191 = 9.95%（Wilson95 [6.46%, 15.01%]），其**下界 6.46%**
> 低于三个 H0 候选给出的阈值（7.85% / 8.72% / 15.71%），且 ON−OFF 的 Δ = +4.71 pp
> 的 Newcombe95 区间 **[−0.69, +10.30] pp 跨 0**——即在 n=191 下，这条提升与抽样噪声不可区分。

**必须同时说的三条（缺一条就是夸大）**：

1. **"不达标"不等于"机制无效"**：注入覆盖率 191/191 = 100%、两日天气派生确定性、提示词零泄漏，这些**机制事实成立**；
   不成立的是"居民把天说出口"的**幅值**。
2. **方向仍为正**：v2 下 ON 仍高于 OFF（9.95% vs 5.24%），只是**证不出显著**；
   不得写成"没有提升"，正确写法是"**提升不显著（CI 跨 0）**"。
3. **v1 的 18.32% 不得冒充结论**：那个数含 16 条可点名假阳性；同样，v2 的 9.95% 也不得与 v1 的阈值 8.72% 混用
   ——本件已把阈值一起重算（§5）。

## 6. 结论依赖的假设 + 仍不可消除的不确定性

**假设（若被推翻，结论要改）**

1. **分母**= `MSG_DM + MSG_PUBLIC` 且 `payload.body` 非空的条数（191/191 两臂对齐）；换成"LLM 调用数"或"事件数"会变。
2. **v2 即判定口径**。若 Leader/复核者不认 v2、坚持 v1，则本议题退回"不可判"（不得混用）。
3. **W-1-a 规则形态不变**（Wilson 下界 vs 1.5 × H0 点估计）。若改成"Δ 的 CI 下界 > 0"，本轮同样判否。
4. 假阳性判定的正确性依赖：28 条逐条复核（已给出）+ denylist 的完整性（见下）。

**不可消除的不确定性**

1. **单 seed、单批、无重复**：Wilson/Newcombe 只兜抽样误差，**兜不住批次间 LLM 采样噪声**；
   n=191 时，要检出 −10pp 级别的差需要更大规模（未做，且本轮禁止跑批）。
2. **denylist 的完备性无法先验证明**：本批 28 条排除**全部由 denylist 复合词触发**（白名单分支未参与筛除），
   意味着判别力集中在"把已知复合词拉黑"，**换一批日志完全可能冒出未收录的新复合词**（如"晒席""风袋""云片"）。
   本轮能做的最强证据就是逐条复核，它不能外推。
3. **"说出口才算感知"这个构造本身有争议**：不说话的居民可能"感知到了但没提"，本口径**测不到**。
   这是 W-1 的上游设计问题，不是本轮能修的。
4. **自然度未判**（W-1-e）：本件只谈提及率，不谈"像不像过日子的人说的"。
5. **行为层结构性不变**：本臂只改提示词，不发事件、不改计划、不改世界态 ⇒ 行为层不可能变，不得据此谈"影响行为"。
