# D9i 预登记：把「禁旁白」变成 env 可关 —— 恢复具体性/态度通道

> 立件：Leader（team-leader）｜2026-10-30 00:15
> 上游：`narration-ban-scope-inventory.md`（`f04b57db…`）—— **26/35 = 74.3% 的臂跑在禁旁白配置下**
> 依据：`a637371`「A1 措辞臂：压低括号旁白」（2026-10-21），裁定 **B：真实但有副作用**（`reports/R9-wording-a1.md`）
> 本件批准 **实现 + mock 验证**；真 LLM 臂是否跑，由**用户按预算决定**。

## 0. 为什么这是当前最高优先级

今天的因果链已经闭合：

```
参数线三方向全空（窗口 / 顺序 / 对端）
  → 转查判定器：假阳性 100%、召回 0/14
  → 追到上游：74.3% 的臂跑在「禁旁白」配置
  → 根因：具体性/态度通道（动作·神态·旁白）被系统性移除
```

而 R9 当时的裁定原文已写明代价：

> **被砍掉的是「人物正在做什么、眼前有什么」这条具体性通道**，腾出的篇幅被「送礼—推让—表态」的客套循环占据。台词 mean **58.3 → 27.5（−53%）**。

**六维评估里最弱的三个维度（③误会与和解、④习惯偏好、①日常节律偏科）恰恰全靠旁白承载**：`（皱眉）`、`（把围裙往腰后一掖）`、`（低头刨木，木屑卷起）`。

⇒ **本件的目标不是"加新机制"，而是"把一条被关掉的通道恢复成可开关"。**

## 1. 单变量与实现

| 项 | 值 |
|---|---|
| 受检变量 | **`LIFE_PROMPT_NARRATION`** ∈ {**`0`（禁旁白，= 现状）**, **`1`（允许旁白）**} |
| 基线代码 | 当前 `origin/master`（含 `a637371` 的两句禁旁白指令） |
| 改动点 | **仅 `code/life/agent.py` 的两句收尾指令**（`:1497` / `:1523`），按 env 二选一 |
| 两臂固定 | `seed=42 / agents=16 / rounds=84 / max_turns=6 / max_slots=2 / window=4 / provider=mock` |
| **等价性** | env 未设或 `=0` 时，**prompt 必须与现状逐字节相同**（单测断言字符串相等） |

**实现硬约束**：
1. **只改 prompt 字符串的选择逻辑**，不改任何其它行为（阈值 / 结构 / 事件类型全不动）；
2. **不得**顺手改"一句家常话"这类其它措辞（那是 R9 的另一半，本节不碰）；
3. 新 env 名须与既有 `LIFE_PROMPT_*` 命名一致（`MEMORY_F6_ENV = "LIFE_PROMPT_MEMORY_F6"` 是现成范式）；
4. **默认值必须是 `0`（禁旁白）**——不得悄悄改变现状。

## 3. 判定四档

| 序 | 档 | 条件 |
|---|---|---|
| 1 | **N-通道恢复** | 量 1 > 0 且 量 5 中"动作类"占多数（非纯情绪标签） |
| 2 | **P-恢复但代价超限** | 量 1 > 0，但 `MSG < 686×0.9` 或 `L-7` 恶化 > 基线+5pp |
| 3 | **T-未触达** | 量 1 = 0（env 没生效或指令未改成功）⇒ 查接线，**不得判"旁白无用"** |
| 4 | **U-不可判** | 量 1 > 0 但量 5 几乎全是情绪标签（"（笑）""（点头）"）⇒ **只是换了标签，没恢复具体性** |

## 4. 写死的三条禁令

1. **本件只证"通道恢复"，不证"生活气息改善"**——旁白回来是现代价，读起来是否更像人**须人工读样本**（mock 的旁白是模板生成的，不能作语言质量证据）；
2. **不得用本件推翻 R9**：R9 测的是"有→禁"（副作用：台词 −53%、具体性下降），本件测的是"禁→有"（**方向相反**），**两者结论不可互推**；
3. **`mock` 只能验接线与结构量**；语言层必须真 LLM 批（预算另议）。
