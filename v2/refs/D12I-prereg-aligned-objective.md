# D12-I 预登记 · **目标/判据/参照系三者同源**：run 内按"对外部语料的 `overlap_frac`"择优

> 立此存照：**2026-10-24 00:30，在任何 D12-I 代码改动与跑批之前**。判据、闸、反事实先写死。
> 依据：`v2/evidence/d12h_result.md`（判「无效（靠砍旁白换重复）」）、`v2/evidence/d12h_leader_terminal_check.md`、`v2/evidence/d12h_midpoint_reversal_finding.md`（自亲和偏差）、runbook §3.107–§3.112。

## 0. 为什么是这一步（三条已证事实）

1. **D12-H 证明「选优目标 ≠ 判据指标」是结构性缺陷**：run 内按 `recent16` 选，判据用全局 `overlap_frac` ⇒ **被选候并未针对判据优化**；
2. **D12-H 证明「参照系由落库组决定」会造成自亲和偏差**：同一批候选，自身历史 −4.97pp、外部语料 +4.26/+9.02pp，**符号反转**；
3. **D12-H 证明「一行提示词会在形态层做两件事」**：加"以称呼开头"⇒ **旁白从 57.84% 清零到 0.20%**，代价闸崩、单变量破产。

⇒ 本臂只做一件事：**让 run 内选优直接用"对外部固定语料的 `overlap_frac`"**，使**目标 = 判据 = 参照系**三者同源；并**强制形态闸**。

## 1. 设计（一个 run、60 轮不变）

**选优指标（run 内实时）** = 候选对**固定外部语料**的 8-gram 交集率：
```
score(c) = |shingles(c) ∩ S_ext| / |shingles(c)|
S_ext = T5（run_d12g_diverse2_n16r60_seed42）**前 40 轮**已落库消息的 shingle 并集（8-gram，normalize_body）
```
- `S_ext` 在起跑前**从 T5 日志一次性算出、落盘为 `v2/evidence/d12i_external_shingles.json`**（含 sha），run 内**只读**；
- **为什么取前 40 轮**：与本臂 60 轮的前 2/3 同量级，且**固定不变**（不随本 run 生长）⇒ 参照系**与本 run 落库选择无关**；
- 三候选**同 prompt**（即"ON/OFF 之分被取消"），各用 `sample_index` 0/1/2；**择优取 `score` 最小者**（平局取最小 index）；
- **落库 = 选中那条**（单一组，无 ON/OFF 之分）⇒ **不再有"落库组污染参照系"问题**（参照系是固定的外部语料）。

## 2. 形态闸（**1/3 处必核，这是 D12-H 的直接教训**）

| 闸 | 阈值 | 何时核 |
|---|---|---|
| **F1 `L-3` 含括号块率** | **相对 T5 漂移 ≤5pp**（T5 = 57.84% ⇒ 区间 [52.84%, 62.84%]） | **1/3（约 20 轮）+ 收尾** |
| **F2 称呼起头率** | 相对 T5（41%）漂移 ≤15pp | 1/3 + 收尾 |
| **F3 `len_p50`(excl)** | 相对 T5（53）漂移 ≤10% | 收尾 |

> **形态闸必须是"一条命令"**：`tools/d12h/shape_gate.py --run <run.jsonl> --rounds 20` ⇒ 直接出 `paren_rate` / 括号起头率 / 称呼起头率 / `len_p50` 四项 + 与 T5 的漂移。
> **⚠ mock 冒烟抓不到形态漂移**：mock 文本是模板、本来就没有旁白 ⇒ **§2 的所有闸必须对真跑日志核**（D12-H 的 22:07 mock 里 `paren` 类指标毫无意义）。

**F1 或 F2 在 1/3 处越界 ⇒ 立即停跑**，判「**作废（形态漂移，非单变量）**」，不进入效果判定。
（D12-H 正是因为没在 1/3 处核 F1，花 6,073 次调用才发现旁白被清零。）

## 3. 主判据（**目标与判据同源**）

| # | 判据 | 阈值 |
|---|---|---|
| **1（主）** | 落库语料对 `S_ext` 的 **`overlap_frac` 均值**，与 T5 同窗对比 | **低于 T5 同窗前缀** 且 **配对/独立 CI 不含 0**（slot 级 + 线程级双口径，不得互代） |
| 2（机制闸） | `ctx.d12i` 命中率 / 择优 argmin 命中 | 各 = 100% |
| 3（实现闸） | **三候选必须 shingle 层互不相同**（重采上限 **5**） | `resampled` 后仍全同的条数占比 **<2%**（D12-H 为 4.1%） |
| 4（形态闸） | F1/F2/F3（§2） | 见 §2 |
| 5（效果层，仅记录） | `L-7`、`P1`、`F-2'`、`L-15` | 点估计，明写"不判显著性" |

> **判据 1 的对比方式**：本臂落库语料 vs **T5 同窗（前 40 轮）** 的 `overlap_frac` 均值。**两臂参照系相同（都用 `S_ext`）** ⇒ 这是本设计相对前几臂的关键改进。

## 4. 反事实（跑前写死）

| 观察到 | 判定词 |
|---|---|
| 判据 1 达标 + 形态闸全过 + 实现闸过 | **有效** |
| 判据 1 未达（CI 含 0 或方向反） | **机制未生效**（选优目标换了但仍不降外部重叠） |
| F1/F2 在 1/3 处越界 | **作废（形态漂移）**，停跑 |
| 三候选全同占比 ≥2% | **机制未生效（无选择空间）** |
| 形态闸过但 `L-7` 反而上升 >5pp | **无效（换目标代价）** |

## 5. 落盘字段（消歧义）

```
ctx.d12i = {m:3, picked, scores[3], cand_shingle_hashes[3], cand_shingle_counts[3],
            score_kind:"overlap_frac_ext", ext_ref_sha256, resampled_per_cand[3]}
```
- **`resampled_per_cand[3]`**：每候选各自的重采次数（D12-H 的 `resampled` 是合计，无法区分是哪一候选）；
- `ext_ref_sha256`：`S_ext` 文件的 sha，保证参照系可追溯。

## 6. 成本与边界

| 项 | T5 | **D12-I** |
|---|---|---|
| `dialogue calls` | 1,530 | **≈1,530**（**3 采，不是 6 采**——本臂没有 ON/OFF 两组） |
| 重采追加 | — | 上限 5/候选，预期 +5~10% |
| 墙钟 | 49 分钟 | **预计 60–80 分钟** |

**边界**：单 seed / 单规模 / 单树；**参照系是"T5 前 40 轮"**（外部、固定），故本臂结果**只能与"用同一 `S_ext`"的臂比较**；`overlap_frac` 的"外部"仍是**批序**语料，不是 agent 实际上下文；无人类评证据；不得写"更自然"。

## 7. 与前几臂的关系（避免误读）

- **不是** D12-H 的"再跑一次"：D12-H 是 **ON/OFF 双组 6 采 + 自身历史参照**；本臂是**单组 3 采 + 固定外部参照**；
- **判据指标与 D12-H 相同（`overlap_frac`）但参照系不同**（D12-H 主参照 T5 前缀、本臂用固定 `S_ext`）⇒ **两者数值不可互译**；
- 本臂**不设"开头约束"那类结构位**（D12-H 已证它会连带清零旁白）⇒ 形态闸预期轻松过；**若仍越界，说明"按外部重叠择优"本身会改变文体**，那本身就是结论。
