## 0. V2 为什么会漏（根因，不是口味差异）

repro-verifier 的 V2 判据（其文件 §1 原文）：

- **A** ＝ `≥3 回合展开` **且**（`≥1 处第三方旧账` **或** `具体物链互相接物`）
- **B** ＝ 未满足 A 之一（"多为短线程或推进弱"）
- **C** ＝ `同句骨架复现 ≥3 次` **且** `未引入新事由/新对象/新分工`；token 泄漏直接 C

**根因一（结构性漏检）**：A 的第一个合取项是 `≥3 回合`。⇒ **R ≤ 2 的线程在数学上不可能被判 A**，只能落 B。而 C 的门槛（骨架复现 ≥3 次）在 2 回合线程里也几乎不可能达到。**两条一夹，"回合失接""槽位填装"这类缺陷在短线程里既进不了 A 也触发不了 C ⇒ 必然判 B。** 这正是 `TH-P015-P011-40` 与 `TH-P001-P009-18` 被漏检的机制，与阅读者的口味无关。

**根因二（A 无干净度闸）**：A 是**松 OR**——只要"有一处接物"就够 A，没有任何"减分项"。⇒ 一条线程可以同时有具体物链**和**"先这样。"这种收束公式粘贴，仍然判 A（#6 即此）。repro 侧 A=8/12 明显偏高，与该结构一致（他自己也写"V2 的或分支偏松"）。

**根因三（缺陷项无处安放）**：V2 里"句尾收束公式""悬空提问""镜像问答"**不在判据表里**，只作为读者的直觉扣分项存在 ⇒ 是否扣、扣多少、扣到哪档，全凭个人 ⇒ #6/#7/#8 三条分歧。

⇒ v3 的修法不是"调阈值"，是**换结构**：把 V2 的「松 OR + 无缺陷项」改成「**先计数、再按有序决策表判档**」，并给缺陷项**闭集、可数、带档位落点**。

## 1. 判据 v3（机械版）

### 1.0 前置定义（全部可数，不用形容词）

| 符号 | 定义 | 怎么数 |
|---|---|---|
| **R** | 线程回合数（台词条数） | 该线程内 `[rX turn=n]` 行计数。本批可用 `awk` 得到（见 §7） |
| **锚点** | 一个**可指名的**具体物 / 数 / 人名 / 待办事由 | 例：`粗盐`、`三斗`、`七月廿三那页`、`王婶家孙子`、`补板车`。**"东西""事"不算锚点** |
| **接物** | 后一句对前一句的锚点**指名复述并做动作** | 例：`半块红薯`→`皱皮红薯`→`红薯给我` |
| **P（推进计数）** | 满足 P1/P2/P3/P4 **任一**的**回合对**数量 | 见下 |

**P1–P4（推进的四种操作化动作，逐对判，满足一种即 +1）**

| 代号 | 判定问句 | 是 ⇒ |
|---|---|---|
| **P1** | 后一句是否给前一句的某个锚点**新增了状态或量化**？ | +1 |
| **P2** | 后一句是否给出**决定 / 承诺 / 带理由的拒绝**（不是"嗯""是啊"）？ | +1 |
| **P3** | 后一句是否引入**一个此前未出现的第三方或新待办**，并与当前锚点挂接？ | +1 |
| **P4** | 前一句提出**需要对方回答的具体问题**，且后一句**回答了它**（不接受"另起话头")？ | +1 |

⚠ **P4 必须"闭合"才算**。提问未被回答 = **悬空**，记入 Q2，**不计 P4**。这一条把"问一句换个话题"与"真推进"分开——是 #1 与 #8 的判档分水岭。

### 1.1 Q1 内部 token 泄漏

- **判定问句**：台词中是否出现非中文的标识符 / 英文 `snake_case` / 内部枚举名（如 `scarce_buy`）？
- **是** ⇒ **C，终止全流程**（不再数其余项）。**否** ⇒ 继续。

### 1.2 Q2 悬空提问（针对三类盲区之二）

- **判定问句**：线程内是否存在这样一句——它含**直接疑问**（`？` 或 `成不/咋样/顺不顺/没/要不要/在不在` 等疑问式），指向**对方或第三方的一个具体事由**，而该事由在**此后至少一个对方回合**里**既未被回答、也未被同义追问**？
- **是** ⇒ 该处计 **Q2 +1**（**按处计数，不按措辞去重**）。**否** ⇒ Q2 +0。
- **落到哪一档**：见 §1.8 表；单条规则为 **Q2 ≥ 1 ⇒ 不得判 A**；**Q2 ≥ 2 ⇒ 判 C**。

### 1.3 Q3 光杆收束公式（盲区之二）

**闭集词表（不得外延，不得"类似"）**：
`先这样` / `就这样吧` / `先这么着` / `先搁着吧` / `先搁下` / `先放放` / `先不急`

- **判定问句**：某句台词的**最后一个分句**是否**仅由**上述词表中的一个短语构成（前后无具体物、无具体动作、无事由），且该句**不是线程最后一句**？
- **是** ⇒ **Q3 +1**。**否** ⇒ +0。
- **关键分辨（必须写死，否则 #1 会摇摆）**：**事由是否在该短语"内部"**——短语内部带事由 = 有指向的推迟，**不计**；短语内部什么也没有、只能靠上文回指 = **光杆，计**。
  - `药引子这事先放放，我…`（#1 r4）＝ 事由在短语**内部** ⇒ **不计**（且该短语非末分句）
  - `药引子先不急，我…`（#1 r6）＝ 同上 ⇒ **不计**
  - `…我先搁下。红薯给我。`（#3 r30）＝ `先搁下` **非末分句** ⇒ **不计**
  - `你听听这声儿是不是有点闷。先这样。`（#6 r0）＝ 末分句只有 `先这样`，无内部事由 ⇒ **计 1**
  - `我这户口册子还差三页没对完，先搁着吧。`（#8 r17）＝ 末分句只有 `先搁着吧`，事由靠上文回指 ⇒ **计 1**（**这条是已知假阳性，见 §4.3-6**）
- **落到哪一档**：**Q3 ≥ 1 ⇒ 不得判 A**；**Q3 ≥ 2 ⇒ 判 C**。

### 1.4 Q3b 句尾标签复现（盲区之二，与 Q3 分开计）

- **判定问句**：是否存在一个 **≤6 字**的短语，在同一线程内出现 **≥2 次**，且**每一次都处于句末位置**（后接 `。！？` 或台词结束）？
- **是** ⇒ **Q3b +1**（每短语 1 次）。**否** ⇒ +0。
- **落到哪一档**：**Q3b ≥ 1 ⇒ 不得判 A**；**Q3b ≥ 2 ⇒ 判 C**。
- 例（已机核，`grep -n "账要平"` 命中第 43/72/73 行）：在 #11 `TH-P009-P004-0` 内 `账要平` 出现 **2 次**（第 72 行 r0 P009 句末 `…轧平。账要平。`／第 73 行 r1 P004 句首 `哎，账要平是正理，…`）；**因 r1 那次不在句末，条件"每一次都在句末"不成立 ⇒ #11 Q3b = 0**。#6 `TH-P010-P009-0` 内只出现 1 次（第 43 行，句末）⇒ 亦为 0。
- ⚠ 这条规则故意只认"**句末**标签"，因为句首/句中的复述是**正常接话**（r1 的 `账要平是正理` 是有效承接，是 A3 的来源），把它算缺陷会误伤好样本。

### 1.5 Q4 镜像问答（盲区之二）

- **判定问句**：抽取相邻两回合的**句式骨架**（去掉专名与具体物后剩下的结构），是否出现「**B 回答 A 的提问 → 随即提出同型提问 → A 照此回答并再反问**」这一 **≥3 步**的循环？
- **是** ⇒ 该循环计 **Q4 +1**。**否** ⇒ +0。
- **落到哪一档**：**Q4 = 1 ⇒ 不得判 A**；**Q4 ≥ 2 且 P = 0 ⇒ 判 C**。
- 依据：镜像问答是"轮转正确但无信息增量"，单独一条不足以判 C（人也会这样搭话），**两条以上且零推进**才等于复读机。

### 1.6 Q5 槽位填装（盲区之一：短线程 C 档判据的主武器）

**三个条件同时成立才算 1 处**：

| 条件 | 判定问句 |
|---|---|
| (a) | 该句是否由 **≥3 个短句**并列构成（逗号或句号分隔）？ |
| (b) | 这些短句之间是否**零连接词**（无 `就/倒/可/不过/所以/要不/回头/等/才/便` 等衔接成分）？ |
| (c) | 是否至少有一个短句是 **≤5 字的纯状态标签**（只有状态、没有物、没有动作，如 `肚子还空着。`／`饿得慌。`／`手都酸了。`）？ |

- **三条件全"是"** ⇒ **Q5 +1**。任一"否" ⇒ +0。
- **落到哪一档（短线程单列，这是本次最重要的改动）**：
  - **R ≤ 3 且 Q5 ≥ 1 ⇒ 判 C**
  - **R ≥ 4 且 Q5 ≥ 2 ⇒ 判 C**；`R ≥ 4 且 Q5 = 1` ⇒ 不得判 A（降 B）

### 1.7 Q6 回合失接（盲区之一：短线程 C 档判据的第二武器）

- **判定问句**：后一句对前一句的**核心请求 / 提议**（形如 `成不？``要不…？``得空来坐坐``你帮我…`）是否出现下列任一 ——
  - **(i) 否定性误读**：回答了一件**对方并未提出**的请求（例：对方说"要不先搁搁，等我说了再喊你"，回答却是"你先别急着喊我搭手吧"）；
  - **(ii) 完全无响应**：既不接受、不拒绝、不替代，且下一句直接另起完全无关的话头。
- **是** ⇒ **Q6 +1**。**否** ⇒ +0。
- **落到哪一档**：**Q6 ≥ 1 ⇒ 判 C（任何 R）**。理由：失接是**功能性断裂**（读者无法把两句接成一个对话），一句就够，不需要累积；这一点与"缺陷要累积到 3 次"的 Q3/Q4/Q5 不同，必须显式说明是**不同阈值族**。

### 1.8 判档决策表（**有序执行，先 C 后 A，命中即停**）

```
第 1 步  Q1 ≥ 1                        → C
第 2 步  Q6 ≥ 1                        → C
第 3 步  R ≤ 3 且 Q5 ≥ 1               → C
第 4 步  Q2 ≥ 2 或 Q3 ≥ 2 或 Q3b ≥ 2   → C
第 5 步  Q4 ≥ 2 且 P = 0               → C
第 6 步  以下四条全部为"是"             → A
         (A1) R ≥ 3
         (A2) P ≥ 2，且其中至少 1 次来自 P1 或 P2
         (A3) 可指名锚点 ≥ 2（物/数/人名/待办，非"东西/事"）
         (A4) Q2 = 0 且 Q3 = 0 且 Q3b = 0 且 Q4 = 0 且 Q5 = 0
第 7 步  以上都不是                     → B
```

**A 的结构变化（这是修 #1 分歧的关键）**：V2 是「`≥3 回合` AND (`旧账` OR `接物`)」——**具体性可单独换 A**。v3 把"具体性"降级为**必要但不充分**（A3），并加 **A2 推进** 与 **A4 干净度** 两道闸。⇒ **"物链具体但无推进 / 带收束公式"不再能换 A**。

**"推进"的操作化定义（回答任务的第 3 问）**：推进不是"有新信息"，而是**后一句对前一句的锚点做了 P1–P4 四类动作之一**。特别地：
- 同一锚点被**反复挪动**（粗盐"码柜上"→"挪里屋"→"油纸裹"）如果每次都只换动作不换状态意义，**只算 1 次 P1**（判据：动作是否改变该锚点的**可用性/位置/归属**，改才算）；
- **反复推迟**（"先放放"→"先不急"）**不算推进**，且计入 Q2（若被推迟的是提问）；
- 提问不计推进，**提问被回答才计**。

## 3. 「横向比对发现模板复用」是否回溯改单条档位

### 3.1 决定：**保留"不回溯"，但必须把横向工件登记为「批级附图」**

**理由（三条，缺一不可）**：

1. **两个读者的"横向视野"不对等，回溯会把不可比的东西塞进条级判定**。横向复用只有把多条线程**并排**才看得见；并排需要先拿到**整批**，而整批的构成（抽到哪 12 条、以什么顺序读）本身不是判据的一部分。若允许回溯，同一条文本在"只看它自己"与"和它的兄弟一起看"两种情形下会得到不同档位 ⇒ **同一条文本没有唯一定值**，κ 从"判据一致性"退化为"抽样运气一致性"。
2. **回溯会把"批级缺陷"错记成"条级缺陷"**。W1（P011 三条同模板开场）的正确含义是**该人设的提示词产出有问题**，不是"这三条线程各自不合格"。条级档位若吸收批级信号，未来就无法用档位差去定位**是哪个环节**坏了。
3. **回溯具有不可闭合的传染性**。一旦允许"发现复用就改档"，读者可以因"我在别处见过类似句式"而下调任意一条，**无法复算、无法仲裁**。

### 3.2 代价与补偿

- **代价**：#7/#10 这类"自身文本尚可、但因同模板而应下调"的线程，在条级档位上会**偏高**。此代价**显式承认**，不用任何方式掩饰。
- **补偿（强制项）**：每份判读文件必须附 **「批级附图」**，登记横向工件，格式固定为三列（`工件 ID | 逐字证据（≥2 条，带 thread_id 与 round）| 命中条数与命中率分子/分母`）。批级附图**不进 κ**，但**进下一轮修改方向**。
- **v3 下的判例**：本批 W1（`我这木剑都挥得手软了…先歇会儿吧。`#3 ／ `我这木剑挥得胳膊都酸了…先歇会儿吧。`#7 ／ `我手里这木剑都快握不住了呀`#10，3/12）**不改 #7/#10 的条级档位**，只登记为批级工件。
