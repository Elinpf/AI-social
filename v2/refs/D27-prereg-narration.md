# D2.7 预登记 · **放开旁白**：允许每句带一个括号动作（恢复被 A1 臂禁掉的生活质感）

> 立此存照：**2026-10-24，在任何 D2.7 代码改动与跑批之前**。判据、阈值、反事实先写死。
> 依据：`v2/evidence/d27_narration_ban_rootcause.md`（根因）、`v2/evidence/d25a_result.md`（当前基线 `paren=0.00%`）。
> 锚点：master HEAD = `21b6738`；当前 `prompt_fn_sha256`（本树）= `47623c9d…4f58`，改后**必变**（预期）。

## 1. 目标

当前居民的每句话**只有台词、没有动作**（`paren_rate = 0.00%`，历史基线曾是 79.41%）。
本臂放开一处限制：**允许句首一个括号动作/神态**，看对话是否变得"像有人在那儿"。

**这是"恢复"，不是"新增"**：被禁掉的旁白曾是默认行为。

## 2. 改动（受控解冻范围内：提示词/措辞层）

`code/life/agent.py` 两处收尾指令（`:1453` initiate / `:1478` reply），**同改**：

| | 改前 | 改后 |
|---|---|---|
| 旁白 | 「不要用括号、方括号或星号写动作、神态或心理旁白」 | 「**句首可用一个括号写一个具体的动作或神态**（如"（把烟袋往桌上磕了磕）"），**一句只一个、不超过 15 字**；不要写心理活动」 |
| 其余 | 「不要解释也不要总结；用口语短句，别反复用同一句口头禅」 | **一字不改** |

**单变量声明**：只改这两句里"旁白"那半段；句长、口头禅、不解释不总结、结构提示（`_l7_struct_line`）、
上下文装配、配额、线程参数**一律不动**。零 config 改动 ⇒ 不碰 `engine_version` 指纹（但 `prompt_fn_sha256` 会变，属预期）。

## 3. 臂

两臂 **同批、串行、同 seed（42）、n16r60**，`--override` 不使用（本臂不需要 override）。

## 4. 判据（跑前写死）

| # | 指标 | 达标线 | 未达档位 |
|---|---|---|---|
| **M1 机制生效** | `paren_rate`（正文以 `（`/`(` 起头） | **0.00% → ≥ 30%** 且 `len(body) ≤ 80` 的旁白占比 ≥ 80%（防成长篇描写） | 判**「机制未生效」** |
| **P 主判据（生活质感）** | `P1 具体性代理`（`d12c_metrics.py` 的器物/动作词表命中率） | 相对 C **↑ ≥ 5.0pp** | 判**「无效（只是加花架子）」** |
| **Q1 复述闸** | `L-15 restate_rate` | 相对 C **↑ ≤ 2.0pp** | 破 ⇒ **「无效（靠复述填旁白）」** |
| **Q2 重复闸** | `L-7 norm8` | 相对 C **恶化 ≤ 3.0pp**（**若下降则记为增益**，务必并列报） | 破 ⇒ **「无效（重复恶化）」** |
| **Q3 跑题闸** | `F-2_content_drift`（=F-2′，**不用** `F-2_topic_drift`） | 相对 C **降 ≤ 2.0pp** | 破 ⇒ **「无效（内容漂移）」** |
| **S 保结构** | `n_threads`、`n_msgs_total` | 相对 C **±10%**（本臂不动配额，故可用绝对闸） | 破 ⇒ **「作废（非单变量）」** |
| **T 文体闸** | `len_p50_excl`（**去括号后**的正文长度） | 相对 C **±10%** | 破 ⇒ **「作废（台词被旁白挤短）」** |
| **代价闸** | `llm_calls`（应≈不变）、`tokens`（预期 +10~25%） | `calls ≤ +10%`；`tokens ≤ +40%` | 破 ⇒ 只记录，不判作废（本臂 token 增长属预期） |

> **T 闸用 `len_p50_excl` 是关键设计**：旁白会加长整条消息，但**台词本身**不应变短。
> 若 `len_p50_excl` 显著下降 ⇒ 说明模型把预算花在旁白上、台词变敷衍 ⇒ 作废。

## 5. 反事实（跑前写死）

| 观察 | 判定词 |
|---|---|
| M1 过 + P 过 + Q1/Q2/Q3 过 + S/T 过 | **有效** |
| M1 过、`paren_rate` 高但 P1 不升 | **无效（只是加花架子）** |
| M1 过、P 过，但 `len_p50_excl` 降 >10% | **作废（台词被旁白挤短）** |
| M1 过、L-7 **下降** ≥3pp（意料外的增益） | 仍判 P 是否过；若过则 **有效，且并列记录"重复率同时下降"** |
| M1 未过（paren < 30%） | **机制未生效**（改指令位置/措辞再测，不宣布方向错） |
| S 破 | **作废（非单变量）** |
