> 立此存照：**2026-10-24，在任何 D2.9 代码改动与跑批之前**。判据、阈值、反事实先写死。

## 1. 目标（只解决 D2.8 剩下的那一个破项）

D2.8 已做成"旁白与台词并存"（`paren 29.22%`、`len_p50_excl 41→53`、`P1_count +28.6/+37.5%`、`F-2′` 两 seed 均改善），
**唯一破项是 `L-7` 两 seed 同向 +7.26/+9.41pp**，归因已实证为**旁白句法骨架单一**（"把"字句 66–69%，词汇互异率 89%）。

**本臂只动一件事：把"旁白写什么骨架"从"模型自由选"改成"按确定性哈希指定"，让骨架均匀分布。**
**不动**旁白比例（`para_on` 保持 1/3）、不动台词长度要求、不动其他任何提示词段落。

## 2. 改动（在 D2.8 的 `narration_instruction` 内加骨架选择）

```
skel_idx = int(sha256(f"{thread_id}|{turn}|skel")[:8],16) % 5      # 与 para_on 用不同盐，避免相关
```

`para_on == True` 时，收尾指令按 `skel_idx` 指定**一种**骨架（各 20%）：

| idx | 骨架（示例，提示词里给形态不给例句原文） |
|---|---|
| 0 | `把 N 往/在 P 一 V`（现状写法：把锄头往墙根一靠） |
| 1 | `V 着 N 说`（攥着抹布说 / 捏着针线说） |
| 2 | `N 在 <身体部位/手边> 一转/一沉/一顿`（烟袋在手里转了转） |
| 3 | `抬头/低头/眯眼/侧身 + 看/听/闻`（抬眼看了看天） |
| 4 | `一边 V 一边 …`（一边擦桌子一边…） |

- **不是禁用「把」**：`把` 仍占 1/5=20%，只是不再占 2/3；
- `para_on == False` 时仍为「只写台词，不写任何动作/神态/心理」；
- 其余（`台词本身不少于 30 字、不超过 80 字`、`不要解释也不要总结`、`用口语短句，别反复用同一句口头禅`）**一字不改**。
