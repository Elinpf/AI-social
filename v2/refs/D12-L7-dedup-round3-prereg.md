## 2. 三个候选臂（**正向约束**；每个臂单变量，互不叠加）

### 臂 D12-A ·「具体性插槽」（正向要求"说出一个可验证的具体细节"）

**改动（只改提示词，逐字）**：在 `_dialogue_prompt` / `_reply_prompt` 的收尾指令处**追加一行**（不删改任何现有行）：

```diff
+ "\n说话前来得及的话，先说一个你此刻手上或眼前的具体东西（一样器物、一个数、一个刚发生的小事），"
+ "再顺着它说下去。"   # 注：允许不是每条都用，但**使用率须 ≥30%**（见"机制生效闸"）
```

**为什么这是正向约束**：不禁止任何句式，而是**提供一个"从具体物起句"的替代路径** ⇒ 预期减少模板句式的复用，同时**提升**具体性（与 D4 的代价方向相反）。

| 项 | 内容 |
|---|---|
| 预期方向 | L-7（raw8）**↓**；具体性密度 **↑或持平**；纯台词长度 **↑或持平**（允许 +0~15%） |
| **机制生效闸（先验，判"机制未生效"而非"无效"）** | **插槽实际使用率 ≥30%**。代理口径（写死）：`台词含具体物/数/量词` 的消息占比（用 D4 的 `DETAIL_WORDS` 词表，per-message 命中即 1）。**<30% ⇒ 判「机制未生效」，不得判「无效」**（模型压根没用插槽，说明指令没被执行，要回去改指令位置/措辞，而不是宣布这条路走不通）。与 B 臂「句首 4 字熵无变化 ⇒ 机制未生效」对称。 |
| **反事实判据（若无效会看到什么）** | 在**机制生效（使用率 ≥30%）的前提下**：① L-7 Δ 落在 `[−4.31, +5.88]pp` 带内（即 ≤5.88pp 下降）；② 或 L-7 降但**具体性密度同时降 ≥5pp**（说明又走了"删信息换不撞"的老路）；③ 或 `len_excl_paren` p50 反而降 >15%（被压短）。**任一出现 ⇒ 判「无效」**，不是"小样本波动"。 |
| 代价检查 | 具体性密度 proxy、`len_excl_paren` p50、干瘪率、`L-5 模板句命中`、tokens_in/out |
| 风险 | 可能变成"每句都先报一个物件"的新套路 ⇒ **必须同时看 L-7 是否只是被"物件清单"替换**（检查 raw8 是否转移到"器物名"上：抽样人工读 10 条） |
