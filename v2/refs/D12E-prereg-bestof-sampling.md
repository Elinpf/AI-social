# D12-E 预登记 · 采样择优（best-of-3）——**机制层去重**，不是提示词层

> 立此存照：**2026-10-23 10:20，在任何 D12-E 代码改动与跑批之前**。判据、阈值、反事实**全部先写死**。
> 前置证据：`v2/evidence/d12d_leader_terminal_check.md`（D12-D 阴性 + 机制发现）、`v2/evidence/d12c_result.md`（D12-C「有效」但有模板化代价）。

## 0. 为什么必须换层（**两轮实验直接指出来**）

1. **D12-C**（提示词加"具体物/第三方"两行）：P1 **+10.20pp**、P2 **+16.08pp**，但 `L-7` **+20.98pp**（44.12%→65.10%）⇒ 具体物被**同一批骨架**承载；
2. **D12-D**（提示词再加"换新物/换开头"两行）：`L-7` **只降 0.59pp**（65.10%→64.51%）⇒ **未过 5pp 闸**；而旁白砍掉 **16.07pp**，**删掉旁白后重算的 `L-7` 反而升 0.99pp** ⇒ **模板句从旁白搬进正文，撞车总量不变**。

⇒ **提示词层已到边界**：模型会照做"内容"（槽里填什么），但不照做"骨架"（怎么组织）。再往指令里加约束，只会换来"看起来按要求了"。
⇒ 既有两条机制也已被击穿：`code/life/anti_repeat.py`（事后重试，R12 实测 `retries=88=collisions=88`，重试率 17.25%）、`code/life/l7_structural.py`（开口/收束轮转，A5 抽检 #7 仍三次复用同一骨架）。
⇒ **本臂换机制：不再"求"模型别重复，而是"选"出一条不重复的。**

## 1. 设计（**机制层 · 采样择优 · 确定性选优**）

新增 env **`LIFE_PROMPT_D12E_BESTOF`**（**默认 1 = 关闭，行为与现树逐字节一致**；`3` = 开启三采样择优）。

**开启时（`=3`）**，对**每一处对话生成**（`_dialogue_prompt` / `_reply_prompt` 的调用点，**仅对话生成**，`judge` / `importance` / `plan` / `reflect` 一律不受影响）：

1. 用**同一个 prompt** 连采 **M = 3** 次（温度等参数不变，靠采样随机性）；
2. 对每条候选算「与**该 agent 可见的最近 N = 16 条台词**」的 **8-gram 交集条数**（shingle 集合沿用 D5 `normalize_body` + 8-gram，**不自创口径**；最近台词取材复用 `l7_structural.recent_bodies(wv, agent_id)`，**replay 安全、无状态**）；
3. **确定性选优**：取交集数**最小**的那条；**平局取第 1 条**（保证 replay 可复现）；
4. 落盘 `ctx.d12e = {"m":3, "scores":[a,b,c], "picked":i}`（additive，进日志不进 `state_hash`）。

**与既有机制的区别（必须写进报告，防止被当成"又一个 anti_repeat"）**：
| 机制 | 触发时机 | 选择方式 | 已知效果 |
|---|---|---|---|
| `anti_repeat`（既有） | 生成后撞车才重试 | 盲目重试 1 次 | R12：`retries=collisions=88`，**无效** |
| `l7_structural`（既有） | 生成前给开口/收束模板 | 无选择 | A5 #7：**仍复用同一骨架** |
| **D12-E（本臂）** | 生成时**采 M=3** | **按 8-gram 交集确定性择优** | 未知（本预登记要测） |

## 2. 代价（**跑前先认账**）

- **对话生成调用数 ×3**：D12-C/D12-D 两臂各 510 次对话调用 ⇒ 本臂约 **1,530** 次（+1,020 次网络调用）；**judge/importance 不变**；
- **墙钟预期 ×1.5–3**（50 分钟 → **75–150 分钟**），跑批期间仍须串行；
- 因此**本臂只跑一臂**（T3），基线用已有 T1（同树，`BESTOF` 默认 1 ⇒ 逐字节相同）。

## 3. 三态与单变量

| 态 | env | 期望 `prompt_fn_sha256` |
|---|---|---|
| **T0** 中性 | 无 | `5cf08593d562dc09…`（逐字复现，否则作废） |
| **T1 = D12-C** | `LIFE_PROMPT_D12C_SPECIFIC=1` | `effc14dbffdb6865…`（逐字复现，否则作废） |
| **T3 = D12-C + D12-E** | 上式 + `LIFE_PROMPT_D12E_BESTOF=3` | **必须与 T1 逐字相同**（D12-E **不改提示词**，只改采样与选择）⇒ **这是本臂最关键的一条接线证明：sha 必须等于 T1，不等就是"偷偷改了提示词"** |

⇒ **本臂的单变量不是"提示词差一行"，而是"同一提示词采 3 次并择优"**。所以 `prompt_fn_sha256` **必须与 T1 完全相同**，配 `ctx.d12e.m=3` 出现率 **= 510/510** 作为执行层证据。

## 4. 机制生效闸（**先验**）

| 代理 | 定义（冻结） | 达标线 |
|---|---|---|
| **M1** | `ctx.d12e.m == 3` 的对话消息占比 | **= 100%**（否则机制没接上 ⇒ 判「机制未生效」） |
| **M2** | 三候选中**发生过"非第 1 条被选中"**的比例 | **≥ 20%**（若几乎总选第 1 条，说明择优没起作用） |

> M1/M2 是**接线闸**（不是效果闸）：任一未达 ⇒ 只能写「机制未生效」。

## 5. 判据（**四条同时满足才算「有效」**）

| # | 指标 | 达标线 | 理由 |
|---|---|---|---|
| 1 | **`L-7` norm8** | **≤ 55.10%**（相对 T1 65.10% **↓≥10pp**） | 本臂正面目标 |
| 2 | **`L-7` raw8** | **≤ 64.12%**（相对 T1 74.12% **↓≥10pp**） | 双门槛（保守口径），与 §D12-D 同一纪律 |
| 3 | **`P1` 具体性** | **≥ 93.82%**（不降 >5pp） | 不得拿具体性换去重 |
| 4 | **`F-2` 内容漂移率**（**新增，采纳执行者建议**） | **≤ 75.09%**（相对 T1 的 70.09% **不得更漂 >5pp**） | **防"重复降了、话也不接了"** |

**第 4 条为什么必须有**（依据不是猜测）：D12-D 已经演示了这条风险——`F-2 drift_rate` 从 T1 的 **70.09%** 升到 T2 的 **82.40%（+12.31pp）**，相邻消息 char-bigram Jaccard 均值从 0.0814 降到 0.0665 ⇒ **"求模型换说法"直接把内容关联打散了**。所以本臂若不设这条闸，就可能出现「`L-7` 降了、但对话变成各说各的」而被判有效。

**次级（只记录，不判定）**：`len_p50`(excl) 不涨 >10%（≤ **57.2**）；`K-1 cont_lexical`（T1 = 0.994135，**已近天花板，只作下限守卫**，不降 >2pp）；`L-3` 含括号块率（T1 = 66.27%，**不再砍旁白**）；结构 510 / 169 / 2 **±5%**；`L-6`（T1 = 9.61%）。

## 7. 反事实（跑前写死）

在 **M1/M2 过闸** 前提下：
| 观察到 | 判定词（5 档之一） |
|---|---|
| `L-7` 双口径都 ↓≥10pp、P1 与 F-2 都守住 | **有效** |
| `L-7` 降了但 **F-2 漂 >5pp** | **无效（拿承接换重复）** ← 本预登记新设，防 D12-D 式假成功 |

| 结构超 ±5% | **作废**（不是单变量） |
| M1 或 M2 未达 | **机制未生效** |

## 9. 边界

1. 单 seed / 单规模 / 单树；**本臂只改"采样与选择"，不改提示词**（sha 必须等于 T1）；
2. `L-7` 是 8-gram 撞车代理、`F-2` 是 char-bigram Jaccard 代理，**都不等于"读起来重复/接不接得上"**；
3. 本臂引入 **3× 对话调用成本**，若有效也只是"在 M=3 下有效"，**不证明 M=1 时模型自己会换说法**；
4. **不得**写"对话更自然了"——本臂无人类评证据；`judge` 与系统同源，只能作旁证；
5. 判据与阈值**同时冻结**；要改须新开预登记并说明前一份为何作废。
