## 0. 定位、现状与设计原则

### 0.1 现状（来自代码，`【事实】`）
| 域 | 现有实现 | 缺口 |
|---|---|---|
| 人格 M1 | `life/persona.py`：大五 5 维 + Schwartz 4 维 + 技能 + 背景 + `goal_tendencies` + `needs_init` + `speech_style`；派生标量 `work_ethic/social_initiative/risk_appetite/saving_propensity`；`compressed_profile()` ≤200 token | **人格会否漂移无定义、无观测、无防护**；无跨会话"人格指纹" |
| 记忆 M2 | `life/memory.py`：`AssociativeMemory`（kind=`observation/plan/reflection/chat`，importance 0–10，三因子检索 `recency(decay=0.995)/importance/relevance(lexical)`，top_k=8，反思触发 `importance_sum≥150` 或每周强制，`R_max=7/周`）；正文/嵌入入侧存储，主日志只存 `body_ref/embed_ref` | **无分层（工作/情节/语义/反思只是 kind 标签）**；**无容量上限**；**无压缩/摘要聚合**；**无睡眠、无遗忘** |
| 需求/目标 M7 | `NEED_UPDATE` 6 维衰减/满足、`GOAL_*`、周计划 | 情绪维度缺失；习惯/口头禅未建模 |
| SKYCity 对照 `【事实】` | 工作/情节/语义三层记忆、加权检索（实体+关键词+重要性+新近度+**未解决度**）、每日 23:30 反思；`sleep` 只恢复精力/心情 | **同样没有遗忘机制**；睡眠无记忆副作用 |

**结论**：用户点名的「**睡眠/遗忘**」是本项目与参考实现的**共同真缺口**，需自研；「人格连续/稳定」「像人」缺少**可验收判据**，是当前无法交付的根因。

### 0.2 设计原则
- **P1 只写方案**：本文不修改任何代码；所有改动以"建议项 + 验收判据"形式给出，供后续拆任务。
- **P2 与内核同构**：一切"判定"（遗忘与否、漂移与否、是否达标）走**确定性纯函数**，可用日志重放；LLM 只产内容与候选，不产判定。延续 `06` C4 / `08` L-1。
- **P3 可复算优先**：每个"指标"都能从 `EventLog` + side storage 纯函数重算，逐位一致。
- **P4 成本显式**：每个机制标注"**50+ agent 是否负担得起**"，并给出 token 控制手段。
- **P5 不滥用心理学**：任何"像人"的假设一律标 `【未验证】`；**不把未经验证的心理学结论当设计依据**（见 §9）。

## 1. 人格工程（M-P）：连续 / 稳定 / 可靠

### 1.1 表征选型 —— 结论：**三层混合表征**
| 层 | 载体 | 可变性 | 用途 |
|---|---|---|---|
| **L-A 人格卡（锚）** | 结构化 JSON（现有 schema，`persona.py`） | **不可变**（运行期永不写回） | 身份、prompt 身份段、派生标量、抗漂移锚点 |
| **L-B 人格状态向量（表达层）** | 每维量化整数 `p_i(t)` ∈ [0,100]（大五 5 + 情绪基线 1） | **有界缓慢漂移** | 承载"这个人最近变了点"的可观测性 |
| **L-C 规则层** | 派生纯函数（现有 `work_ethic` 等）+ 习惯/口头禅规则表 | 半静态 | 把人格落到行为 |

- **为什么不选"纯向量"**：向量人格不可读、不可审计、难与 `persona.json` 静态配置对齐，且容易在长跑中发散（`【未验证】`）。
- **为什么不选"纯卡"**：纯卡无法表达"人在经历后会变"，与 #3「有状态」冲突。
- **结论 `【设计】`**：以**卡为锚**、**向量为有界表达**，两者用 §1.2 的显式回归约束绑定。

### 1.2 抗漂移：三机制（核心 `【设计】`）
**M-P1 锚定不写回**：L-A 卡运行期只读；任何"性格变化"只能改 L-B 向量，永不改卡。卡变更需人工改 `personas.json` 并重生成指纹。

**M-P2 有界更新 + 均值回归**（确定性）：
```
每个"漂移事件"（由反思/重大经历产出候选 delta）：
  p_i ← clamp( p_i + α·(anchor_i − p_i) + Δ_i , 0, 100 )
  Δ_i ∈ [−δ, δ]          默认 δ = 1（单事件最大 ±1 分）
  α   = 0.02             默认回归系数（越大越"弹回"锚点）
  触发门槛：候选 delta 必须来自 importance ≥ θ_drift（默认 7）的记忆，且同一维
            每 W_drift（默认 1 周）内至多更新 k_drift（默认 3）次
```
- **性质**：均值回归项保证 `p_i` 长期围绕 `anchor_i` 有界振动；`δ` 上限保证单步不跳变；冷却与门槛保证 LLM 不能"刷人格"。
- **确定性**：`Δ_i` 由裁决器从记忆的（importance, 情绪权重, 维别）**确定性映射**得到，不由 LLM 直接给分（延续 AR-C3 立场）。

**M-P3 漂移预算**：每 `W_drift` 内全 agent 的漂移更新次数有全局上限，超限记 `PERSONA_DRIFT_REJECTED`（可审计）。

### 1.3 跨会话 / 跨重启连续性（`【设计】`，复用内核）
- **身份连续** = `persona_id` + **人格指纹** `PF0 = sha256(canonical({pid, big5, values, skills}))`（静态、可单列校验）。
- **状态连续** = 内核既有的 **`State = fold(apply_event, Log, init(seed))`**：L-B 向量作为 `WorldState` 内的确定性子状态，由 `PERSONA_DRIFT` 事件折叠重建；**重放不重调 LLM**（`06` L-3）。
- **冷启动不变量**：`replay(log) 的 L-B 向量 == 首跑`（纳入现有 `replay_parity` 门禁）。跨会话只需同一 `seed + engine_version + log + side storage`。

### 1.4 人格指纹与漂移观测（**可复算判据** `【设计】`）
```
静态指纹   PF0        = H(pid, big5, values, skills)                    # 身份不变则不变
动态指纹   PF(t)      = H(pid, quantize(P(t)), mood_baseline)           # P 为 L-B 向量
漂移度量   drift(t)   = || quantize(P(t)) − quantize(P(0)) ||_1 / (5·100)   ∈ [0,1]
维度漂移   drift_i(t) = |P_i(t) − anchor_i| / 100                        ∈ [0,1]
漂移斜率   slope_i    = 线性回归(P_i over 窗口) 的斜率（定点）            # 检测单调漂移
```
- 全部**整数/定点**实现、**全序 tie-break**、快照写 `metrics.life.persona{drift, drift_i, slope_i, pf0, pf_t}`。
- 判定（示例，可由 T10 标定）：`drift(t) ≤ D_max（默认 0.15）` 且 `max_i drift_i ≤ 0.20` 且 `|slope_i| ≤ 0.01/周`。

### 1.5 人格一致性验收判据
- **可复算（硬门禁）**：跑满 **1000 回合**（≈12 模拟周）后 `drift ≤ D_max`、无 `PERSONA_DRIFT_REJECTED` 越限、`PF0` 不变、`replay_parity=True`。
- **人工验收（量表）**：见 §5.1「人格一致性 Likert 量表」。

### 1.6 成本（`【设计】`）
- 人格本身 **0 在线调用**；漂移候选来自**已有**的反思调用（不新增调用）；`PERSONA_DRIFT` 事件为纯计算。
- **50 agent 负担得起**：无新增 LLM 调用，仅少量事件（每 agent 每周 ≤ k_drift 次）。

## 2. 记忆工程（M-M）

### 2.1 四层记忆（`【设计】`；把现有 `kind` 升级为显式分层）
| 层 | 名称 | 内容 | 载体 | 容量（默认） | 生命周期 |
|---|---|---|---|---|---|
| **WM** 工作记忆 | 当前心智 | 本会话计划、最近对话、当前检索命中的"临时拼装上下文" | 内存 ring buffer | 8 项 | **不持久**，会话结束即弃 |
| **EM** 情节记忆 | episodic | 具体经历（谁/何时/何地/发生了什么），含 `observation/chat` | 侧存储 + `MEMORY_WRITE` | `CAP_EM`=1500/agent | 可被遗忘/摘要 |
| **SM** 语义记忆 | semantic | 对人物/地点/话题的**稳定印象与事实**（如"阿林爱打听消息"） | 侧存储 + `MEMORY_WRITE(kind=semantic)` | `CAP_SM`=300/agent | 慢遗忘，多由 EM 聚合而来 |
| **RM** 反思记忆 | reflection | 反思产出的高层洞见 | 侧存储 + `MEMORY_WRITE(kind=reflection)` | `CAP_RM`=200/agent | 基本不遗忘（除非被合并） |
- 与 SKYCity 对照：其"工作/情节/语义 + 每日反思"与我们一致；**我们额外显式定义容量与遗忘**（SKYCity 缺，`【事实】`）。

### 2.2 写入时机（`【设计】`）
| 来源事件 | 写入层 | kind | importance 来源 |
|---|---|---|---|
| 感知到显著事件（`OBSERVATION`） | EM | observation | 规则 or LLM 打分（批量），沿用现有 `_score_importance` |
| 收到/发出消息（`MSG_*`） | EM | chat | 话题新颖度 + 关系强度（规则） |
| 周计划（`SCHEDULE_PLANNED`） | WM→EM | plan | 固定 3 |
| 反思产出（`MEMORY_REFLECT`） | RM（+ 可能派生 SM） | reflection | 固定 6–8 |
| 夜间聚合（§3） | EM→SM | semantic | 聚合算子产出 |

### 2.3 检索排序（升级现有三因子 `【设计】`）
```
score = w_rec·recency + w_imp·importance + w_rel·relevance
        + w_unres·unresolved        # 未解决度（借 SKYCity；未闭环事件权重高）
        + w_emo·|emotional_weight|  # 情绪强度
        + w_ent·entity_match        # 查询实体与记忆 subject/关键词命中
默认权重：w_rec=1.0, w_imp=1.0, w_rel=1.0, w_unres=0.3, w_emo=0.4, w_ent=0.5
全序 tie-break：(score desc, last_access desc, mem_id asc)   # 保持现有可复现口径
```
- 检索结果照常落 `MEMORY_RETRIEVE`（选中 id + 分数 + 权重），**重放不算嵌入**（`06` L-3 / `08` C4）。
- 去冗余：命中后按 `subject`/关键词做一次确定性去重（同主体最多 2 条），避免 prompt 被同一话题刷满。

### 2.4 压缩 / 摘要（`【设计】`）
- **EM→SM 聚合**（夜间批处理，§3.4）：对同一 `subject` 的 EM 聚类 → 产出一条 SM 摘要，原 EM 标记 `compressed_by=sm_id`（**不立即删除**，进入遗忘候选）。
- **SM 再压缩**：SM 数量超 `CAP_SM` 时，按（importance, access_count）淘汰/合并。
- **prompt 压缩档案**（Agentopia 经验，`06` §3.6）：进 prompt 的永远是"身份段 + top_k 相关记忆 + SM 摘要 + 最近对话"，**≤ `M_mem` token**（默认 800，可调 400–1500）。

### 2.5 容量上限与 token 成本（核心 `【设计】`）
**每 Agent 每周记忆相关 token 量级（估算，系数待 T10 实测）**：
```
观测/周 obs_w ≈ SLOTS_PER_WEEK × o_per_slot   (28 × 0.5–2 → 14–56)
写入调用  ≈ obs_w / B_imp            (B_imp=10 → 1.4–5.6)   # importance 批量
嵌入调用  ≈ obs_w / 16               (1–3.5)                 # 批量嵌入
检索调用  = 决策次数（已含在生活层调用内，不新增）
反思调用  ≤ R_max = 7/周
夜间聚合   ≈ 7/周（与反思合并可摊薄）
→ 记忆专属新增调用 ≈ obs_w/B_imp + obs_w/16 ≈ 2–9 次/agent/周
→ 每决策注入 token ≈ 身份200 + 记忆≤320 + 摘要≤300 + 对话≤300 ≈ 1100–1500 tokens
```
- **50 agent / 周**：新增记忆调用 ≈ **100–450 次/周**、注入 token ≈ `决策数 × ~1300`（决策数由 `00 §7.2` 主档给出）。**结论：可控**——因为检索是"读取"不调 LLM，写入是**批量**的。
- **控制手段**（全为确定性）：`top_k` 上限、`M_mem` 截断、去冗余、EM→SM 聚合降基数、`obs_w/B_imp` 批量、遗忘降采样（§3）。

## 3. 睡眠与遗忘（M-S）—— 用户点名，本项目真缺口

### 3.1 睡眠机制（`【设计】`；把睡眠做成"离线批处理窗口"）
```
触发：night 时段（TIME_CONFIG.sleep_slots=["night"]）→ 每 Agent 进入 SLEEP（可被强事件打断）
时长：默认 1 个时段（=ROUNDS_PER_SLOT 回合）；由 needs.energy 决定是否午休（energy<θ_nap）
睡眠期间：
  ① 记忆固化（§3.4）② 反思（沿用现有 RM 触发）③ 日结（日界快照）
  ④ 遗忘评估与执行（§3.2）⑤ token 预算复位（新一周的检索/反思配额）
产出事件：SLEEP_STARTED / SLEEP_COMPLETED / MEMORY_CONSOLIDATE / MEMORY_FORGET
```
- 与 SKYCity 差异：SKYCity 的 `sleep` 只恢复精力/心情；**我们让睡眠承担记忆运维**（`【设计】`）。

### 3.2 遗忘曲线设计（**可实现、确定性** `【设计】`）
采用**离散分档 + 定点保留度**，避免浮点不可复现：
```
保留度（permille，整数 0..1000）：
  R(m, t) = round( 1000 · exp( −Δt / (H0 · S(m)) ) )        # exp 用固定查找表/定点近似
  Δt = 自 m.last_access（或写入）以来的 slot 数
  S(m) = clamp( s_base + a·access_count + b·importance + c·|emo| + d·consolidated , S_min, S_max )
  默认：H0=14(slot), s_base=1, a=0.5, b=0.30, c=0.40, d=0.50, S∈[1,6]
遗忘触发：睡眠时批量评估；R(m,t) < θ_forget（默认 300‰）→ 进入遗忘处理
```
**三级遗忘处理（防"一刀切删除"）**：
| 级别 | 条件 | 动作 |
|---|---|---|
| **L1 降级** | 300‰ ≤ R < 600‰ | EM→SM 摘要化（丢失细粒度时间/措辞，保留要点），原 EM 标 `demoted` |
| **L2 合并** | R < 300‰ 且未受保护 | 与同 subject 的 SM 合并，删原 EM |
| **L3 删除** | R < 300‰ 且为低重要性孤立项 | 逻辑删除（`MEMORY_FORGET` 事件留痕，可审计） |
- **永不遗忘（保护名单）**：`importance ≥ θ_keep（默认 7）` ∨ `access_count ≥ 3` ∨ `被任一 reflection 引用` ∨ `|emo| ≥ θ_emo（默认 6）` ∨ `属于 SM/RM 层`。受保护项只允许 L1 降级/合并，**不 L3 删除**。
- **可复算判据**：`retention(Δt, importance, access_count, emo, consolidated)` 是**纯函数**，给定输入输出逐位一致 → 单元测试可 golden 比对。

### 3.3 "如何保证不忘掉重要的"（多信号）
重要性评分（现有 importance）**不够**，叠加：**访问频率**（被反复取用 = 常青）、**情绪强度**（`|emo|` 由消息/事件确定性映射，非 LLM 判定）、**被反思引用**（进入高层认知）、**聚合归属**（已成 SM 的要点）。四者加权进 `S(m)`；再加 §3.2 的**硬保护名单**。

### 3.4 睡眠的其他作用（固化 / 反思 / 日结）
- **固化**：夜间对当天 EM 按 `subject` 聚类 → 生成 SM（"我对阿林的印象：爱打听消息、做生意精明"），并强化被引用 EM 的 `S`（`consolidated=1`）→ **降低其遗忘速率**（睡眠"加固"重要记忆）。
- **反思**：沿用现有 `MEMORY_REFLECT`（阈值/周强制），产物入 RM，并被 §1.2 用作**人格漂移候选**（受 `δ`/冷却约束）。
- **日结**：写入 `TIME_MARK` + 当日统计快照（供观测层/前端）。
- **预算复位**：重置本周检索/反思配额计数。

### 3.5 成本（`【设计】`）
- 遗忘评估 = **纯计算**（0 LLM）；固化/反思 = **夜间批处理**，每 agent 每晚 ≤ 1 次聚合 + ≤1 次反思 → **≤7 次/agent/周**。
- **收益**：遗忘**降低** EM 基数 → **降低**检索注入 token 与侧存储体积（长期反而**省钱**）。
- **50 agent**：新增 ≤ `50×7 = 350 次/周`（可与反思合并摊薄）。**负担得起**。

## 4. 行为拟人化（M-H）：像人

### 4.1 值得做的清单（按性价比排序 `【设计】`）
| # | 行为 | 机制 | 成本 | 优先级 |
|---|---|---|---|---|
| 1 | **作息节律** | 睡眠/工作/社交按时段与 `work_ethic` 分布 | 0（规则） | **P0** |
| 2 | **情绪** | `mood` 维度：随事件确定性升降（NPC 死亡 -、被救助 +、成交 ±），影响措辞与活动选择 | 低（进 prompt 身份段） | **P0** |
| 3 | **习惯/口头禅** | 每 agent 由 persona 派生 `top_phrase` + 高频活动偏好；进 prompt "说话风格" | 0（规则） | P1 |
| 4 | **关系驱动行为** | 关系强度影响谁被联系、响应优先级（已在 `RELATION_CHANGE`） | 0 | P1 |
| 5 | **响应延迟** | 回复不即时（隔 k 回合），k 由关系/情绪/忙碌决定 | 0 | P1 |
| 6 | **不一致性（人也有矛盾）** | **受控**的偶发偏离：以概率 `p_dev`（默认 0.1）偏离模板活动/改变主意 | 0（RNG，确定性种子） | P1 |
| 7 | **记忆偏差** | 记忆措辞随遗忘降级而"模糊化"（§3 的 L1） | 0 | P2 |
- **红线**：不设"预设剧情"；不一致性是**统计属性**（有分布、可复现），非脚本。

### 4.2 "像人"怎么度量（**两类判据**）
**A. 可复算指标（来自日志，`【设计】`）**
```
① 作息规律性 regularity = 1 − normalized_var(每日 sleep_start_tick)         ∈[0,1]，目标 0.5–0.9（太规律=机器，太乱=失序）
② 行为熵 act_entropy   = H(activity_type 分布, 窗口) / ln(8)                可用性 + 多样性
③ 口头禅稳定 phrase_stability = 每 agent Top1 短语在窗口间的频次一致性      ∈[0,1]
④ 承诺-行动一致率 consistency = 1 − 违诺数/承诺数（从 INTENT 与后续事件算）
⑤ 偶发不一致率 deviation_rate = 偏离模板活动数/活动数                       应落在带内 [0.05,0.25]（0=死板、过高=噪声）
⑥ 响应延迟分布 reply_latency = 中位数/分位数（回合）
⑦ 情绪波动 mood_volatility = var(mood)/窗口
```
**B. 人工验收量表（Turing-like，1–5 Likert，`【设计】`）**：见 §5.2。抽样 N≥20 agent × 若干窗口，评审读"角色视角故事线"打分。

## 5. 验收判据总表

### 5.1 人格一致性（**必须可交付**）
- **可复算（硬门禁）**：1000 回合后 `drift ≤ 0.15`、`max_i drift_i ≤ 0.20`、`|slope_i| ≤ 0.01/周`、`PF0` 不变、`replay_parity=True`、无越限 `PERSONA_DRIFT_REJECTED`。
- **人工量表**（对同一 agent 的三个时间切片盲评）：
  | 维度 | 1 分 | 5 分 |
  |---|---|---|
  | 身份稳定 | 判若两人 | 明显同一人 |
  | 价值一致 | 价值观前后矛盾 | 一致 |
  | 可成长但可信 | 要么僵化要么乱变 | 有变化但合乎经历 |
  - 通过线：各维均值 ≥ 4.0，且"判若两人"出现率 ≤ 5%。

### 5.2 "像人"验收
- **可复算**：§4.2 A 的指标落在目标带内（regularity∈[0.5,0.9]、deviation_rate∈[0.05,0.25]、act_entropy≥0.5、consistency≥0.85）。
- **人工量表**（Turing-like）：
  | 维度 | 1 分 | 5 分 |
  |---|---|---|
  | 可信度 believability | 明显是脚本 | 像真人 |
  | 自发性 spontaneity | 机械 | 会主动做事 |
  | 情境贴合 | 答非所问 | 贴合处境 |
  | 行为连贯 | 前后割裂 | 有前因后果 |
  - 通过线：各维均值 ≥ 3.5；且"像真人"与"明显脚本"比例 ≥ 2:1。

### 5.3 记忆正确性
- 遗忘曲线**纯函数 golden 测试**通过；`recall@keep`（被保护记忆在窗口后的可检索率）= **100%**；`MEMORY_FORGET` 事件可从日志复算。

## 10. 结论速览
1. **人格连续稳定** = 卡（锚，不可写回）+ 有界漂移向量（均值回归 + 冷却）+ 指纹观测；判据 = 1000 回合 `drift≤0.15`（可复算）+ Likert 量表（人工）。
2. **记忆** = 四层（WM/EM/SM/RM）+ 六因子检索 + 压缩摘要；token 靠检索截断/批量/聚合/遗忘控制。
3. **睡眠与遗忘**（点名缺口）= 睡眠作为离线运维窗口，遗忘用**定点保留度 + 三级处理 + 保护名单**，纯函数可复算，且**降 token**。
4. **像人** = 作息/情绪/习惯/延迟/受控不一致；判据 = 可复算指标带内 + Turing-like 量表。
5. **成本**：不增决策类 LLM 调用，夜间运维 ≤7/agent/周；**50+ agent 负担得起**。
