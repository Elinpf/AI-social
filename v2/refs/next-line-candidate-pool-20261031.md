### 3.1 为什么**不能**用 `gap=0` 占比当主判据（三条硬风险）

| 风险 | 说明 |
|---|---|
| **① 基线为 0，没有下限** | 实测 `0/125`：干预让 **1 条**变同轮即 `0.80%`、**2 条**即 `1.60%`。从 0% 到 1.6% 读起来像"质变"，**实际只动了 2 对**。任何 X% 阈值都与"像不像当面说话"无对应关系 |
| **② 分母随干预漂** | 分母 = Σ(线程轮数−1)：干预若让线程变短（两句就散）⇒ 相邻对总数下降 ⇒ 占比被放大。**与我们踩过的 `H_norm_nonempty`、`(d2)` 分母 9 是同一族** |
| **③ 可被"变碎变多"旁路** | 一轮内连发多条 / 缩短单条，`gap=0` 自然上升，但那是"变碎变多"不是"变快" ⇒ 必须有 MSG 总数、线程数、单条字数三护栏 |

⇒ **⚠ 上面"`rounds 84` 就够"是错的**（`repro-verifier` 更正）：`16 agents × 84` 仅 ≈457，**要 `16 agents × 110`（≈100 分钟）才到 598**。

| 组合 | 估算相邻对 | 墙钟（按"`rounds` 线性、`agents` 免费"外推） |
|---|---|---|

### 3.6 `32 agents × 8 rounds` 小样本：**三项产出 + 两条预置判读**（`repro-verifier` 定稿）

> **它不是"预演跑批"，是"标定三件事"**：斜率、降级率、墙钟。三项都拿到，`N` 与 `gap≥2` 才有依据。

| # | 产出 | 为什么必须 |
|---|---|---|
| 1 | **每轮相邻对斜率**（对/轮） | 验证 16 agents 下的 **5.43** 在 32 agents 下是否仍成立 —— **"愿意聊的人"比例可能被摊薄** |
| 2 | **持续并发下的 `degraded` / 重试次数 / `tokens_in` 是否漂移** | 这才是"长时承压"的真指标。**突发压测只能证明"没被拒"，证明不了"没被降速降质"** |
| 3 | **墙钟（含启动 + 收尾）** | 替换所有外推 |

**⚠ 单点标定分不清机制（`research-writer` 指出，Leader 采纳）**：
> 只测"一个 `32×8`"时，`∝n` 与 `∝C(n,2)` **都能拟合出一条直线** ⇒ **必须两维各动一次**：
> **①固定 `rounds=8`，`agents` 取 16 与 32；②固定 `agents=16`，`rounds` 取 8 与 15**（后者可与既有 `16×24` 对照）。
> ⇒ **标定卡从"单点"改为"两点以上"，否则只能得到斜率、判不出机制。**

**精确公式（`repro-verifier` 修正到"配对数"层，Leader 采用）**：
```
相邻对 ∝ 配对数 ≈ places × C(agents / places, 2) ≈ agents² / (2·places)
⇒ 倍率 = (agents₂/agents₁)² ÷ (places₂/places₁)
   agents 16→32、places 不变 ⇒ 4.0 倍 ⇒ ≈157
   agents 16→32、places 翻倍 ⇒ 2.0 倍 ⇒ ≈76
```
⇒ **`76` 与 `157` 不是两个"机制假设"，而是同一公式的两个端点：关键变量是 `places` 有没有一起翻倍。**

| 实测 | 对应配置 |
|---|---|
| **≈157** | agents 翻倍、**places 不变**（每处更挤） |
| **≈76** | agents 翻倍、**places 也翻倍**（每处人数不变） |
| 100–140 | places 部分增加（**中间配置，不是异常**） |
| **显著低于 76（≤50）** | 才真的可疑（摊薄或配对数没兑现） |

⇒ **卡面必须同屏报「`places` 数 + 每 place 人数分布」**（§11 第④行：配对数怎么数本身就要写死）。
> **口径待定（两值不一致，先不取一）**：Leader 按"每 place 去重 agent 再累加 `C(n,2)`"得 **13 places / 246 对**；`repro-verifier` 报 **15 places / 360 对**。**差异须先对齐**（按 place 去重 vs 按轮快照累加），否则 `157` 与 `76` 的基准数本身不一致。

**预期区间：两个**机制假设**并列，不是一个预期值****预期区间：两个**机制假设**并列，不是一个预期值**（`repro-verifier` 两版计算 + Leader 复算；**这是本节最重要的一处更正**）

```
基线斜率 5.43 对/轮（= 125 / 23 有效轮，16 agents）；32×8 有效轮 = 7

假设 A｜相邻对 ∝ agents（线性）
   5.43 × 2.000 × 7 = 76.1
假设 B｜相邻对 ∝ C(n,2)（平方，可配对数）
   C(32,2)/C(16,2) = 496/120 = 4.133
   5.43 × 4.133 × 7 = 157.2
摊薄档（每轮对数不随 agents 涨反降 50%）= 38.0
斜率 <5.0 档 = 35.0
```

| 实测相邻对 | 机制判读 | 对 `agents × rounds` 规模公式的含义 |
|---|---|---|
| **≈157（150–165）** | **平方增长**：每轮"可配对数"被充分使用 | 加 agents **极划算**（`64×24` 可达 ~600 且墙钟不变） |
| **≈76** | 线性增长：只有固定比例的 agent 在说 | 收益线性，规模须 `agents × rounds` 同倍增长 |
| **38–60** | **摊薄**：agents 翻倍但对话对没跟上 | 性价比重算，可能回到加 `rounds` |
| **≤35** | 斜率 <5.0 | 回到加 `rounds` |

> **⚠ `76` 与 `157` 都是"正常"，只是机制不同** —— **不要再用单一预期值判"超预期/不及预期"，要用"落在哪个假设的邻近区间"判机制。**
> ⇒ 因此本批第 1 项产出的价值**不是"斜率会不会摊薄"，而是"相邻对随 agents 是线性还是平方"** —— **这个答案直接决定 P1 怎么定。**

**两条判读规则（跑前写死，免得跑完再讨论）**：
1. **斜率 < 5.0**（比 5.43 低 8% 以上）⇒ **加 `agents` 会摊薄对话密度**，"加 agents 换样本"的性价比须重算，可能回到"加 `rounds`"；
2. **`degraded > 0`** ⇒ 判"32 agents 超 provider 承受力" ⇒ **该批不得用于估算墙钟**（降级会同时改变耗时与质量）。

**斜率分母写死：`rounds − 1`，不是 `rounds`**（`round 0` 是纯预热轮）。实证（本臂）：
```
round 0：MSG 12 条、相邻对 0 个      ⇒ 纯预热
125 / 24 = 5.21（错，系统性低估；8 轮样本下低估约 12.5%）
125 / 23 = 5.43（对）
```

### 3.5 扩规模前必须做的两项小样本验证（**否则会重演"看起来卡住"**）

1. **斜率验证**：先跑 `32 agents × 8 rounds`，确认"每轮相邻对"是否仍 ≈5.2（**配对数上升，但"愿意聊的人"比例可能下降** ⇒ 不能线性外推）；
2. **并发压测已完成（`repro-verifier` 实测，`α` 为负）**：

   | 并发 | 总耗时 | 成功 | 单条 |
   |---|---|---|---|
   | 16 | 1.51 s | 16/16 | 1.32–1.51 s |
   | 32 | **1.16 s** | 32/32 | 0.90–1.15 s |
   | 48 | **1.28 s** | 48/48 | 0.97–1.26 s |

   ⇒ 实测 `α(32) = −0.378`、`α(48) = −0.154` ⇒ **并发在 48 以内近乎零成本**（服务端做了批处理/预热）。
   ⇒ **时间只随 `rounds` 线性涨**；因此**优先加 `agents`**，不必再加 `rounds`。

   **⚠ 必须同屏的边界**：该压测是"**48 条独立请求打一次**"，**不是"48 agents 持续跑 24–40 轮"**：
   - **短时突发 ≠ 长时持续承压**（限流、队列累积、连接复用未测）；
   - 压测 prompt 只有几十字，**实际 prompt 是几百字 + `thinking`**。
   ⇒ **"`α≈0`"只对短时突发成立**；长时持续下仍可能退化。
   ⇒ **最终墙钟以 `32 agents × 8 rounds` 小样本实测为准**；上表 `48×40 ≈37 分钟` 只是**上界估计**。

**两条手段分工（不可互相替代）**：

| 手段 | 解决 | 不能解决 |
|---|---|---|
| 跨批次复现 | **真实性**（现象真的存在） | **分辨率**：两批各 125 ≠ 一批 250；"都没检出" ≠ "效应不存在"，只是"看不见" |
| 扩大 `rounds` | **分辨率** | 不能替代"是否偶然" |

⇒ **`N` 与 `gap≥2` 阈值必须"按扩后 `n` 重算"，现在不得冻结。**
⇒ `gap=0` 条数可作**真实性**证据（`N` 取小值 + 两批复现），与 `gap≥2` 分工：**一个管"有没有"，一个管"够不够"。**
