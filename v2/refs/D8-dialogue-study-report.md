## §1 问题与背景：AI 小镇要什么

### 1.1 要的是什么

要让 AI 小镇里的居民"说话像人"，且这件事**可被外人亲眼看到、可被独立复算**。这不是一个主观审美要求，它落在三个可检验的位置上：① 对话在**结构**上是否表现为多轮往复（不是各自喊一句）；② 对话在**措辞**上是否贴合人设与情境（不是模板句）；③ 这两点是否有**读数与原文**支撑，而不是"看着挺好"。

### 1.2 底座是什么

**【事实】** 底座是「确定性内核 + life 生活层 + obs 观测层 + frontend」四层。内核按固定六阶段编排：`P0 ROUTE → P1 PERCEIVE → P2 DECIDE → P3 COMMUNICATE → P3.5 LIFE → P4 ARBITRATE → P5 LIFECYCLE → P6 COMMIT`；所有状态变更只经中央裁决器，事件以哈希链形式追加，每回合末追加 `TURN_SEAL`（来源 `code/README.md` §3.1–§3.2，锚点 `b79f07e`）。

**【事实】** 重放语义是 `replay(log) = reduce(apply_event, EventLog, InitialState(seed))`，**不重跑 hook**；同一日志重放两次 `state_hash` 必须相等（来源 `code/README.md` §3.4）。

**【事实】** 设计上的分工原则：世界随机由确定性内核决定，LLM 只"填已定分支的内容"——`code/life/llm.py` 文件头原文："the life layer never decides world randomness from LLM output; it only fills already-determined branches with content"。这条原则决定了后面 §2 与 §7 的一个关键边界：**世界可逐位重放，措辞不能**。

**【事实】** 时间结构：1 时段 = 3 回合，1 日 = 4 时段 = 12 回合，1 周 = 7 日 = 84 回合（来源 `code/config/default.json` 的 `time_config`：`ROUNDS_PER_SLOT=3`、`SLOTS_PER_DAY` 四项、`DAYS_PER_WEEK=7`；并见 `code/engine/time.py:3` 头注释、`code/engine/cli.py:22` `WEEK_ROUNDS = 84`）。

### 1.3 改造前到底长什么样（这是本报告的起点）

本轮改造前，对话链路被勘察确认为「**决策 → 单条措辞 → 一条事件**」，没有"会话"这一层：

**【事实】** 每条 `MSG_*` 都是**独立单发消息**，不是会话中的一轮（来源 D1-现状勘察.md §0 结论 1，证据 `life/agent.py:729-767`、`orchestration/integration.py:739-841`）。

**【事实】** `reply_to` / `in_reply_to` / `thread_id` 在整仓库代码与文档中 **0 命中**（来源 D1 §0 结论 2，检索命令见该文附录 A）。`topic` 键只在 `MSG_PUBLIC` 存在但**恒为 `null`**（`orchestration/integration.py:814` vs `life/agent.py:763`）。`refs`（唯一可能"引用另一条消息"的通道）在 life 侧**恒写 `[]`**（`life/agent.py:763`）。

**【事实】** 生成对话的提示词只含「人设压缩档案 + 场景模板 id + 对象名 + 一句指令」，**不含**最近对话、对方上一句、关系亲密度、情绪、地点、时间（来源 D1 §1.3，`life/agent.py:769-772`）。

**【事实】** 结构字段缺失的后果被 D1 明确写出：消息层没有会话对象，"对话深度"只能靠"同一对 agent 的 DM 是否连续回合出现"近似（D1 §1.5 末段）。

**【判断】** 上述四条合起来给出一个**结构性的、而非调参性的**结论：生成时看不见对方说过什么，就不可能出现"你来我往"。因此本轮把"线程化"当作靶心，而不是继续调措辞。**这条判断是本报告的唯一立论基础**，若它不成立（例如另有隐藏的上下文通路），后续全部结果都要重读——D1 §1.3 是该判断的证伪入口。

## §2 方法

### 2.0 本报告的可信边界清单（请先读这六条，再读任何数字）

本报告的每条结论只在其边界内成立。六条边界如下，凡是超出边界的读法都不成立：

1. **措辞不可逐条复现** —— 世界状态可逐位重放，但重新生成不会得到同一句话（`code/life/llm.py` 头注释；§2.1、§7.1）。措辞证据是**冻结快照**，不是"可重跑"。
2. **mock 不可测措辞** —— MockProvider 按 `hash(system+user)` 从词池取句、不读语义，故 mock 上任何提示词改动都不可测；措辞层结论**只能来自真 LLM 臂**（§7.2）。
3. **单批 + 噪声带** —— 单 seed、单批次，不做显著性主张；两臂差值须同时超过 null-pair 噪声带与合并 CI 才称结论，`|vs_null_band| ≤ 1` 只记「印象」（§2.4b、§7.3）。
4. **冻结与受控解冻** —— 本轮只对"对话路径"受控解冻，经济/生命周期/世界层数值行为仍冻结；改动范围与回退方式见 §2.5。
5. **规模豁免** —— 84 回合超出本轮默认 ≤24 回合约定，属 Leader 批准的一次性豁免，不推广（§7.3）。
6. **副本结论需标副本 sha** —— 任何非主树读数必须标副本 sha 并注明"落地需复核"（§7.7）。
7. **所有计数均为事件级，不是人次级** —— 本报告的 `MSG_*` 计数、`LLM_CALL` 计数、指标分母全部以**日志事件条数**为单位，不是"多少人说/说了几次"。本项目历史上已出现同名不同义（双计、per-agent 与 per-round 混用），故在此一次性声明：凡正文出现"条"，默认 = 事件级；凡出现 per-agent-round / per-thread 等统计单位，均按 `D5-指标定义-定稿v1.0.md` §0 的定义使用，不与事件条数换算。

> 这六条不是免责声明，而是**判读说明**：它们告诉你"哪句话可以信到哪一步"。若正文某处与本节冲突，以本节为准并把该处视为待修。

### 2.1 为什么这套底座能做对话实验

**【事实】** 三层保障：① 世界状态由确定性内核 + 哈希链承载，可逐位重放；② LLM 输出一次生成后**冻结**，重放链路不再调用模型（`code/life/llm.py` 头注释 + `freeze/` 层）；③ 观测层 `obs` 只读日志、且构造时先校验哈希链，非法日志直接拒绝（`obs/reader.py:24-50`，经 D1 §1.6 转述）。

**【判断】** 因此本实验的可复算性只覆盖"**事件流与世界状态**"，不覆盖"**措辞文本**"。任何把措辞层的差异说成"重放可复现"的表述都是错的；措辞层能保证的是"**同一次冻结快照可被反复读取**"，不是"重新生成会得到同一句话"。这一点写进 §7 局限第 1 条。

### 2.2 线程化对话（D2）

**【事实 · 待 D2 正式文档定稿】** 与 dialogue-core-dev 对齐的口径（**以 D2 交付文档为准**，本报告在 D2 落地后回填路径与 sha）：
- 只**追加字段**、不新增事件类型：`MSG_DM` / `MSG_PUBLIC` / `MSG_GROUP` 的 payload 增加 `thread_id`、`turn_index`、`reply_to`、`participants[]`、`ctx{relation,mood,need,topic}`。
- `thread_id` 生成侧保证全局唯一：DM `TH-<发起人>-<对方>-<round>`；GROUP `TH-<发起人>-G<group_id>-<round>`；PUBLIC `TH-<发起人>-PUB-<round>-<k>`（k 为本 round 该 agent 的 PUBLIC 自增序号）。
- 线程边界**只约束生成、不参与复算**：发起且无未回应入站 → 新建线程（`turn_index=0, reply_to=null`）；作答 → 沿用 `thread_id`、`turn_index=max+1`、`reply_to=被回复 msg_id`；结束条件 = 达 `max_turns`（默认 6）/ 末条后 2 回合无回应 / 参与者离开场所 / 出时段。
- **复算规则**：按 `thread_id` 分组、`(round, seq)` 升序即得线程；轮次 = 组内条数；无 `thread_id` 的旧日志计为单发线程（长度 1，标注 `legacy`）。

**【判断】** 把"边界规则"与"复算规则"分开是这份方法里最要紧的一处设计：边界规则变了只影响新生成的世界，不会让人重算旧日志时得出不同数字。任何读者按上段复算规则都能得到与报告一致的线程切分。

**【未完成】** D2 的 before/after 两臂尚未跑完；两臂必须同 `n`/`rounds`/`seed`/`provider`（本轮 n=12、rounds=84、seed=42、provider=openai_compat），否则差值不进结果栏。

### 2.3 措辞与 persona（D4）

**【事实】** 迭代工具 `tools/prompt_iter/prompt_iter.py` 的既有方法与限制：只改一处提示词（T362 用 `prompt_sha 88ddbb92e20029e4 → 0261445defb9fdca` 证明改动生效）；读数分行为面/措辞面/成本面三面；真 LLM 迭代必须用副本并登记 `PROMPT_ITER_COPY_SHA`，否则会在主树上跑；`_prompt_sha` 只哈希 `life/agent.py|soft.py|planner.py` 三个文件，改别处它感知不到（来源 D1 §4.2，转引 `v2/evidence/T362-real-llm-prompt-iteration.md`）。

**【事实】** mock 下改提示词**无意义**：MockProvider 按 `hash(system+user)` 从词池选句，不读语义（`v2/evidence/T356-prompt-iter-demo.md:27`，经 D1 §3.2/P12 转述）。

**【判断】** 因此本轮措辞层结论**只能在真 LLM 臂上产生**；mock 臂只能验证"行为面无变化"，不能作为"自然度"证据。报告的每张措辞读数表都会标注 provider 与证据级。

### 2.4 评测口径（D5 定稿 v1.0，全队唯一口径源）

**【事实】** 指标分四层且**统计单位不同**：结构层 per-thread（S 系列）、话题层（K 系列）、措辞层 per-message（L 系列）、效率层 per-agent-round（E 系列）；judge 单列 J 系列。**禁止**把 per-message 均值冒充 per-thread，**禁止合成单一"自然度总分"**（来源 `D5-指标定义-定稿v1.0.md` §0）。

**【事实】** 前后对照的主口径是 **S-1 A（说话人交替轮次）**：`turns_A = 1 + #{i : speaker(m_i) ≠ speaker(m_{i-1})}`，不依赖 `reply_to`，故 v0 与改造后都算得出；**S-1 B（往复对数）只报后臂、不参与前后差**（改造前无该字段，报 0 并标"字段缺失，非缺陷"）（同上 §1 S-1）。

**【事实】** 碎片化的核心判据是 `single_msg_thread_ratio`，且裁决为**长度 1 的线程不剔除、进入分母**，只单列比例（同上 §2 S-2）——这条裁决方向明确：剔除会让结果人为好看。

**【事实】** 证据级字段 `evidence_level ∈ {probe, evidence}` 必须标在每张读数表上；`meta.json.provider` 为空/缺失即**非证据级、不进对照**；mock 组与真 LLM 组**永不混算**（同上 §0）。

**【事实】** judge 抽样以**线程**为单位，每臂 12 条线程、每条取首条 + 随机 2 条、每臂 ≤36 条消息；同批重复评 2 次并报 exact agreement、Cohen's κ 与 Spearman ρ；judge 只评质量维度，**不替代**客观读数与原文样本（同上 §5 J 系列）。

**【判断】** 本报告不会出现"整体更自然了"这类总结论，只会出现"某编号指标在某个统计单位上从 A 到 B，附原文样本与 judge 结果；若两者冲突，冲突原样保留"。

### 2.4b 分母门槛、置信区间与噪声带（决定"能不能称结论"）

**【事实】** 来自 `D5-基线准入清单v1.1.md`（sha256 `19e00fcd91978b564ad8ca078434a089d76337551c9557f8914ed070718e47f1`）：
- **v0 基线（before 臂）**：`MSG_DM ≥ 60`，且覆盖 **≥10** 个不同 `(day, {from,to})` DM 会话线；另要求 `degraded_calls / llm_calls ≤ 5%`、`round` 集合 `0..R-1` 连续无洞、`verify_chain` 通过（B-9~B-18）。
- **同 seed 对照两臂**：**每臂 `MSG ≥ 150`**（v1.1 §4）。
- **低于门槛的批次**：只做原文抽查 + 标 `probe`，**不出比率结论**（§4 末行）。
- **本轮实际分母（Leader 裁决，全队统一）**：**n=16 × 84 ≈ 188 条 `MSG`/臂**，故上述两档门槛均满足；本报告所有比率表分母统一写 **≈188/臂**。

**【事实】** 同一文件的置信区间换算：比率 p 在分母 m 下的 95% CI 半宽 ≈ `1.96·√(p(1−p)/m)`；示例 p≈0.5 时 m=60 → ±12.6pp、m=150 → ±8.0pp、m=230 → ±6.5pp。两臂差值只有**同时大于噪声带与各自 CI 合并后的幅度**才可称结论。

**【事实】** 噪声带采用**两级口径**（`v2/evidence/D3-noiseband-two-level.md`，sha256 `12416374add21ca9feb762de27be2a75e5ef8b53a6ff3e29b86d9fa9533d8f6b`；脚本 `v2/evidence/d3_noiseband_bootstrap.py`，sha256 `d878ac643716f437c57cc12753fd667bb49c2dd3d9dbda4bc72121a84d822986`）：
- **B1 观测对差**：t300 vs t355 单次实测，旁白 0.87pp / 裸 ID 0.87pp / 无人称 1.75pp。**这是一次观测，不是带**，只作**差异量级参照**，**不作阈值**；
- **B2 抽样噪声带**：对两批消息级重采样 2000 次（seed=42），取比率差的 2.5–97.5 分位 ⇒ **n=230 ±8.7pp；n=170 ±10.6pp（L-8 裸 ID ±10.0pp）；n=100 ±13–14pp；n=68 ±16pp**。**判定阈值用 B2 的同分母上界**。
- **规模适用**：B2 依赖分母。本轮 D2/D4 两臂 n=16×84（≈188 条 `MSG`，扣除 group 后**有效分母约 170**）⇒ **采 n=170 档**；跨规模（如 t350 50×12）**不适用**。

**【判断】** 本报告的口径句固定为：`|Δ|` 超过同分母 B2 上界 ⇒ 记「**带外（结构性）**」；否则记「**带内，仅印象**」。**不得**用 B1 的 0.87–1.75pp 当阈值——两次跑的实测差小只说明那次运气好，不说明分布窄。

**【判断 · 一条正面证据】** `B1 ≪ B2` 本身说明：两次跑之间**结构性成分高度一致**（说话人/渠道/模板序列 230/230 对齐），差异集中在**措辞层**。这恰好是 §1.2 "世界确定、措辞非确定" 分工原则的实测印证，也是本报告能同时给"结构可复算"与"措辞只可快照"两种证据的原因。

**【判断】** 这三件（门槛 / CI / 噪声带）是本报告"不吹"的技术落点。**写读数时必须三者成对**，不许只写其中一个：

| 判定情形（三件同引） | 报告写法 |
|---|---|
| `\|Δ\| >` 同分母 B2 上界 **且** `\|Δ\| >` 合并 CI | 可写「在本配置/本规模/本 seed 下观测到 X 由 A 到 B（Δ=…, B2 上界=…, 合并 CI=…）」 |
| `\|Δ\| >` B2 上界 **但** `\|Δ\| ≤` 合并 CI | 必须写「**不足以下结论**」（不得写"有改善趋势"） |
| `\|Δ\| ≤` B2 上界 | 只能写「带内，仅印象」，**不得称改善** |

**【判断】** 这样写的理由很实际：读者不可能只看到"Δ=6pp"就判断它对不对，必须同时看到"噪声带多宽、CI 多宽"。把三者拆开写，等于把判读责任推给读者。

**【未完成】** ① `D5-评测方法.md` 与 `dialogue_noiseband.py` 尚未读到，噪声带的 band 数值待补；② **分母格局已定（Leader 裁决）**：本轮**全队统一 n=16×84 ≈188 条/臂**（D2 两臂与 D4 两臂同规模），单一种分母，`vs_null_band` 与 CI 都同分母可比；p≈0.5 时 CI 半宽 ≈ **±7.1pp**（`1.96·√(0.25/188)`）。③ **中止留痕**：D2 before 臂曾以 n=12 起跑，约 4 分钟后中止并改 n=16 重跑；**该批不作为任何基线或对照，不入结果**，仅记录以说明本轮未发生选择性丢弃。

### 2.5 受控解冻（本轮的"受控偏离"小节）

**【事实】** 对话链路的两个靶心——`life/agent.py::_dialogue_prompt`（提示词）与给 `MSG_*` 追加线程字段——都落在世界层冻结区内（`v2/00-anchor.md:190,205`；经 D1 §2.2 核实）。Leader 裁决为**对"对话路径"做受控解冻，其余冻结不动**：

- **仍然禁止**：经济结算、生命周期、世界层数值参数、`world_director` 双事件 did（T372 保持未修）、T373 收口。

**【未完成】** D2/D4 交付文中的「受控偏离」小节尚未见到；本报告在 D8 定稿前会逐条核对四条前提是否真的满足（尤其②回退开关与③向后兼容）。

## §7 局限与失败案例

本节在成稿前不会缩短。凡未解决的，一律标注，不用"未来工作"淡化。

### 7.1 措辞层不可逐位复现
**【事实】** LLM 只填已定分支内容，世界状态可重放，但重新生成不会得到同一句话（`code/life/llm.py` 头注释；§2.1）。**【判断】** 所以措辞层证据是"冻结快照 + 当时 provider/model/温度"，不是"可重跑得到同结果"。报告引用任何措辞原文，都必须能追到具体 `run.jsonl` 与 sha。

### 7.2 mock 臂不能证明"自然度"（本报告最重要的一条边界）

**【事实】** MockProvider 按 `hash(system+user)` 从词池取句，**不读语义**（`v2/evidence/T356-prompt-iter-demo.md:27`，经 D1 §3.2 / P12 核实）。

**【判断】** 由此可直接推出三条连锁结论，本报告全程遵守：
1. **mock 上任何提示词改动都不可测**——改了提示词，mock 的输出分布不会因为"更自然"而变化，只会因为 hash 变了而换一批句子。所以 mock 臂上"改了没变好"**不构成反证**，"改了变好"也**不构成正证**。
2. **本项目的措辞层结论只能来自真 LLM 臂**。所有 L 系列（措辞层）读数表都会标注 `provider`，`provider` 为空或含 `mock` 的表**不进对照**（D5 定稿 §0）。
3. **即使真 LLM 臂，措辞也不可逐条复现**：`temperature=0.0`（`code/freeze/llm_client.py:263`）下，同 seed、同 provider、同提示词的两批真 LLM（t300 / t355，各 230 条）**台词逐字节相同仅 49/230 = 21.30%**；`strip` 后与归一化后均为 49/230 ⇒ 差异不是空白或标点造成；同位置说话人 230/230 相同、渠道序列 230 位一致 ⇒ 对齐有效，但同位置 `seq` 相同仅 28/230 ⇒ **禁止按 seq 对齐**。因此措辞证据的正确形态是"**冻结快照 + 当时的 provider/model/温度 + 可追到 run.jsonl 的 sha**"，且**只能做分布级比较，不能逐条配对比较**。
   （来源 `v2/evidence/D3-null-pair-t300-t355.md`，sha256 `79d9ea19f91ea7fb782044e521d586dcd6bfa3fc2894ec8731fe0ef76bd04ba8`；复算 `python3 v2/evidence/d3_null_pair.py`；脚本与结果 sha 见该文 §6）
   **两条不得越界的读法**：① 这是"**近似** null pair"（两臂树不同、`_dialogue_prompt` 未变），只能当**噪声下界**，不是"零差异应然值"；② **不得**把 21.30% 当作"复现率下限"去要求别人复现到 21%，它只是同一批配置下的观测值（同上文 §5）。

**【判断】** 这条不是短板，而是**诚实性证明**：如果一个团队说"我们把对话调得更自然了"却不区分 mock 与真 LLM、不声明不可复现，那它的措辞结论就是无法被检验的。本报告宁可承认"措辞层只能给快照"，也不把不可复现的差异包装成可复现的结果。

### 7.3 规模与噪声
**【事实】** 本轮规模纪律原为 n≤12、回合≤24；D2/D4 批次经 Leader 批准豁免至 **84 回合（= 1 个模拟周：3 回合/时段 × 4 时段/天 × 7 天/周，来源 `code/config/default.json`（sha256 `a94fba10e6d71ea0b9c12d2513e74fc0be2d3a70ad3d8468863e23e207e6ab8d`）、`code/engine/time.py:3`；批次实际 **n=16、rounds=84、seed=42、provider=openai_compat`）**。豁免理由：24 回合内跨回合线程几乎不可观测（84 回合覆盖 28 个时段、7 个日边界），会使 D2 的核心论证失去观测窗口。影响：成本约为常规批 3.5 倍、墙钟 55–90 分钟/批，期间全队停跑。适用范围：仅本轮 D2/D4 批次，**不推广为通用规模**。

**【事实 · 中止留痕】** D2 before 臂曾以 n=12 起跑，约 4 分钟后中止并改 n=16 重跑；**该批不作为任何基线或对照，不入任何结果表**，此处记录仅为说明本轮未发生选择性丢弃。全队统一 n=16×84（≈188 条 `MSG`/臂）的理由：① D2 的结构指标分母实为**线程数**，比 `MSG` 更小、CI 更宽，对分母更敏感；② 一种分母 = 一套噪声带、一套 CI、一张表；③ null-pair 噪声带本身是从特定规模估的，跨规模通用性需再论证；④ 代价仅是 agents 12→16（约 +33% 调用），换来 D2 与 D4 可放同一张图比较。

**【判断】** 全队统一 n=16 之后，"同规模"本身成为证据质量的一部分——不同分母的两组读数即使方向一致，也不能叠加成一个更强的结论。
**【判断】** 单 seed、单批次 ⇒ 不做显著性主张；"规模是否足够"以 eval-researcher 的门槛与噪声带结论为准（每臂 ≥150 条 `MSG` 分母），本报告不自行评价。

### 7.4 judge 的自评偏差与样本量
**【事实】** judge 每臂 12 条线程、≤36 条消息、重复 2 次做一致性（`D5-指标定义-定稿v1.0.md` §6）。**【判断】** 样本小、且 judge 与被评系统同源，存在偏好同类的风险；报告只把 judge 当"旁证"，不当"判决"。

### 7.5 已知口径陷阱（会被误读的那些）
按 D1 §5 原样列出与本报告相关者，引用时不得混用：
- **P2** `LLM_CALL` 条数 ≠ 实际调用次数（命中缓存也各记一条）⇒ 报成本必须说明口径。
- **P5** `MSG_PUBLIC` **不产生沟通图边**（`_comm_edges` 里 PUBLIC 分支靠 `refs` 反查，而 `refs` 恒空）⇒ 不能用"沟通图密度"论证"公开讨论活跃"。
- **P6** `MSG_GROUP` 一条消息 = N-1 条边，与 `MSG_DM` 的 1 条边**权重语义不同**。
- **P13** 加字段会让**哈希链变**但 `state_hash` 不变（②档）⇒ 不能把"链变"说成"行为变"。
- **P1** 两个"2×"不是一回事：`world_params` 同 `directive_id` 双发累加（T372 未修，真缺陷）vs `LLM_CALL` 的"2×"（已结案假象）。**绝不能并成一条**。
- **P3** `make gate` 同名不同义：仓根 = 术语棘轮+单测+插件；`code/` = 前端真渲染门禁。

### 7.6 世界层强度 2× 口径未修
**【事实】** `world_director` 一拍发两条事件共用同一 `did`，导致 `world_params` 逐条累加（世界层强度 ×2），已立 `T372`，**未修（停手冻结中）**；登记位置为 `v1.1/08-engine-stats-extension.md` §1.2 T.6（**不是** 07 号文档，07 中 0 命中）（D1 §1.7、§5 P9）。**【判断】** 本报告凡引用世界层强度绝对值，一律注明"2× 口径、T372 未修"；对话结论本身不依赖该数值。

### 7.7 副本树结论的边界
**【事实】** 任何基于副本/worktree 而非主树的结论，必须标副本 sha，落地需复核（Leader 裁决 + D1 §2.3）。**【判断】** 报告出现副本读数时，"可在主树复现"这句话不能写。
