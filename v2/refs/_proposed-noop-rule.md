## 0. 规则一句话

> **凡件里写了「已做某步清洗/筛选/去重/剔除」，必须同屏给出该步的「操作前值」与「操作后值」两个数；两值相等时，必须写明「本批该步为空操作」。**

判据是**两个数是否相等**，不是"作者是否勤快"。这与现有闸门的根本差别是：现有闸门查**数字对不对**，本规则查**这一步在本批是否真的非空**。

---

## 1. 为什么需要（两个真实例，均可核数）

### 例 A：`去重` 是空操作，但写法像做过一次清洗（"本来就没有"）

**原文（D9z 基线件，照抄卡面口径）**：「`v2/evidence/d9t-on_n16r24_s42/run.jsonl`……**MSG 去重后 191 条**」。

**可核数（实测）**：

| 量 | 值 | 复算方式 |
|---|---|---|
| 原始 `MSG_DM` + `MSG_PUBLIC` 事件数 | **191** | `grep -c` / Python 计数 |
| `unique(msg_uid)` | **191** | 同上取 set |
| **被去重删掉的条数** | **0** | 191 − 191 |

⇒ **"去重"在本批没删掉任何一条。** 结果（191）是对的，**过程是空的**。

**为什么这比"漏做一步"更难发现**：漏做会留下痕迹（数字不符）；**空操作不留痕迹**——它产出的数**恰好等于**正确值。所以作者可以完全诚实地说"我去重了 191 条"，而读者会以为"存在 191→191 之外的清洗历史"。

### 例 B：占比该报却没报（"应当有却没有"）

**原文（同件）**：卡面口径写「同一 `thread_id` 内相邻的**优先**」，件里写「**天然满足**（125/125 全为同线程相邻轮），故未再二次筛选」。

**可核数（实测）**：

| 量 | 值 |
|---|---|
| 相邻对总数 | **125** |
| 同 `thread_id` | **125 / 125 = 100%** |
| `turn_index(本条) = turn_index(父条) + 1` | **125 / 125 = 100%** |
| `gap` 分布 | `{gap=1: 77, gap=2: 48}`，`gap=0 = 0` |

⇒ 「优先」这个筛选动作**在本批没有区分力**（100% 全中）。**若只写"按规则抽样"而不报这个 100%，读者根本无法知道"优先"是否起了作用。**

**本例的危险不在数字，而在读法**：因为 125/125 全是**线程内紧邻两轮**，所以本批 `gap` 量的是**轮次距离**，不是"是否下一句"——`gap=2` 的配对**在线程内仍是紧邻两轮**。**不写这句，`gap≥2` 会被读成"接不上话"，而实际是"接得慢"。** 这是两个不同的问题。

**两例的关系（Leader 已在卡面点明，此处按其实质分开）**：
- 例 A 是**「本来就没有」**——去重是真做不了的（无重复可去），标注"空操作"即可，**不构成过错**；
- 例 B 是**「应当有却没有」**——占比是可算的，**不报就构成信息缺失**，因为它改变读法。

⇒ 所以规则要求的是「**两个数 + 一句空操作标注**」，而不是「不许有空操作」。**空操作不违规，隐瞒空操作才违规。**

## 2. 三条可机械执行的检查步骤

面向**文本件**（`v2/evidence/**`、`v2/refs/**`、`reports/**` 的 `.md`），对每一处"清洗类声称"执行：

### 步骤 1：定位声称（关键词，闭集）
在同一行（或同一个句子）中命中以下**动词+方位词**组合之一：

```
去重后 | 去重后得 | 剔除后 | 过滤后 | 筛后 | 筛选后 | 清洗后 | 排除后 | 去掉重复后 | 修剪后
```

**只认"后"字结尾的形态**（"去重后 191"），**不认**不带结果的动词本身（"做了去重"没有数，属另一类，见 §3.3）。

### 步骤 2：取数对（同句优先，其次邻行窗口）
- **窗口**：该行 + 其后 **3 行**（仿 `check_definitions.sh` 的 `§12` 窗口），且允许取**同一表格行内的相邻单元格**；
- **取数**：在窗口内抽取**带量纲的整数/小数**（`191`、`191 条`、`3,827 B`、`84.48%`），要求**至少两个**；
- **对齐规则（关键，决定假阳性）**：两个数必须**同一量纲**（条/行/字节/词/百分比），且**至少一个数紧跟在"前/原/原始/共"或"后"之后**。跨量纲（`191 条` vs `3,827 B`）**不算数对**。

### 步骤 3：三态判定（**不允许只有两态**）
| 判定 | 条件 | 输出 |
|---|---|---|
| `NOOP-CONFIRMED` | 两值**相等**（同量纲、同对象） | **提示**「本批该步为空操作」，并要求作者同屏加一句标注 |
| `NOOP-NONEMPTY` | 两值**不等** | 通过（这是"真的洗过"） |
| `NOOP-UNJUDGEABLE` | **取不到两个同量纲数** | 提示「声称了清洗但未给前后值」——**不得判为空操作，也不得判通过** |

**第三态是这条规则的骨**：把"没写"与"写了且相等"分开，否则会把"只写了一个数"的诚实件打成空操作。

## 3. 什么算「空操作」，什么算「真的洗过」

### 3.1 三种"真的洗过"（都要求两值不等）
1. **删除了条目**：`37 候选 → 收 22`（拒 9 / 已在表 6，22+9+6=37）⇒ 非空；
2. **替换了内容**：`verbs_expansion_22 → 25`（追加 3 词）⇒ 操作前后**集合不等**，非空；
3. **收敛了对象集**：`501 条 → 191 条 MSG`（剔除事件类型）⇒ 非空。

### 3.2 两种"空操作"（两值相等，须标注）
1. **本来无可操作**：例 A（191 → 191，零重复）；
2. **条件恒真**：例 B（125/125 全满足 ⇒ "优先"没有筛掉任何对）。

### 3.3 不属本规则管辖（**必须写清，否则会滥用**）
- **只说"做了去重"但从不给数**：这是"没有可核形式"，属 §11 四行定义/§7.2 最小可核形式的管辖范围，**不由本规则处理**；
- **口径变更**（换词表、换切法、换分母）：这是**可比性问题**，属 V-4/§7.2 管辖；
- **同值量当有效性论证**：属 §7 V-4 管辖，与本规则**形似而神不同**（V-4 禁"用同值证明有效"，本规则要求"同值时标明它是空的"）。

## 4. 反例边界（**必须随本规则一起引用**）

1. **样本小 ⇒ 某过滤自然为空，不等于作者在冒充。** 例 A 就是合法的：零重复是数据的属性，不是作者的敷衍。⇒ **本规则只要求"写明"，不要求"避免"**。
2. **必须区分「本来就没有」与「应当有却没有」**：
   - 「本来就没有」⇒ 标注即可（例 A）；
   - 「应当有却没有」⇒ 是**信息缺失**，因为它可能改变读法（例 B）。
   ⇒ 同一句话"空操作"，在这两种情形下的**严重性不同**，**不可用同一档处理**。
3. **两值相等可能只是量纲巧合**：`191 条` 与 `191 B` 不是同一对象。⇒ 步骤 2 的量纲对齐是**硬前提**，缺它就退化成"数字碰巧相同即报警"。
4. **百分比相等 ≠ 计数相等**：`84.48%` 在 v2.0 与 v2.1 同值（均 `147/174`）是**真的**两版同值，但它**不是**"清洗空操作"，而是"版本间无差异"（属 V-4）。⇒ 两值相等**只是提示**，性质由人判。
5. **不得把本规则变成"每个动词都要交两个数"**：那会制造大量 `NOOP-UNJUDGEABLE` 噪声，最终被无视（`check_definitions.sh` 精确率 10–20% 的教训）。
