## 1. 问题

DR（误会与和解）**现在技术上可分离、可测**（工具与复核都齐了）。但**技术可行 ≠ 该做**。
立预登记前必须回答一句：

> **开"处境注入"这一臂，预期让 D1 / D2 / D5 / D7 里的哪一个动？动多少？**

**如果答不出，就不该开** —— 因为跑完只能得到"某些数字变了"，而**变好变坏无从判断**。

## 2. 为什么现在答不出（三个硬理由）

| # | 理由 | 依据 |
|---|---|---|
| 1 | **D5（记忆延续）当前不可判** | `refs`/`body_ref` 从未落值；且"什么算重提旧事"未定语义 |
| 2 | **D1/D2/D7 与 DR 没有公开的因果链** | DR 注入的是"心里压着什么事"（处境），它最该影响的是**关系张力→和解**，而这一维恰好是 D4（当前不可判） |
| 3 | **D7 已经 56.67%，但分母只有 60** | 效应若小于 CI 宽度（±11.7pp），本批规模测不出 |

⇒ **DR 唯一直接对应的维度是 D4，而 D4 没有独立判据**（现在只有 `dialogue_rift` / `dialogue_repair` 两个**机制内字段**，不是生活气息判据）。

## 3. 由此得到的三条出路（择一，须显式选）

| 出路 | 内容 | 代价 |
|---|---|---|
| **A. 先给 D4 立判据** | 把"张力→和解"写成可测维度（如：旧账产生率 / 被注入比例 / 同线程修复配对率），并回答"这些数与'像镇子'的关系" | 只读、零跑批；**但可能结论是"D4 也不可测"** |
| **B. 不开 DR，先补 D5 字段** | 让记忆延续这一维可用 | 改代码 + 定语义；中等 |
| **C. 承认当前架构测不出生活气息** | 把已得的结构性结论（时序、配额、沉没）作为阶段成果收口 | 零成本，但**北极星未推进** |

**Leader 倾向：A** —— 因为 **DR 是唯一"世界里明显缺一块"的机制**（误会与和解是北极星明列的行为），先花零跑批的代价把它的**判据**立起来，比先跑两小时再想"这数说明什么"便宜得多。

## 4. 若要走到"开真批"，预登记必须写死的两层

### 4.1 单变量声明
```
enabled=1, gripe_context=1, repair_ask=false, reply_priority=false
⇒ 只注入"处境"，不动"动作要求"、不动"优先选中"
```

### 4.2 证据三层（**不得同句混用**）

| 层 | 证据 | 管什么 | 不能用来证明 |
|---|---|---|---|
| ① 汇总计数 | `L2b`：`context_line_nonempty_calls` + `rifts_nonempty_calls` | 通道**被调用且在有旧账时注入** | **不能**证明"这条消息的 prompt 变了" |
| ② 逐条字段 | `dialogue_repair.prompted`（**`=bool(repair_line)`**，本臂应为 0）/ `dialogue_rift.prompted` | 这一条消息**真的**带/不带该段 | **不能**与 ③ 同时引（互斥） |
| ③ 链等价 | 默认全关 vs 基座的逐事件链 | **默认全关时世界没变** | **开 DR 后不可用**（日志内容已变） |

> **互斥禁令**：② 与 ③ **不得出现在同一段论证里** —— 一个说"日志变了"，一个说"世界没变"。

### 4.3 护栏（沿用 `T-DR-ON-ASSESS` G1–G7）
`MSG` 总数**按臂各报**（不设跨臂阈值）｜单条字数**中位 ≥ 66**｜`<7 字` 占比 **= 0**｜`degraded=0` + `dialogue` 回放 0｜`places` sha / `n` 一致｜台账可重放复现｜两臂 `INTRA`/`OPENINGS` 设置一致。

## 5. 边界
