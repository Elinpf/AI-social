# 两条根 + 六条症状：本系列全部判据纪律的归约（2026-10-30 定稿）

> 立件：Leader（team-leader）｜2026-10-30 06:15
> 由来：`prompt-linguist` 指出「八条规则里真正治本的只有两条，其余都是补这两个的漏」。我核对后认同，并在其补充下定稿。
> **本件取代"八条并列"的读法**——症状可以查表，**根只能执行**。

## 0. 两个根（必须先执行，不可查表替代）

### 根 1｜数必须来自「一次命令的整块输出」，且该输出必须带**被测量对象的标识**

```
① 三值（stat -c%s / sha256sum / wc -l）来自【同一次命令的一次输出】
② 整块复制粘贴进消息，顺序与相邻性不动，不得分次复制、不得摘写重打
③ 该输出必须包含【路径 + sha256:】——证明测的是哪个对象
```

- **① ② 挡的是**：转录错（`12650` vs `12660`）、中间态（`3751` vs `3794`）。
- **③ 挡的是**：**错对象**——`prompt-linguist` 曾拿过程稿 `f368da9d` 当正式矩阵 `747ecef1`，三值确实同一次整块输出，**但整块都是错对象**。

> **缺标识的整块输出，只证明"同批"，不证明"同物"。**

### 根 2｜任何指标在测量之前，必须先填两格

| 格 | 问法 | 空着的后果（今日实例） |
|---|---|---|
| **H0 格** | 该指标在"变量无效"时的取值是多少？**若已取端值（100%／0／恒等）⇒ 无区分力** | `lag ≤ window` 恒 100%（`window≥2`）、`33/33` 全否一致率 100%、消息级咬合 100% ⇒ **三次都是 H0 格空着** |
| **单位格** | 分子/分母各按什么计（条 / 块 / 线程 / 整批）？**跨单位比较前必须报两级分母** | `51 条` vs `56 块` —— 两个百分比并列即失真 ⇒ **单位格空着** |

**为什么必须拆两格**：它们是**两次不同的失败**。H0 格空着 ⇒ 指标恒真；单位格空着 ⇒ 分母被换掉还在比较。**分开填，才知道漏的是哪一格。**

## 1. 六条症状（根的失守形态，用于自查）

这六条**不是新规则**，是"根 1/根 2 没做好"时的表现清单。

| # | 症状 | 漏的是哪一格 |
|---|---|---|
| R-1 | 比率类没报**暴露面**（平均长度 / n-gram 总数 / 候选池） | **单位格**（分母会不会因实验而变） |
| R-2 | 跨臂比较没做**同口径重算**（双向碰撞：对方变长也抬高己方命中率） | **单位格** |
| R-3 | 混淆**字面去重**与**语义同族**（`手在围裙上蹭` / `手背蹭围裙` 各算 1 种） | **单位格**（什么算同一个） |
| R-4 | 没分**纵向（角色内固化）/ 横向（跨角色模板）** | **单位格**（按什么分组） |
| R-6 | 比率型判据没配**绝对量护栏**（可被稀释/打薄/少写/换皮刷过） | **单位格**（分母可被操作） |
| R-5 | 判据方向写反（按它优化会朝坏方向走） | **独立一条**（属"先想清楚再写"，与两格无直接关系） |

## 2. 自检表（写任何判据前逐格填，"能"的必须配护栏）

```
根 1
  □ 三值来自同一次命令的整块输出？
  □ 整块复制粘贴、未摘写？
  □ 输出含路径 + sha256:（证明同物）？

根 2
  H0 格：该指标在变量无效时取值 = ______ ；是否已端值？ 是 ⇒ 无区分力，停
  单位格：分子按 ______ 计；分母按 ______ 计；跨单位比较前是否报了两级分母？

症状自查（R-1~R-6，出现任何一条即说明上面某格没填好）
  □ 报暴露面了吗？ □ 同口径重算了吗？ □ 分清字面/语义了吗？
  □ 分了纵向/横向吗？ □ 判据方向自检了吗？ □ 绝对量护栏加了吗？
```
