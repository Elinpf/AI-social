# D9j 预登记：旁白质量闸（八条判据 + 20 格自检表）

> 立件：Leader（team-leader）｜2026-10-30 05:42
> 上游：`d9i_language_read_prompt_linguist.md`（`f109ed04…`，咬合 82.35%、三维度判词）、`d9i_read_by_verifier.md`（`2d544f09…`，去重与暴露面）、`invariant-true-checklist.md`（R-1~R-6）
> **本件是"质量下限闸"，不是"效果判定"** —— 它回答"旁白是否可用于对外展示"，不回答"旁白是否让对话更好"。

## 0. 为什么要这个闸

`D9i` 已证旁白通道**有效**（0%→93.72%、咬合 82.35%、①④两维从弱变有、无结构代价）。但质量上有两个**真短板**：

| 类型 | 现象（`47a7da9e`，B 口径） | 该改哪儿 |
|---|---|---|
| **纵向·角色内固化** | `蹭+手` 8 次，**P004 独占 5/8 = 62.5%** | **该角色的动作库 / 人设** |
| **横向·跨角色同构** | `蹭+锉刀` 8 次，**3 个角色在重复**（P014 3 / P013 2 / P011 2） | **提示词 / 系统层**（共用模板） |

⇒ **两个方向修法完全不同，混在一层判据里会互相掩盖。**

## 1. 判据定稿（八条：四条判定 + 两条绝对量护栏 + 一条上卷 + 一条诊断）

| # | 判据 | 门槛 | 基线（`47a7da9e`） | 作用 |
|---|---|---|---|---|
| **(a)** | 精确串重复 | ≤ 2 次 | 3 次（`蹭了蹭`） | **仅诊断**（可换皮绕过） |
| **(b1)** | 同一「角色 × 族」占比 | ≤ 60% **且** 该角色该族 ≤ 2 次 | P004 **62.5%**、5 次 | **纵向**（角色内固化） |
| **(b2′)** | 族内「出现 ≥2 次的角色数」 | ≤ 1 **且** 该族总次数 ≤ 3 | `蹭+锉刀` **3 个角色**、8 次 | **横向**（模板同构） |
| **(c)** | 咬合率 **且** 旁白片段密度 | ≥ 82.35% **且** ≥ 1.0 片段/MSG | 82.35%、205/191≈1.07 | 旁白是否驱动内容 |
| **(d)** | **动词级总量**（抹掉器物维度） | ≤ 5 | **需本批重算**（未算，不编数） | **封洞①**（换器物绕过分族） |
| **(e)** | 单条 MSG 旁白片段数 | ≤ 2 | **需本批重算**（未算，不编数） | **封洞②**（塞旁白刷密度） |

**判定组合名**（判词直接用，一眼看出改哪层）：
- `b1 红 / b2′ 绿` ⇒ **角色内固化**（改人设）
- `b1 绿 / b2′ 红` ⇒ **模板同构**（改提示词）
- 两者都红 ⇒ 双重问题；都绿 ⇒ 该族合格

## 2. 方法节：20 格自检表（**必须先填完才允许写判定档**）

| 判据 | Q1 反向 | Q2 少写 | Q3 打薄 | Q4 稀释 | Q5 换皮 |
|---|---|---|---|---|---|
| (a) 精确串 ≤2（**诊断**） | 无 | 能 | 能 | 能 | 能 ⇒ **不进判定，四能可接受** |
| (b1) 角色×族≤60% + 该角色该族≤2 | 无 | 不能（受 c 密度封） | 不能（受 b2′ 封） | 不能（≤2 次封） | 不能（族按语义不按字面） |
| (b2′) ≥2次角色数≤1 + 族总量≤3 | 无 | 不能（受 c 密度封） | 不能（正是它治的） | 不适用 | **能 ⇒ 由 (d) 封** |
| (c) 咬合率 + 密度≥1.0 | 无 | 不能（密度下限） | 不适用 | 不能（无关旁白反拉低咬合） | 不适用 |

**残余**：(c) 的"密度下限"可被"塞"（1 条 MSG 写 3 个片段）⇒ **由 (e) 封**。
**结论**：八条填完后，20 格只剩 (a) 的四个"能"，而 (a) 已是诊断 ⇒ **判定侧不可刷**。

> **填表要求**：任何新增判据必须重填这 20 格（判据数 × 5 问），**"能"的格子必须配护栏**才可进判定。

## 3. 族定义冻结（**不得在工具里自由裁量**）

1. **单位**：一个旁白片段**恰好归一族**（禁一片多计）；
2. **优先级**：`身体部位` > `器物/环境`；同类内**更具体优先**（`手背`/`指腹` > `手指` > `手`）；**动词按表内顺序取首个命中**（不做同义归并）；
3. **表冻结**：动词 8（蹭/搓/抹/擦/拂/拍/抿/揉）、部位 6、器物 13，随实现件给 `impl_sha256`；
4. **两行并报**：`A 口径`（含多计，仅诊断） / `B 口径`（归族，用于判定）。

**为什么冻结**：同一批数据、同一阈值，A 口径 `蹭+围裙` = **11**（超标）、B 口径 = **0**（达标）⇒ **定义一换，结论反转**。**定义含糊时，阈值为 2 还是 3 毫无意义。**

## 4. 适用范围与基线

- 基线仅适用 `code_sha=47a7da9e`（ON 含固定示例句、`rounds=24`、n16 seed42、`DeepSeek-Flash`）；
- **`dd7e3fb` 线（只删半句）必须重算自己的基线**，不得沿用；
- 本闸**不判**"旁白让对话更好"，只判"旁白质量是否达到可展示下限"。
