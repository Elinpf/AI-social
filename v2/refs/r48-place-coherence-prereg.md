## 1. 维度定义：什么叫「场所使用得自然」

### 1.1 一句话定义

**场所使用得自然 = 居民之间的交互受物理空间约束**：不在同一个地方的人，不能像面对面一样即时往返；距离必须带来代价（时间或不可能）。

这不是"对话里提到地点"（那是 C1 处境锚的活），而是"**空间对交互有没有约束力**"。场所若不约束交互，它就退化成消息上的一个标签。

### 1.2 反向线索 → 可测量定义

最直接的"不自然"已在盘上：**跨地点同轮往返（zero-latency cross-place reply）**——A 在 `place=X` 说了一句，B 在 `place=Y≠X` **同一个 `round` 内**回了。

- 同轮内两人互不见面、也没有任何位移到对方场所（§9.2 实测：`74` 条里 **`0/74`** 的回复方在本轮移动到过父消息所在地）；
- ⇒ 这条回复在**物理上不可能**以"当面说话"完成，只能等价于"瞬时通信"。

**为什么这属于「场所使用的自然性」，而不是另开一个维度（如"对话时序自然性"）**：

1. 被判违规的不变量是**空间**，不是时间。同地点同轮往返（面对面说话）完全正常，本卡**不判它**；只有"**距离 × 零延迟**"这一交叉项才违规。若单独把时序当维度，就无法把"当面即时"与"异地即时"区分开，尺子会失去区分度。
2. 该量是场所维度的**反面证据**：它度量的是"空间是否还起作用"，与 D23（发起侧：谁约谁）构成同一维度的两面——**发起侧看"跨地点约人"**（`v2/evidence/d23_place_offline_verdict.md:28` 记 70.18% 发起为跨地点），**接话侧看"跨地点即时回话"**（本卡）。两面不可互代（§7）。
3. 它**不是**可见性缺陷，而是**设计层缺失"投递延迟"这一维**：DM 的可见性类是 `private`，判据里**没有地点项**（§2.4 实核），所以跨地点投递属既有设计；缺的是"到达需要时间"。因此它落在"空间对交互的约束"上，属场所维度。

### 1.3 与既有维度的分界（一眼看懂）

| 维度 | 量的对象 | 已有归属 |
|---|---|---|
| 本卡（R48） | **交互的"距离×延迟"**：异地是否零延迟往返 | 新立（本卡） |
| C1 处境锚 | **对话内容**与所在场所/手上活动是否相符 | `LIFE_PROMPT_SCENE`，`R45`/`R46` |
| D2.3 地点亲和 | **发起时选谁**（跨地点约人比例） | `D23-prereg-place-affinity.md` |
| 群体聚集 / 独处 | **场所使用频率与共处分布** | CYCLE-16、`R23-solitude-idle.md` |

## 2. 主判据（可复算，字段级）

### 2.1 主指标一句话

**跨地点同轮往返率 `R_cross`** = 「同轮往返中两端地点不同」的对数 ÷ 「同轮往返中两端地点均可判定」的对数。

### 2.2 数据源（精确到事件类型与字段）

| 项 | 取值 |
|---|---|
| 文件 | `<arm_dir>/run.jsonl`（逐行 JSON 事件流） |
| 消息事件类型 | `type ∈ {MSG_DM, MSG_PUBLIC, MSG_GROUP}`（与 R47/`d9z_gap_recompute.py` 同口径） |
| 去重键 | `payload.msg_uid`（同一 `msg_uid` 会重复出现：作为自身事件 + 作为他人可见事件；**必须去重**） |
| 轮次 | 事件顶层 `round`（**不是** `turn_index`） |
| 地点 | `payload.place`（**发言时刻所在地**；见 §2.4 的可靠性论证） |
| 配对 | 子消息 `payload.reply_to` 能在同一份去重样本里找到父条的 `payload.msg_uid` |
| `gap` | `round(子) − round(父)`（**轮次距离**，不是"是否下一句"） |
| 位移 | `type = PLACE_MOVE`，`payload.actor_id`/`actor` + `payload.day`/`slot`/`from_place`/`to_place`/`travel_ticks`（仅用于 §9.2 的"路径排除"） |

### 2.3 分子 / 分母（写死在卡里，不允许事后换）

- 分母 `n_gap0_both` = 满足全部条件的对数：`gap == 0` **且** `payload.place(子)` 非空 **且** `payload.place(父)` 非空。
- 分子 `n_cross` = 上述对中 `place(子) != place(父)` 的对数。
- 同地点对 `n_same` = `n_gap0_both − n_cross`。

### 2.4 代码事实（`git show 43a56c1:…` 实核，逐条可验）

1. `code/config/perception_scope.json`：`"MSG_DM": "private"`；`private` 类的判据字段集是 `["payload.from", "payload.to", "payload.to[]", "payload.agent_id", "payload.observer", "actor"]` —— **不含地点**。⇒ 跨地点投递是**设计层既有事实**，不是可见性 bug。
2. `code/contracts/visibility.py::visible()` 的 `private` 分支只查 `from/to/to[]/agent_id/observer/actor`，**无 `place` 比较**。
3. `code/life/agent.py:1166 _pick_reply_target()`（@`43a56c1`）的接话硬条件只有：类型 ∈ `{MSG_DM, MSG_GROUP}`、`reply_window_rounds` 内、未到 `max_turns`、未重复回、`max_turns_per_round` 上限 —— **没有任何地点条件**。⇒ 异地同轮接话在结构上被允许。
4. `code/engine/perceive.py::with_pending()`（D9z，`INTRA_ROUND_ENV = "HITT_INTRA_ROUND_VISIBILITY"`）把**本轮已发出的 `MSG_*`** 直接并入可见候选集；`MSG_DM` 随后按 `private` 类判定 ⇒ 本轮刚发出的异地 DM 对本轮后续 agent 立即可见。
5. **缺什么**：全仓无「消息投递延迟 / 到达时间」字段。`PLACE_MOVE.payload.travel_ticks` 只服务**移动**（且 `code/orchestration/integration.py:557` 固定写 `1`），消息侧没有对应量。⇒ 本卡**无法判定"多久算即时"的绝对刻度**，只能用 `round` 距离作为离散刻度（见 §3.3）。

> ⚠️ 上面第 3、4 条的**行号只对 `43a56c1` 有效**。报告引用时必须写「`43a56c1` + 文件:行号」；用当前分支 `a947cce` 行号引用即为口径错误。`payload.place` 的可靠性另见 §10.2（`ctx.scene.place` 的移动前快照缺陷**不适用于** `payload.place`）。

## 3. 率的定义

> 本节为 `scripts/check_tables.py` 强制表（`v2/refs/_template-prereg-tables.md`）。

| 率名 | 分子 | 分母 | 计算式（含边界） | 纳入排除 |
|---|---|---|---|---|
| `R_cross`（主判据 · 跨地点同轮往返率） | `gap=0` 且两端 `place` 非空且 `place` 不同的对数 | `gap=0` 且两端 `place` 非空的相邻对数 | `n_cross ÷ n_gap0_both`；基线 `74 ÷ 133 = 0.556391` | 仅 `MSG_*` 去重后带可解 `reply_to` 的对；**任一端 `place` 为空 ⇒ 不进分母只报条数**；不做 `residence` 排除（与 R47 同口径，排除即另立口径须整臂重算并声明） |
| `R_cross_strict`（辅 · 严格瞬移率） | `n_cross` 中「回复方在本轮**无任何** `PLACE_MOVE`」的对数 | `n_cross` | `44 ÷ 74 = 0.594595`；用于把"连走都没走"从"走了但没到对方那儿"里拆出来 | 只作辅读，**不进通过线** |
| `R_cross_allgap`（辅 · 全域跨地点占比） | 全部 `gap` 中两端 `place` 非空且不同的对数 | 全部两端 `place` 非空的相邻对数 | `180 ÷ 278 = 0.647482`（`gap=1` 60/97、`gap=2` 46/48） | 辅读，**不得**与 `R_cross` 混用；`gap≥1` 在信件语义下可解释，本卡不判其自然与否 |

## 5. 阈值与噪声带

### 5.1 噪声带：本卡**诚实地给不出**

- 本维度**只有 1 个批**（`d9z-on_n16r56_s42`）可用，**没有重复批、没有第二个 seed**，因此**批间方差未知**，无法给出可信噪声带。
- 可算的只有**二项区间（描述性，不含批间方差，不得当噪声带）**：`74/133 = 0.5564`，Wilson95 `[0.4716, 0.6381]`；`n_same 59/133 = 0.4436`，Wilson95 `[0.3619, 0.5284]`。
- 因此本卡的通过线采用**绝对条数 + 率**双条件（对"分母被撑大导致的占比下降"免疫——这是 R47 的教训：`gap≥2` 占比降 55.0% 全部来自分母 125→278，绝对条数一条没少）。**不使用"Δ 显著性"作为判据**。

### 5.2 通过线（对未来的 fix 臂 vs 基线；**先验写死，不允许事后下调**）

`fix` 臂判定「**成立**」需**同时**满足 T1–T7：

|---|---|---|---|
| T1 | `R_cross(fix) ≤ 0.20` | 基线 0.5564 ⇒ 至少 **−35.6pp** | 两位数百分点量级的下降才能称"空间约束起作用"，1~5pp 在本尺子的批间不确定性内无从区分 |

> 若 `A0` 的 `gap=0` 跨地点**绝对条数 < 12**，则 **T10 不出判定**，只报 `A0`/`A1` 条数并标 `probe=true`。

### 5.3 结构上界验算（防止 F-5 作息那类"数学上不可达"的判据缺陷）

- 本卡要求的**最好情形**是：`R_cross → 0`、`n_cross → 0`、`n_same` 保持 59、每轮消息率不变、分母仍 133。**这个点可达**：只要把"异地投递需要时间"（≥1 轮）或"同轮接话要求同处"加在判定点，跨地点同轮往返即消失，而 74 条跨地点回复可整体后移为 `gap=1`（信件语义），`n_same` 与消息总量不受损。
- ⇒ **不存在结构上界不可达**（与 `R25` F-5 的 `M1 结构上界 +0.46875 < +0.50` 不同）。为保持这一性质，本卡**不在 T1–T4 里写"必须让对话变多"或"必须让同一批人更换地点"**这类会与机制冲突的条件。
- **本卡不指定实现路线**（"加同处条件"还是"加投递延迟"），选择权属实现任务（`T4-place-fix`）；但**两条路线的读数必须分开报**：抑制式（消息变少）与延迟式（消息后移）不可混为一谈（§7 第 4 条）。

## 6. 判据纪律（硬约束，写进卡）

### 6.1 分母纪律

1. 分母 `< 30`：**只报条数，不报比率**（不写"跨地点率 0%"这类话，改写"6 条同轮往返中 0 条跨地点"）。
2. 分母 `< 68`：一律标 **`probe = true`**，且**不得**写"显著/有效/提升"。
3. 分母 ≥ 68 也不等于"可外推"：本卡数据是单 seed 单批，**一律点估计**。

### 6.2 状态词白名单（只允许这五个）

| 状态词 | 本卡的触发条件 |
|---|---|
| `已成立` | T1–**T11 全部**满足 |
| `部分有效（未达阈值）` | T1/T2 满足但 T3/T4/T7 有一条不满足；或仅单 seed（T7 缺） |
| `未成立` | T1 或 T2 明确不满足，且分母 ≥ 68、机制层已核实生效（T5 过） |
| `不可判` | 分母不足（T6 不过）、两臂不可比（配置差异不止一处）、验真失败、或**基线/OFF 侧分母为 0**（§9.3） |
| `机制未生效` | 开关层可证未接通：fix 臂读数与基线**逐项完全相同**、或 `code` 中判定点未被改动 / env 未生效（须先查 `switch_effective`），且此时**不得**写 `未成立` |

### 6.3 三档不得互替（逐字写死）

> **机制接通 ≠ 效果成立 ≠ 生活气息提升。**
> - 「机制接通」只允许表述为"判定点存在/开关生效，`R_cross` 读数发生了变化的原因已定位"；
> - 「效果成立」只允许表述为"按 T1–T11 判定为 `已成立`"；
> - 「生活气息提升」**本卡无权给出**：本卡只管"空间是否约束交互"，而"更有生活气息"还需要方向一致的其它维度（对话量、话题多样性、关系延续）同时不恶化。本卡最多只能为该结论提供**一条**证据。

## 7. 证伪条件（什么读数推翻"生活气息提升"的宣称）

1. **`R_cross` 不降或上升** ⇒ 「场所使用更自然」被推翻（方向相反）。
2. **`R_cross` 降但 `n_same` 同步塌缩 ≥20%** ⇒ 推翻"更自然"，改写「同轮往返被整体压制」——分母塌缩式假提升。
3. **`R_cross` 降但 `rate_msg_per_round` 跌破 0.9×** ⇒ 推翻"生活气息提升"，只能并列写「空间自洽 ↑ / 对话密度 ↓」。
4. **`n_cross(gap=0)` 降但 `R_cross_allgap` 不降** ⇒ 只能写「同上轮异地通信被消除」，**禁写**「跨地点交流减少」——那 74 条可能只是被推到 `gap=1`，空间约束并未生效。
5. **基线读数本身已构成对"现状自然"的证伪**：`74/133 = 55.64%` 且 `0/74` 有路径可解释（§9.2）⇒ 任何"当前版本场所使用已经自然"的陈述**当场不成立**，无需等对照臂。
6. **只在 `MSG_PUBLIC` 上变"自然"不算**：公开面接话本来就要求同处（R41 的 `PT.is_replyable_public` 带 `co_present`），在该通道上读出的"自然"属**选择效应**，不能顶替 DM 通道的读数（§10.1）。

## 8. 边界：本卡**不评价**什么

1. **不评价对话内容与场所是否相符**（"在图书馆推刨子"这类）——属 C1 处境锚（`R45`/`R46`，`LIFE_PROMPT_SCENE`），本卡的尺子对内容一个字都不看。
2. **不评价"谁跟谁说话"的地点亲和**（跨地点约人 70.18%）——属 D23 发起侧，两处口径不可互代。
3. **不评价场所使用的频率/聚集分布/独处**——属 CYCLE-16 群体聚集与 `R23` 独处。
4. **不评价"信件应该多久到"的绝对刻度**：仓库无投递延迟字段（§2.4-5），本卡只用 `round` 距离这一**离散代理**；`gap=1` 是否"够真实"本卡不判。
5. **不评价文本风格**（旁白率、套路化、是否像人说话）——属 R3/R9/R12 一系。
6. **不评价 `MSG_GROUP` / 群体场景**：基线批 `MSG_GROUP = 0`，无读数可依（登记，不推断）。
7. **不做因果推断**：`R_cross` 与 D9z 开关的关联是**结构事实+读数**；"若改判定点则 `R_cross` 必降"属**待验证假设**，须由 `T4-place-fix` 的对照臂验证。
