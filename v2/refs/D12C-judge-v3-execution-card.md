## 0. 前置定义（全部可数，不用形容词）

| 符号 | 定义 | 怎么数 |
|---|---|---|
| **R** | 线程回合数（台词条数） | 该线程内台词行计数（每行一个 `turn`） |
| **锚点** | 一个**可指名的**具体物 / 数 / 人名 / 待办事由 | 如 `某具体货物名`、`某具体数字`、`某人名`、`某件待办`。**"东西""事"不算锚点** |
| **接物** | 后一句对前一句的锚点**指名复述并做动作** | 构造例：`半块薯`→`那块薯皮皱了`→`薯给我` |
| **P（推进计数）** | 满足 P1/P2/P3/P4 **任一**的**回合对**数量 | 见下 |

**P1–P4（推进的四种操作化动作，逐对判，满足一种即 +1）**

| 代号 | 判定问句 | 是 ⇒ |
|---|---|---|
| **P1** | 后一句是否给前一句的某个锚点**新增了状态或量化**？ | +1 |
| **P2** | 后一句是否给出**决定 / 承诺 / 带理由的拒绝**（不是"嗯""是啊"）？ | +1 |
| **P3** | 后一句是否引入**一个此前未出现的第三方或新待办**，并与当前锚点挂接？ | +1 |
| **P4** | 前一句提出**需要对方回答的具体问题**，且后一句**回答了它**（不接受"另起话头"）？ | +1 |

⚠ **P4 必须"闭合"才算**。提问未被回答 = **悬空**，记入 Q2，**不计 P4**。这一条把"问一句换个话题"与"真推进"分开。

## 1. 计数项（逐条填整数，不填形容词）

### 1.1 Q1 内部 token 泄漏

- **判定问句**：台词中是否出现非中文的标识符 / 英文 `snake_case` / 内部枚举名？
- **是** ⇒ **C，终止全流程**（不再数其余项）。**否** ⇒ 继续。

### 1.2 Q2 悬空提问

- **判定问句**：线程内是否存在这样一句——它含**直接疑问**（`？` 或 `成不/咋样/顺不顺/没/要不要/在不在` 等疑问式），指向**对方或第三方的一个具体事由**，而该事由在**此后至少一个对方回合**里**既未被回答、也未被同义追问**？
- **是** ⇒ 该处计 **Q2 +1**（**按处计数，不按措辞去重**）。**否** ⇒ +0。
- **落到哪一档**：**Q2 ≥ 1 ⇒ 不得判 A**；**Q2 ≥ 2 ⇒ 判 C**。

### 1.3 Q3 光杆收束公式

**闭集词表（不得外延，不得"类似"）**：
`先这样` / `就这样吧` / `先这么着` / `先搁着吧` / `先搁下` / `先放放` / `先不急`

- **判定问句**：某句台词的**最后一个分句**是否**仅由**上述词表中的一个短语构成（前后无具体物、无具体动作、无事由），且该句**不是线程最后一句**？
- **是** ⇒ **Q3 +1**。**否** ⇒ +0。
- **关键分辨**：**事由是否在该短语"内部"**——短语内部带事由 = 有指向的推迟，**不计**；短语内部什么也没有、只能靠上文回指 = **光杆，计**。
  - `甲：那件事先放放，我这就去…` ＝ 事由在短语**内部** ⇒ **不计**（且非末分句）
  - `甲：我先搁下。那东西给我。` ＝ 该短语**非末分句** ⇒ **不计**
  - `甲：你听这声儿是不是有点闷。先这样。` ＝ 末分句只有 `先这样`，无内部事由 ⇒ **计 1**
  - `甲：这册子还差三页没对完，先搁着吧。` ＝ 末分句只有 `先搁着吧`，事由靠上文回指 ⇒ **计 1**
- **落到哪一档**：**Q3 ≥ 1 ⇒ 不得判 A**；**Q3 ≥ 2 ⇒ 判 C**。
- ⚠ 已知本项会**误伤合法口语**（"先搁着吧"常是人对自己的活说的）。误伤的最坏后果只是 **A→B 一格**，不会制造 C。执行时**照规则数**，不要用"我觉得这句挺自然"去豁免。

### 1.4 Q3b 句尾标签复现

- **判定问句**：是否存在一个 **≤6 字**的短语，在同一线程内出现 **≥2 次**，且**每一次都处于句末位置**（后接 `。！？` 或台词结束）？
- **是** ⇒ **Q3b +1**（每短语 1 次）。**否** ⇒ +0。
- **落到哪一档**：**Q3b ≥ 1 ⇒ 不得判 A**；**Q3b ≥ 2 ⇒ 判 C**。
- ⚠ 只认"**句末**"标签。句首/句中的复述是**正常接话**（属 A3 的来源），算缺陷会误伤好样本。

### 1.5 Q4 镜像问答

- **判定问句**：抽取相邻两回合的**句式骨架**（去掉专名与具体物后剩下的结构），是否出现「**乙回答甲的提问 → 随即提出同型提问 → 甲照此回答并再反问**」这一 **≥3 步**的循环？
- **是** ⇒ 该循环计 **Q4 +1**。**否** ⇒ +0。
- **落到哪一档**：**Q4 = 1 ⇒ 不得判 A**；**Q4 ≥ 2 且 P = 0 ⇒ 判 C**。
- 依据：镜像问答是"轮转正确但无信息增量"，单独一条不足以判 C（人也会这样搭话），**两条以上且零推进**才等于复读机。

### 1.6 Q5 槽位填装

**三个条件同时成立才算 1 处**：

| 条件 | 判定问句 |
|---|---|
| (a) | 该句是否由 **≥3 个短句**并列构成（逗号或句号分隔）？ |
| (b) | 这些短句之间是否**零连接词**（无 `就/倒/可/不过/所以/要不/回头/等/才/便` 等衔接成分）？ |
| (c) | 是否至少有一个短句是 **≤5 字的纯状态标签**（只有状态、没有物、没有动作，如 `肚子还空着。`／`饿得慌。`／`手都酸了。`）？ |

- **三条件全"是"** ⇒ **Q5 +1**。任一"否" ⇒ +0。
- **落到哪一档（短线程单列）**：
  - **R ≤ 3 且 Q5 ≥ 1 ⇒ 判 C**
  - **R ≥ 4 且 Q5 ≥ 2 ⇒ 判 C**；`R ≥ 4 且 Q5 = 1` ⇒ 不得判 A（降 B）

### 1.7 Q6 回合失接

- **判定问句**：后一句对前一句的**核心请求 / 提议**（形如 `成不？``要不…？``得空来坐坐``你帮我…`）是否出现下列任一 ——
  - **(i) 否定性误读**：回答了一件**对方并未提出**的请求。
    构造例：甲说「要不先搁一搁，等我把手上这点活弄完再喊你」，乙答「你先别急着喊我」——甲并没有要求乙现在来，乙拒绝了一件未提出的请求。
  - **(ii) 完全无响应**：既不接受、不拒绝、不替代，且直接另起完全无关的话头。
- **是** ⇒ **Q6 +1**。**否** ⇒ +0。
- **落到哪一档**：**Q6 ≥ 1 ⇒ 判 C（任何 R）**。
- 理由（必须与结论一起引用）：失接是**功能性断裂**（读者无法把两句接成一个对话），一句就够，**不需要累积**；这与 Q3/Q4/Q5「缺陷要累积多次」属**不同阈值族**，不是阈值随手定。

### 1.8 判档决策表（**有序执行，先 C 后 A，命中即停**）

```
第 1 步  Q1 ≥ 1                        → C
第 2 步  Q6 ≥ 1                        → C
第 3 步  R ≤ 3 且 Q5 ≥ 1               → C
第 4 步  Q2 ≥ 2 或 Q3 ≥ 2 或 Q3b ≥ 2   → C
第 5 步  Q4 ≥ 2 且 P = 0               → C
第 6 步  以下四条全部为"是"             → A
         (A1) R ≥ 3
         (A2) P ≥ 2，且其中至少 1 次来自 P1 或 P2
         (A3) 可指名锚点 ≥ 2（物/数/人名/待办，非"东西/事"）
         (A4) Q2 = 0 且 Q3 = 0 且 Q3b = 0 且 Q4 = 0 且 Q5 = 0
第 7 步  以上都不是                     → B
```

**"推进"的操作化定义**：推进不是"有新信息"，而是**后一句对前一句的锚点做了 P1–P4 四类动作之一**。特别地：
- 同一锚点被**反复挪动**，若每次都只换动作不换状态意义，**只算 1 次 P1**（判据：动作是否改变该锚点的**可用性/位置/归属**，改才算）；
- **反复推迟**不算推进，且计入 Q2（若被推迟的是提问）；
- 提问不计推进，**提问被回答才计**。

## 3. 已知局限（不读会误用）

1. **阈值全部待校准**：`Q3≥2 ⇒ C`、`Q4≥2 且 P=0 ⇒ C`、`Q5≥1 且 R≤3 ⇒ C`、`P≥2 ⇒ A` —— 这些数字**没有一个来自数据**，是设计选择。
2. **短线程判据（Q5/Q6）样本极少**，验证不足。
3. **A 档可能偏紧**：具体性已降级为必要不充分条件，A 档会变少；本卡无法区分"判据太紧"与"文本真的差"，**执行时不许因为"A 太少了"而自行放宽规则**。
