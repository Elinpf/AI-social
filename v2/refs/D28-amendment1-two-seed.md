# D2.8 预登记 · 修正案 1：改为 **2 seed** 设计（因文本层噪音与判据同量级）

> 日期：2026-10-24，**在 D2.8 任何跑批之前**。修正对象：`v2/refs/D28-prereg-narration-quota.md`。
> 依据：`v2/evidence/d27_amendment3_text_noise.md`（两批 C 臂文本层差 4.90pp 的实证）。

## 1. 为什么必须改

同一份代码、同一 seed、同一规模，两次 C 臂的 `L-7` 分别是 **20.59%** 与 **25.49%**（**差 4.90pp**）。
而 D2.8 原预登记给 `Q2`（`L-7` 恶化）定的闸是 **≤3.0pp** —— **阈值小于噪音**，单批数据无法判定。

## 2. 臂规模（改）

| | 原 | 改后 |
|---|---|---|
| 臂 | C×1 + B×1（2 批，≈1.8h） | **C×2 + B×2（seed 42 / 43），共 4 批 ≈3.6h**，串行 |
| C 臂来源 | 复用 `run_d27_C` | seed42 的 C 复用 `run_d27_C`（省一批）；seed43 的 C 新跑；B 两批新跑 ⇒ **3 批新跑 ≈2.7h** |

## 3. 判据口径（改：区分"可单批评判"与"需跨 seed 一致"）

| 类别 | 指标 | 判定方式 |
|---|---|---|
| **结构/长度/计数**（噪音小） | `paren_rate`、`len_p50_excl`、`P1_count_mean`、`n_threads`、`n_msgs`、`llm_calls` | **单批即可判**（沿用原阈值：M1 ∈[25%,45%]、P1 `len_p50_excl` ≥40.0、P2 `P1_count_mean` ≥+10%、S ±10%） |
| **重复/复述/漂移**（噪音 3–5pp） | `L-7`、`L-15`、`F-2′` | **必须在两个 seed 上方向一致**才可判；阈值放宽到 **≤ 5.0pp**（噪音带上界）；**单 seed 出现超限只作观察** |

**新增一致性要求**：若两个 seed 的 `L-7` 变化方向相反 ⇒ 判 **「不足以下结论（seed 间不一致）」**，不得挑有利的那个 seed。

## 4. 主判据不变

- **P1（一票否决）**：`len_p50_excl` ≥ 40.0（不得变短）——两个 seed 都要满足；
- **P2**：`P1_count_mean` 相对同 seed 的 C **↑ ≥10%**——两个 seed 都要满足。

## 5. 为什么仍然值得跑

D2.7 的旁白模板化（台词层 L-7 反而从 25.49% 降到 7.37%）说明**旁白不必等于重复**；
本臂用"概率性旁白 + 旁白 ≤15 字 + 台词 ≥30 字"三件套同时约束，是**唯一可能同时满足"生活质感"与"台词不被挤短"**的组合。
3 批 ≈2.7h，比再试两个失败方向便宜。
