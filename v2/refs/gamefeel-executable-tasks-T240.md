## 2. 本任务先落地 3 项（P0）——以及**为什么选这 3 项**

选 **G-8 / G-9 / G-14**，理由（**是"提升游戏感"，不是"更好看"**）：
- **G-8 剧情卡（因果链）**：把"一条事件"变成"**一段因果**"——玩家看到 `因 → 果` 的**可点溯源链**，从"发生了"升级到"**为什么会这样**"。这是**故事沉浸**的核心动作（RimWorld/CK 式），且**零外部依赖**（只读 seq 索引 + `fact_event_seqs`）。
- **G-9 小镇周报**：给小镇一个**"节拍"与"世界观感"**——每周一页（数字 + 纪事 + 镇民原话），玩家有"**在过日子**"的时间感；**逐句可溯源**，不编造。直接对应用户"想沉醉其中"。
- **G-14 关系图**：把隐藏的**社会网络**变成**看得见的边**（边粗=好感、绿正/红负），"**谁和谁走得近**"一眼可见 → 社会关系成为可感知的"场"，而非数字。
> 三者都在 §4.3/§4.4「故事化 UI / 反馈与因果」——正是"沉浸"而非"装饰"的部分；且**全部只读日志、无资产/数据前置**，能立刻交付。
