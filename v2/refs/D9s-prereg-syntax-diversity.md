## 1. 为什么现在做句式，而不是继续改词

- **改词已到边界**：`(d2)` 种类 12→8，`(d3)` 逃逸率 0.7704（门限 0.778049，余量 0.0076）。**再加词面禁令只会把动作推得更远离词表。**
- **扩表不改表达**：可归族/不可归族两侧把+拿占比相同（73.3% vs 72.2%）⇒ 扩表只改变"记账方式"，不改变"怎么说"。
- **示例改不了句式**：示例里把起首仅 33.3%，实测 81.7% ⇒ **句式由底层模板决定，不由示例决定**（`d9m-syntax-slot-monotony.md` 边界②）。

## 2. 变量（**两处改动，必须声明为两处**）

同 `code/life/agent.py` 的旁白收尾指令区域，新增两条约束：

**S-1｜起首频率上限**
> 旁白动作**不要总是以「把」或「拿/用」开头**；每三条旁白最多一条可以用这种方式开头，其余请用别的写法起头。

**S-2｜角色专属句式（写入角色档案，不是写入全局提示词）**
为每个角色指定 2–3 个**专属起句方式**，例如：
- 木匠：**结果先行**（`木花卷着落下来，刨子还在推`）
- 账房：**数字先行**（`三两七钱，对上了`）
- 灶上：**气味/声音先行**（`锅里那股焦香先冒出来`）

⇒ **S-1 是禁令（全局），S-2 是正向供给（按角色）**。二者**在同一次实验里同时启用**，因此本实验**不是单变量**——若要拆分，须拆成 S1-only / S1+S2 两轮。**本预登记只批准 S1+S2 合并，并明确声明这一限制。**

### 4.1 为什么 `H/log₂6` 而不是 `H` 或 `H/log₂(非空类数)`（**三次踩坑记录**）

| 版本 | 问题 |
|---|---|
| v1 `H ≥ 2.0` | **不可达**：② `c2_sp` 三臂恒为 0 ⇒ 4–5 类非空；`A+B` 上限 `log₂4=2.0`，要求四类各 25%；若 ①=50% 且其余均分，**实算上限仅 1.79** |
| v2 `H/log₂(非空类数) ≥ 0.75` | **反向奖励退化**：分母随非空类数缩小而抬高比值 ⇒ `①50%+③50%`（两类独吞，正是"换集中点"）得 **1.0000 满分** |
| **v3 `H/log₂6 ≥ 0.68`** | **固定分母，单调**。拦得住：A+B 0.4858 / H0 0.5057 / **全给③ 0.6415** / **两类独吞 0.3869**；放得过：3 类均分 0.6934 / 4 类均分 0.7737 |

**为什么是 0.68 而不是 0.65**：`0.65 − 0.6415 = 0.0085`，只差 0.85pp ⇒ **余量过脆**（与 `(d3)` 的 0.75 vs 0.778 同型错误）。0.68 两侧各留约 3pp。

### 4.2 v1/v2 中被废掉的判据（**必须同屏，防复用**）
- `H6 ≥ 2.0`：不可达（见 4.1）。
- `③ ≥ 10%`：现值 10.20%、H0 10.24% ⇒ **起跑线即满足，无区分力**。
- **`③ ≥ 20%`：被主判据蕴含**——H0 构成 `①72.20+③10.24+④11.22+⑥5.85+⑤0.49`，若 `①≤50%` 释放 22.20pp 全落 ③ ⇒ `③≈32.4% ≫ 20%`。**凡"主判据达标时自动达标"的量，不得入表。**
- `⑥ ≤ 15%`：两套口径同一批数据差 3 倍，且现值 ≪ 阈值 ⇒ 改护栏 ≤8%。
- 「任一类 >40%」：与主判据在 72% 上完全重合，**零独立信息量**。
- `second_max_share ≥ 0.12`（曾考虑）：`①50%+③50%` 的 second=0.50 ⇒ **拦不住两类独吞**，故不用。
- **`c3a_result_first ≥ 15%`（v3 首稿）：不可达**。冻结仪器实测三臂 `c3a` = **H0 2.44%（5 条）/ A_only 2.48% / A+B 1.53%（3 条）** ⇒ 15% 要求 6–10 倍增长。**这是第六次"先定阈值再找 H0"**（由 `eval-researcher` 用 H0 值撞出）。改为 **≥5.5%（H0 + 3.1pp）**，含义："结果先行"从每 41 条 1 条提到每 18 条 1 条。
- **`c3a` 最终被降为描述量（第七次修正，但这次有实测噪声底）**：`eval-researcher` 用冻结仪器跑 OFF 臂（code `f384335`，SYNTAX=0），与 D9m 的 A+B（`be091a3`，**语义同配置**）对照——① 差 **2.81pp**、`H/log₂6` 差 **3.17pp** ⇒ **跑批间噪声底 ≈2.8–3.2pp**。而 `c3a` 要求 `5.5−2.06 = **+3.44pp**`，**仅比噪声高 8%** ⇒ 单 seed 下无法区分真效应与抖动。**降为描述量。**
- **`c3a` 的单 seed 噪声必须先声明（`repro-verifier` 指出）**：H0 基数仅 **5 条**、`A+B` 仅 **3 条**；`n≈196` 时 1 条 ≈ 0.51pp，**±2 条 = ±1pp**。因此 5.5%（≈11 条）虽"跳一跳够得着"，但 **6 条净增在噪声边缘**。⇒ 本条**同时要求绝对条数 ≥11**（绝对量不依赖分母，R-6），且判定件须写：「点估计达标，但基数仅 3–5 条，**不作强结论**」，除非在 r84 上复现。
- `c3a` **不被主判据蕴含**（`repro-verifier` 论证）：① 只约束"把/拿/用"这一类，释放的量只保证 `③`（兜底类）总量上升，而 `c3a ⊂ ③` 是子类占比 —— `③≈32%` 而 `c3a≈0` 完全可以并存。**但前提是 c3a 必须是正向定义、且账目句排除机械可判**（仪器已满足）。

### 4.3 阈值标定规程（动作式，判据入表前必须贴）
```
(0) NOISE：跑批间噪声底（同配置两臂实测差）      → 需改变量 < NOISE 的指标，单 seed 下只能作描述
(1) H0_val：变量「无效」时该指标的取值          → 必须 < T（否则无区分力）
(2) MAX_val：变量「完美」时的理论上限（含类数/分母约束） → 必须 > T（否则不可达）
(3) 冗余检验：主判据达标时，本判据是否自动达标？    → 是则不得入表
(4) 退化检验：本判据在"变量把指标推向极端退化"时是否反而变好？ → 是则换实现
(5) 余量检验：|T − 最近可达值| 应 ≥ 2pp            → 否则阈值太脆
（本次 (1) 废了 ③≥10% 与 ⑥≤15%，(2) 废了 H6≥2.0，(3) 废了 ③≥20%，(4) 废了 H/log₂(非空)）
```

## 8. 边界（预登记即写，防越证）

1. **不是单变量**（S-1 + S-2 两处改动）。若 ON 生效，**不得**归因为"限制了把字句"，只能说"句式干预（合包）有效"。
2. **`OFF` 复用 D9m 的 `A+B` 臂**：必须先用 `arm_config_guard` 确认"新 ON/OFF 只差 `LIFE_PROMPT_NARRATION_SYNTAX`"，且新 OFF 与旧 A+B 的 `code_sha` 关系须显式登记（若差代码，判为 `DIFFERENT_CODE`，只能做方向比较）。
3. **`把+拿` 判据是首字分类**，不是句法分析（见 `d9m-syntax-slot-monotony.md` 边界①）。因此**本判据只能证明"起首方式变了"，不能证明"表达更丰富"**。
4. **不承诺提升"生活气息"**：本实验只检验"句式多样性"这一中间量；它对六维「生活气息」的传导**未验证**，不得在报告里跳步。
5. **n=191 步骤 1 的 `±7pp` 噪声**：50% 的绝对阈值只能在步骤 2（r84）判定。
