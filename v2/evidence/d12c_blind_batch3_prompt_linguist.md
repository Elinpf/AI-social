## 2. 判据缺陷（本批判读过程中暴露，**一律不在本轮改规则**）

**为什么不改**：判据自 `981ea19c…` 起已定稿并被对方按同一份执行；此刻改动＝看数改判据，本批 κ 直接作废。⇒ 以下三条只登记，留 v4。

**D1 · Q2 对"线程末轮提问"无定义（影响 #3、并可影响任何批次）**
v3 原文「该事由在**此后至少一个对方回合**里既未被回答、也未被同义追问」——末轮提问**没有**后续对方回合，"此后至少一个"不存在。字面可读成"条件不成立 ⇒ 不算悬空"，也可读成"没人答 ⇒ 算悬空"。**这一处歧义直接决定 #3 是 A 还是 B**。我取"须有后续回合才有机会答"，理由：① 更贴字面（"此后至少一个对方回合"是前置条件）；② 否则**线程末轮一提问就必然被判悬空**，等于对"自然收尾征询"系统性扣分。⇒ v4 须写成：「**仅当存在后续对方回合、且该回合未答亦未同义追问时，才计悬空；末轮提问不计**」。

**D2 · v3 丢失了 V2 的「同句骨架复现 ≥3 次 ⇒ C」主武器（影响 #4）**
V2 的 C 判据原文含 `同句骨架复现 ≥3 次 且 未引入新事由/新对象/新分工`。v3 的 Q1–Q6 里**没有任何一项覆盖它**（Q4 只管"问答镜像循环"，Q3b 只管"≤6 字且须句末"）。后果：#4 出现"我正剥着花生呢"由**两个不同人物**在 r7/r8 逐字复现、r10 第三次换皮，v3 只能给出 Q3b=0/Q4=0/Q5=0、P=1 ⇒ **B**。**人读它是本批最明显的复读机，本应 C。** ⇒ v4 须补 Q7：`同一句骨架（去专名/去具体物后相同）在同一线程内跨 ≥3 个回合复现，且未引入新对象/新分工 ⇒ C`。
