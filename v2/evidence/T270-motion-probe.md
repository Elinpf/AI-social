# T270 核实：「动得生硬」到底是哪一种 —— rAF 采样实测（**非猜测**）

**方法**：无头浏览器打开 `?log=sample/run_c_n20.play.jsonl&round=60&autoplay=1&speed=800&view=default`，
用 `requestAnimationFrame` 连续采样 **160 帧**，逐帧记 19 个可见角色的 `container.x/y` 与步态帧 `_fr`。
（脚本 `/root/t270_probe.py`；原始数据 `T270-motion-probe.json`。）

## 实测结果

| 量 | 实测 | 含义 |
|---|---|---|
| **first_move 帧 spread** | **0**（19/19 同帧启动） | **所有人同一帧起步** → 同频同步 |
| move_frac（在动帧占比） | mean 0.886 | 几乎一直在移动（不是"停-走"节奏） |
| 每 agent 移动段数 | 0–3（160 帧内） | 无离散"走一段停一段"节奏 |
| **速度剖面（agent0 前 40 帧）** | `…0.19 → **36.95** → 30.3 → 24.8 → … → 0.078` | 起步**一帧内从 0.19 跳到 36.95**（突变），随后**指数衰减**到近 0 |

## 定性（可多选 → 实测命中 3 项 + 1 项部分）

- ✅ **3「无缓动」**：速度**起步瞬间即峰值**（剖面 `0.19→36.95` 一帧突变）——**没有 ease-in 加速段**，只有指数 ease-out 减速。且**无 dt 归一化**（`tick()` 用固定 `k=0.18`，帧率一变速度就变）→ 低端机更僵。
- ✅ **4「所有人同频同步」**：`first_move spread=0`，**19 人同帧起停**；连踏步 bob 虽有 `_ph` 相位，但**起停时刻完全对齐** → "齐步走"。
- ✅ **1「像滑行」**：位移是"最大速→指数滑到停"，**步态帧 `_fr` 以固定 0.16/帧推进、与真实速度无关**，且**朝向不插值**（`_dir` 未用于转向）→ 脚在滑、身不转。
- ◻️ **2「一跳一跳」**：**部分**——速度剖面在**回合边界**出现一次**位移突变**（0.19→36.95，单帧 37px）；是"**起步跳变**"而非"格间瞬移"。**播放倍速越高（如 5x）越明显**。

## 结论一句话
**主因 = 无缓动（起步突变、缺 ease-in、无 dt）+ 全员同频同步 + 滑行（步态与速度脱钩、无转向）；次因 = 回合边界位移突变。**
