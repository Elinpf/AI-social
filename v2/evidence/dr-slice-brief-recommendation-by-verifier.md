## ① 体积账：**切片比预想的小一个量级**

| 事件类型 | 条数 | MB | 占比 |
|---|---:|---:|---:|
| `MEMORY_WRITE` | 25,524 | 15.27 | **34.6%** |
| `MEMORY_FORGET` | 20,644 | 9.17 | **20.8%** |
| `OBSERVATION` | 25,014 | 8.68 | **19.7%** |
| 其余（含全部 `MSG`） | — | — | 24.9% |

**砍掉这三类即砍掉 75.1%。**

**关键实测**：`MSG` 事件全批仅 **0.38 MB**（`body` **0.03 MB**、`ctx` 0.11 MB）。

| 方案 | 估算体积 |
|---|---|
| 仅 `MSG` + 关联键 | **0.20 MB** |
| `MSG` + 关联键 + **`body` 全文不删** | **≈0.40 MB** |
| 原文件 | 44.2 MB |

⇒ **不需要在"留不留 `body`"上做取舍**——body 全留也仅原文件 1%。这直接消解了"词表漏要不要靠 body 核"的两难：**要核，且留得起。**

## ② 字段清单（建议直接写进卡）

**留**（每 MSG 一条）：
`seq` / `type` / `hash` / `prev_hash`（**链可独立验，不必回头要原件**）、`round` / `day` / `slot` / `place`、`from` / `to` / `thread_id` / `turn_index` / `msg_uid` / `reply_to`、`ctx.trigger`、**`body` 全文**、`dialogue_rift`（全字段）、`dialogue_repair`（全字段）。

**不留**：`MEMORY_WRITE` / `MEMORY_FORGET` / `OBSERVATION` / `MEMORY_CONSOLIDATE` / `MEMORY_RETRIEVE` / `NEED_UPDATE` / `INTENT_REJECTED`（合计 ≈78% 体积，与 D4 无关）。
`LLM_CALL` 建议**只留** `purpose` / `tokens_in` / `cached`（判"是否真调用"），**不留 `prompt` 全文**。

## ③ ⚠ 真正的约束：**rift 没有独立的生命周期事件**

**实测**：
```
事件类型中与 rift/repair 相关的独立类型：无（命中的 PERSONA_DRIFT 是人格漂移，与 DR 无关）
code/life/dialogue_repair.py、code/life/agent.py 中 emit rift 事件：无
```
⇒ **rift 的"创建 / 关闭 / 淡忘"没有任何事件**，只以 **MSG `payload.dialogue_rift` 的快照**存在。

| D4 要算的 | 能否从快照得到 |
|---|---|
| 某 MSG 生成时"我有哪些未了结旧账" | **能**（`dialogue_rift.open` 快照） |
| 这条是否把旧账写进提示词 | **能**（`prompted`） |
| 这条是否触发修复配对 | **能**（`dialogue_repair{rift_id, trigger_seq}`） |
| **rift 何时被创建** | **不能**——只能从"首次出现在某条快照"反推，**必晚于真实创建时刻** |
| **rift 何时被关闭/淡忘**（`max_age_rounds=84`） | **不能**——无事件 |
| **未了结 rift 总量随时间曲线** | **不能** |
| **从未进入任何提示词的 rift** | **不能**——不在任何快照里，**天然不可见** |

**后果**：D4 的分母（tension 事件数）只能得「**至少在 MSG 快照中被看见过的 rift**」这个**偏小口径**；**偏倚单向（只少不多），且无法从现有数据估计少多少。**

## ④ 建议的卡面写法（两步，不要合成一步）

**不要**写成「零跑批做 D4 底稿」——做出来会是偏小口径而不自知。

1. **第一步（现在就能做，零跑批）**：切片底稿 + **快照口径的 D4 试算**；件内**明写**「分母 = 被 MSG 快照看见过的 rift，漏掉从未进提示词者」。
2. **第二步（要动代码，不一定跑批，归实现方）**：补 **`RIFT_OPEN` / `RIFT_CLOSE`（或 `RIFT_EXPIRE`）两个事件**，**必须在预登记前定**，否则两臂 D4 分子分母口径不一致。

**为什么第二步不能塞进底稿里顺手绕过**：绕过去的话两臂各算一个偏小口径，**看起来能比，实际比的是两个不同的漏斗**。

## ⑤ 结论

**建议派给我，但卡面按 ④ 的两步写。**
**体积完全不是约束（0.2–0.4 MB）；真约束是 rift 生命周期事件缺失。**
