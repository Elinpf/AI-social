## 1. 假设（承接 A1 的实测）

A1 证明：**机制生效但产能去向错**——回复解绑后省下的额度被用来**再发起**（发起 228→266，+16.7%），新起的单发线程把 `p50` 拉回 1。
A2 假设：**堵住"对未回对端的新发起"这条去向，产能会转成"接着聊"**，从而 `p50` 上移。

**A2 = 在 A1 之上加一条前置约束**：若某 agent 对某对端**存在未回入站**（DM `to==me` / GROUP 我在 `participants`、且该消息 `turn_index` 我尚未回复过），则该 agent 在本 slot 内**不再向该对端发起新线程**；对其他对端、以及对无未回入站的对端，发起行为**不变**。

## 5. 「对未回对端不再发起」会不会掐掉该发起的新对话？（事前反事实设计）

**风险**：A2 可能靠"少说话"把 `p50` 抬起来——线程少了、短线程被掐掉，中位数自然上升，但居民之间的**搭话总量下降**，这在"生活气息"上是负面的。

**三条事前反事实指标（缺一不可，全部要报绝对值）**：
1. **新起线程数**（含 vs A1 的降幅）；
2. **≥3 轮线程的绝对条数**；
3. **有未回入站的 agent-slot 分母**（若分母大幅缩水，说明吞吐被掐，转化率再高也没意义）。

**判读规则**：
- 若「新起线程 ↓、≥3 轮绝对条数 ↑」⇒ 是**真加深**（用同样的/更少的线程聊得更长）；
- 若「新起线程 ↓、≥3 轮绝对条数 不升」⇒ **判"用少说话换比值"**，即使 `p50` 达到 ≥2 也不算有效；
- 若「新起线程 ↓ 且 ≥3 轮绝对条数 ↓」⇒ 判**损伤吞吐**，直接否掉。

**若判「触发不是唯一瓶颈」**，下一个怀疑点按此顺序排查（写进结论，供下一轮预登记）：
1. **「入站未回」判定的窗口**：`reply_window_rounds=2` 是否太短（跨 slot 的未回入站到下一 slot 已过期，导致"想接也接不上"）；
2. **perception 的同回合不可见**：双方同回合各自发起（本轮机制无法跨回合协调）；
3. **发起侧的对端选择**：`_initiate` 仍按计划模板选人，可能选到"已经聊过、没有新信息"的对端；
4. **`max_turns_per_round=2` 之外的单回合节奏**：一个 slot 只有 3 回合，回复与发起在时间上是否天然错开。

## 6. 反引力的三条防自欺（沿用 A1）
