# F-4「真张力」人工判读判据（先写后判 · preregistration）

> 版本 v1｜撰写时刻 2026-10-20T20:06 (+08:00)｜撰写人 batch-evidence-runner（单一标注者）
> HEAD `fcf42bf931fb239867886674f68db822d1a162e2`
> **用途限定**：本判据只用于给**词表口径 F-4** 提供"噪声水平兜底"的并列注记。
> 它**不是**指标、**不进**结论表的率、**不与**词表口径相加或互证。
> 效力上限（必须随结果一起写）：**单一标注者、无第二编码者、无一致性检验（无 κ）**，因此其结论只能称"一个标注者的判读"，不得称"人工校验通过"。
> 适用范围：v0 基线与本轮新批**用同一份判据**判读，保证两臂人工层同口径。

## 1. 为什么需要这层

词表口径的张力检测是**子串包含 + 极性词计数**，天然会命中反诘、成语、安抚语中的负向词。
在 v0 已实测到至少 2/5 假阳性（`#1` 反诘「怕」、`#5` 成语「头疼脑热」），说明**词表口径的分母不是"真实张力计数"**。
词表口径的价值只在**跨臂同规则可比**；要谈"真实冲突"，必须另起人工层。

## 2. 判定单元

同词表口径：**一条被词表判为张力事件的触发消息**（`seq` 定位），逐条判，一条一个结论。不合并、不拆事件。

## 3. 判为「真张力」需同时满足（全部满足才算）

- **T1 有对象**：话是对**在场的另一个角色**说的（`to` 非空，或正文明确点名对方），不是自言自语、旁白、内心独白、对读者的说明。
- **T2 有指向**：不满/对抗/质问指向**该在场对象本人**（或本人与其之间的具体事），不是对第三方（配偶、邻居、镇上风气）的吐槽转述。
- **T3 有张力性**：文本本身表达负面情绪、指责、逼问、关系受损信号（如"忍了很久""还处不处""你把话说清楚"）；
  仅**提及**负向字眼（成语、比喻、安抚、宽慰、否定式劝导如"别怕""不用担心"）**不算**。
- **T4 不因结果改造**：判读只看触发消息及其上下文，**不因"后面有没有修复"反向影响本条是否为真张力**（否则闭环率会被判据污染）。

## 4. 判为「非真张力（词表噪声）」的常见形态（示例，非穷举）

- 反诘/自问自答中的负向词（"怕什么""有什么好担心的"）；
- 成语/固定搭配（"头疼脑热""哭笑不得"）；
- 安抚、鼓励、劝解语（"别怕问错""别难过"）；
- 自言自语、内心独白、场景旁白；
- 对不在场第三方的吐槽/转述，且对在场对象无对抗。

## 5. 允许的第三种结论

「不可判」——文本过短、语境不足、或需要跨事件才能判断时使用；**不可判既不算真张力也不算噪声**，单独计数并在结果表并列。

## 6. 判读流程（可复算）

1. 由 `f4_events_v0.md`（或新批同款枚举）取得全部张力事件，逐条抽 `seq` + 原文 + 命中修复词（若有）；
2. 按 T1–T4 逐条判，写结论与一句话理由，**理由必须引用原文片段**；
3. 结果落 `f4_manual_judge_<臂>.md` / `.json`，附本判据文件 sha256；
4. 两套口径并列报：`词表口径 X 条 / 0 闭环` 与 `人工判读 Y 条 / 0 闭环`，**两个分母都写**，都不换算百分比。

## 7. 如实披露（不包装）

本判据在起草前，我已通读过 v0 的 5 条张力事件原文——**假阳性正是在那次通读中被发现的**。
因此这不是盲判，也不具备"判据先于数据"的严格独立性。可以主张的只有：**判据文本在正式逐条判定之前已成文并留 sha**，且禁止事后为凑结论修改判据；
不可以主张的是：判读未受先前阅读影响。此点写在结果文件里，一并引用。
