# Arm-C 抽检人工判读 · 抽样规则（先写后抽，跑批前写定）

> 写定时刻 2026-10-20T20:14 (+08:00)｜作者 batch-evidence-runner｜HEAD `fcf42bf9`
> 适用对象：**Arm-C（对照臂）** 的词表口径 F-4 张力事件。Arm-T 全量判读，不用本规则。
> 状态：**在 Arm-C 跑批之前写定**，因此不含任何 Arm-C 数据信息（无事件数、无内容）。这是为了不让抽样规则被结果塑形。

## 1. 规则（确定性，不使用随机数）

1. 取 Arm-C 词表口径枚举出的**全部**张力事件（`f4_repair_evidence.py` 输出）。
2. 按 `channel` 分层：`dm` / `public` / `group`（仅取非空层）。
3. 层样本量用**最大余数法**按层内事件数占比分配，总数 `N=10`：
   - 先算 `quota_c = N * n_c / n_total`，各层取整数部分；
   - 剩余名额按小数部分从大到小分配；小数相同按 `dm → public → group` 顺序优先。
4. 层内抽样：把该层事件按 `seq` **升序**排列，第 `i` 个样本取索引
   `round((i + 0.5) * n_c / k_c)`（0-based，即层内等距取中点），重复索引去重后顺延到下一个未用索引。
   ⇒ 完全由 `seq` 排序与计数决定，**任何人用同一份日志都能复算出同一批 seq**。
5. 若某层事件数 < 该层分配额：该层**全取**，余额按 `dm → public → group` 顺序顺延给下一层；若全部取完仍不足 10，则**如实按实际条数**报，不虚增、不重复取。
6. 抽样结果落 `f4_sample_armC.json`（含：规则版本与 sha、每层 n_c 与 k_c、被选中的 seq 列表、复算命令）。
