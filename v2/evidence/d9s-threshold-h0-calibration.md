## 2. 三条判据为什么被废（逐条，可复算）

### ① `H6 ≥ 2.0 bit` —— **在 4–5 类非空下不可达**
- ② `c2_sp` **三臂恒为 0.00%**（S-2 的出口是"名词性"，不是"主谓"）⇒ 实际只有 4 类非空。
- 若主判据 `①≤50%` 达成、其余 3 类均分 16.7%：`H = −0.5·log₂0.5 − 3×(0.1667·log₂0.1667) = 0.5 + 1.292 = **1.79 bit**`
- ⇒ **1.79 < 2.0**：即使 ① 完美达标 + 其余完全均分，也到不了 2.0。**该阈值自相矛盾。**

### ② `③ ≥ 10%` —— **起跑线就满足，无区分力**
- 现值 **10.20%**，H0 是 **10.24%** ⇒ 维持现状即"通过"。
- 这正是 H0 格的定义：**"变量无效时该指标取值"** 已经落在阈值内 ⇒ **无区分力，废**。

### ③ `⑥ ≤ 15%` —— **同一批数据两套口径差 3 倍**
- 我口径（`c6_interj`）：**4.59%**；`dialogue-core-dev` 口径（`other`，把副词/时间/语气全并入）：**14.29%**。
- 14.29% 距 15% 只剩 0.7pp ⇒ 用谁的口径决定"通过或不通过"。**口径未统一前，此判据不得启用。**

## 3. 新四条制（定稿）

| # | 判据 | 阈值 | 现值 | 需改变量 | 有区分力 |

| 护栏 1 | 旁白密度 blocks/MSG | ≥1.0 | 1.026 | — | ✓ |

**为什么用 `H_norm_nonempty` 而不是 `H`**：它按**非空类数**归一（`H / log2(n_nonempty)`），天然免疫"某类恒为 0"；且 `A+B`=0.6279 > H0=0.5630 说明它**能看见已有差异**，不是死指标。H 的绝对值只在同非空类数下可比，跨臂不可比。

**规程补一条（动作式，可复制）**：
```bash
# 定任何阈值前，必须先跑这三行并贴进件里：
#   (1) 变量「无效」时的取值  H0_val
#   (2) 变量「完美」时的理论上限  MAX_val（含"类数/分母"约束）
#   (3) 阈值 T 是否满足  H0_val < T < MAX_val
```
**不满足第 (3) 条的阈值，一律不得写进预登记。**
