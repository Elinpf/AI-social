## 4. 为什么这是"词表法"的终点，不是"再调一轮"

`prompt-linguist` 的补测（`b1477807…` / 135 行）给出三类**任何词表都抓不到**的漏检形态：

| 形态 | 例 | 为什么词表抓不到 |
|---|---|---|
| **语境反讽/挑衅** | `你这话上回也说过` / `你奈我何` | 无任何负向词 |
| **沉默·转移话题** | 把话题拐去"灶上炖的啥" / `规矩是规矩` 式僵持 | 无负向词、无指责句法 |
| **旁白承载** | `（语气有点冲）` | **旁白被剥掉了**，且 74.3% 的臂根本无旁白 |

⇒ 召回为零**不是"词表不够大"，是"这类表达不在词里"**。⇒ 加词（已裁不批）无解；**换判据形态**或**先恢复旁白通道**才有解。

## 5. 局限

1. **A 闸无独立样本**：33 条是小样本且被用于调参 ⇒ 3.03% 不可外推；本批**没有任何"未参与调参"的人工判读样本**。
2. 干净基线（44 / 5 条）**无人工标签** ⇒ 只能报保留率，不能报假阳性率。
3. 锚样本 9 条中 `f6off` 侧仅 3 条，且该臂**无旁白**（态度无出口）⇒ 该臂召回 0 部分是**结构性**的。
4. mock 三臂 0→0 **不能当证据**（模板池无冲突句，0 是结构必然）。
