### A. `TH-P004-P002-0`（6 条，r0–7）——秀娘（揉面）× 老石（木工）

```
P004 r0 （把沾着面粉的手在围裙上蹭了蹭）听说你这两天为灶上那屉发糕犯愁呢？我正揉着给李家孙子满月的那盆面，想着顺道讨你一句准话——发糕到底啥时候揭盖才不塌？
P002 r1 （放下刨子，指腹蹭过刚开的榫眼）哟，秀娘，发糕揭盖得看汽——汽直了再等半袋烟工夫。你给李家孙子揉的那盆面，发得咋样了？
P004 r3 （把沾着面粉的手在围裙上蹭了蹭，凑近看你刚开的榫眼）你这榫肩留得真齐整，我那块案板腿松了半年，一直没敢动——你说我这种只会揉面的，头一回上手该从哪儿下凿子？
P002 r4 （放下凿子，拿拇指蹭了蹭榫眼边）哎，你先别急着下凿，找块废料画条线，顺着线走两遍手就熟了。
P004 r6 （把面团往案板上一按，指节压出个浅窝）这话在理，我头回学揉碱水面包，也是盯着王婶的手腕子看了三遍才敢下手。（揪下一小块面，搓成条）你瞧，面软了加粉，硬了蘸水，跟你们凿木头一个脾…
P002 r7 （拿砂纸蹭着李家那扇窗棂的边角）你这面揉得，手底下有数。我这窗棂子卡榫总差半丝，你说，是木头没干透，还是我下刀急了？
```

**看了什么**：两人各自带着手里的活（揉面 / 木工），**用自己行当的经验回答对方的问题**，然后**反过来问对方本行的事**。这是"熟人请教"的真实形态——不是问答机，是**互相当师傅**。

### B. `TH-P010-P009-0`（6 条，r0–7）——舞者 × 账房

```
P010 r0 金先生，（把压腿的脚尖从把杆上收回来，顺手抹了把额角的汗）这段新编的舞我总踩不准拍子，您耳朵灵，帮我听听是哪儿抢了。您说。
P009 r1 （搁下毛笔，把账本往桌角推了推）拍子我听着，第三下你脚落早了半拍。账要平。
P010 r3 （把月琴往膝上一搁，指尖还按着弦）哎，金先生，我这第三下是踩着台口那块翘起来的木板了，上回李家二小子钉的钉子冒了头。要不您再给我数一遍？
P009 r4 （拿铅笔在算盘珠上点了一下）李家二小子那钉子，我明儿叫他来起。你踩哪块板，我记哪块。账要平。
P010 r6 （把吉他往膝头一搁，指尖还按着第三根弦）那钉子起出来，木头上准留个眼儿，我拿块松香给你填上吧。
P009 r7 （拿指甲刮了刮算盘珠子上的灰）我这儿对账呢，西街油坊上月的流水差三文，怎么拨都拨不平。你那松香填眼儿，得先拿小锤把木刺敲平了再填。
```

**看了什么**：**从"踩错拍子"一路推到"钉子冒头→起钉子→填松香→先敲平木刺"**。这是**问题解决链**，而且两人都在用自己的方式还人情（"你踩哪块板我记哪块"↔"我给你填松香"）。`账要平` 作为口头禅出现两次，但**每次都在新语境里**。

### C. `TH-P014-P011-0`（6 条，r0–7）——两个人一起磨铜皮

```
P014 r0 （拿锉刀在铜片边上蹭了两下）小满，你刚说"练"，我这就练上了——老石家那破门轴拆下来的铜皮，磨圆了能当个小铃铛。你要不要也来蹭两下？
P011 r1 巧儿，我这儿正拿砂纸蹭老石家那截铜皮呢，蹭亮了挂你窗上。（低头吹了吹铜屑）你听听，响不响？
P014 r3 （拿废铜片在掌心掂了掂）你那铜皮蹭得咋样了，老石家那截还够不够长？我这儿正给赵家小孙子磨个铁环。（吹掉掌心的铜屑）响不响？
P011 r4 （用锉刀蹭着铜片边）这铜皮越磨越薄，倒像咱镇口那层老墙皮。老石家那截还够，就是手一抖就歪。你给赵家小孙子磨的铁环，圈口收圆了没？
P014 r6 （把铁环往膝头一磕，听个响）赵家那小孙子昨儿就套手上满街跑了，圈口我拿小锤收了三遍，圆得能滚。你那铜片薄成这样，还够给谁家打片儿？
P011 r7 （拿锉刀蹭着铜片边，铜屑落了一裤腿）我这铜片是给李家小闺女裁的，她娘要个薄片锁柜门。你那铁环圆不圆，得看滚不滚得直。滚一个瞧瞧。
```

**看了什么**：**两件活并行推进**（铜皮 / 铁环），互相汇报进度、互相验收（"滚一个瞧瞧"）。而且"铜皮越磨越薄，倒像咱镇口那层老墙皮"这种比喻，**是从手上的活里长出来的**，不是硬贴的。

### D. `TH-P016-P005-0`（6 条，r0–7）——摊主 × 郎中

```
P016 r0 陈医，我这正把摊上那筐新到的山药码齐呢，你练完功顺道帮我瞅一眼成色吧。
P005 r1 哎，我刚在院里把晾的那簸箕黄芪翻了个面，顺手给你搭把手看看山药——兰姐，你这筐是后山老赵家送的吧？
P016 r3 这山药粉性足得很，一掰就断，老赵家后山那片土就是养人。（拿指甲刮了刮断口，白浆沾在指腹上）陈医你眼神也毒，我这儿刚摆上你就瞧出来了，练功练出来的吧。
P005 r4 （把药碾子往桌角推了推，碾槽里还留着半截没研碎的甘草）练功这事啊，我也就是每天早起在院里站站桩，倒是你家老赵那腰，上回贴的膏药该换了吧。
P016 r6 （把摊上那筐新到的干姜翻了个面，挑出块发霉的搁一边）我这几天收摊后也跟着比划两下，站得腿肚子直打颤。你家那药柜第三格的山楂该翻晒了。老赵腰还那样。
P005 r7 （把药碾子里的山楂片拨了拨，捻起一片对着光看）这腿啊，站三天就服软了。老赵昨儿来扎针，腰还是弯不下呢。
```

**看了什么**：**寒暄→验货→互相提醒该做的事**（膏药该换、山楂该翻晒）。"挑出块发霉的搁一边"是**道德性的细节**——摊主在检查自己的货。
