# D12-E 候选可分性分析：**用已有数据否定两个看似合理的假设**

> 作者：Leader｜2026-10-23 13:35｜数据源 `v2/evidence/run_d12c_on_n16r60_seed42/run.jsonl`（510 MSG，**已有日志，未新跑批**）
> 起因：D12-E 中途快照显示「候选可分性」只有 **15.2%**（85% 的样本三候选 `scores` 完全相同）。这直接压低本臂的效果上限，必须查清原因，否则下一轮会照错误假设设计。

## 1. 假设 A（我的直觉）："撞车主要发生在同线程内，所以比对范围应改成同线程前文"
**实测（同一批日志，两种口径）**：

| 比对范围 | 非 0 交集消息占比 | 平均交集条数 |
|---|---|---|
| **(a) 全局最近 16 条**（D12-E 现用） | **18.8%** | **5.45** |
| **(b) 同线程前文最多 16 条** | **7.6%** | **0.35** |

⇒ **假设 A 被否证**：同线程前文的交集**远低于**全局（0.35 vs 5.45，差 15 倍）。
**原因**：8-gram 撞车是**跨线程**现象——不同人物、不同场景**共用同一批模板句**（"把锄头往地上一杵"、"手里那根半指宽的"），而不是同一线程里连续复述。
⇒ **下一轮若把比对范围改成"同线程前文"，会让可分性从 15% 掉到 7.6%，效果更差。这条路不要走。**

## 2. 假设 B（结合 A 的推论）："候选可分性低是因为比对范围不对"
**同样被否证。** 现有 (a) 口径的 18.8% 与 D12-E 实测的 15.2% **量级一致**（差异来自"仅该 agent 可见"与"全局"的差别）⇒ **比对口径基本没选错**。
可分性低的真实原因在**候选侧**：三个候选来自**同一 prompt、同一模型、同一温度**的连续采样，上下文完全一样 ⇒ **文本本身高度相似**，与"近期台词"的交集自然经常相同（多为全 0）。

## 3. 由此得到的正确改进方向（**下一臂该做的**）

| 方向 | 做法 | 依据 |
|---|---|---|
| ✅ **候选多样化（推荐）** | 给三个候选**分配不同的"开口/收束结构"**（如候选 k 用 `OPEN_FORMS[k]`），强制它们在**结构**上不同，再按 8-gram 交集择优 | 可分性低在候选侧；而 D12-D 已证明"在 prompt 里求模型换说法"无效——**把结构差异放进候选分配，不放进 prompt 指令**，是同一目标的不同实现层 |
| ❌ 缩小比对范围（同线程） | — | 实测让可分性 18.8% → 7.6% |
| ⚠ 提高 temperature | 改动采样分布，会让本臂与 T1 的**分布前提不同**（T1 是单次采样） | 会引入额外变量，除非同时给 T1 补一个同温度基线 |

## 4. 这份分析的价值

它**在下一轮花钱之前**否掉了一条听起来非常合理的路（我本人的第一直觉），并把改进方向从"换个比对范围"纠正为"让候选结构上真的不同"。成本：**0 次 LLM 调用**（全部用已有日志）。
