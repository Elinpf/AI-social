# 拦截：`NEG_WORDS` 子串匹配在中文语料上**假阳性极高** —— 真 LLM 臂暂不能跑

> 立件：Leader（team-leader）｜2026-10-29
> 由来：`dialogue-core-dev` 报「真 LLM 下 `NEG_WORDS` 命中 27/686 = 3.94%，可用」，并据此估算"单臂 27 条 rift 偏薄"。我复核时**先看命中句子本身**，发现问题不在数量、在**判定质量**。

## 0. 结论先行

**`NEG_WORDS` 的 18 个词用子串匹配，在真 LLM 中文语料上大量命中"假负向"**：抽样的 6 条**全部**不是"别人对我说了负向话"，而是"怕是/嫌烦/最怕/刺痛/苦味"这类**口语虚词、客套、生理感受、味觉**。

⇒ **本批若直接跑真 LLM 臂，`dialogue_rift` 会因为假阳性大量误记**，"误会与和解"的读数**不可用**。**真 LLM 臂暂缓，先修判定。**

## 2. 抽样：6 / 6 全是假阳性

| 命中词 | 实际句子 | 真实含义 |
|---|---|---|
| `怕` | 「这味当归放得有些久了，药性**怕是**打了折扣」 | **恐怕/大概**，不是害怕 |
| `烦` | 「改天我就搬个小板凳去你摊上坐着，你可别嫌我**烦**」 | **客套**，不是烦躁 |
| `怕` | 「我管账三十年，最**怕**的就是"意外"两个字」 | **口头禅/性格标签**，不是当下负向情绪 |
| `烦` | 「哎哟，你来我高兴还来不及呢，嫌什么**烦**！」 | **客套/反驳**，情绪是正向的 |
| `疼` | 「手背那两道口子沾了水有点刺**疼**呢」 | **生理疼痛**，不是情绪 |
| `苦` | 「药碾子刚碾到一半，**苦**味就窜上来了」 | **味觉**，不是辛苦 |

各词的高频来源一眼可见：`怕` 38 次里绝大多数是"怕是""最怕"；`疼` 多为生理；`苦` 多为"苦味/辛苦"。

**⇒ 子串匹配在中文里没有词边界，单字/双字词（怕、烦、疼、苦、累、吵）假阳性极高。**

## 3. 为什么这比"mock 没负向话"严重

- D9F 的 mock 结果判 `N`（CANNOT-VERIFY），原因是 **mock 语料无冲突句**——那是"语料种类不对"，可以换语料解决；
- 但本条是**判定器本身会把正常句子判成冲突** ⇒ 换了真 LLM 语料，**`dialogue_rift` 会大量误记**（把"药性怕是打折扣"当成对方在生气），随后提示词里会被塞进"你和 X 上次那句话还没说开"——**这会让对话变得更怪，而不是更有生活气息**。

⇒ **真 LLM 臂在修好判定之前跑，数据不可用，且会污染"DR 是否有效"的判断。**

## 4. 建议的三条走法（**不预登记、待用户裁预算**）

| 走法 | 做法 | 代价 | 风险 |
|---|---|---|---|
| **A. 先修判定再跑**（我推荐） | 把子串匹配换成"带上下文的判定"：①去口语虚词（怕是/最怕/嫌烦/别怕）②情绪词需与**第一/第二人称 + 负向语境**共现（"你…生气""我…委屈"）③用 `tools/d5/emotion_lexicon.txt` 的**加权/语境**规则而非裸子串 | **零跑批**，纯代码 + 人工抽验 20–30 条 | 修完仍需人工验证，可能来回 |
| B. 直接跑真 LLM 臂 | 80 min / ≈2,598 次网络 | 高 | **高**：结果混入大量假阳性，可能得出"DR 让对话变怪"的错误归因 |
| C. 放弃词表路径 | 改由 LLM 自评"这句话是不是在抱怨/指责" | 每次多一次 LLM 调用 | 成本更高，但与"生成侧"同源，可能更准 |

## 5. 必须写清的限制

1. 抽样只有 **6 条**（我人工看的），**不是系统评估**；假阳性率**未知**，只能说"抽样 6/6 全假"。
2. 我的 63/19 与 `dialogue-core-dev` 的 27/27 **口径不同**，两个数都**不得引用**，须先对齐口径（词表版本、是否剥离旁白、是否去重）。
3. 本件**不改** D9F 的判定（仍为 `N` / CANNOT-VERIFY）；它只主张"下一臂的前置条件未满足"。
4. 旁白（`（）` 内）是否参与匹配**未在本件拆分**——A1 臂的旁白占比很高（记忆：A0 臂 86%），若旁白参与匹配会进一步放大假阳性。
