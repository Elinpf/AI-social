# D2.7 根因：**旁白是被一条"措辞臂"的收尾指令主动禁掉的**（不是 bug，是遗留默认值）

> 日期：2026-10-24。只读定位。触发：D2.5a 发现当前 master `paren_rate = 0.00%`（历史 T0 = 79.41%）。

## 1. 根因（两处，硬编码、无开关）

```
code/life/agent.py:1453（_initiate 的 prompt 收尾）
  + "\n只写台词本身（一句家常话）：不要用括号、方括号或星号写动作、神态或心理旁白，
     不要解释也不要总结；用口语短句，别反复用同一句口头禅。"   # A1 措辞臂：只改收尾指令

code/life/agent.py:1478（_reply 的 prompt 收尾）
  + "\n只写台词本身（接着刚才的话往下说一句）：不要用括号、方括号或星号写动作、神态或心理旁白，
     不要解释也不要总结；用口语短句，别反复用同一句口头禅。"   # A1 措辞臂
```

⇒ **"不要用括号…写动作、神态或心理旁白"** —— 一句话把旁白彻底禁掉。
这正是 `paren_rate` 从 T0 的 **79.41%** 掉到 **0.00%** 的原因；`L-3_paren_block_any = 0.0` 亦印证。

**性质**：这不是回归 bug，是某次"去重/防口头禅"的措辞臂（注释标明 `A1 措辞臂`）**只按当时目标优化，未评估对文体/生活质感的代价**，之后成为默认。

## 2. 代价（对照实文）

| 来源 | 首条消息原文 |
|---|---|
| T0（`run_d12c_off_…`，paren 79.41%） | 「（刨子推过木料，卷起薄薄一层刨花）这块料子，得顺着纹路来。」 |
| 当前 master（C 臂，paren 0.00%） | 「这木头真硬。张家闺女要的嫁妆箱，榫头得再修修。急不得。」 |

差别不只是括号：**T0 有"在场感"——手上有活、有物件、有动作节奏；现在只剩干说话**。
对"生活气息"这是最直接的损失，也与 D2.4/D2.5a 的"短、齐、注水"叠加。

## 3. 为什么这条值得做（与 D2.5a 结论方向相反）

D12-H / D12-I 的核心结构性发现：**旁白（动作描述）是与历史 4-gram 重合最少的那类文本**；
称呼起头与对话内容最易撞车。因此：

- D2.5a（加配额）⇒ 加长靠**重复**（L-7 +8.91pp），已判无效；
- **放开旁白** ⇒ 加长靠**新信息**，理论上**同时**提升生活质感与降低词面重复。

这是"量与质同旋钮"那个死结的一个**反例出口**：旁白是唯一"增加字数却减少重复"的成分。

## 4. 现成旁路（备选，不等于本臂）

`agent.py:1447 self._scene_line(wv)` 注释标"处境锚臂：时段/场所/手上事（**默认 OFF** ⇒ 空串）"。
打开它会给模型"手上正在做什么"，可能自然引出旁白 —— 但它**不保证出旁白**，且属另一变量。
**本臂不打开 scene_line**（保持单变量），只在收尾指令里放开旁白。
