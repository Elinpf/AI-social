### 2.3 结论：**不是"人设动作池窄"，是"万能过渡动作"被当默认值**

证据三条：
1. **动作池不窄**：除 5 条「蹭了蹭」，另 **9 条各不相同**（揉面 / 按面团 / 揪面搓条 / 翻桃酥 / 折油纸 / 翻面团 / 嗅面盆 / 掀蒸笼 / 掀炉门）⇒ 面食系动作至少 9 类，**不构成"没得写"**。
2. **重复的是同一句**：`（把沾着面粉的手在围裙上蹭了蹭）` **精确 3 次** + 加长变体 2 次（`…凑近看你刚开的榫眼`、`…从案板底下摸出那把卷刃的刀`）⇒ 属**同一句逐字复读**，不是"同族不同句"。
3. **这句话在语义上是"过渡/收拾手"**，不是"正在做的事" —— 而 initiate 示例正好是 **`（把围裙往腰后一掖）`**（同类：收拾身上/围裙）。⇒ **示例给了"围裙型收拾动作"，模型把它当成了开场默认填充**。

⇒ 对 Leader 三个猜测的裁定：①示例句直接引导 **成立**（第 3 点）；②人设动作池窄 **不成立**（2.3-1）；③场景单一 **不能由本件判定**（本臂 `LIFE_PROMPT_SCENE` 未开，prompt 里根本没有场景信息；P004 是否只在一个场所活动，须看 `PLACE_MOVE` 事件，本卡未取）。
> 这一条同时说明：**"P004 独占"其实是"开场旁白的通病"**，只是 P004 出场多（15 条，第 5 多）才显得突出。

## 3. 问题③：横向同构的源头

### 3.1 跨角色**精确同串**极少，说明同构发生在"句式+器物"层


⇒ **没有任何一条「锉/刨」串被两个角色逐字复用** —— 这也解释了为什么**片段去重率高达 96.10%**（197/205）而读起来仍然机械：**句子各不同、句式同一套**（R-3 的直接实证）。

### 3.2 但同构在词面层非常清楚（四个角色同一模板）

| 角色 | `role_id` | 样例（逐字） |
|---|---|---|
| P014 巧儿 | craftsman | `（拿锉刀在铜片边上蹭了两下）`、`（拿锉刀蹭了蹭凳角，木屑落在鞋面上）` |
| P013 铁头 | craftsman | `（拿锉刀蹭着犁头缺口）`、`（拿锉刀蹭了蹭犁头边）` |
| P002 老石 | craftsman | `（拿锉刀在木马耳朵上蹭了两下，木屑落在鞋面）` |
| **P011 小满** | **student** | `（用锉刀蹭着铜片边）`、`（拿锉刀蹭着铜片边，铜屑落了一裤腿）` |

- 三个 `craftsman` **全部**落在该族（3/3），另有**非工匠的 student 也照写** ⇒ **不是"职业必然"，是"模板被沿用"**。

### 3.3 源头结论

- **无共享模板库**（3.1 的 grep + 1.2 的代码排除）；
- 源头是 **①reply 示例给出的"工具+摩擦+碎屑"模板** + **②prompt 未给"手上活计"信息**（`LIFE_PROMPT_SCENE` 未开、`compressed_profile` 不含 skills/道具）⇒ 模型只能从示例与 `role_id` 两个粗略线索里借扭矩，于是"工匠/在场者都在磨东西"。

### 7.5.3 **自纠：纵向「收拾手」不是示例造成的**（§2.3 的归因要改）

A0（无示例）里的实测原文：

```
（没动那糕，手在围裙上蹭了蹭）            ×4   ← P002 与 P013 **跨角色逐字复用**
含「手在围裙上蹭了蹭」共 7 条 / 633 片段（1.11%）
（拿刨子蹭了蹭木料边）(P002) （站着没动，手在裤腿上蹭了蹭）(P001) …
```

⇒ 该句是**模型的通用"收拾手"填充动作**，与示例句无关。示例真正带来的增量是两处：
1. **「蹭」这个动词被强化**：率 1.58% → **15.12%**（约 9.6 倍）；
2. **「锉/铜片」从 0 → 10 条**（`蹭+锉刀` 族是示例导入的）。

⇒ **本件 §2.3-3 与 §1.4 的暗示须修正**：
- `（把围裙往腰后一掖）` 示例与「围裙」词面的关系是**共现，不是因果**（两版围裙率 7.42% vs 6.34%，接近）；
- **纵向短板（角色内固化 / 万能过渡动作）不是示例能治的**，§6 里我写的"A 同时对纵向有效"**作废**；
- 由此：**只改示例（方案 A）只能削横向**（蹭/锉 词面强度），**治不了纵向**。

### 7.5.4 口径限定（必须与上面的数一起引用）

- 上表的率值**跨 `code_sha`（`3ec85a0` vs `47a7da9e`）且跨规模（686 vs 191 条）** ⇒ 按族纪律**只作存在性/方向，不作量级断言**；
- 但「`（没动那糕，手在围裙上蹭了蹭）` 在无示例版里同样存在、且被两个角色逐字复用」属**存在性结论**，按纪律用小样本即可成立（团队纪律：存在性用小样本，量级必须足样本）。

### 7.5.5 由此修订的方案取向（替代 §6 的"只做 A"）

**建议 A+B 合并成一个单点改动（仍在 `code/life/agent.py:93-96` 同一处，仍单变量）**：
- **A 部分**：示例 ≥6 句、按 `sha256(agent_id|round)` 确定性轮换，排除 蹭/磨/抹/擦 与 围裙/锉刀/木屑 词面；
- **B 部分（新增，治纵向）**：同一句里加**禁过渡动作**约束——「不要写整理衣角/收拾手/擦手这类过渡动作；动作要说清你在做什么，或眼前有什么」。
- 理由：§7.5.3 已证纵向源头是"万能过渡动作"，只改示例会把它留下；两处同在收尾指令内，不引入第二个变量文件。
- 验收仍须 **同 `code_sha` 的 OFF 对照**（`LIFE_PROMPT_NARRATION=0`），因为改示例即改 `code_sha`，不能与 `narr-on-20261030` 直接比（跨 sha 只能作观测）。
