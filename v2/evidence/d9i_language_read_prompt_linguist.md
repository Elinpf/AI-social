## 2. 专看一项：旁白是否与台词"说同一件事"（咬合 vs 装饰）

**判定口径（写死）**：**咬合 = 旁白中的物件/动作在台词里被指涉、被延续，或为其直接工具/因果**；否则记**装饰（不咬合）**。

| 量 | 分子/分母 | 值 |
|---|---|---|
| ON 抽样消息 | — | **56** |
| 含旁白的消息 | **51 / 56** | **91.07%**（旁白块 56 个） |
| **旁白与台词咬合** | **42 / 51** | **82.35%** |
| **装饰（不咬合）** | **9 / 51** | **17.65%** |

**咬合实例（原文对）**：
- `（把沾着面粉的手在围裙上蹭了蹭）` ↔ 「我正揉着给李家孙子满月的那盆面」（`TH-P004-P002-0` r0）
- `（把捣药杵往铜臼里顿了顿，陈皮末子沾在袖口）` ↔ 「陈皮先搁着」（`TH-P007-P005-18` r19）

### 2b. 换用"两分定义"重判（leader 2026-10-30 要求，**新旧并列**）

**旧定义**（只认"同物/同动作"）：咬合 **42/51 = 82.35%**、装饰 **9/51 = 17.65%**。
**新定义**（二分，可执行）：
```
咬合 = 旁白中的动作/器物/姿态 与台词满足任一：
  (a) 同物或同动作（= 旧定义）
  (b) 旁白描述的是台词所述行为的**发生条件/处境**（蹲着=闲等、夹紧=要走、推远=怕弄脏、掩门=怕火大…）
装饰 = 只表达情绪/表情，且不提供任何处境信息（（笑了笑）（顿了顿）（叹气））
```
**新定义下的重判（同 51 条含旁白消息 / 56 个旁白块）**：

| 层级 | 咬合 | 装饰 | 比例 |
|---|---|---|---|
| **按消息**（51 条） | **51** | **0** | 咬合 **100.00%** / 装饰 0.00% |
| **按旁白块**（56 个） | **54** | **2** | 咬合 **96.43%** / 装饰 **3.57%** |

**旧判为"装饰"的 9 条，在新定义下全部转"咬合"**（均为 (b) 处境型）：
- `（蹲在灶边拨了拨柴火）`：提供"他正守着灶"的处境 ⇒ 解释他为何此刻在灶前谈面
- `（放下刨子，指腹蹭过刚开的榫眼）`：放下工具＝腾出手来答话
- `（拿钳子夹起通红的铁块…白汽冒起来）`：正在打铁 ⇒ 解释"抢货"的不耐
- `（把红笔搁在作业本上，指腹还沾着点墨）`：教师身份处境
- `（蹲在灶前添柴，锅里水刚响）`：厨房同场景
- `（蹲在院墙根下拿树枝戳蚂蚁窝）`：蹲着＝闲等 ⇒ 解释"来讨饼"
- `（把火钳往水桶里一插，白汽窜起来）`：刚干完活 ⇒ 解释"饿得手抖"
- `（把药碾子往桌角推了推…半截没研碎的甘草）`：正在碾药 ⇒ 解释话题转向
- `（把药碾子里的山楂片拨了拨，捻起一片对着光看）`：同上

**新定义下仅存的 2 个"纯装饰"块**：`（顿了顿）`（`TH-P013-PUB-4-0` r4）、`（抬头冲他咧嘴）`（`TH-P011-P008-13` r13）——**都是纯表情/停顿，不提供任何处境信息**。
⇒ **真正的纯装饰几乎不存在**（2/56 = 3.57%），且**没有任何一条消息只有装饰而没有咬合**（故消息级咬合 100%）。

**两个数必须并列引用**：旧 82.35% 是"同物口径"，新 100%/96.43% 是"含处境口径"——**不是谁判错，是定义宽窄不同**。若只报新值，读者会以为旧判读有误。

**结论（只报事实、不作评价）**：**旁白多数（82.35%）与台词指同一件事**，因此它更像"**同一动作的可见化**"而非随机装饰；但 **17.65% 的装饰里，全部是"打铁/药碾等手上活"与"台词在谈吃食/他人"的错位**——这类错位集中在**同一角色同时干两件事**的场合。

## 5. 抽样脚本与输出（可逐字复算）

```python
import json,re,random,collections
SEED=42
PAIR=re.compile(r"[（(][^（）()]*[）)]")
def rnd(m):
    mm=re.findall(r'-(\d+)-', m.get('msg_id') or ''); return int(mm[-1]) if mm else None
def load(p):
    th=collections.defaultdict(list)
    for line in open(p,encoding='utf-8'):
        line=line.strip()
        if not line: continue
        d=json.loads(line); t=d.get("type") or ""
        if not t.startswith("MSG_"): continue
        pl=d["payload"]; th[(t,pl.get("thread_id"))].append(pl)
    for k in th: th[k].sort(key=lambda x:(rnd(x) or 0,x.get("turn_index") or 0))
    return th
for arm in ["narr-on-20261030","narr-off-20261030"]:
    th=load(f"v2/evidence/{arm}/run.jsonl")
    pub=sorted([k for k in th if k[0]=="MSG_PUBLIC"]); dm=sorted([k for k in th if k[0]=="MSG_DM"])
    short=[k for k in dm if len(th[k])<=3]; long_=[k for k in th if False] or [k for k in dm if len(th[k])>=4]
    rng=random.Random(SEED)
    pick=sorted(set(rng.sample(pub,3)+rng.sample(short,3)+rng.sample(long_,9)))
    print(arm, len(pick), [k[1] for k in pick])
```
