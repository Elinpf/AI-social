| ④ | **习惯偏好**（固定说话方式/口味/作息） | **弱，且与"模板复读"难区分** | 偏好类词 A1 **12/686 = 1.75%**、F6off **0/686 = 0.00%**；口语化口头禅存在（如"账要平"），但**同一角色高频贴尾**，更像模板而非偏好 | 「我管账三十年，最怕的就是"意外"两个字」 |
| ⑤ | **关系张力**（不同意/拆台/沉默抵抗） | **有，且是本批最稳的一维** | 观点交锋、软性推让、说服拉锯三类均有完整回合结构（§2 #2/#3/#5/#8） | 「差一点活了，差一点也死了。」（对上一句的直接反驳） |
| ⑥ | **记忆延续**（前文提过的事后文再提） | **有** | 同线程内跨回合回指可逐条核（§2 #6/#7/#8）；**跨线程**记忆未检出（未做检索，见 §5 局限） | 「李记那壶茶钱昨儿就划掉了」→ 后文「划掉就划掉吧」；「你当年学揉面，头一回是跟谁学的？」 |

**③ 的重要限定（必须随表引用，证据分四级）**：`误会与和解` 判"无"的主因是**生成侧机制未启用**，但四项证据强度不同，**不得合并成一句"跑批时未启用"**：

| 命题 | 判定 | 依据（我自己实测） |
|---|---|---|
| 代码层默认关闭，且当前配置 `enabled: false` | **PASS** | `code/config/dialogue_repair.json` → `"enabled": false` |
| 该 config **不受指纹保护** ⇒ 跑批当时的 `enabled` 值**不能由 `config_digest` 反推** | **PASS** | `engine/version.py::FINGERPRINT_FILES` 逐项核过，无 `dialogue_repair.json` |
| 两臂日志零 repair 痕迹（`repair` / `HITT_` / `dialogue_rift` 均为 0） | **PASS** | `grep -c` 实测：两臂 `repair=0, HITT_=0, rift=0` |
| **「跑批当时 env 未设 / 当时 `enabled` 就是 false」** | **CANNOT-VERIFY** | 日志不记 env；该 config 不在指纹内，digest 也证不了 |

⇒ **规范措辞**：「机制在代码层默认关闭、当前配置为 `false`、且两臂日志零痕迹 ⇒ 该维度未产生内容的主因是机制未启用（**跑批当时的具体开关值无法由日志与 `config_digest` 确证**）」。
⇒ **`0/686` 只能读作"机制未启用下的观测结果"，不能读作"该维度不可实现"**。这是本件最容易被人引错的一格。

**一句话总述**：**⑤关系张力与 ⑥记忆延续有实证据；②闲话存在但多为事务包裹；①日常节律偏科（只有饭点）；④习惯偏好弱且与模板纠缠；③误会与和解在 1,372 条消息里一条证据都没有。**

## 5. 局限（不读会误用）

1. **不得把本件读成"已达真人水平"**。本件只给"某维度存在/不存在这类证据"，**没有**给出与真人语料的对照，也没有任何盲评。

3. **跨线程记忆未检索**：⑥只核了**同线程内**回指；"前文提过、隔了几十个回合再提"这种未测。
4. **两臂同 id 不同文本**：同一 `thread_id` 在 A1 与 F6-off 里内容完全不同（见 §2 #6），**不得按 id 跨臂对比**，只能按文本对读。
5. **A1 臂含 13.85% 重复文本**（§3-B），凡"A1 里 X% 的对话如何"类统计须先剔重。
6. **`F3-on` 未用于任何判定**（异配置，仅参照），本件结论只基于 A1 与 F6-off。
7. **③「误会与和解」= 机制未启用下的观测**：代码默认关 + 当前配置 `false` + 两臂日志零痕迹（三项均 PASS）；但**"跑批当时的具体开关值"属 CANNOT-VERIFY**（日志不记 env、该 config 不在 `FINGERPRINT_FILES`）。**不得**把 `0/686` 引作"该维度为 0"或"模型做不到"，也**不得**写成"已证实跑批时未启用"。
8. **关键词法标注为 `（代理·关键词）`**：它只做筛查，不作维度测量（同一文本换关键词即变）。凡下结论须回原文人工核并报核了几条。
