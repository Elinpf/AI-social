3. **渲染进 prompt 的字段没变**：prompt 模板（`d12f_wiring_proof.md` §2 原文）只含 人格 / 场景 / 对象与熟悉度好感 / 情绪 / 最紧需求 / 目标 / D12C 具体物要求，**不含近期对话、不含自身上一句**；近期台词只用于择优打分（8-gram 交集）。
4. **body 不同而 prompt 相同 ⇒ 候选文本被复用、`picked` 因"最近 16 条台词"变化而改变** ⇒ 这不是"重复"，反而是"择优在工作"的直接证据。
5. 线程 id 每轮新开（`…-24` → `…-25`）⇒ 不是同一段对话的延续，而是"同一状态在新线程里被再问一遍"。
