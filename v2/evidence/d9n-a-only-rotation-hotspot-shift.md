## 4. 结论（三条，可分别引用）

**C1｜「蹭」确实降了 22.6%（31→24），但没有降到判据下。**
`(d)` 要求 `max_v ≤ 5`；24 距阈值仍是 4.8 倍。⇒ **A 对主短板是「削弱」而不是「修复」**。

**C2｜A 属于机制 (ii)「换了个集中对象」，不是 (i)「没变化」。**
两条独立证据：
- **词表直连**：`挪` +72%（3.66→6.28），而 9 句词表里恰有 2 句以「挪/撤」为落点 ⇒ 注入路径清晰；
- **词表外溢出**：`拍` 从 0 冒到 4.19，而 9 句里**没有任何一句含「拍」** ⇒ LLM 在禁用「蹭」后**自行换了一个同族的过渡动作**。
⇒ **「分散示例」无法消除动作同质化，只能改变同质化的落点。** 这一条与 D9k 的「词面模板 = 拿/用+工具+蹭/磨+受事」判断一致，但给出了**新的一层**：换成 9 句后模板换个词继续成立。

**C3｜A 带来一个新增越线（副作用）。**
`max_k` 2→3：出现 1 条 MSG 含 **3 个**成对括号片段（`e_dist = {0:9, 1:163, 2:18, 3:1}`）。`ON_CONST` 同口径只有 2（`(e)` 成立）。⇒ **A 让 `(e)` 从「成立」退为「失败」**。
⇒ 这条必须计入 D9m（A+B）的验收：**若 B 有效，应同时看到 `max_v ≤ 5` 且 `max_k` 回到 2**，只降 `max_v` 而 `max_k` 仍为 3 不算通关。

## 5. 边界（不可越证的四条）

1. **`A0_NOEXAMPLE` 不是本对照的臂**：它是 n16**r84**（686 MSG）、且是 D9 时代的 prompt（无禁令无示例），与 r24 三臂**跨单元**。它的 `max_v = 73（低）`、`dupMax = 12` 只说明「热点随 prompt 走」，**不得**用于「A 有没有改善」的任何计算。跨单元只允许比**归一化率**，且不得做显著性。
   **出现位置（明示许可）**：允许出现在 **§2 判据读数表的参照行**（已标 `[跨单元·参照]`）与本节；**禁止**出现在 §3 及之后任何含「变化 / 差值 / pp」列的表或句子里。
2. **`OFF` 臂 blocks=0 ⇒ 三条判据全部「不可判」**，不是「通过」。`NARRATION=0` 下旁白按构造为 0（D9i 已记 0/191），`(d)(b2′)(e)` 在无片段时**无定义**。
3. **本件的 `verb_counts` 是「每个片段首命中动词」（lexicon R2），不是「字面包含」**。D9k 的「含蹭 31/205」是字面包含且与 `ON_CONST.max_v=31` 恰好同值 —— **同值不等于同定义**，任何跨口径引用必须重算。
4. **n=191 的 `max_v` 差值不做显著性**。31→24 是描述性对比；若要判「A 显著降低了蹭」，需预登记 + 重采样，本件不提供。

## 6. 对下一步的直接含义

- **A 单独不足以作为整改手段**（`(d)` 距阈值 4.8 倍，且新增 `max_k` 越线）——D9n 的「行为层未改善」成立，本件把它精确化为「**降低 22.6% + 热词转移 + 新增越线**」；
- **B（禁「整理衣角/收拾手/擦手这类过渡动作」）必须有独立效应**才能解释为有效，不得与 A 的 −22.6% 混算；
- D9m（A+B）的判定必须**三条同看**：`max_v ≤ 5`、`max_k ≤ 2`、`b2′ 违例族 ≤ 1`。只满足其中一条即为「部分有效（不足以通关）」，不得写成「有效」。
