## 2. 旧尺子到底漏了什么（集合差，逐条计数）

| 计数（OFF / ON） | 含义 |
|---|---|
| `opener6_hit` = **42 / 57** | 旧口径判为"开口有物" |
| `first_clause_skip` 命中 = **112 / 146** | 位置修正后"开口第一个内容分句带物" |
| **`opener6` 漏判（旧判否、修正判是）= 70 / 89** | 旧尺子**在 OFF 臂漏掉 70 条（36.6%）**、**在 ON 臂漏掉 89 条（46.6%）**确实带具体物的发言 |
| `opener6` 判是但修正判否 = **0 / 0** | 修正档是旧档的**严格超集**（不丢任何旧命中）⇒ 两档可比、可对账 |
| `skip_only`（`first_clause` 判否但 `first_clause_skip` 判是）= **64 / 85** | 增益主要来自"称呼/寒暄之后才落物"的那一段 |

**R49 选点缺陷：证实。** 证据是三条，不是一条：

1. **量级错**：旧窗只在 22%/30% 的发言里命中，而按"开口第一个内容分句"口径，实际有 **58.6%/76.4%** 的发言带具体物
   ⇒ 旧判据把基线压在 1/5 附近，等于**在一个被压扁的量上做功效计算**（MDE 10.7pp 建立在错误的 p1 上）。
2. **对象错位**：R49 ON 臂典型句 `金先生，（把琴弓在松香上蹭了两下）天刚亮我就开练了…`——具体物在**称呼与旁白之后**，
   旧窗判 0。这类"称呼后落物"的条目在 ON 臂有 89 条被漏，比 OFF 臂的 70 条**多 19 条**
   ⇒ 干预越有效，旧尺子漏得越多，**方向性偏差会系统性低估 ON 臂**（这解释了为何 R49 的 +7.85pp 看起来那么弱）。
3. **旁白/称呼不是内容载体**：`anywhere`（含旁白）已 97.9%→100%，说明"有没有说具体物"根本不是问题；
   旧尺子把"旁白里有物"当成"句中已饱和"、把"称呼挡住前 6 字"当成"没有物"，两次都测错对象。

**同时必须说清**：以上是**位置口径的差异**，**不是效果的证明**。R49 的结论（机制未生效 / 效果不可判）**不因本文件而改变**。

## 3. 对下一轮（R50）意味着什么（只做功效估算，不做判决）

| 项 | 读数（脚本产出） | 怎么用 |
|---|---|---|
| 主判据候选 `first_clause_skip` 的 `p1`（OFF 实测） | `0.586387` | 填 R50 预登记 §5，MDE = **14.4pp**（`n=191/臂`） |
| 若希望检出 12pp 级效应 | 每臂 ≥ **271** 条消息 | 预登记 §5 方案 B 的成本依据 |
| 若希望检出 10pp 级效应 | 每臂 ≥ **390** 条消息 | 预算不足则不追此档 |
| `first_clause`（守卫档）`p1` | `0.251309` ⇒ MDE 11.4pp | 只作方向一致性守卫（Δ>0），不设显著性 |
| `no_cue` 两臂差 | −2.09pp（< 10pp 阈值） | 未触发 R50 预登记 U7 的"地板漂移"不可判条件 |

**为什么主判据选 `first_clause_skip` 而不是"看起来更容易过"的那档**：

- 它的基线最高（58.6%）、剩余抬升空间最小、`n=191/臂` 时 **MDE 最大（14.4pp）** ⇒ **它是四档里最严的闸**，不是最好过的闸；
- 它是唯一**直接对应机制假设**的窗口（"把具体物搬到开口处"，而不是"旁白里有没有物"或"整句有没有物"）；
- 为防止窗口机械性造成假象，预登记另设 **M1b 一致性守卫**（`first_clause` 必须同向为正）。

**必须同屏的风险声明**：`first_clause_skip` 的"跳过≤2个短分句"参数是在 R49 同一批数据上定的 ⇒ 该窗口对 R49 数据存在**拟合成分**。
因此 ① 它的 MDE 用的是 R49 实测 `p1`（与判据同源）；② 预登记建议下一轮换 `seed 43`（新世界），使下一轮成为**真正的独立检验**；
③ 报告必须**四档 + `no_cue` 同屏**，禁止只摘主判据。
