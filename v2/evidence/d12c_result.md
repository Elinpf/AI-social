## ⑦ 边界

1. **单 seed（42）/ 单规模（n=16×r60，510 条）/ 中性树**（`3ec85a0` base，`paren_rate` ≈0.79 而非 0）——外推到其它 seed/规模/非中性树需重测；
2. **提示词只差两行**（`LIFE_PROMPT_D12C_SPECIFIC` 开关渲染），属单变量；但**回答侧仍受模型非确定性影响**（D5 §5：同 seed 逐条一致仅 21.3%），故一切结论为**分布级**；
3. **bootstrap 只反映抽样不确定性**，不含 run 间非确定性；
4. `L-7`/`L-6`/`paren_rate` 为**辅助观察**，不进 §10.4 判定；
5. **`run_f6_off_n16r60_seed42` 不是中性树**（`paren_rate=0.0`、`len_p50=29`、`L-6≈19.4%`），**与 D12-C 不可比、不作基线**；
6. 本表所有"带外/达标"判断均以**冻结读数器 + bootstrap CI（B=2000/seed42）**为准；CI 含 0 一律写"无结论"。
