  - `src/main.js::startLiveTail()`：只随增长取字节 + **节流重建**（MIN_BUILD=4s）+ **显式状态**；`index.html` live-box 增 `live-batch`/`live-status`。

## 对照 Leader 四条约束
1. **防穿越**：白名单根 `HITT_LIVE_ROOTS`（默认 `/root/t271/runs`），**realpath 规范化后**判落点；只读；文件头明示"**本地开发服务，非对外**"。实测：白名单内可取，`/etc/passwd` 被拒。
2. **首轮尾窗**：默认从末尾 **4MB** 回退并**对齐到完整行边界**（绝不返回半行，防首条残缺污染解析）；界面标"**尾部窗口**"。实测 1MB → 2282 行、首行为完整 JSON。
3. **治静默定格**：状态显式 —— `连接中… / 跟随中 / 等待新数据 / 无增长（疑似已结束） / 读取失败：<原因>`；`eof` 且连续 3 次无增长 ⇒ 显式"已结束"并**停止轮询**（状态可达）。
4. **只随增长走 + 增量量级**：单次增量 = 自上次 `off` 以来的**新增字节**（夜间 ~26KB/s ⇒ 每次轮询约 **几十 KB**；**无增长则 0**）；**不再整文件重下**（旧实现每 600ms 重下整份）。
