### 1.1 「内容寻址等价性证明」落点（这是复用 OFF 臂的唯一依据）

预登记 §2 要求两臂**同 `code_sha`**；实测两臂 `code_sha` 不同 ⇒ **必须由等价性证明补上**，否则应判 CANNOT-JUDGE。我逐条复算如下：

```bash

git diff --stat fff3e2da..46cfd9e -- code/   # 空
git diff --stat 46cfd9e..9dce475 -- code/    # 空
```

| 项 | 值 |
|---|---|
| 两臂 `code/` 子树对象 | **同为 `616c7147c44017889f3027840ba14a256cdfd901`** |
| `git diff --stat fff3e2da..46cfd9e -- code/` | **空**（`code/` 逐字节等价） |
| `git diff --stat 46cfd9e..9dce475 -- code/` | **空** |
| 结论 | **代码侧单变量成立**：两臂仅差 `LIFE_PROMPT_SCENE`（ON=`1`；OFF 不设该变量） |

**该证明的能力边界（必须同屏）**：内容寻址等价只保证**代码同构**，**不保证**"两臂同一次进程 / 同一采样序列"。⇒ 残余不可消项：**跨批采样噪声 + model drift**（单 seed，见 §7）。
