# T350 · N=50 真 LLM 小规模可行性探针（N=50×12）

> **性质：非证据级探针**（供判断，不当作结论）。**目标**：把「真 LLM 下 50 人能不能跑、多慢」从"未知"变成"有数"。
> **实现锚（provenance）**：**冻结副本 sha = `10428f24`**（`git archive` 于 12:38 解出，`/tmp/t271-probe50/code`）。⚠️ **不是主树 HEAD**（跑批不读主树）。

## 0. 结论摘要
1. **能跑**：N=50×12 真 LLM **跑满 12 回合、`rc=0`、自检全绿**（`chain_ok=True replay_parity=True conservation_ok=True`），**未碎**。
2. **多慢**：引擎实测 **9998.5 s（2h46m39s）**；墙钟 **12:40:59→15:31:00 = 10201 s（2h50m）** ⇒ **≈833 s/回合（13.9 min/回合）**。
3. **成本主项**：`LLM_CALL=43,798`（全 `openai_compat`，**无 mock**）；**`importance` 占 95.6% 但 97% 命中缓存**（便宜）；**`judge` 仅 3.4% 却零缓存**（贵）。缓存命中 **92.7%**。
4. **内存**：peak RSS **448 MB**（未触 `MemoryMax=8G`）。
5. **对照 N=20**：**调用/回合 ≈ 63.7×**（N 仅涨 2.5×）⇒ **强超线性**；但**token/回合仅 ≈10×**（因 N=50 的调用被廉价 `importance` 缓存摊薄）。

## 1. 复现命令（绑 sha `10428f24`）

```bash
     --side-root /root/t271/runs/t350_n50_real/side --flush-every 3
```

## 2. 计时口径（全 —— 三件必须一起读）
- **单核**：跑批单进程、无并行 worker；主进程全程 CPU 仅 ~53 s（**LLM-IO 受限**，非 CPU）。
- **并发**：**确有一次重叠** —— kernel 12:43 跑 `make verify`（T338），与本批（12:40 起）短暂重叠 ⇒ ⚠️ **时长读数受一次并发 verify 影响**（不抹掉，如实标注）；当前 `ps` 无 verify/pytest 后，读数主体干净。
- **缓存冷热**：**冷缓存**（`freeze_cache` = `<side_root>/freeze_cache`，起跑前 `rm -rf` side）。⚠️ **与 N=20 那 90 min 的"热/共享缓存"口径不同 ⇒ 不能直接比 per-round**。
- **世界层变动**：运行期主树世界层被改（kernel `T338` = `d598f47`）——但本批读 `10428f24` **冻结副本**（`cwd=/tmp/t271-probe50/code`、`/proc/<pid>/maps` 主树 `code` 映射数=0、`PWD=/tmp/t271-probe50/code`）⇒ **对该批零影响**（非"影响小"，是"不读主树"）。两 sha 并列记录：起跑 `10428f2` / 12:45 后 `d598f47`。
- **落盘口径**：`--flush-every 3` ⇒ 落盘点在 round **2/5/8/11**；"某回合未落盘"**不代表没跑到**（缓冲中）。

## 4. 与 N=20 真 LLM 对照（**同口径：真 LLM 单核；缓存口径不同，务必读**）
| 指标 | N=20×84（热/共享缓存） | N=50×12（**冷**缓存） | 比值 |
|---|---:|---:|---:|
| 墙钟 | 3781.6 s | 9998.5 s | — |
| **s/回合** | 45.0 | **833** | **18.5×** |
| **调用/回合** | 57.3 | **3650** | **63.7×** |
| **token/回合** | 7,863 | **78,508** | **≈10×** |
| 每 agent-回合 调用 | 2.865 | **73.0** | 25.5× |
| 缓存命中 | 65.3% | 92.7% | — |
| token/调用 | 137.2 | 21.5 | — |

> ⚠️ **两条免责**：① N=20 是**热/共享缓存**、N=50 是**冷缓存** ⇒ **s/回合、调用/回合不可直接比**；② N=20 是 84 回合均值（跨 7 天平滑），N=50 只 1 天且含"段首爆发" ⇒ 口径不同。

### 4.1 「是否 O(N²)」判断
- **调用维：强超线性，指数 > 2**。调用/回合 63.7×（N 仅 2.5×）⇒ 拟合指数 `log(63.7)/log(2.5) ≈ 4.5`；每 agent-回合 25.5× ⇒ 指数 `≈3.5`。
- **结论**：**确实超线性，且比 O(N²) 更陡**（受"事件触发型 `importance`/`judge` 随人口/记忆/关系对累积放大"驱动 —— 与 `v2/refs/scale-50-efficiency.md` §2 同因）。
- ⚠️ **口径限制**：冷/热缓存、12 vs 84 回合、段首爆发不同 ⇒ 指数是**量级判据**，**非精确拟合**。
