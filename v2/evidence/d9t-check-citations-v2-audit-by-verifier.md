## 3. 建议修法：标注必须"绑定紧邻括号"，而不是"落入窗口"

最小改动（把"窗口内出现白名单词"换成"**紧跟在该 sha 的括号里**出现"）：
```bash
# 只认紧邻：`<sha>` 后 0–3 字内出现的 （…）/(…) 里含白名单词
tail_ctx=$(printf '%s' "$line_text" | sed -E "s/.*${tok}.{0,3}([（(][^）)]*[）)])?.*/\1/")
printf '%s' "$tail_ctx" | grep -qE '历史版|内容 sha|字符串级|不存在|已废弃|未入库|MISSING' || 报漏
```
判据一句话：**标注是"给这个 sha 的"，就必须贴在它自己身上**；贴在隔壁 sha 身上不算。

**并把 `t2.md` 这 4 行加进 `--selftest` 作第三组**（期望：L2 的 `78ec29a6…` 必须 **BAD**、L3 的必须 **BAD**）。现在 selftest 只测"无标注死 sha"和"strict 待审"，**测不到"辐射"这种跨 token 污染**。
