## 2. N-3：逃生门实测（这是本轮核心）

夹具（`vv_t4.md`，两行）：
```
- 错引用但无路径：`deadbeef1234567890`
- 正确引用带路径：`86e448e09b6fd517` 见 v2/refs/D9t-launch-checklist.md
```
非 strict（= `v2/evidence/` 件口径）实跑：
```
  content(实测值·免核) L2  deadbeef1234567890              ← ✗ 错引用被判"实测值"豁免
  **BAD(content 不符)** L3  86e448e09b6fd517  <- … 实际 77643f93…   ← 带路径的反而被抓（正常）
== 共 2 个：可核 0，待审 1（豁免），漏 1 ==
```
strict 实跑：
```
  **BAD** L2  deadbeef1234567890  ← 非对象、无路径      ← strict 下能抓
  **BAD(content 不符)** L3  …
== 漏 2 ==
```
⇒ **结论**：只要该件按 `v2/evidence/` 走非 strict，**任何错的外部引用只要不写路径就自动豁免**。而"引用要带路径"这条**只是约定，脚本无法强制**——作者不写，就等于豁免。

## 3. N-4：为什么这不能接受（与"空集不算通过"同构）

今晚刚立：**"什么都没比到" ≠ "没变"**（`FP` 空目录给稳定假指纹 → 假通过）。
这里是同一形态：
- **"没写路径" ≠ "证明是实测值"**，而是**"没提供证据"**；
- 于是 **豁免从"作者举证"变成了"作者沉默"** —— **免费豁免 = 空检查**。

**修法（一处小改，两行）**：豁免必须**显式**——
```
无路径的 sha：同行必须含「实测值」或「内容 sha」字样 ⇒ 才判 content(实测值·免核)
              否则 ⇒ 仍列"待审（未声明）"，非 strict 下**不算漏但要报**，strict 下算漏
```
判据一句话：**豁免要付费（写两个字的标注）；免费豁免等于没有检查。**
成本很低：你库里那 9 个豁免项，只需在同行补「实测值」三字即可（9 处）。
