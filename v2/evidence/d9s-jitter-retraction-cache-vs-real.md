## 5. 今天真正该记的一条规程

**R-11｜任何"跑批结果"必须先报真调用率，再读数**

```bash
# 每条 LLM_CALL 的 payload.tokens_in > 0 ⇒ 真调用（命中缓存时为 0）
python3 -c "
import json,collections
by=collections.Counter(); real=collections.Counter()
for l in open('<run.jsonl>',encoding='utf-8'):
    e=json.loads(l)
    if e.get('type')!='LLM_CALL': continue
    p=e['payload']; k=p.get('purpose','?')
    by[k]+=1
    if (p.get('tokens_in') or 0)>0: real[k]+=1
for k,n in by.most_common(): print(f'{k:14s} {n:5d} 真{real[k]:5d} ({real[k]/n*100:5.1f}%)')"
```

配套三条：
1. **两臂必须同为 100% 真跑**（各用全新 side-root），否则判「不可比」；
2. **"抖动"只能由"两次都 100% 真跑"的同配置臂估计**，否则写「不可测」，不得引用上界代替；
3. **`cached=True` 这个字段不能直接当"回放"证据** —— 它的口径是 `meta` 统计，与 `tokens_in` 不一致（本例 `meta` 报 191/191，`tokens_in` 实测 183/183 真调用）。

## 6. 这条错误的性质（比前几次深一层）

今天我已经纠正过 5 次「把两个量当成一个」。**这次不是两个量，是同一个量的两种"来源"**：
- 同一个数字（① 74.13%），可以是「新鲜采样 191 次」得到，也可以是「回放 184 次 + 采样 7 次」得到；
- **两者在同一个表里长得一模一样**，而**只有后者能代表"模型会怎么写"**。

⇒ **"跑了" ≠ "生成了"。** 我在今天之前的所有判定里，从未问过这一句。
