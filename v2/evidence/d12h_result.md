## ⑥ 方法层结论（**本臂真正的产出**）

**`L-7` 用"各批自己的全局 shingle 索引"⇒ 基线与实验臂的参照系各自为政 ⇒ 跨批比较天然受限。** 本臂把它直接量化了：**同一批候选，只换参照系，符号就反转**（自身历史 −4.97pp vs 外部语料 +4.26 / +9.02pp）。
⇒ 三条推论：
1. **跨批 `L-7` 差（D12-E/F/G 的 −9.22 / −12.55 / −3.92pp）只能读作"各批内部去重程度的变化"，不能读作"与前一批相比的净减少"**；
2. 这解释了"D12-E/F/G 改善但不够大"：**评价指标（全局索引）与优化目标（`recent16`）不同源**，且两者都无法与另一批直接对齐；
3. ⇒ **下一臂的选优目标应换成"对固定外部语料的 `overlap_frac`"**（本报告 §④ 的口径），这样**目标、判据、参照系三者同源且跨批可比**。

## ⑧ 边界

1. **墙钟口径冲突**：任务卡写"47 分钟"，`meta.duration_sec = 4,046`（67.4 分钟）。我按 meta 报，**请以 meta 为准**；若任务卡用的是"从首个 LLM 调用到末个"的另一口径，需在终态核验里统一，否则会被引用成两种时长。
2. **`resampled` 字段语义歧义**（累计 vs 每候选）+ **成本超预估 21%**：已披露；建议下一臂把 `resampled` 拆成 `resampled_per_cand[6]`。
3. **本臂 treatment 与预登记不符（第二重混淆）**：预登记写"ON/OFF 唯一差别是一行提示词"，实测差别还有"旁白消失 66.27%→0.20%" ⇒ **"只开一个结构位"在效果层不成立**；下一臂须在预登记里加**形态闸**（`L-3` 相对基线的允许漂移，如 ±5pp），并在 1/3 处先核。
4. `F-2′`、`L-15`、`overlap_frac` 匹配为**点估计阈值，未做显著性检验**；`overlap_frac` 的 CI 是**配对 bootstrap**（slot 级 / 线程级），不含 run 间非确定性。
5. **`ctx` 未落候选文本**（只有 shingle hash 列表 + counts）⇒ "选中那条具体写了什么"只能人读落库体，**OFF 组候选文本完全不可见**。
6. 单 seed / 单规模（n16×r60，510 条）/ 单树；无人类评证据 ⇒ **不作任何"更自然/更好读"判断**。
7. **外部参照语料本身是另一批的产物**（T5/T1）⇒ "重叠更低"也可能反映"文体不同"，不能单独读作"陈词更少"（§⑤-2 已由此得到实证支持）。
