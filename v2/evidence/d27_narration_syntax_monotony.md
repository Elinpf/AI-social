# D2.7 补充事实：**旁白"词汇多样、句法单一"** —— 60.2% 以「把」开头，46.6% 是「把…往/在…」骨架

> 日期：2026-10-24。对 B 臂 502 条旁白的句式统计。**本件是 `d27_amendment4` 的量化补强，也是并发线 `cb26a38` 判断的独立验证。**

## 1. 读数（可复算）

| 量 | 值 |
|---|---|
| 旁白条数 | 502 |
| 互异旁白 | 420（83.7%） |
| **以「把」开头** | **302（60.2%）** |
| **「把…往/在/向/回」骨架** | **234（46.6%）** |
| 首字 TOP6 | 把 302 / 拿 62 / 捏 41 / 用 13 / 放 9 / 掀 9 |

⇒ **词汇层面确实多样（420 种），但句法层面高度单一：近一半旁白是同一个"把 N 往 P 一 V"模板。**

## 2. 这解决了两个悬而未决的问题

1. **为什么"互异 420 种"却读起来单调**：变的是名词与动词（算盘/锄头/账本），不变的是**骨架**。
2. **`L-7 +3.00pp` 的真正来源**：不是"同一条旁白反复"，也不是"词汇贫乏"，而是**共享 8-gram 骨架**
   （"把…往…一…"这类片段在 234 条旁白里重复出现）。我此前"词汇模板化"的判断**方向错了**，并发线的"句法骨架集中"才是对的。

## 3. 对 D2.8 与下一步的意义

- **D2.8（概率性旁白 + 台词配额）不解决句法单调**：它只控制"要不要旁白"与"台词多长"，
  不约束"旁白怎么写"。所以 D2.8 即使 P1/P2 达标，也别指望 `L-7` 改善——**不要把 L-7 当 D2.8 的期待**。
- **若后续要压 L-7，应约束句式多样性**，而不是继续压旁白长度：
  - 候选约束：「避免连续两句都用『把』起句」「每 5 句至少 1 句不以『把』开头」「动作要落在具体器物上，不用『把…一 V』套式」；
  - 这类约束**与"生活质感"不冲突**（真人动作描述本就以动词为主、句式各异）。

## 4. 局限

- 仅 seed42 单批、仅 B 臂（C 臂无旁白，无从比较句式）；
- 骨架判定用的是正则近似（`^把` / `把.{1,8}[往在向回]`），可能低估其它套式（如"…了一下"）；
- 不作判据，仅作方向参考。
