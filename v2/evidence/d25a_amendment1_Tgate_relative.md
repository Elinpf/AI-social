## 2. 修正（不动阈值，只改参照系）

**T 闸由"绝对 PASS"改为"A vs C 相对不劣化"**（口径与 §3.115 的 B−C 同精神）：

| 闸 | 原（作废） | 改后（有效） |
|---|---|---|
| T1 | F1 绝对 PASS（±5pp vs T5 57.84%） | **`paren_rate(A) − paren_rate(C)` 的绝对值 ≤ 5.0pp** |
| T2 | F2 绝对 PASS（±15pp vs T5 36.47%） | **`addr_head_strict(A) − addr_head_strict(C)` 的绝对值 ≤ 15.0pp** |
| T3 | F3 绝对 PASS（±10% vs T5 53.0） | **`len_p50_excl` 相对 C 的变化 ≤ 10%** |

阈值**一个都没改**（5pp / 15pp / 10% 原样），只把参照系从"T5 旧树"换成"同批 C 臂"。
理由：本臂要测的是**配额 2→3 是否改变形态**，只有 A vs C 有意义；vs T5 属跨树比较，已不可比（`d26` 系列与 §3.117 已确立"锚点必须按树实算"）。
