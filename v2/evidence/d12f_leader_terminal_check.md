## 4. ⚠ 判定：按预登记是「机制未生效」，但这个判定**不能**被读成"候选结构多样化无效"

**按预登记 §3**：M4 未达 ⇒ 判定词 = **「机制未生效」**（不许因"差 3.43pp"或"`L-7` 达标"改判）。

**但必须同时写清三件事**（否则报告会误导）：
1. **`L-7` norm8 首次达标且降幅最大**：**65.10% → 52.55%（−12.55pp）**，比 D12-E 的 −9.22pp 更强；
2. **机制在 `scores` 上是压倒性有效的**：候选 1/2 与近期台词的交集均值 **0.37 / 0.38**，而候选 0 是 **2.02**（1/5.5）；argmin 命中 **110/110**；
3. **M4 是坏闸**（见 `v2/evidence/d12f_m4_gate_defect.md`）：它测的是"三候选 `scores` 是否全相同"，而**三候选都与近期台词无交集时（scores 全 0）必然同分**——**哪怕候选文本差异巨大**。实测 21.57% 的"不可分"多数属于这种情况。

⇒ **一句必须同屏的结论**：
> 「按预登记判**『机制未生效』**（M4 21.57% < 25%）；但该闸受『三候选全 0 必然同分』的天花板限制，**机制本身的直接证据是** `L-7` norm8 **−12.55pp 首次达标**、`scores` 均值 **2.02 vs 0.37/0.38**、argmin **110/110**。」

## 5. 我的裁决（三条）

1. **判定不改**：「机制未生效」——这是预登记的意义，也是我不许别人因"差一点"通融的同一条规则，不能对自己例外；
2. **但 D12-F 的效果数据必须保留为独立证据**：`L-7` norm8 **52.55%（首次达标）**、raw8 **65.10%（差 0.98pp）**、三项代价闸全守 —— **下一臂的基线应用 T4，不是 T1**；
3. **M4 永久废弃**，下一臂改用 **`cand_jaccard_dist_mean`（候选文本两两 8-gram Jaccard 距离均值）**，且**必须落 `candidate_shas`**（本轮缺口，已写入 runbook §3.104）。
