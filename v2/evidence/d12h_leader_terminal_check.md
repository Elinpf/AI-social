## 4. 判词

按 **amendment-2 §4**：本 run 的历史"仅 ON 生成"不可回溯，外部参照系是**该件起生效的新判据**，**不能回溯给本 run 定判定** ⇒ 判定词 = **「不可判定（设计混淆：历史仅由 ON 生成，配对比较含自亲和偏差）」**。

**但必须同屏写（这是本臂真正的价值）**：
> **在固定外部语料下（与本 run 落库选择无关），ON 组对项目公共语料的重叠显著更低：对 T5 前缀 −4.26pp（绝对命中 3.30 vs 5.50，低 40%，CI 不含 0）、对 T1 前缀 −9.02pp（1.57 vs 5.45，低 71%，CI 不含 0）；而"自身历史"口径反号 +4.97pp，正是自亲和偏差。⇒ 该约束**确实减少"说别人说过的话"**，但**这不是本 run 的判定**，而是为下一臂建立的双参照系基线。**

## 5. 这一臂真正改变了什么（方法层）

1. **"与自身历史比"会给出反向结论**：D12-H 的自身历史口径 −4.97pp（ON 更差），外部语料口径 +4.26/+9.02pp（ON 更好）——**同批数据、两个方向**；
2. ⇒ **凡"与共享历史重合"类指标，参照系必须固定为外部语料**，否则落库组会污染参照系（runbook §3.110）；
3. ⇒ 这也解释了 D12-E/F/G 的 `L-7` 为何"改善但不够大"：`L-7` 用的是**本 run 自身**的全局索引，而 `L-7` 的基线 T1 也是各自批次的自身索引 —— **同族但参照系各自为政**，跨批比较天然受限。
