# D12-H 中途发现：**两个口径方向相反** —— 「开头约束」把重复从"最近 16 条"搬到了"更早的历史"

> 作者：Leader｜2026-10-23 23:00｜**中途读数（40/60 轮、332 条有效对）**，非终值
> 复算：`.worktrees/d12h-pairing/tools/d12h/overlap_frac.py --log <run.jsonl> --out-json <json>`（出数时全局重算，不采信落盘自证）

## 1. 事实（同一批消息、同一上下文、真配对）

| 口径 | ON 组（开头约束） | OFF 组（T1 逐字节） | 比较 |
|---|---|---|---|
| **选优指标** `recent16_scores`（run 内 argmin 用） | **D12-F 实测均值 0.357** | **2.463** | ON **远优**（低 1/5.5） |
| **判定指标** `overlap_frac`（全局累计交集率） | — | — | **ON 反而更差**：`mean(d) = **−3.90pp**` |

配对差 `d = off.overlap_frac − on.overlap_frac`：
```
n = 332 个有效对（valid_pairs 332 / invalid 0 / na_on 0 / na_off 0）
mean(d) = −0.038994（含 d=0）
slot 级 CI = [−0.0535, −0.0254]；thread 级 CI = [−0.0546, −0.0258]   ⇒ 整段负、不含 0
三分比：d>0 48 / d=0 169（50.9%）/ d<0 115
```

⇒ **`d < 0` 意味着 ON 组被选候的全局交集率更高（更重复）。方向与预期相反。**

## 2. 机制解释（可验证）

"开头先叫对方一声"⇒ **ON 组 3 条候选全部以"称呼 + 名字"起头**（D12-F 的形态证据：被选中时 95.92% 以称呼起头）。而**名字是高频 8-gram 前缀**，历史里到处都是同类句式 ⇒

> **约束把重复从"最近 16 条"推到了"更早的历史"**：与近处不同了，但与远处撞得更多 ⇒ **总重合没降，略升**。

## 3. 这解释了什么（比 D12-H 本身更重要）

1. **`recent16` 作为选优目标是错的**：它奖励"与最近 16 条不同"，但**不约束与更早历史的重合**；模型可以靠"换个说法绕开最近几条"骗过这个目标，而总重复不变甚至升。
2. **这给 D12-E/F/G 的 `L-7` 改善设了一个上限**：`L-7` 用的是**全局 shingle 索引**（任何人重合都算）⇒ 当"近处去重"是**搬移**而非**消除**时，全局指标只会小幅下降（实测 D12-F −12.55pp、D12-G −3.92pp，而 `recent16` 口径的改善达 1/5.5）。
3. **所以前几臂的"有效"里含一部分"指标搬移"**：这不是说它们无效（`L-7` 确实降了），而是说**优化目标（`recent16`）与评价指标（全局 `L-7`）不一致**，收益被结构性削弱。

## 4. 若终值维持此方向，判定应如何

按预登记 §2：判据 1 要求 `mean(d) > 0` 且 CI 不含 0。
实测 `mean(d) = −3.90pp`、CI **整段负** ⇒ **判据 1 明确未达，且方向相反** ⇒ 判定 **「机制未生效」**（不是"不可分辨"，因为 CI 不含 0 且整段负 —— 效应可辨，只是方向相反）。

**但必须同屏写**：
> 「ON 组在 `recent16` 口径上更优（0.357 vs 2.463），在全局口径上更差（−3.90pp）⇒ **约束把重复搬到了更早的历史，而非消除**。故本臂的"机制未生效"应读作**「该约束不降低总体重复」**，不是「约束没被执行」。」

## 5. 边界

中途快照（40/60 轮、332/510 对），终值以全批为准；单 seed / 单规模 / 单树；`overlap_frac` 的"全局"是**批序**（非 agent 实际上下文）；口径细节见预登记 v3 §5。
