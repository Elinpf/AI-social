## 0. 为什么需要这个工具（一条实证结论换来的）

`L-7_dup_ngram8_rate` 的定义是「**与任一其他 MSG 共享 ≥1 个归一后 8-gram 的 MSG 数 / 总 MSG 数**」。
⇒ 分子取决于"能否别处找到同一 8-gram"，**因此任一条目变长都会抬高其他条目的命中率（双向碰撞）**。

D9i 的旁白开关把 body 平均长度抬了 **+41.5%**，`L-7` 表面 **+7.33pp**；但**剥掉新增载体后重算，`L-7` 反而低 7.33pp**。
⇒ 那是**暴露面效应**，不是质量下降。**这类"看起来退化"的指标必须在"同口径"下复算一次**，本工具把这一步自动化并给出判定。

## 1. 它输出什么

| 输出 | 内容 |
|---|---|
| **暴露面** | MSG 数（=候选池）、dup 命中数、`L-7`、**body 平均字符**、字符总数、**8-gram 总数**、8-gram/条 |
| **同口径重算** | 剥除「新增载体」（默认＝成对全角/半角括号内旁白）后，同上全部量，**两臂都剥** |
| **差异** | `L-7` 原始差（pp）、`L-7` 同口径差（pp）、body 平均长度差（字符/百分比）、8-gram 总数差（/百分比） |
| **判定** | `PASS` / `WARN-暴露面效应` / `FAIL` + 一句理由 |
| **退出码** | 判定为 `FAIL` → **1**，否则 **0**（可直接当 CI 闸门） |

## 2. 判定阈值（预登记，写死）

```
raw   = L-7(on) − L-7(off)                    （原始口径，单位 pp）
same  = L-7(on剥) − L-7(off剥)                （同口径，单位 pp）

① raw ≤ +5.00pp                     ⇒ PASS
② raw > +5.00pp 且 same < +2.00pp   ⇒ WARN-暴露面效应
③ raw > +5.00pp 且 same ≥ raw       ⇒ FAIL（同口径差未下降 ⇒ 疑真实退化）
④ 其余（raw > +5pp、+2 ≤ same < raw）⇒ FAIL（无法归因于暴露面）
```
> 阈值改动**必须另立预登记**；本工具把两条门槛写在文件顶部常量 `RAW_DIFF_GATE_PP / SAME_DIFF_GATE_PP`，便于审计。

## 6. 局限（必须随工具一起引用）

1. **只支持剥"成对括号"这一种载体**；将来若有别的"新增载体"（如新的句末标记、新字段），需扩 `strip_narration()` 或加 `--strip` 策略，否则"同口径"不是真同口径。
2. **未做长度分层**：本工具用的是"全体同口径重算"。更严格的做法是**按 body 长度分桶后比较同桶命中率**，此处未实现（若需要再加 `--stratify`）。
3. **不给置信区间**：`L-7` 是小样本比率（本例 n=191），差异的抽样波动未建模；**小 n 或小计数时不得把 pp 差当显著**（D9i 的 12 条子集 `2/12` CI 宽到 [0.047,0.448] 就是例子）。
4. **不判"哪个臂更好"**：工具只回答"差异能否被暴露面解释"，**质量结论仍需人工读样本**。
