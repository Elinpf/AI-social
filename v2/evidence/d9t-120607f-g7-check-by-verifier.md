## 3. C-4/C-5：G7 是双条件，而相对条件**在基线上已破**、且**分辨力不足**

**算术（无需再跑，全部可复算）**
```
绝对条件：≤5%             → ON2 3.45% ✓（余量 1.55pp）
相对条件：≤ OFF + 2pp = 1.03 + 2 = 3.03%  → ON2 3.45% ✗（超出 0.42pp）
```
⇒ **件里"余量 1.6pp"只算了绝对条件。按"且"的口径，G7 在 OFF/ON2 现值上已经不成立。**
⇒ 若 D9t 沿用这条，**ON 臂必须把短旁白压到 ≤3.03%**（即 174 片段里 ≤5 条），比现值 3.45%（6 条）更低——**这是一条"必须改善"的门，不是"不许恶化"的门**，件里没这么写。

**分辨力（这条更要紧）**
```
OFF 侧基线只有 2 条（2/194）；OFF+2pp 在 174 分母上 ⇒ 3.03%×174 = 5.27 条
⇒ 判定空间 = 「≤5 条」vs「≥6 条」—— 整条判据只差 1 条片段
```
而本线已实测：**同配置两跑 ON 之差 = 2.67pp**（远大于 2pp 的门槛宽度），OFF 两跑之差 1.13pp。⇒ **G7 的相对条件落在计数噪声带内，没有分辨力**（换跑一次就可能翻转）。

⇒ 建议二选一：
- **删掉相对条件**，只留绝对 `≤5%`（并承认它很松）；或
- **改成绝对条数**（如"短旁白 ≤5 条"，与 R-9 线里"验收门槛优先用绝对条数"一致），并声明它**只在 174±10 片段规模下有效**。
