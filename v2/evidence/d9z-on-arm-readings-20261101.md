## 5. **必须同屏的读数事实（本件最重要的三条）**

### 5.1 `gap≥2` 的**绝对条数两个臂完全相同：48 = 48**
```
OFF：48 / 125 = 0.3840
ON ：48 / 278 = 0.1727
```
⇒ **`B` 的"降 55%"全部来自分母从 125 涨到 278，不是"迟回变少了"。**
**机制实际做的是"在原有 48 条迟回之外，新增了 133 条同轮回复"，而不是"把迟回改成了同轮"。**
**任何写成"迟回减少 55%"的说法都是错的**，只能写"迟回**占比**降 55%，迟回**条数**不变"。

### 5.2 新增的 155 对（278 − 125）落在哪
```
gap=0：0 → 133（+133）
gap=1：77 → 97（+20）
gap≥2：48 → 48（+0）
```
⇒ 新增量**几乎全在 `gap=0`**（133/155 = 85.8%），其余在 `gap=1`。

### 5.3 分母变大本身需要解释（不是免费的）
本批 `rounds` 56 vs OFF 24、MSG 444 vs 191 ⇒ **分母涨是"跑得更久"的直接后果**。
⇒ **`B` 过与 `A` 过都同时受了"跑更久"的影响**，判定件必须把"轮次/规模不同"写进归因，**不得把占比下降独归机制**。
（`n` 的规模是预登记指定的 —— 这一条不是违规；但**读数解释必须带上**。）
