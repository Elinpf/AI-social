> 触发：核对「生活气息」时发现，北极星明确要的**误会与和解**（`F-4` / `DR`）在当前世界可能根本没跑

## 2. ⚠ 一条我差点报错的口径（必须记住）

我最初想用"事件里有没有 RIFT/REPAIR"来判断机制是否开着，**这个方法是错的，两个原因叠加**：

1. **`PERSONA_DRIFT_CANDIDATE` 里含 `RIFT` 子串** ⇒ `grep RIFT` 会把人格漂移事件当成年轮；
2. **DR 根本不上报事件**：rift 台账是**进程内** `self._rifts`，和解判定靠 `REPAIR_WORDS` 词表在**提示词装配层**做，**不落任何 `run.jsonl` 事件**。

实测：`d9z-on` 与 `cycle36_f3_off` 两批**均无任何 `RIFT_*` / `REPAIR_*` 事件类型**（59 / 72 种类型里都没有）。

⇒ **结论**：**"事件里没有 ⟹ 机制没开"这个推理不成立**；**"事件里有 ⟹ 机制开了"也不成立**（子串误配）。
**机制开关只能用配置 + `/proc` 环境判定**，与「通道接通」用运行期计数判定（清单 `L2b`）是两件不同的事：
- **开关状态** → 读 `config/` + `/proc`；
- **开关是否真的起作用** → 数运行期分支/函数调用次数（`L2b`）。
**本件属于前者；不能用后者替代。**

## 3. 这件事对"生活气息"的意义

北极星要求的行为里，**「误会与和解」是明确列出的**（`DR` / `F-4` 机制就是为它写的，`T-D9F-DR-MOCK` 当年只做 mock，**从未在真批里开过**）。
而在**关着**的世界里测出来的所有结论（D9t 的旁白出口、D9z 的同轮往返、配额与沉没）**都发生在"没有误会、也不需要和解"的世界里**。

⇒ **不能把当前这一串结论当成"生活气息已推进"的证据**；它们是**前提不同**的实验。报告里必须写明这一条。

## 3.1 更正（同日 14:2x，Leader 自查）：**DR 其实有可观测面，只是「关了就没有」**

我上节写"DR 不上报事件"，**方向对但不完整**：它**不产生独立事件类型**，但**在 MSG 事件的 `payload` 里挂两个审计字段**（仅 `enabled=true` 且确有旧账时才出现）：

| 字段 | 来源 | 含义 |
|---|---|---|
| `payload.dialogue_rift` | `agent.py` 内 `DR.audit_fields(..., route="reply"\|"initiate")` | 本条生成时"我有哪些未了结旧账"：`{v:"f4/1", open, with, threads, route, age_rounds, prompted}` |
| `payload.dialogue_repair` | `DR.repair_audit(...)` | 本线程旧账的可审计配对（`rift_id` + `trigger_seq`） |

⇒ **结论修正为**：**"事件里没有这些字段"在当前批次是"DR 关着"的**必要不充分**线索**（关了必然没有；没有却不一定是关了 —— 也可能是开了但无旧账）。
⇒ **开关状态仍须读 `config/` + `/proc`**；但**一旦开启，是可测的**（`dialogue_rift.open`、`route`、`prompted`、`dialogue_repair` 均可计数）。

**这条对下一步有意义**：DR-on 的实验**不需要新造指标**，现有 `payload` 字段就够算"旧账产生率 / 被注入提示词比例 / 同线程和解配对率"。**门槛在"要不要开"，不在"开了怎么测"。**

## 4. 边界

1. 本件只说"**本批 DR 关着**"，**不说**"DR 开了会更好" —— 那是未测的；
2. 本件**不改任何判定**；D9z 的判定仍为通过（判定的是时序结构，与 DR 无关）；
3. 若后续要开 DR，属**新实验**：须新分支/新预登记，且**必须先补 `MSG` 总数与单条字数护栏**（否则会与"变碎变多"旁路混淆）。
