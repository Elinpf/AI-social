# D2.7 旁白的真问题：**词汇多样，但句法骨架单一**（`把…往/在…` 占 46.6%）

> 日期：2026-10-24。只读复算，B 臂 502 条旁白（`run_d27_B_…`）。
> 缘起：我先前判"旁白模板化"（错，已撤回）；并发线改判为"词汇多样但句法单一"，本件**复算确认后者成立**。

## 1. 两条读数并列（不互相替代，§3.113）

| 口径 | 读数 | 说明 |
|---|---|---|
| **词汇层**：互异旁白数 | **420 / 502 = 83.7%** | TOP1「把算盘珠子拨回原位」仅 8 次（1.59%）⇒ **词汇确实多样** |
| **句法层**：以「把」开头 | **302 / 502 = 60.2%** | — |
| **句法层**：`把…{往|在|向|回}…` 模式 | **234 / 502 = 46.6%** | 近一半旁白是同一个句法模板 |
| 首字分布 TOP6 | 把 302 / 拿 62 / 捏 41 / 用 13 / 放 9 / 掀 9 | 「把」是第二名的 **4.9 倍** |

TOP5 旁白也印证同一骨架：`把算盘珠子拨回原位` / `把锄头往墙根一靠` / `把锄头靠在门边` / `把账本往膝头一摊`（四个都是 `把 N 往/在 P (一)V`），只有 `刨子推过木料` 例外。

## 2. 结论

**"旁白模板化"是错的；真问题是"词汇换着来、句法只有一个"。**
⇒ 这解释了 `L-7 +3.00pp`（8-gram 重复）为什么在**词汇多样**的情况下反而上升：
重复不在词，在**骨架**（`把…往…一…` 这个 8-gram 结构反复出现）。

**与"台词层 L-7 25.49%→7.37%"并不矛盾**：台词层句子结构多变，旁白层骨架单一 ⇒ 剥掉括号后台词更干净。

## 3. 对后续的指示（重要，改变方向）

若下一步目标是压 `L-7`，**应约束句式多样性**（例如要求"不要总用'把X往Y一V'"、或给 2–3 种可选句式），
**而不是继续压旁白长度或砍旁白**——后者会重犯 D12-H 的错（砍旁白换低重复，文体崩到 0.20%）。

## 4. 局限

- 骨架判定用正则近似（`^把` / `把.{1,8}[往在向回]`），未做依存句法分析；误差方向未知，但 60.2%/46.6% 的量级足以支撑结论；
