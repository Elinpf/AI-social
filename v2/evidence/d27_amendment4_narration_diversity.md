# D2.7 更正（amendment 4）：**"旁白模板化"是我说错了——旁白文本很丰富，重复在句法骨架**

> 日期：2026-10-24。更正我在 `d27_result.md`（我的初版）§4.1 的说法，当时已被并发线的完整版覆盖修正，本件补上独立核实的数。

## 1. 我错在哪

我说过：「Q2 恶化 +7.90pp：旁白本身也重复（示例「把烟袋往桌上磕了磕」有被当模板的迹象）」。
并据此在 D2.8 立项里写"约束旁白不要模板化"。

**实测（502 条旁白逐条提取括号内文本）**：

| 量 | 值 |
|---|---|
| 旁白条数 | 502 |
| **互异旁白数** | **420**（**83.7% 互异**） |
| **TOP1 占比** | **8 / 502 = 1.59%**（`把算盘珠子拨回原位`） |
| TOP5 | `把算盘珠子拨回原位` 8、`把锄头往墙根一靠` 7、`刨子推过木料` 4、`把锄头靠在门边` 4、`把账本往膝头一摊` 4 |

⇒ **旁白没有退化成模板**，示例也没有被照抄。**我的判断错了，撤回。**

## 2. 真正的问题：**句法骨架**集中，不是文本重复

看 TOP5 就能看出：它们共享 **「把 N 往 P 一 V」** 这个骨架（把算盘珠子/锄头/账本 + 往/靠 + 动作）。
⇒ 旁白的**词汇多样、句法单一**。这更可能是 `L-7`（8-gram 词面重合）上升的来源：
不同词的同一骨架，在 8-gram 层面仍会撞车。

**这条对 D2.8 的含义**：约束"旁白不要套路化"是**对的，但盯错了维度**——
要约束的是**句式**（"换一种说法/换一个动作类型"），不是"别重复同一个词"。
⇒ D2.8 的"旁白 ≤15 字"**不解决这个问题**（本臂 max 已是 15，仍出现骨架集中）。

## 3. D2.8 的主设计不受影响（两条核心理由仍成立）

| D2.8 的设计 | 依据是否仍成立 |
|---|---|
| **概率性旁白**（≈1/3，而非 100%） | ✅ 成立：`paren_rate` 0%→**100%** 的过冲是实测事实，与"是否模板化"无关 |
| **台词 ≥30 字（P1 一票否决）** | ✅ 成立：`len_p50_excl` **41→26（−36.6%）** 是实测事实 |
| 「旁白不要模板化」 | ⚠ **依据被证伪**（420/502 互异）⇒ 从 D2.8 依据里**移除**，改为观察项 |

## 4. 结论

- D2.7 判定「作废（台词被旁白挤短）」**不变**（主依据 T 闸 −36.6%）；
- **旁白的质量比我说得好**（83.7% 互异、无心理描写、长度守约），这是本轮该记住的正面事实；
- 若 D2.8 之后还要继续压 `L-7`，方向应是**约束句式多样性**（如"换一种动作类型"），而不是继续压旁白长度。
