# M4「候选可分性」闸的定义缺陷 + 观测缺口（D12-F 跑批中复核所得）

> 作者：Leader｜2026-10-23 17:00｜时点：D12-F 跑到 44/60 轮
> 用途：**不是**为 D12-F 改判（判定仍按预登记走），而是把"闸测不准"这件事**在下一个臂之前**修掉。

## 1. 现象

| 时点 | M4 可分性（非全同分占比） | `scores` 三列均值 |
|---|---|---|
| 10 轮 / 91 条 | **20.9%** | 0.49 / **0.31** / 0.51 |
| 44 轮 / 377 条 | **21.8%** | **1.72** / **0.32** / **0.40** |

M4 几乎不动（+0.9pp），但 `scores` 三列均值的**差距在扩大**：候选 1/2 的交集均值只有候选 0 的 **1/4 ~ 1/5**。

## 2. 为什么 M4 测不出候选差异（**定义缺陷**）

M4 定义 = 「三候选 `scores` 不全相同的样本占比」。
但 `scores` = 候选与「最近 16 条台词」的 8-gram 交集条数。**当三条候选都与近期台词无交集时，`scores` 全是 0，必然同分** —— **哪怕三条候选文本差异巨大**。

⇒ M4 实际测的是「**多少样本恰好与近期台词有交集**」，而不是「**候选之间差多少**」。它被"全 0 天花板"压住，**结构性无法反映结构提示的真实作用**。

**这是本项目的第三类闸缺陷**（前两类：M2 的"分布假设错误"、`L-15` 首版的"前提不成立仍硬算"）：

| # | 闸 | 缺陷类型 | 后果 |
|---|---|---|---|
| M2（D12-E） | 非第 1 条被选中 ≥20% | **分布假设错误**（假定最优均匀分布） | 惩罚"第 1 条恰好最优"的正确行为 |
| M4（D12-F） | 非全同分占比 ≥25% | **天花板限制**（全 0 时不可分） | 低估候选真实差异 |
| `L-15` 首版 | 无 thread_id 时硬算 | **前提不成立仍出数** | 产出 33.69% 假值 |

## 3. 正确的替代指标（下一臂用）

**候选文本差异度**（与"是否被选中"完全无关）：

- **C1 `cand_jaccard_dist_mean`**：三条候选两两之间 8-gram 集合的 **Jaccard 距离**均值（`1 − |A∩B| / |A∪B|`，3 对取平均）；
  - 它**不受"与近期台词是否有交集"影响**，只测"三条候选像不像"；
  - 对照口径：`cand_jaccard_dist_mean` 在 D12-E（三候选同 prompt 采样）下预计较低，在 D12-F（结构提示）下应显著更高 —— 这才能验证"结构多样化"是否真起作用。
- **C2 `cand_len_cv`**（次要）：三条候选长度（excl_paren）的变异系数，辅助判断差异是否只在长度上。

**达标线（下一臂预登记时写死）**：`cand_jaccard_dist_mean` 相对 D12-E 的基线 **↑ ≥0.05**（绝对值）。

## 4. ⚠ 观测缺口（本轮已无法补救）

`ctx.d12f` 只落了 `{m, picked, scores, group}`，**没有落候选文本**（也没落 `candidate_shas`）⇒ **C1/C2 无法事后补算**，只能等下一臂重新跑。

**教训（写入 runbook）**：**审计字段必须在跑前设计到"足以覆盖所有判据依赖"**。本轮的判据依赖"候选差异"，但字段只覆盖"分数与选择"⇒ 闸不可复核。下一臂的 `ctx` 至少要加 `candidate_shas: [sha256(c0), sha256(c1), sha256(c2)]`（落 sha 而非全文，控体积）。

## 5. 对 D12-F 判定的处置（**不改判，只要求分层陈述**）

1. **判定仍按预登记**：M4 < 25% ⇒ 「机制未生效」，**不许因"差 3pp"或"L-7 达标"改判**；
2. **但必须同屏写三条**：①M4 21.8% vs D12-E 15.9%（+5.9pp，相对 +37%）；②`scores` 均值 1.72 / 0.32 / 0.40 ⇒ **候选 1/2 交集仅为候选 0 的 1/4~1/5**；③**M4 的"全 0 天花板"缺陷**（见 §2）；
3. 一句话结论建议：**「判定『机制未生效』（M4 未达 25%），但该闸受全 0 不可分限制；机制本身的直接证据是候选 1/2 交集均值仅为候选 0 的 1/4~1/5」**——两句必须同屏。
