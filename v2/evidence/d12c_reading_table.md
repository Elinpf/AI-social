## 1. `switch_proof` 记录格式（**执行层真值，别记外层 shell**）

起臂命令须形如（示意，跑时按实际粘贴）：
```bash
systemd-run --unit=t271-d12c-on --property=Environment=LIFE_PROMPT_D12C_SPECIFIC=1 \
  --setenv=... -- bash -c 'cd /tmp/t271-d12c/code && exec python3 -m orchestration run ...'
```
**记录三件真值**（缺一不算证明）：
| 项 | 取法 | OFF 臂 | ON 臂 |
|---|---|---|---|
| unit 名 | `systemctl show -p Id` | 待填 | 待填 |
| **执行层环境真值** | `tr '\0' '\n' < /proc/<PID>/environ \| grep LIFE_PROMPT_D12C` | 待填（应为 **无输出**） | 待填（应为 **`=1`**） |
| 实际 cmdline | `ps -o cmd= -p <PID>` 或 `/proc/<PID>/cmdline` | 待填 | 待填 |

## 3. 判定词规则（**出数前写死；只能落进下列几种之一**）

按顺序匹配，命中即停：

| 条件 | 判定词 |
|---|---|
| P1 与 P2 **都未** ↑≥5pp | **「机制未生效」**（不是"无效"） |
| 机制生效，但结构变化 **超 ±5%** | **「作废：非单变量」** |
| 机制生效，P1 ↑ 但 `len_p50` **降 >10%** | **「无效：拿具体性换长度」** |
| 机制生效，P1 **未升** | **「无效」**（附人读 10 条证据） |
| 机制生效，P1 ↑ 且长度、结构均达标 | **「有效：具体性上升且无长度/结构代价」** |

> `paren_rate` 与 P2 **只作观察**，无论高低都**不改判定**（P2 是可选指令，不达标不算失败）。
