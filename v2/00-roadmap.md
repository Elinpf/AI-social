## 0. 总纲（用户最新定调，最高优先级）

> **「作为 AI 自己驱动的小镇，我们不替他们设计经济，而是给他们能自己造经济的底座与工具；但必须有产生的手段。」**

### 0.1 两层分离（**核心架构立场**，与 T78 `v2/01 §0.2` 一致）
| 层 | 谁定 | 内容 | 约束 |
|---|---|---|---|
| **A 物理层（我们定死）** | 我们（确定性代码） | **生产函数/产出/库存/消耗/折旧、账本与结算原语、守恒、时间结构、可见性、事件契约** | 确定性、可复现、可审计；**不得写死制度** |
| **B 制度层（AI 涌现）** | AI Agent 自己造 | **价格/工资/雇佣/借贷/租佃/分成/税收/发行（铸币）/规范** | 由 Agent 的对话/协商/组织**自发产生**；我们只给**工具箱** |
| **C 保底（我们定，最小、不强制）** | 我们 | **最小市场、总量地板、存活救助、兜底铸币** | 防自毁；**不写死价格/工资/税率** |

> 一句话：**A 是「物理定律」，B 是「玩家能造的规则」，C 是「停电时的应急灯」。**

### 0.2 保底机制（**必须有，但不强制、不写死**）
- **无条件下系统仍自洽**：即使 AI 什么都没造（无市场/无雇佣/无税收），世界**不崩**——时间照走、结算守恒、生命与观测正常（`v2/01 §4`）。
- **保底 ≠ 代劳**：保底只保证「**不崩**」，**不替 AI 做决定**，也**不预设**「价格=1、工资=X」。
- 「**必须有产生的手段**」= A 层必须提供**能被 AI 用来创造制度**的原语（生产函数、可转让物品、可成交、可订立契约、可公开发声、可组织）。

### 0.3 路线顺序铁律
> **先给底座与工具（A 物理层） → 再看涌现（B 制度层） → 再谈调参（C/仅当涌现不足或失衡）。**
> **里程碑必须含「制度涌现指标」**（`v2/01 §5.2` + `v2/02 §5`）——衡量的是「AI 是否自己造出了制度」，而非「我们是否调出了好看的数」；且须**消融证伪**（去掉工具则涌现消失、写死常量不算涌现）。
> 📌 **P1 实测印证本铁律**：P1 已把 A 底座给足（`PRODUCE=321`、商品双账本守恒），但**货币仍未循环**——因为**商品→货币转换通道缺失（G-P1-1，属 B 层未涌现，非 A 层缺陷）**。故下一步**不是调 A 层参数，而是推进 P2 让 B 层涌现**（见 §3 P2 首要命题）。

### 0.4 世界层 / 社会层分离（**作者化边界**，用户已确认读法）
> 用户确认：「**世界层我们定、社会层只给手段不写死**」——作者化的活世界。

| 层 | 谁定 | 内容 | 约束 |
|---|---|---|---|
| **世界层（作者=我们定）** | 我们 | **地理 / 背景故事 / 初始居民 / 宏观事件 / 世界导演的介入** | 只铺「舞台与初始情境」，**不给结局**；每次介入可审计/可消融/不改过去 |
| **社会层（只给手段）** | AI 涌现 | 货币 / 价格 / 工资 / 税 / 制度 / 规范 | **只提供"定义手段"**（A 层原语+工具箱），**红线：不预设价格/工资/税率/是否铸币** |

### 1.1 货币总量曲线（`TURN_SEAL.money_supply`）——**⚠️ P1 前历史口径**

- **前 59 回合严格线性下滑**：每回合恰好 **−2,800 = 20 人 × 140 mu 代谢销毁**，**零对冲**。

- **r78 救助铸币 +24,779**：证明「**只有救援才创造货币**」；发行**一次性且滞后**，故路径先穿负。
- **全期净额可为正，但路径先穿负** → **「`M(t)≥0` 约束」是必要修法**（已列入 `v2/01 §2.3`）。
- 🔻 **⚠️ 时效标注（重要，防误导）**：以上 **「中途跌破 0，最低 −9,620」是「P1 前历史口径」**（旧 B2_N20）；**v2 口径 A + P1 已修**：`M_min=0`、`M_final=35100`、**全程不穿负**（T91 实测，见 §3 P1 实测结果）。原曲线**保留作为诊断依据**（说明"销毁无地板"的病），**非当前状态**。

### 1.4 核心洞察（写给「小镇如何运转」，`v2/01 §1.5`）
1. **钱 ≠ 价值**：生产创造的是**商品与服务**，货币只是**交换媒介**；「没有生产」的后果是「劳动无法变现、无人有收入、只剩消耗」。
2. **总量枯竭的直接原因是「回收 > 投放」**：代谢吸走货币，无常规投放（工资/采购/铸币）送回 → 单向漏斗。
3. **小镇运转的答案**：`劳动→产出→出售/工资→收入→消费/纳税→公共品/再生产` 的**循环** + **总量锚**（投放≈回收）。

## 2. 目标态：「一个小镇是如何运转的」

> 按总纲：**A 层给底座与工具，B 层 AI 自己造制度**；「运转」= **A 稳定承载 + B 自发成形 + 可观测**。

### 2.1 A 物理层（我们定）提供什么「底座与工具」
```
生产函数（劳动 tick → 产出，含技能成长/资源丰度/工具加成）  ·  库存与消耗/折旧
结算原语（原子转账/成交、双账本守恒、M(t)≥0 硬约束）
发声原语（公开板/群聊/私聊三通道，visibility=global/members/private）
契约底座（可执行契约的登记与确定性执行器）
安全保底（守恒不变量 + 生命护栏 + 最小市场/总量地板）
```

### 2.2 B 制度层（AI 涌现）应当能自己造出什么
```
价格与市场（议价/挂单/成交价由供需形成，非写死）
雇佣与工资（EMPLOYMENT：雇主→雇员按约发薪）
借贷与信用（LOAN：本金/利率/期限/抵押由双方谈）
租佃/分成/合作社（TENANCY/PROFIT_SHARE/COOPERATIVE）
税收与公共品（NORM_PROPOSED→VOTE_CAST→NORM_ADOPTED→执行）
发行/铸币（有阀门的铸币权：仅经 NORM_ADOPTED 或 C 兜底）
规范与组织（议题→决议→（行会/互助/合作社）→制裁）
```
- **货币闭环（涌现目标）**：生产 → 工资 → 消费/交易 → 税收 → 公共品 → **再生产**——但**由 AI 自己组织**，我们只保证原语具备。
- **脚本化示例（T78 §3.5）**：A 农场产 food；A 向 B 发 `EMPLOYMENT` 要约、B 还价、成交 → `CONTRACT_CREATED`；A 挂单、C/D 竞价（价格离散度由此产生）；B 借 `LOAN` 买工具；C 提 `sales_tax` 规范、投票过半 → 征税资助学校；货币不足时 D 提 `mint` 提案、阀内执行。
- **全过程无一处需要我们写死工资/价格/税率/是否铸币**——这正是「AI 自己造经济」。

### 2.3 C 保底态（AI 什么都没造时）
- 世界**不崩**：时间照走、守恒成立、生命正常、观测可读、Agent 能靠**最小生产**存活（`v2/01 §4`）。
- 若 AI 未造出货币源，则呈现「**低活跃但稳定**」（而非当前「穿负崩塌」）——差异在于**`M≥0` 地板**与**最小市场**。
- **保底只保证「不崩溃」，不保证「繁荣」**；繁荣必须由 AI 自己谈出来。

### 2.4 「运转良好」的可观测量（**含制度涌现指标**）
| 维度 | 指标 | 现状 | v2 目标 |
|---|---|---|---|
| 货币健康 | `M(t)/M_target`（`TURN_SEAL.money_supply`） | P1 前：穿负至 −9,620；**P1 后：`M_min=0` 不穿负**（`M_final=35100`） | **全程 ≥0**（OFF 默认下 `M_min=0` 属**预期**、非回归）；向 ∈[0.9,1.1]×M_target 收敛 |
| 货币流速 | `V=(ΣTRANSFER+ΣMARKET_TRADE)/M` | ≈0.04（近乎冻结） | ∈[0.3,1.5] |
| 价值创造 | 总产出 `Y=ΣPRODUCE×p_ref`；中位工资 | **`PRODUCE=321`（商品造出来了）但未变现：`I_eff` P50=0**（G-P1-1） | `Y>0` 且不萎缩；工资 ≥ metabolism |
| 公平 | `Gini` | 低位（因无交易） | ∈[0.2,0.5] |
| **制度涌现①（市场/价格）** | 价格离散度 `CV=σ/μ`（同类成交价） | 无 | `>0`（确有议价） |
| **制度涌现②（雇佣）** | `CONTRACT_CREATED(type=EMPLOYMENT)` 数 | 0 | >0 |
| **制度涌现③（借贷/信用）** | 自发 `LOAN` 契约数（非仅系统续命贷） | 仅系统贷 | >0 |
| **制度涌现④（税收/公共品）** | `NORM_ADOPTED(type∈{tax,public_good})`、公共品预算执行额 | 无 | >0 |
| **制度涌现⑤（发行/规范）** | `MONEY_MINTED(by=vote_id)`、`NORM_ADOPTED` 数 | 仅 rescue | >0 |
| 契约健康 | 契约类型去重数 / 履约率 / 违约率 | 无 | 多样性↑、履约率↑ |
| 社会丰富度 | 公开/群聊消息数、`n_norms_adopted`、组织数、议题数 | 公开/群聊=0 | 显著上升 |
| 生命动态 | 死亡率 | 20/20 集中雪崩 | **稀疏、错峰** |

### P2 · **制度层：看涌现**（总纲第二步；`v2/01 §3` + `v2/02 §2/§3`；**token 不限量**，放开 LLM 参与）

> 🎯 **P2 首要命题 G-P1-1｜商品→货币转换通道缺失（属 B 层未涌现，非 A 层缺陷）**
> **证据（T91 钉死）**：`PRODUCE=321` 且商品双账本守恒，但 **`MARKET_TRADE` 仅 21 笔、`distinct_sellers=1`（卖方全是世界 `MARKET`，`top_seller_share=1.0`）、volume 2100 mu → 无 Agent 间交易**；收入 `I_eff` **P50=0 / P90=400 / Max=2100 / 正收入者占比 0.4**；84 回合总量 = genesis 200000 + rescue 40000 / **metabolism −208058** / market 2100。`WAGE/EMPLOYMENT = 0`。
> **结论口径**：**P2 要解的不是「最小市场带宽不足」，而是「Agent 间交易/雇佣/契约根本没发生」**——A 层已给「产生的手段」（生产/库存/技能/折旧），但**没有把商品变成货币的通道**。故 **P2 ≠ 调参数**，而是**让 B 层涌现**（雇佣/契约/Agent 间市场/最小市场带宽），把「造出来的商品」变现为「货币收入」。
> **与 §0.3 挂钩**：这正是「先 A 底座 → 再看 B 涌现」的实证——A 已就绪，卡点在 B。

## 5. 里程碑与验收：「小镇能自洽运转、且看得出它在运转」

### 5.1 里程碑（对齐总纲顺序）
| 里程碑 | 定义 | 判定 |
|---|---|---|
| **M1「它活着」** | 世界长时无系统错误、可复现、成本可接受 | 复现门禁 + `SYSTEM_ERROR=0`；token 不限量下以**告警**代替阻断 |
| **M2「底座可用（保底态）」** | **A 层给足工具**；即便 AI 未造制度，世界**不崩、`M(t)` 全程 >0** | `M≥0` 成立；生产/成交/立约/公开发声原语可用；保底态低活跃但稳定 |
| **M3「制度涌现」** | AI **自发造出制度**（§2.4 ①–⑤ ≥K 项），且**非我们写死** | **制度涌现指标**达标 + **消融证伪**（去掉工具则涌现消失、写死常量不算涌现） |
| **M4「看得出它在运转」** | 观测台/叙事能用**因果与故事**呈现：谁在挣钱、钱怎么流、议题怎么成规范、公共品怎么装满 | 观测台经济/制度/社会面板 + 小镇日报样例可读且**逐句可溯源日志** |

### 5.2 「自洽运转」量化验收清单（v2 放行）
1. **A 层**：原语可用；`M(t)≥0` 全程成立（**P1 已达成：`M_min=0`；`fallback_mint_enabled` OFF 默认下 `M_min=0` 属预期、非回归**）；**双账本守恒**（货币式 + 商品式，`v2/01 §2.3`；P1 已达成 `ΣPRODUCE=ΣCONSUME+库存+溢出+折旧`）。
2. **制度涌现**：§2.4 ①–⑤ **≥K 项**出现，且**消融对照**（移除对应工具/回退 A 层）后消失 → 非「写死的假制度」。**首要=打通 G-P1-1（商品→货币转换通道）**。
3. **货币**：有源后 `M(t)/M_target∈[0.9,1.1]` 且**不再穿负**（P1 已不穿负）；流速 `V` 回到 [0.3,1.5]。
4. **价值创造**：总产出 `Y>0` 且不萎缩；中位工资 ≥ metabolism。
5. **社会**：公开/群聊持续；出现 ≥1 个**公共议题 → 规范/组织**闭环。
6. **生命**：死亡**稀疏、错峰**；有复活/续命路径（保底机制）。
7. **复现/观测**：回忆 → 同日志逐位一致；观测台/叙事「看得出」运转；`llm_judged_metric_count==0`。
8. **门禁**：`pytest -q`、`lint-imports`、`obs gate`、`make lexicon-gate` 全绿；重冻 G6 基线（含制度涌现指标）。
