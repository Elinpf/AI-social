## 0. 决策与本文目标

### 0.1 用户拍板
> **采用 A + B 双主线**：**A 能力训练**（在有硬约束的世界里训练/微调社会智能）+ **B 受控社会实验平台**（可复现的政策 A/B 实验床）。

这回应了「纯观察不是好的推进手段」的反馈：项目从此有**两类可验收交付物**——**训练产物（模型/数据/提升证明）** 与 **实验结论（政策效应报告）**。

### 0.2 双主线的核心论断
> **两条线共用同一套确定性世界；同一批运行「既产出可复现的实验结论（B），又产出训练轨迹（A）」。** 这是相对「建两套系统」的最大优势——**避免管线重复建设**，且因为世界**确定性可重放**，训练数据来源**可审计**、实验效应**可复现**。

## 1. 双主线总览

### 1.1 一张图
```
                    ┌─────────────────────────────────────────────┐
                    │  确定性世界（v1.1 内核，单小镇/周尺度/N=20）   │
                    │  同一 seed → 同日志逐位一致（可重放）          │
                    └───────────────┬─────────────────────────────┘
                                    │ 一次 run 产出唯一 EventLog
              ┌─────────────────────┼─────────────────────┐
              ▼                     ▼                     ▼
      ┌───────────────┐   ┌───────────────────┐   ┌───────────────────┐
      │ 轨迹导出器(A) │   │ 实验统计器(B)     │   │ 观测层(评估)      │
      │ state/决策/   │   │ 政策 A/B 效应量   │   │ WBV 七维 + 涌现   │
      │ outcome 轨迹  │   │ 显著性/置换检验   │   │ （只读、确定性）  │
      └──────┬────────┘   └─────────┬─────────┘   └─────────┬─────────┘
             ▼                      ▼                       ▼
      A 线：训练信号→离线训练→   B 线：政策实验报告      公共：评估不压平
           微调模型/策略（提升证明）
```

### 1.2 两条线共用什么、各自独有什么
| 组件 | A 线（训练） | B 线（实验） | 共用？ |
|---|---|---|---|
| 确定性世界/内核/日志 | 用 | 用 | ✅ **同一套** |
| 生活层/观测层 | 用 | 用 | ✅ 同一套 |
| **轨迹导出（state/decision/outcome）** | 核心 | 辅助 | ✅ 同一份日志 |
| **实验编排（A/B 分区、多 seed）** | 用（生成训练分布） | 核心 | ✅ 同一编排器 |
| **奖励/训练信号计算** | 独有 | 不用 | ❌ A 独有 |
| **离线训练流水线 + 算力** | 独有 | 不用 | ❌ A 独有 |
| **效应量统计器** | 不用 | 独有 | ❌ B 独有 |
| **评估（WBV 七维 + 涌现）** | 只读、不优化 | 只读、汇报 | ✅ 同一评估口径 |

**结论**：**写入世界的部分 100% 共用**；差异只在「下游消费者」（A 加训练信号+训练流水线，B 加效应量统计）。→ **一套世界，两种产出。**

## 2. 共用世界的机制：轨迹、奖励、统计如何在同一 run 上并存

### 2.1 一次 run 的并行产出流（【可行判断】）
```
run(seed, config, rounds) → EventLog（唯一权威）
   ├─ [B 线] 实验统计器：读 log → 政策效应量（组间差 + 显著性 + 效应量）
   ├─ [A 线] 轨迹导出器：读 log → 训练样本（state→decision→outcome 三元组）
   └─ [公共] 观测层 metrics/emergence_report/wellbeing_report（评估，只读）
```
- **三条消费流都只读同一份 EventLog**（延续 v1.1「只读日志、纯函数」铁律）。
- **不新增写入路径**：轨迹与奖励都是**日志的下游派生**，不改世界、不改内核。

### 2.2 轨迹采集（A 线）
- **采样单位**：`(agent, slot/round)` 的决策点；字段 = `state 摘要（perceive 视图）+ 该 Agent 的 intent/decision + 事后确定性 outcome`。
- **反泄漏**：训练样本**只含决策时点可见信息**（对应 IF-1 `perceive` 视图），**不含未来事件**（否则训练数据被污染）——由导出器强制裁剪。
- **标签来源**：outcome 全部来自**确定性事件折叠**（存活/财富变化/关系变化/规范采纳…），**不由 LLM 打分**（避免 Agentopia 的 LLM-judge 污染）。
- **可审计**：每条样本可回溯到 `seq`/`turn_seal`，来源可复现。

### 2.3 奖励计算（A 线）
- **独立模块**：`reward_calculator(log) -> {capability: signal}`，**只读日志**，输出**按能力分解的多维信号**（§3.1）。
- **与世界解耦**：奖励**不写回世界**、**不改 Agent 目标函数**（观察实验里 Agent 仍按自身人格/目标行动）。
- **同一 run 既算 B 也算 A**：奖励计算与效应量统计**并行**读同一日志，互不干扰。

### 2.4 实验统计（B 线）
- 复用 v1.1 已有：A/B 双胞胎（同 seed 去种子事件）、置换检验（N_perm 固定）、效应量、S1–S4。

### 2.5 实验分区 vs 训练分区（**关键复用点**）
用**同一编排器**做两种「分区」，避免两套：
| 分区类型 | 目的 | 做法 |
|---|---|---|
| **实验分区（B）** | 因果识别 | 同 seed 的对照组/处理组（仅差一个政策参数或种子事件） |
| **训练分区（A）** | 防过拟合 | train / val / **held-out 场景**（不同世界参数/人格分布）按 seed 切分 |
- **关键纪律**：**训练分区与实验分区必须解耦**——用于 B 结论的场景**不得**混入 A 的训练集（否则 B 的「留出」被污染）；train/val/test 的 seed 切分**预先冻结**。
- **复用**：两者都用「同 seed 多副本 + 参数切换」能力，编排器同一套。

## 3. 训练目标 vs 评估指标的分离（必须自洽）

### 3.1 两层分离（延续 v1.1 红线）
| 层 | 用途 | 是否标量化 | 处置 |
|---|---|---|---|
| **评估指标层** | 衡量「过得好不好」 | **否**：保持 **WBV 七维 + 背离**，不压平 | **完全保留**，v1.2 不动 |
| **训练目标层** | 驱动能力提升 | **按能力分解**（非「好生活」标量） | **新增独立层**（A 线） |

### 3.2 训练信号定义草案（capability-specific，**非单一标量**）
| 能力维 | 训练信号（示例，确定性来源） |
|---|---|
| 长期规划 | 风险调整后**存活回合数**；跨周目标达成率；`financial_security_rounds` 趋势 |
| 风险管理 | 破产/违约率倒数；负债峰值；现金流稳定度 |
| 谈判/协作 | 协商成交率、让价效率、协作产出质量（确定性 `quality`） |
| 制度协作 | `norm_adoption_success_rate`、规范内化率、治理参与度 |
| 反欺诈鲁棒性 | 对 `flags∈{wash,cycle,self,mule}` 场景的识别与规避率 |

**三种可选组合方式（均为多目标/条件化）**：
1. **Capability-specific reward**：每个能力一个专用信号，**不跨能力加权成单一标量**。
2. **多目标帕累托**：保留多目标，训练用约束优化或权重扫描（**权重是实验变量，非「真理」**）。
3. **离线偏好学习**：轨迹对（更优/更差）由**确定性结果**定义偏好，避免 LLM 评判。

### 3.3 是否需要在 `06`/`13` 追加「训练视图」（**推荐，且不动评估口径**）
- **推荐做法**：在 `06-life-layer.md`/`13-wellbeing-metrics.md` **各追加一节「训练视图（Training View）」**，声明：
  1. **评估口径不变**：WBV 七维、不压平、`llm_judged_metric_count==0` 对入门禁命名空间成立——**完全保留**。
  2. **训练视图是独立命名空间**：新增 `metrics.training.*`（或独立 `reward_spec`），**只读日志派生**，**不进入评估、不进沙盒门禁**。
  3. **训练信号源**：capability-specific，**确定性可审计**，**不得**使用 F 类（LLM 冻结判定）。
  4. **硬约束**：训练信号**不得回写世界**、**不得作为观察实验的唯一目标函数**。
- **结论**：**不需要修改已定评估结论**，只需**追加「训练视图」条款**——这是范围**扩展**，不是**推翻**。

### 3.4 是否需要修正已定结论（明确回答）
**不需要推翻。** 已拍板禁令针对「评估层」；A 线**新增独立训练信号层**。需补的是 **3 条硬约束**（写入 v1.2）：
1. 训练信号不得回写为评估指标；
2. 训练信号不得成为 Agent 在观察实验中的唯一目标函数；
3. 训练信号由确定性结果导出、可审计，**F 类不得作训练信号**。

## 4. 与 Agentopia 的差异化：硬约束为何对社会智能训练有价值

### 4.1 Agentopia 的做法与局限（来源 `11`/`brief`）
- 用 Agentopia 的 `life reward`（社会 0.4/主观 0.4/经济 0.2 的**加权标量**）**反训模型**；
- **无死亡/破产/市场/税收**（经济只是奖励一维）；
- **不可整体重放**；指标含 **LLM 评判**；
- 训练后出现 **经济 +2.5% 但物质满足 −14.8%、个人活动 −19.8%** 等**背离**——说明压平奖励有代价。

### 4.2 我们的差异化：硬约束让「短视/欺诈」有真实代价
| 维度 | Agentopia | **我们（A+B）** |
|---|---|---|
| 死亡/破产 | 无 | **有**——净值连续低于硬地板即判死（可续命但带惩罚） |
| 经济 | 奖励的一维 | **完整闭环**（发行/回收/税收/借贷/负资产） |
| 复现 | 不可重放 | **确定性可重放**（训练数据可审计） |
| 奖励 | 单一加权标量 | **能力分解 + 评估多维** |
| 判定 | 含 LLM 评判 | **判定 100% 确定性** |

**为什么硬约束有训练价值（【可行判断】）**：
- **短视/欺诈有真实代价**：无死亡世界里 Agent 可长期空转/欺诈而无后果；我们有**破产→判死→惩罚**，使「跨期规划、风险控制、守信合作」成为**生存必要**而非可选。
- **议价/承诺有约束**：负资产/借贷成本随深度上升 → 迫使 Agent 学**真实信用与履约**。
- **可审计的能力来源**：确定性日志让「能力提升」不是「讨好 LLM 评委」而是「在硬约束下存活与协作」。

### 4.3 可验证的优势假设【需验证假设】
- **H-A1**：在**含死亡/破产**的世界微调，相比**同世界但关闭死亡**（消融）或 Agentopia 式无死亡环境，模型在**留出高压场景**的存活/协作指标提升更大。
- **H-A2**：硬约束训练出的策略，在**新世界参数**上泛化更好（学到的是「约束下的稳健策略」而非「记忆题」）。
- **H-A3**：能力分解训练信号，相比单一标量，训练的模型在**多维福祉**上**不产生新的背离**（如「经济↑但成长↓」）。
- （以上均为**需验证假设**，由 A 线的消融与 held-out 评测回答。）

## 5. 分阶段推进 P0–P3

### P0 世界跑通（N=20）
| 项 | 内容 |
|---|---|
| **入口条件** | v1.1 分册就绪；`config`（personas/places/topology）冻结 |
| **交付物** | N=20 单/双周可重复 run；护栏判据全过；日志与复现一致 |
| **成功标准** | 09 护栏判据（存活率/Gini/坏账/通胀/LLM≤N×0.5/守恒/可复现）全过 |
| **成本量级** | 纯推理：N=20 单周≈2×10⁶ token；双周≈4×10⁶ |
| **对应** | 09 L0(N=10)→L1(N=20) |

### P1 B 线首批政策实验
| 项 | 内容 |
|---|---|
| **入口条件** | P0 通过；政策参数层 + 实验编排器 + 效应量统计器就绪 |
| **交付物** | 首批政策实验报告（如 UBI、累进税、借贷利率、惩罚强度各一组），含效应量 |
| **成功标准** | 效应量在 ≥3 seed 方向一致、p≤0.05；报告给出**多维福祉 + 背离**完整画像 |
| **成本量级** | 纯推理：`政策档 × seed × 周数`；如 4 政策 × 3 seed × 2 周 ≈ 数十×10⁶ token |
| **对应** | 09 观测判据 + 因果识别 |

### P2 A 线轨迹采集与首轮微调
| 项 | 内容 |
|---|---|
| **入口条件** | P0 通过；轨迹导出器 + 奖励计算模块 + 训练/评估分离条款就绪；**训练算力到位** |
| **交付物** | 训练数据集（可审计）+ 首轮微调模型 + 相对基线提升证明（held-out） |
| **成功标准** | 留出场景能力指标显著提升；**泛化**到未见世界参数仍提升；**不产生新背离** |
| **成本量级** | ⚠️ **推理 + 训练算力**：数据量 ≈ 数十×10⁷–10⁸ token；微调 GPU 预算**需立项**（参考 Agentopia 30×8×H100/1 epoch 属单方研究，须自标定） |
| **对应** | 09 观测判据 + A 线训练流水线 |

### P3 联合评估与封装
| 项 | 内容 |
|---|---|
| **入口条件** | P1 + P2 产出稳定 |
| **交付物** | 联合报告（B 的政策结论 + A 的能力提升 + 二者关系）+（可选）对外 Benchmark |
| **成功标准** | 训练提升与政策结论**互相印证**（如「学会守信的模型在惩罚政策下效应更明显」）；可复现 |
| **成本量级** | 推理为主（+ 可选评测发放） |
| **对应** | 09 + C（可选封装） |

**阶段门禁原则**：每阶段结束按成功标准判定「放行/回滚」；**A 线的算力立项是 P2 的硬入口**。

## 7. 风险与开放问题

### 7.1 风险
| # | 风险 | 说明 | 缓解 |
|---|---|---|---|
| R1 | **训练算力/成本** | A 线需 GPU，当前无预算；数据/算力下限未知 | P2 前置算力立项 + 先小规模标定【需验证假设】 |
| R2 | **训练信号塌缩为单一偏好** | 多目标易被隐式压平 | 能力分解 + 帕累托 + 显式权重声明 |
| R3 | **LLM 判定冻结与训练信号关系** | 若训练信号用 F 类（LLM 冻结判定），则数据被主观污染 | **硬约束：F 类不得作训练信号**；只用确定性 outcome |
| R4 | **训练后世界观测价值是否保持** | 微调模型可能「会解题」而失去真实多样性 | 训练视图与评估视图分离；held-out；保留未训练基线对照 |
| R5 | **实验与训练场景串味** | 训练集混入 B 的留出场景 → B 结论失效 | §2.5 分区解耦 + seed 冻结 |
| R6 | **泛化不足** | 过拟合训练分布 | held-out 世界参数迁移评测 |
| R7 | **假涌现/假效应** | 规则/干预造成 | 沿用 v1.1 六类区分法（消融/A-B/复现） |

### 7.2 开放问题（交用户/Leader）
