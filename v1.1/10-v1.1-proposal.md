## 1. 实验目标与定位

### 1.1 一句话定位
> **让一群有结构化人格的 LLM Agent 在一个「五脏俱全」的虚拟小镇中自主生活若干「模拟周」，用确定性引擎保证可复现、用确定性指标观测「在稀缺与规则下，Agent 社会会自发产生什么」。**

### 1.2 经济与死亡的新角色（用户拍板）
| 维度 | v1（受控经济实验） | **v1.1（AI 生活观察实验）** |
|---|---|---|
| 经济 | 实验主角、验收对象 | **背景条件 + 健康度护栏**：提供稀缺与激励，是生活的一部分 |
| 死亡/破产 | 核心机制、验收主角 | **健康度护栏 + 极端压力源**：防僵尸账户、提供戏剧张力；须**打标以便统计剔除**，避免其主导叙事 |
| 成功判据 | 经济指标达标（闭环自持） | **护栏不越界（必要） + 观测到有意义的涌现（充分）** |
| 核心问题 | 经济能否自持 | **在稀缺与规则下，Agent 社会会自发产生什么** |

### 1.3 研究假设
| 编号 | 假设 | 说明/状态 |
|---|---|---|
| **A0'** | 「长时程 AI 生活观察实验中，由确定性内核给出货币/死亡约束、并以确定性指标观测涌现」这一组合存在可探索空间 | **待验证**（更正后口径，见 §0.4）；不依赖公开项目的空白性断言 |
| H1 | 同 `replay(log)` 与 `metrics()/emergence_report()/wellbeing_report()` 对同一日志逐位一致 | 确定性可复现（09 §1.1） |
| H2 | 死亡阈值不抖动，模拟周内可观测到自然死亡 | 1 周=84 回合 > 65（§3.5） |
| H3 | 带惩罚的借贷/负资产不让少数 Agent 无限续命 | 护栏 |
| H4 | 撮合价量不发散、货币围绕锚、流速稳定 | 护栏 |
| H5 | 通信不爆炸（配额硬封顶） | 护栏 |
| H6 | LLM 成本在预算内（≤N×0.5/回合） | 护栏 |
| H7 | 反作弊 C1–C10 被封堵 | 护栏 |
| H8 | 指标可从日志纯函数重算 | 硬门禁 |
| H-E1–H-E5 | 种子级联达 depth≥2/R0≥1；强关系变稠密；职业转变；圈层涌现；规范被采纳 | **预注册观测假设**（07 §6.1） |

### 1.4 待验证的观测预期（预注册）
- **种子事件自主传播**（Smallville「派对」范式）：注入 1 个种子事件 → 零追加干预 → 观测自主传播、二/三级效应。
- **长期社会演化**（长窗）：关系漂移、职业/身份转变、规范形成、圈层涌现、**福祉背离**（富而不乐等）。

## 2. 总体架构（以 T12 / `00` 为准）

### 2.1 三层结构
```
┌──────────────────────────────────────────────────────────────────────┐
│  L2  涌现观测层（M8）— 只读、纯函数、确定性                              │
│      metrics(log,T,TIME_CONFIG) / emergence_report / wellbeing_report  │
│      （D 类判定，LLM 仅叙事描述，非权威）                                │
└───────────────────────────────▲──────────────────────────────────────┘
                                 │ IF-4 只读
┌───────────────────────────────┴──────────────────────────────────────┐
│  D0  确定性内核（世界法则）                                             │
│   时间派生 round→slot→day→week；World State；Central Rule Arbiter       │
│   （唯一写入口）；RNG 流；Ledger（append-only + SHA-256 链）           │
│   Hooks: P0..P6；生活层挂 Phase 3.5(L1..L7)；经济/生命周期 4.1..4.8     │
└───────▲───────────────────────────────────────┬──────────────────────┘
        │ IF-1 perceive（只读视图）              │ IF-3 events（唯一事实出口）
┌───────┴───────────────────────────────────────▼──────────────────────┐
│  L1  人格生活层（M1/M2/M3/M4/M5/M7）— LLM 生成内容/意图 + 记忆          │
│   感知 → T0/T1/T2 决策 → 非货币状态（Phase 3.5 结算）+ 意图 → 4.x       │
│   内部子模块：硬功能 +（LLM）软判定层 +（LLM）叙事层                     │
└──────────────────────────────────────────────────────────────────────┘
   OBSERVER ──inject_seed_event──► D0（唯一人类/观察者干预入口 IF-5）
```

### 2.2 三层职责边界（铁律：**写世界的只有 D0 中央裁决器**）
| 层 | 定位 | 必须做 | 绝不越界 |
|---|---|---|---|
| **D0 确定性内核** | 世界法则 | 时间派生、状态、全部裁决 hook、账本、RNG、规则校验、货币/生命周期结算、所有判定 | 不生成内容、不调 LLM |
| **L1 人格生活层** | Agent 的生活与人格 | 生成计划/对话/反思/叙述等内容，产出非货币状态与**意图** | 不直接写世界状态/账户、不绕过裁决器、不自定货币后果 |
| **L2 涌现观测层** | 度量与描述 | 从日志**确定性重算**生活/涌现/福祉指标；LLM 仅描述 | **只读**、判定不用 LLM |

### 2.3 回合流程与 hook 链（顺序冻结）
```
P0 ROUTE → P1 PERCEIVE → P2 DECIDE(T0/T1/T2) → P3 COMMUNICATE
→ P3.5 LIFE（新增）：L1 advance_time → L2 resolve_schedule → L3 settle_activities
                     → L4 apply_needs → L5 update_relations → L6 write_memories → L7 emit_tags
→ P4 ARBITRATE（顺序冻结）：4.1 settle_market → 4.2 settle_obligations → 4.3 apply_tax
                     → 4.4 apply_metabolism → 4.5 apply_penalty → 4.6 check_lifecycle
                     → 4.7 resolve_revival → 4.8 check_death
→ P5 LIFECYCLE → P6 COMMIT（追加日志 + 守恒校验 + 快照 + 指标）
```
- **Phase 3.5 在 4 之前**：生活层先结算**非货币状态**，其**货币后果以 intent 交 4.1–4.8**（完全不动 4.x 顺序）。
- 先税后代谢（v1 D1-1）；`I_eff` 在 4.1+4.2 后、4.3 前计算（v1 C-04）。

### 2.4 底座三条「角色带」与确定性边界（用户拍板）
功能三轴（内核/生活层/观测层）之外，按「**LLM 到底被允许做什么**」再正交切分为三条角色带：
| 角色带 | 执行者 | 允许做 | 绝对禁止 |
|---|---|---|---|
| **① 硬内核（Hard Kernel）** | 确定性代码 | 时钟、账本、结算、状态变更、**死亡判定** | **LLM 绝不碰「金额/死亡/结算」三类数字** |
| **② 软判定层（Soft Judgment）** | LLM | **仅定性社会判断**（如「师徒关系是否建立」） | 不产出金额/死亡/结算数字；判定结果写入日志后**冻结**（`frozen=true`） |
| **③ 叙事层（Narrative）** | LLM | 把**已定结果**叙述成情节/对话（`NARRATIVE`，`affects_state=false`） | 纯输出、不影响任何状态 |

**三条关键澄清**：
1. **随机性不得由 LLM 承担**：所有分支/结果分布由**种子化 RNG**（`redraw(stream_id,round,seq)`）决定；LLM 只往已定分支里填内容——**LLM 不是掷骰子的人**。
2. **LLM 判定结果冻结**：首跑允许 LLM 定性判定，结果落 `LLM_JUDGMENT{decision, model, context_digest, frozen=true}`；重放/统计**只读日志、不重问 LLM**。
3. **可复现口径 = 同日志逐位一致**：首跑可含 LLM 判定；`replay = reduce(apply, EventLog)`，**同日志逐位一致**（跨跑因 LLM 不保证逐位一致，故复现单位是**日志**）。

### 2.5 确定性 / 非确定性边界（逐条）
**必须确定性（D）**：时间派生、阶段顺序、状态存储、经济全部结算、借贷准入、生命周期、反作弊打标、RNG、场所合法性/容量/营业时段/`travel_ticks`、日程 slot 分配、需求衰减函数、**关系数值更新函数**、记忆 salience/反思阈值/检索 top-k **结构**、标签频次/规范采纳**阈值判定**、账本哈希/重放、全部统计指标、LLM 成本闸门。
**交给 LLM（N/F）**：人格自由文本、计划内容、对话正文、活动结果叙述、反思文本、关系印象叙述、意图生成、涌现描述（散文）。
**关键纪律**：凡「对抗/评分/竞争」类事件（Diff. Scoring、Power Conflict），**胜负与名次必须由 D + R 决定**，LLM 至多给 F 类定性评语（不进排名、不进门禁）（`12` §0/§3）。

## 3. 单小镇世界设定与周尺度时间

### 3.1 场景声明（用户拍板：单一小镇「五脏俱全」）
- **单一小镇「青溪镇（Qingxi Town）」**（展示名可改）；**不引入跨场景/多世界维度**；小镇是**闭合经济系统**（生产→交易→消费→税收/再分配镇内闭环）。
- **规模**：沙盒起步 **N=10**，**本轮目标 N=20（先跑通）**，50 降为展望（§10）。

### 3.2 场所清单（默认 17 处，可调 12–24）
`residence` 住宅 · `farm` 农场 · `workshop` 工坊 · `kitchen` 餐饮 · `clinic` 诊所 · `school` 学校 · `office` 事务所 · `market` 市集（**CDA 撮合**） · `bank` 银行 · `plaza` 中央广场 · `town_hall` 市政厅（规范/投票） · `library` 图书馆 · `community_center` 社区中心 · `cafe` 咖啡馆 · `park` 公园 · `hall` 礼堂（大型活动/种子事件主场） · `gate` 城门。
- 每处含 `affordances`（允许的 activity_type）、`open_slots`（营业时段，确定性）、`capacity`、`owner_role`、`produces`。
- **拓扑**：中心–外围（`plaza` 枢纽）；`travel_ticks` ∈ {1,2,3}；建议 `TOPOLOGY` 落 **config 常数矩阵**（17×17）以保证跨环境可复现（08 §5.6）。

### 3.3 时间结构（用户拍板：先做「模拟周」）
```
回合(round) ─ 1 时段(slot)=3 回合 ─ 1 日=4 时段=12 回合 ─ 1 周=7 日=84 回合
DAY_TYPES = [workday×5, weekend×2]
WEEK_PHASES = [PLAN(day0 morning), CONTACT(day0–4), ACTIVITY(day0–6), REVIEW(day6 evening/night)]
```
- 工作日/周末仅影响**行为倾向与事件概率**（`work_required/leisure_weight/social_event_prob`），**不改 tick 级经济/生命周期结算频率**（代谢/税/计息仍每回合）。
- 跨日/跨周发 `TIME_MARK`；所有生活事件必带审计字段 `day/slot/day_type/place`。

### 3.4 行业/角色最小集（默认 10 类）
`farmer` 农民 · `craftsman` 工匠 · `cook` 厨师 · `merchant` 商人 · `healer` 医护 · `teacher` 教师 · `public_servant` 公职 · `banker` 银行职员 · `artist` 艺术家 · `student|unemployed` 学生/无业。
- 职业↔收入↔场所映射固定（00 §2.5）；职业转变经 `ROLE_CHANGE` 可观测。

### 3.5 周尺度的关键可行性结论
- **最短可交付单元 = 1 模拟周 = 84 回合**；短窗基线 1–2 周（84–168），长窗 4–12 周（336–1008）。
- **死亡可观测性**：默认参数下首个自然死亡约在第 **65 回合**；**1 周 = 84 > 65**，故模拟周内死亡动态可观测，**无需额外延长窗口即满足 H2**。
- ⚠️ **约束 AR-D4**：`ROUNDS_PER_SLOT` 默认 **≥3**；若降到 1（1 周=28<65），周内测不到自然死亡，须设「死亡压力档」（§9.5）。

## 4. 人格生活层（M1/M2/M3/M4/M5/M7）+ 福祉向量

> 定位：在确定性内核之上**新增**，让 Agent「像在生活」；**一切判定与记账仍走确定性内核**。五条铁律：生成/记账分离、意图/事实分离、可复现、LLM 判定冻结、**不设单一「好生活」标量**。

### 4.1 M1 人格/身份
- 结构化人格：大五性格、Schwartz 价值观、技能、背景、`goal_tendencies`、初始需求、`speech_style`。
- **静态配置、与引擎解耦**：`config/personas.json` + 生成规则（templates + seed），引擎只见 `persona_id` 与派生标量；在线**不重新生成人格**。
- **人格→决策参数确定性映射**：`work_ethic/social_initiative/risk_appetite/saving_propensity` 由确定性函数从人格维度派生，供 T0 规则与资格判定。

### 4.2 M2 记忆（Smallville 记忆流 + Agentopia 文件式）
- **主日志**（哈希链）只存元数据 + 引用（`MEMORY_WRITE/RETRIEVE/REFLECT`）；**正文与嵌入进侧存储**（`body_ref/embed_ref` + 哈希校验）。
- **检索打分**：`score = w_rec·recency + w_imp·importance + w_rel·relevance`；`top_k=8`；平局按 `(score desc, last_access desc, mem_id asc)` 全序；**命中结果落日志，重放不再算嵌入**。
- **反思触发**：累积重要性 ≥ `θ_reflect=150`、REVIEW 相位强制 1 次、重大事件；每窗口上限 `R_max=7/周`。
- **控成本**：压缩档案进 prompt、importance 批处理（`B_imp=10`）、低信息量走 T0 规则回退、嵌入批量、反思降级。

### 4.3 M3 关系（Agent 视角、有向）
- 有向多维：`affinity[-100,100]`、`trust[-100,100]`、`respect[0,100]`、`familiarity`；阈值 `ε=20`、`ε_strong=50`。
- **数值一律由确定性函数更新**（LLM 只产印象叙述）；关系「质变」（密友/师徒）走软判定：**RNG 先定 envelope → LLM 定性标签 → 冻结 → D-12 映射为数值**。

### 4.4 M4 日程与活动
- 周相位 PLAN/CONTACT/ACTIVITY/REVIEW；活动抽象（`activity_type` 8 类：`work/learn/socialize/leisure/self_care/civic/trade/rest`）。
- 日程生成：周计划（T2，1 次/周）→ 日解析（T0/T1）→ 到期 slot 执行（`ACTIVITY_STARTED→COMPLETED/INTERRUPTED`）；货币后果交 4.x。
- 唤醒源扩展：W7 计划到期 / W8 需求触发 / W9 周相位 / W10 邀请或同处。

### 4.5 M5 场所与昼夜
- 昼夜由 `slot` 承载；`night` 段多数场所关闭（意图被拒并记 `INTENT_REJECTED`）；`residence` 全天开放。
- 偶遇：同 `place` 同 `round` 配对，按 `agent_id` 升序，仅记录**首次/超阈共处**（`D_enc=3` tick）→ 节流避免 O(N²)。

### 4.6 M7 目标/需求 + 福祉向量 WBV（用户拍板：多维、不合成标量）
- **需求 6 维**：`energy/satiety/social/esteem/mastery/leisure`（0–100）；每时段确定性衰减 + 活动满足；剥夺阈值 `θ_dep=20`。
- **目标**：`layer ∈ {生存,成长,社交,意义}`，进度由确定性规则推导。
- **福祉向量 WBV（7 维，各自独立、均可从日志确定性重算、禁止加权求和）**：
  | 维度 | 口径 |
  |---|---|
  | 社会地位 `wbv.status` | 入边 PageRank(G_rel,respect) 归一（0–1） |
  | 主观满足 `wbv.satisfaction` | 6 维 need **向量本身**（不取均值） |
  | 经济 `wbv.economic` | 窗口净财富变化（mu） |
  | 健康 `wbv.health` | energy+satiety 相关（0–100） |
  | 关系 `wbv.relation` | 入边 affinity/trust 聚合（有向好友数、互惠边数） |
  | 成长 `wbv.growth` | 技能提升次数 + mastery 目标进度 |
  | 意义 `wbv.meaning` | 达成目标数、self_direction/benevolence 相关活动参与 |
- **明确禁止**：对 WBV 做加权求和作为判定输入；可选的展示指数 `WBI` 仅供呈现（须声明权重假设 + 附敏感性分析 + 非优化声明）。
- **可观测的「背离」**：各维独立输出后才能观测「富而不乐」「地位降而幸福升」等——这正是核心观测对象，**必须保留维度、禁止压平**（详见 §5.5 / T15 §4.2）。

## 5. 涌现观测层（M8）与观测方法论

### 5.1 只读契约与判定铁律
- L2 **只读** `EventLog` + `turn_seal`；输入 `(log, T, TIME_CONFIG)`，输出确定性快照；**不调 LLM、不重算嵌入、不写世界**（IF-4）。
- **判定铁律 R1–R7**：R1 判定只读日志；R2 计算过程 `llm_calls==0`；R3 冻结 LLM 判定「可读不可算」；R4 指标分栏列示；R5 硬内核指标绝不接 LLM；R6 判定与描述分离；R7 判定不入世界日志。

### 5.2 指标三级分类（D / F / K）
| 级 | 名称 | 是否参与判定/门禁 | 命名空间 |
|---|---|---|---|
| **D** | 纯确定性指标 | **是（判定主力与门禁）** | `metrics.life` / `metrics.emergence` / `metrics.wellbeing` |
| **F** | 含 LLM 冻结判定指标 | **否（仅描述/敏感性分析）** | `metrics.emergence_soft` / `metrics.wellbeing_soft`（`contains_llm_judgment=true`） |
| **K** | 硬内核指标（金额/死亡/交易） | 作为**护栏**（门禁） | `metrics.econ` / `metrics.lifecycle`（v1 冻结） |

> 核心判定 `llm_judged_metric_count == 0` **仅针对 `econ/lifecycle/life/emergence/wellbeing`**；`*_soft` 单列并**排除在门禁指标集外**。

### 5.3 核心实验范式：种子事件 → 自主传播
- 唯一人类干预入口 `inject_seed_event → SEED_EVENT`；默认种子=「某 Agent 想在周末于 `hall` 办一场活动」，`t0`=day5 morning。
- **传播图（确定性，来自日志）**：节点=(event,agent)；边 u→v：`OBSERVATION(observer=v,target=u)` 或 `msg(v).refs` 含 u；级联=从 `SEED_EVENT` 在窗口内可达子图。
- **度量**：`cascade_size/depth/breadth/R0/time_to_spread/reach_ratio/path_len_dist`。
- **「突现成立」判据（全部满足）**：`reach_ratio≥θ_reach` ∧ `depth≥2` ∧ `R0≥1.0` ∧ `time_to_spread≤1 周` ∧ A/B 显著 ∧ 配额终止占比 `<θ_cap`；`θ_reach=0.50(N=10)/0.40(N=20+)`。
- **对照与显著性**：组内基线 + A/B 双胞胎（同 seed 去种子）+ ≥3 seed；判据 S1 噪声带(z=3) ∧ S2 置换检验(N_perm=1000,p≤0.05) ∧ S3 跨 seed 符号检验 ∧ S4 时间稳定。

### 5.4 观测对象与「有意义涌现」判定清单
A 关系形成/破裂 · B 观点/信息传播 · C 圈层/群体涌现 · D 规范形成 · E 职业/身份转变（各自确定性判定规则与阈值见 07/13）＋ 预注册现象 H-E1–H-E5 ＋ 福祉背离（§5.5）。

### 5.5 福祉背离判据（把「金钱 ≠ 幸福」变成可重算数字）
| 现象 | 判据（D 类） |
|---|---|
| 富而不乐 | `wealth_percentile≥0.75` 且 D 代理满足度低于中位 |
| 地位降而幸福升 | `pagerank_rank` 降 ≥Δrank 且 strong_ties/leisure/self_goal 上升 |
| 经济差而关系/意义强 | `wealth_percentile≤0.25` 且 strong_ties/activity_diversity 高于中位 |
| 成长停滞 | `skill_gain_rate≈0` 且 goal_achievement 下降但 financial_security 高 |
| **背离计数** | `divergence_count(t) = |{i: sign(Δecon_i)≠sign(Δwellbeing_D_i)}|/alive_count` |

### 5.6 区分「真涌现」与「假象」（六类）
① 规则内建→**消融对照**；② LLM 判定污染→**D 类复算 + D/F 分栏**；③ 观察者干预→**A/B + induced/spontaneous 分离**；④ 平凡传播→**要求 depth≥2**；⑤ 算法假象→固定算法+种子+全序 tie-break；⑥ 小样本偶然→多 seed + 置换检验。**白盒底线**：所有判定都能从日志独立重算（这正是 Agentopia 不可重放、含 LLM 评判所缺）。

## 6. 经济背景闭环与死亡护栏（v1 复用 + 改定位）

> v1 的经济与生命周期机制**原样复用、口径冻结**，仅**改定位**：经济=「资源/激励子系统 + 健康度护栏」，死亡=「健康度护栏 + 极端压力源」。完整机制见 v1 `01/02`，本文只列要点与改定位。

### 6.1 经济闭环（背景条件）
- **四层闭环**：L1 生产 → L2 交易（CDA 订单簿）→ L3 财税/信贷 → L4 结算；方向性：税/UBI 是再分配、借贷是时空调配、**只有铸币/销毁改总量**。
- **初始** `E0=100 CR`（=10000 mu）；代谢 `m=2 CR/回合`（销毁主出口）；手续费 1%（50% 税池/50% 销毁）；收入税 10%（对 `max(0,I_eff)`）；财富税 1%（超 2×E0）；UBI 1 CR/回合。
- **守恒不变量**：`ΣB + 销毁 + 手续费沉淀 + 税池 = M0 + 铸币 − 销毁 − 坏账核销`（不成立→回滚+告警）。
- **系统项不计入 `I_eff`**：UBI/铸币/税/费/息/罚/复活费一律排除（否则 UBI 会永远吊住濒死 Agent）。

### 6.2 死亡与可续命（护栏 + 压力源）
- **判定基准=净值 `E`（非现金）**；组合式判定：连续 `N_death` 回合 `E<θ_floor` + 滞回带 + 死亡冻结宽限；默认 `θ_floor=-20`、`N_death=3`（沙盒 5）、`θ_recover=+5`、`θ_warn=20`、`K_exit=6`。
- **可续命路线**：死亡非终局（冻结→救助/借贷→复活）；借贷准入（`LTV=0.6`、`L_max=50`、`D_max=100`、利率随负资产深度上升、`W_refi=3`）；惩罚 P1–P8（经济权利冻结为主、生命惩罚默认关）。
- **安全阀**（防全灭）：存活率 < `ρ_min=60%` → 救助；单回合死亡 ≥ `D_burst` → 暂停判死；**两轮制**（自然模式关阀验证 H2 / 干预模式开阀验证防全灭，救助打 `flag=rescue`）。
- **改定位落地**：死亡事件须**打标**便于统计剔除；`dead/terminated` 从存活率分母口径按 v1 Q2 处理；安全阀窗口标注并在涌现判定中降级为「参考」。

### 6.3 经济/死亡在 v1.1 判据中的地位（09 §6 差异表）
| v1 判据 | v1.1 处置 |
|---|---|
| 存活率/基尼/坏账/通胀/消息触顶 | **改用为「护栏」**（不越界即世界未崩，不追求优秀） |
| 反作弊 C1–C10 / 守恒 / 稳定性 / 可复现 | **保留为硬门禁护栏** |
| 单回合 LLM 调用 ≤ 8 | **改用为护栏（阈值重算 ≤ N×0.5）** |
| 「经济表现优秀」「经济闭环自持」为成功标准 | **废弃**，改为「观测到有意义的涌现」 |
| 经济/生命周期指标口径 | **保留（冻结）**，迁 `metrics.econ/.lifecycle` |

### 8.2 确定性结算规则（**LLM 绝不当裁判**）
- **Diff. Scoring**：`score(i)=Σw_k·norm(attr_k(i)) + rng_noise`；排名 `sort desc by (score, agent_id asc)`；LLM 仅 F 类评语（不进 score/rank）。
- **Power Conflict**：`power(i)=α·wealth+β·ally_strength+γ·respect_pagerank+δ·resource_control+ε·rng_term`；`winner=argmax`；后果走 v1 原子事件。
- **通用协商协议**：`OFFER → {ACCEPT | REJECT | COUNTER}`，轮次 ≤ N_round(3)；接受/还价阈由确定性效用函数；LLM 只生成措辞。

> 沙盒是放量前的**前置门禁**：验证 ① 世界能**长时运转**（不崩、可复现、成本可控）；② 能观测到**有意义的涌现**。判据权威 = `09` v4。

### 9.2 观测判据（充分：观测到有意义的涌现）
| 观测判据 | 口径 |
|---|---|

### 9.3 核心场景与时间尺度
- **核心场景 = 种子事件 → 自主传播**（§5.3）；A 组注入种子 / B 组同 seed 不注入；每级 ≥3 seed。
- **时间尺度**：主档 **N=20 短窗 1–2 周（84–168 回合）**；长窗 4–12 周（336–1008）；「1 周=84 > 65」→ 死亡可观测。

### 9.4 执行清单（可直接照跑）
1. 固定 `config`（含 `rule_version`、`personas.json`、`places.json`、`topology.json`；金额 `1 CR=100 mu`）；N=10，seed ≥3。
2. **轮次 1·自然模式**：关安全阀；跑 `run(seed,config,84×W)`（W=1–2 周）。
3. 每回合末跑 `metrics`；每窗口跑 `emergence_report` 与 `wellbeing_report`；核对 §9.1/§9.2。

6. 执行反作弊 C1–C10 注入测试；核对守恒/不变量。
7. 由 `LLM_CALL` 回放标定 `c_life/c_social`、`θ_*`、`Δ/ε`。
8. L0（N=10）全通过 → 升 L1（N=20）跑通。

### 9.5 失败判据与回滚
人口崩溃（<50% 或 =100%）、过狠全灭（<40%）、财富极化（Gini>0.75 或单调升）、坏账扩散（>10%）、恶性通胀/通缩、成本超支（>N×0.5×1.2）、续命滥用、消息失控、复现失败/守恒破坏 → 暂停冻结现场，单变量调参回滚；**复现失败立即停止放量**。
- **死亡压力档**（补偿 AR-D4）：为控成本缩短窗口/降 `ROUNDS_PER_SLOT` 时，并行跑一档（`m`↑ 或 `E0`↓）专测 H2。

## 12. 成本

### 12.1 分层决策与预算（**已收敛：≤ N×0.5/回合**）
```
每 Agent 每周 LLM 调用 ≈ (c_life + c_social)·SLOTS_PER_WEEK = (1.0+0.5)×28 ≈ 42 次
硬预算闸（护栏）：每回合 LLM 调用 ≤ N×0.5   # N=10→5，N=20→10，N=50→25
```
| 项 | N=10 | **N=20（本轮目标）** | N=50（展望） |
|---|---|---|---|
| 每周调用 | ≈4.2×10² | **≈8.4×10²** | ≈2.1×10³ |
| 每周 token | ≈10⁶ | **≈2×10⁶** | ≈5×10⁶ |
| 每回合预算 | 5 | **10** | 25 |
| 短窗 1 周 | 4.2×10² | **8.4×10²** | 2.1×10³ |
| 短窗 2 周 | 8.4×10² | **1.7×10³** | 4.2×10³ |
| 长窗 4–12 周 | 1.7×10³–5.0×10³ | **3.4×10³–1.0×10⁴** | 8.4×10³–2.5×10⁴ |

- **对照**：Agentopia 单世界一年 ≈13.7B token/56.7 万次调用/186 小时【单方研究】；v1.1 单周（10⁶–10⁷ token）**远低于**其年尺度 → 「先模拟周」成本可行。
- **日志非瓶颈**：目标 N=20 下 12 周压缩后日志仅 ~8MB（50×12 周 ~20MB）。

### 12.2 降级与压缩
- **降级优先级**（超 `LLM_BUDGET`）：濒死求生 > 投资/结盟 > 周计划/反思 > 印象叙述/日解析；T2→T1→T0，写 `LLM_CALL(degraded=true)`。
- **压缩手段（8 项）**：重要性触发反思、压缩档案进 prompt、`top_k` 上限、importance/嵌入批量、低信息量走 T0、相遇节流、快照节流、分层降级。
- **观测层成本 ≈ 0 LLM**：`metrics.emergence/wellbeing`（D 类）全为确定性计算。
