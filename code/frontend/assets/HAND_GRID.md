# 手绘像素网格 · 写法与编辑扩展（HAND_GRID）

> 来源：T88（用户倾向手绘）。**文本像素网格 `.px` 是唯一真源**，脚本确定性渲染 PNG。
> 样例：`references/hand/cottage_2p5d.px`（木屋正面 2.5D）、`references/hand/char_2p5d.px`（角色）。

## 1. 网格格式（`.px`）

- 逐行字符串，**每个字符 = 一个像素**；
- `#` 开头行 = 注释/表头（忽略）；
- 某字符对应 `palette.json` 的键；**`.` 或空格 = 透明**；
- 行宽不齐会自动右侧补 `.`；**不要**在格子里放制表符。

```
# 例：3×3
.k.
kRk
.k.
```

## 2. 渲染（确定性）

```bash
python3 scripts/render_pixel_grid.py <grid.px> <out.png> [--scale N] [--palette references/palette.json]
# 同网格 + 同调色板 + 同 scale → 逐字节一致 PNG（sha256 可复现）；放大用 NEAREST（锐利）
```

## 3. 色键（默认调色板，见 `references/palette.json`）

| 键 | 用途 | 键 | 用途 |
|---|---|---|---|
| `.` | 透明 | `k` | 描边（深暖棕黑） |
| `K/r/R/H/h/Y` | 屋顶红瓦（暗→亮） | `w/W/L/l` | 墙竖板（暗→亮） |
| `o/O/q` | 圆木截面（暗→亮） | `g/G/B/c` | 窗（框/叶/玻璃/高光） |
| `d/D` | 门（暗/中） | `S/s/t` | 石（暗/中/亮，烟囱） |
| `m` | 红地垫 | `n/N` | 橘猫 | 
| `v/V/e` | 木桶/铁箍 | `a/A` | 草（亮/暗） |
| `f/F` | 木台（亮/缝） | `p/P/u/U/x` | 角色（肤/发/衣/衣暗/裤） |

> 需要新色：在 `palette.json` 的 `keys` 里加 `"z":"#rrggbb"`，再在 `.px` 用 `z`。

## 4. 手绘版木屋（`cottage_2p5d.px`）的"件"

按 leader 参考口径逐件落格：**左侧墙=圆木截面堆叠**（`o/O/q` 带年轮）/ **正面=竖板+板缝**（`W/w/L`）/ **人字坡红瓦**（每片`H`上缘提亮、`r`下缘压深、`x%4`竖瓦垄、`K`脊瓦）/ **圆窗（4 格蓝玻白框）** / **石块烟囱（`S/s/t`）** / **门廊木台+台阶+板端圆截面裙板** / **绿百叶窗（`g/G` 叶纹）+ 白框 + 4 格蓝玻** / **红地垫 `m`** / **带箍木桶 `v/e`** / **橘猫 `n`** / **灰小鸟 `s`** / 枯草 `a/A`。

## 5. 如何编辑 / 扩展

1. 直接改 `.px` 文本（新建筑照抄 `cottage_2p5d.px` 改字符即可）；
2. 重跑 `render_pixel_grid.py` 出 PNG；放进 `assets/generated/` 并登记 `assets_manifest.json`（id/file/size/anchor）；
3. **尺寸/anchor 按 v1 冻结**：`place.*` 128×128 anchor(64,120)——手绘网格画完可 **NEAREST 缩放/留白**到该尺寸，或直接按 128×128 网格编辑；
4. 大面积重复元素（瓦片/道路）仍可用程序化生成（②），手绘用于**关键可见资产**。

## 6. 与程序化的分工（手绘优先）

- **手绘网格**：建筑、角色、道具、事件卡场景、图标（关键可见）。
- **程序化（辅助）**：tile/road 等大规模重复、以及需要参数化换色的批量元素。
