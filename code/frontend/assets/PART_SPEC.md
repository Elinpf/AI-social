## 0. 纹理口径（单一口径，5 条 + 4 约束）

> 用户真实差距："我们的件齐了但**更平**"。根因是**缺色阶/微纹理/不规则性**。以下为**执行口径**：

1. **圆木截面**：**错缝 + 大小不一**（相邻径级差 1–2px）；端面**同心环 2–3 圈** + 1px 暗缝 + 中心木节。
2. **竖板墙**：板缝之外加**木节 + 明暗斑块**（每 6–10px 一处 1–2px 深色结）；同色相 ramp 拉 **3–4 阶**。
3. **门廊板**：**板端圆截面**（端面圆角）**+ 顺纹线**（2–3 条 1px 木纹）；板宽不一。
4. **树冠**：**不规则叶簇 + 暗隙**（3–5 级绿同色阶；簇间留 1px 暗隙，禁方块团）。
5. **屋顶瓦**：**每片独立高光**（顶边 1px 亮 / 底边 1px 暗）；**排间错缝**、竖瓦垄。

**统一约束（硬）**：① **单一光源左上前**（顶亮底暗）；② **深暖棕描边**（非纯黑）；③ **限色** Sweetie-16 + same-hue ramp（≤48 色）；④ **不平铺**（每件有微变化）；且**透明底、不烘投射阴影**（影由渲染层施加）。
