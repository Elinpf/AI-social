## 1. 风格定位

> **16-bit 手绘质感像素**：明亮乡土、秋/春暖调、**多阶色相偏移 ramp**、**材质纹理可见**（瓦/木/石/叶）、**顶面亮 / 侧面暗**、**边缘环境遮蔽（AO）**、**暖黑描边**、附属物丰富（烟囱/灌木/柴堆/台阶/木桶/宠物）。

与 T72 的差别：T72 是「**平涂 + 单描边**」；T84 升级为「**多阶 ramp + 材质 + 双面明暗 + AO + 附属物**」。

## 3. 绘制规范

### 3.1 多阶 ramp（3–5 阶）+ **hue-shift**
- 每个材质面**至少 3 阶**（暗/中/亮），主体形用中阶，**左上受光→亮阶**、**右下背光→暗阶**。
- **色相偏移**：沿 ramp 提亮时，**色相向暖/黄偏 ~8–15°**、饱和度**先升后略降**；变暗时**向紫/红偏**并加饱和（Slynyrd hue-shift ramp 法）。避免"直 ramp"发灰。
- 以代码实现：`ramp_of(base)` 由定标色表取；不临时插值（保证**确定性**）。

### 3.2 材质纹理库（库函数，可复用）
| 纹理 | 用于 | 做法 |
|---|---|---|
| **瓦 (shingle)** | 屋顶 | 交错瓦列：每 4px 一列，瓦片底部 1px 暗缝 + 顶部 1px 亮边；按坡度**逐行内缩**。 |
| **原木 (log)** | 木屋侧墙 | 每 6px 一道水平原木；每根顶部亮线、底部暗线；**端面年轮**（同心小圆）在切面处。 |
| **竖板 (plank)** | 门/正面墙 | 每 5–6px 一道竖板缝；板间 1px 暗线 + 左侧亮线；偶见结疤（1px 暗点）。 |
| **石/砖 (stone)** | 烟囱/基座/桥 | 错缝砖块 6×4，缝 1px 暗；每块顶亮底暗；随机（确定性哈希）深浅。 |
| **叶簇 (leaf)** | 树/灌木 | 多 tone 叶团：亮阶在左上、暗阶在右下，边缘**叶尖抖动**（dither）。 |
| **草 (grass)** | 地面 | 底草 + 3px 簇状草丛（亮/暗各一撮）+ 稀疏花点。 |
| **碎石/土 (dirt)** | 道路 | 土底 + 2px 亮/暗碎石 + 边缘受草侵入。 |

### 3.3 描边
- **外形**：`#12161c` 1px 连续包边（**不做抗锯齿**）；
- **内部分界**：材质之间用**该材质暗阶**过渡，不额外加黑（避免"分割线过重"）；
- 特殊：高光面顶边可**去描边**（让亮色直接朝上），符合"左上光源"。

### 3.4 光影与 AO
- **单一光源：左上**（与 T72/T69 一致）；顶面/左坡亮，右坡/右侧墙暗。
- **边缘环境遮蔽（AO，**内部**）**：屋顶下檐对墙的**接触暗带**（1–2px）、墙脚对地面的暗带、部件交接处加深 1 阶。
- **接地**：精灵**自身底边** 1px 加深（接触暗线）；**不**绘制向下投射的椭圆地面阴影——**投射阴影仍由渲染层统一施加**（避免与 art-director 双重阴影）。若最终切到本库自绘，再改为自带软阴影（见 §7 待定项）。

### 3.5 像素密度与剪影
- **剪影优先**：远看轮廓可辨（村舍/谷仓/塔楼/市集各自形状不同）；附属物**不许破坏主剪影**。
- **密度**：建筑主体占 128×128 单元的 **~96–112px 宽、~92–104px 高**；单像素不"填空"，留白成组。
- **比例**：屋顶≈建筑高的 40–50%；门窗按 1.2–1.6 头身尺度对齐角色。

## 7. 与 Stardew 参考的**诚实差距**（对比图见 `assets/compare_stardew.png`）

**已追平的方向**：多阶 ramp+hue-shift、材质纹理、顶/侧明暗、暖黑描边、AO、附属物与剪影差异。

**仍存在的差距（如实列）**：
1. **手绘微结构**：Stardew 的瓦是**手绘每片不规则**；我们是**程序化规则瓦**，细节层次略逊、重复感更明显。
2. **密度与"随手感"**：参考图有**大量非必要装饰**（落叶、光斑、砖缝无规则变化）；程序化会偏"整洁"。
3. **透视与体积**：参考是**3/4 视角**（可见屋顶两面+山墙面+进深）；我们为**俯视正交**，屋顶两面进深表达更简化。
4. **角色/生物手绘**：猫/狗/鸟等生物是**手绘线条**；我们以**极简像素**近似（能辨但要小尺寸看）。
5. **光照情绪**：参考的夜色/窗光氛围更强；我们（本库）只做白天，夜间由渲染层 overlay（同 T72）。
6. **动画帧**：参考为手绘多帧；我们为**程序化 3 帧**，动作幅度与流畅度有限。

> 结论：本管线可稳定产出**精致独立游戏**级的**统一、可复现**素材；要达到"和手工 Stardew 无异"需人工精修（而本机无图像生成、ASEprite 不可用），故**不承诺逐像素等同**。

## 8. 手绘优先（2026-10-10 用户拍板 · 覆盖上文"程序化为主"）

- **全域统一走「手绘像素」**：以**文本像素网格（`.px`）为唯一真源** → `scripts/render_pixel_grid.py` **确定性**渲染 PNG（无 AA、NEAREST 放大、可哈希）。
- **程序化几何（②）退为辅助**：仅用于**瓦片/大规模重复元素**；建筑/角色/道具/事件卡**以手绘网格为准**。
- **建筑原型 = 正面 2.5D**：山墙正面（竖板+板缝）＋ 侧墙（**圆木截面堆叠**）＋ 红瓦双坡（**逐排 + 排距深缝 + 上缘高光 + 脊瓦**）；圆窗、**石块砌烟囱**、门廊木台+台阶、**绿百叶窗 + 红地垫**、道具（**带箍木桶 / 橘猫 / 枯草 / 柴堆 / 石堆**）。
- 口径依据（leader 精读参考）：**多阶色阶 + 每块材质独立明暗 + 物件接地软影 + 天空雪点**。
- 手绘写法/编辑扩展见 `references/HAND_GRID.md`；样例 `references/hand/{cottage,character}_2p5d.px`。
