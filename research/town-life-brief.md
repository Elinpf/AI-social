## 0. 摘要与结论速览

1. **用户所指的「米哈游虚拟小镇生活实验」基本可定位为《Agentopia》**（arXiv:2606.07513，2026-06-05 提交）。这是一项「**让 100 个 LLM Agent 在 3 个虚拟社会中自主生活 10 个模拟年**」的长期人生模拟框架。**论文本身未在摘要页展示机构署名**；「由米哈游/蔡浩宇创办的 Anuttacon 团队主导」来自媒体报道与作者背景关联（**二手**），但作者名单与媒体报道的 Anuttacon 成员高度重合，可信度较高。
   - 关键差异：Agentopia 是「**长期人生/社会模拟 + 用模拟数据反训模型**」，**不是**「货币经济 + 破产即死」的受控经济实验。它**有经济维度**（年末存款−年初存款）但**没有死亡机制**。这与我们 v1 底座存在**定位级差异**。
2. **真正「虚拟小镇」工程范式的一手源头是 Stanford《Generative Agents》（Smallville，25 Agent / 2 天）**（arXiv:2304.03442）——记忆流（memory stream）+ 反思（reflection）+ 计划（planning）三大件 + 突现社会行为（情人节派对传播）。**【已证实】**
3. **可复用的工程落地样板是 a16z《AI Town》**（开源仓库 `a16z-infra/ai-town`）：Convex 做后端状态/事务/向量检索，可切换本地 Ollama 或云 LLM，浏览器空闲即暂停以控成本。**【已证实】**
4. **长时程/大规模涌现社会实验另有两条主线**：Project Sid（Altera，10–1000+ Agent，Minecraft，PIANO 架构）、AgentSociety（清华 FIB Lab，1 万+ Agent、500 万次交互，做社会科学实验床）。两者均可追溯到 arXiv 论文。**【已证实其存在与主张，结论的独立复现性属【二手】】**
5. **方向重构的核心建议**：v1 的「确定性引擎 / 经济闭环 / 死亡续命 / 确定性统计」**作为护栏与度量层全部保留**，但**成功判据从『经济验收』降级为『健康度护栏』**；新增与「生活观察」直接相关的两层——**人格生活层（persona/life layer）** 与 **涌现观测层（emergence observation layer）**。详见 §6。

## 1. 米哈游 / Anuttacon 的长期人生模拟实验：Agentopia

### 1.1 定位与检索说明

- **用户线索**：「米哈游做的一个『虚拟小镇生活』实验」。直接以「米哈游 虚拟小镇」「miHoYo AI town」检索**未命中**对应产品/项目页（米哈游官网、米游社等均为游戏与社区入口）。
- **实际命中的同类项目是《Agentopia》**：媒体报道标题即《让 100 个 Agent 在虚拟世界里生活 10 年，米哈游发了篇论文》（观察者网，2026-06-24），将其归因于蔡浩宇创办的 **Anuttacon** AI 研究团队。
- **补充背景**：米哈游自身 2018 年即成立 AI 研发部门「**逆熵研究部**」，并在《崩坏：星穹铁道》上线「帕姆 AI 助手」；其下一代产品《**Varsapura（雨之城）**》公开招聘含「探索并实现 AI 原生玩法」。（以上来自媒体转述，**二手**）
- ⚠️ **性属说明**：Agentopia 的 3 个模拟世界是「**纽约合租公寓 / 魔法学院 / 中国高中校园**」，严格说更接近「**多场景长期人生模拟**」而非单一「小镇」。但作为「让 Agent 自主生活、看会发生什么」的实验范式，与用户设想高度同构，是最贴近的可核实参照。

| 训练 | **离线**：跑完模拟→算年度 life reward→按相对自身历史的 advantage 选 top 25% 轨迹→拒绝采样/SFT 微调 **Qwen3.5-397B-A17B**（另称输出非法时用 Gemini 3 Flash 兜底重生成） | ★ 论文/代码/解读 |

| 突现行为 | 友谊网络由稀疏变稠密（公寓世界平均互惠友谊 **4.3 → 10.1**）；职业转型（放弃高薪咨询转做登山向导）；性格长期漂移（自信 30→80、内向 95→65）；「社交建筑师被边缘化」等反直觉社会动态 | ★/☆ 论文案例与媒体转述 |

### 1.4 Agentopia 对我们最有价值的经验与警示

**值得借鉴：**
- **把时间尺度从「天」拉到「年」**：短程小镇看不到的关系漂移、职业转向、社交疲惫、长期满足度变化，在年尺度上成为可观测对象。
- **「程序骨架 + LLM 生成式环境引擎」的分工**：程序固定时间结构、动作格式、地点约束、排期规则与数值范围；环境模型只负责生成活动反馈/公开活动/偶遇/档案更新/输出过滤。这与我们「确定性引擎 + LLM 决策」的既有原则**同源**。
- **文件系统式外部记忆**：比单一 memory stream 更可扩展、可审计（append-only 版本日志）。
- **环境模型上下文是「压缩档案」而非全量记忆**：控制 token 成本的关键技巧。

**必须警惕：**
- **环境模型承担过多**（事件生成器 + 活动裁判 + 状态更新器 + 职位评估器 + 输出过滤器）——很多「社会规律」其实来自环境模型的判断，而非独立真实环境。
- **reward 的价值假设很强**：社会/主观/经济三维可操作 ≠ 人的真实福祉；论文自身案例显示「社会奖励下降但主观幸福上升」。
- **归因粗糙**：reward 按「Agent-年」计算，选中的是一整段轨迹，未做细粒度 credit assignment。
- **训练信号来自模型社会内部**：即便评价器固定，也难以区分「学会了社会能力」还是「学会了生成讨好评判器的轨迹」。
- **没有死亡机制**：经济只是奖励的一个维度，不存在破产退场。→ 这正是我们 v1 与之的**根本定位差异**。

## 2. Stanford Smallville / Generative Agents（主参照）

> 来源：Joon Sung Park 等，《Generative Agents: Interactive Simulacra of Human Behavior》，arXiv:2304.03442（v1 2023-04-07，v2 2023-08-06）。**【已证实】**

### 2.1 规模与设定（★一手摘要）
- **25 个 Agent**，运行在一个受《模拟人生》启发的交互式沙盒小镇（Smallville），**观测约 2 个游戏日**。
- Agent 会「起床、做早餐、去上班」；艺术家作画、作家写作；**形成观点、注意到彼此、主动发起对话**；**记住并反思过去的日子，并规划下一天**。
- 用户可用自然语言与小镇互动（唯一的人类干预入口）。

### 2.2 架构要点（★一手摘要 + 论文公开细节）
- **记忆流（memory stream）**：用自然语言存储 Agent 的**完整经历记录**。
- **反思（reflection）**：随时间把记忆**综合为更高层的反思**。
- **计划（planning）**：动态检索记忆以规划行为；递归分解为日计划 → 小时 → 更细粒度。
- **检索（retrieval）**：由**近因性（recency，时间衰减）**、**重要性（importance）**、**相关性（relevance，embedding 相似度）** 三者加权决定。
- **消融实验**：论文通过消融证明 **observation / planning / reflection 三个组件各自对行为可信度都有关键贡献**。

### 2.3 突现行为与结论（★一手摘要）
- **仅给定一个用户设定**「某 Agent 想在情人节办派对」，Agent 在随后两天**自主传播邀请**、**建立新相识**、**互相约着一起去派对**、**协调按时到达**。
- 结论：LLM + 计算式交互 Agent 的融合，提供了「可信人类行为模拟」的**架构与交互模式**。

### 2.4 值得直接复用的设计
1. **记忆流三件套**（存储-反思-检索）是「生活观察」的最小可信内核，**应整块复用**。
2. **重要性驱动的反思触发**（累积重要性超阈值才反思）是控制 LLM 调用成本的关键，**应复用**。
3. **「一个种子事件 → 自主传播」** 是衡量突现（emergence）的标准实验范式，**应作为 v1.1 的核心观测场景**（可复刻「派对」类实验）。
4. **人类仅经自然语言注入干预**：与我们的「观察者」定位一致，可作为 v1.1 的交互接口设计。

⚠️ **局限**：25 Agent / 2 天，**规模与时长都不足以观察长期社会演化**——这正是 Agentopia / AgentSociety 试图突破的点。

## 3. a16z AI Town（工程实现样板）

> 来源：开源仓库 `github.com/a16z-infra/ai-town` 的 README（一手）。**【已证实】** 项目自述「inspired by Generative Agents」。

### 3.1 定位
- 「一个 AI 角色在其中生活、聊天、社交的虚拟小镇」，是一个**可部署的 starter kit**，目标是提供**可扩展的地基**：后端原生支持**共享全局状态、事务、仿真引擎**，从玩具项目到多人在线均可。
- 有意选择 **JS/TS 栈**（因为该领域多数模拟器，含原论文，都是 Python）。

### 3.2 可复用工程栈（★一手 README）
| 组件 | 选型 | 可复用点 |
|---|---|---|
| 游戏引擎 / 数据库 / 向量检索 | **Convex**（一体化后端） | 共享全局状态 + 事务 + 向量检索 + 仿真引擎集中在同一后端，天然支持**状态同步** |
| 渲染 | **PixiJS**（2D） | 轻量像素风可视化，适合「观察窗口」 |
| 默认模型 | `llama3` + `mxbai-embed-large` 嵌入 | **可完全本地推理（Ollama）**，零 API 成本起步 |
| 云 LLM | Together.ai / 任意 OpenAI 兼容 API（含 Anthropic/Groq/Azure） | **模型可插拔**，便于成本分级 |
| 地图 | Tiled 导出 JSON + `convertMap.js` | 场景/场所数据与引擎解耦 |
| 背景音乐 | Replicate + MusicGen | 体验层可选项 |

### 3.3 成本控制与状态同步的可复用点（★一手 README）
- **浏览器空闲 5 分钟自动暂停世界**（加载页面重新激活，UI 亦可手动 freeze/unfreeze），并存在「stop inactive worlds」的 cron——**用观测活跃度驱动算力**。
- **记忆检索数量可调**（`NUM_MEMORIES_TO_SEARCH`），用于在慢/贵时压缩对话 prompt。
- **换 LLM 或嵌入模型需清库重来**：因为记忆用嵌入向量，**向量库维度必须与嵌入模型匹配**——这是一个**架构耦合点**，我们若引入向量记忆需注意。
- 角色/故事/精灵表集中在一个 `characters.ts`，**人格配置与引擎解耦、可批量定义**。

⚠️ **局限**：AI Town 是**工程脚手架**，不含长时程社会机制、经济、死亡、统计程序；其价值在**状态同步与成本控制的工程范式**，不在科学机制设计。

## 4. 其他长时程「涌现社会」实验

### 4.1 Project Sid（Altera.AL）【已证实其论文；结论属二手/未独立复现】
> 来源：《Project Sid: Many-agent simulations toward AI civilization》，arXiv:2411.00114（2024-10-31，35 页）。
- **规模**：**10 – 1000+ 个 AI Agent** 的 agent society；环境为 **Minecraft**。
- **架构**：**PIANO（Parallel Information Aggregation via Neural Orchestration）**——让 Agent 在实时互动的同时，**跨多个输出流保持一致性**。
- **主张的里程碑**（论文自述）：Agent **自主发展专业化角色分工**、**遵守并修改集体规则**、**进行文化与宗教传播**。
- **定位**：面向「AI 文明」的大规模模拟，主张这是通往大仿真、组织智能与 AI 融入人类文明的路径。
- ⚠️ **注意**：这些「文明级里程碑」是**论文自述结果**，**尚无独立第三方复现**；引用时须标注来源为单方研究。

### 4.2 AgentSociety（清华大学 FIB Lab）【已证实其论文；结论属二手】
> 来源：《AgentSociety: Large-Scale Simulation of LLM-Driven Generative Agents...》，arXiv:2502.08691（v1 2025-02-12，v2 2026-04-10）。
- **规模**：**1 万+ Agent、约 500 万次交互**（Agent-Agent 与 Agent-环境）。
- **组成**：LLM 驱动 Agent + 拟真社会环境 + 大规模仿真引擎。
- **定位**：**计算社会科学实验床**，针对 5 类社会议题做实验：**极化、煽动性信息传播、全民基本收入（UBI）政策、外部冲击（飓风）、城市可持续性**，并支持问卷/访谈/干预等研究方法。
- **主张**：其结果与真实世界实验**具有一定对齐**。
- **工程生态**：已有 AgentSociety 2 作为推荐版本，官方文档与 GitHub 开源（`tsinghua-fib-lab/agentsociety`），内置 `governmentagent / bankagent / firmagent` 等角色模板。
- ⚠️ **注意**：这是一手论文 + 开源代码的项目，**可信度高**；但「与真实世界对齐」的具体效应量仍属**论文单方报告**。

### 4.3 其他可留意方向（**未证实/仅方向性,不得当事实**）
- 媒体提及 Anuttacon 曾推出 AI 叙事游戏《Whispers from the Star》、AI 陪伴产品 AnuNeko（已于 2026 年前后停运）、视频角色生成模型 LPM 1.0——**均为产品线，非「小镇生活实验」本体**，且停运/放缓信息来自媒体。**【二手】**
- 米哈游 2030 愿景「打造十亿人生活其中的虚拟世界」、三年最多投入 1000 亿元 AI——**来自媒体转述刘伟表态**。**【二手，未经官方原始声明核实】**

## 5. 「虚拟小镇生活」必备模块清单（可直接映射为 v1.1 设计条目）

> 每条给出：**模块 → 参照实现 → 对 v1 现状的差距（保留 / 需补 / 需改）**。这是 §6 对接建议的细化依据。

| # | 模块 | 参照实现（来源） | 对 v1 现状 |
|---|---|---|---|
| **M1** | **人格 / 身份**（persona, identity） | Smallville 的角色设定；AI Town `characters.ts`；Agentopia 的独特背景/性格/技能 | **需补**：v1 只有「角色」概念，无结构化人格（性格维度、技能、背景、价值观） |
| **M2** | **记忆**（memory） | Smallville 记忆流（recency/importance/relevance 检索 + 反思）；Agentopia 文件系统式 scratchpad（read-before-write、append-only） | **需补/可借力**：v1 日志是「事件账本」，不是「Agent 自传体记忆」；可复用 v1 的 append-only + 规范 JSON 机制 |
| **M3** | **关系**（relationships） | Smallville 社交网络；Agentopia 有向喜爱/尊重图 + PageRank | **需补**：v1 有「金钱图/沟通图」统计口径，但无 Agent 视角的关系状态 |
| **M4** | **日常活动与日程**（daily routine & schedule） | Smallville 起床→早餐→上班、递归计划；Agentopia 每周 Plan/Contact/Activity/Review 四阶段 + 活动日槽位 | **需补**：v1 是「回合六阶段」，缺「日/周生活节律」与「活动」抽象 |
| **M5** | **场所与昼夜**（places & day/night） | Smallville 小镇地点 + 时间；AI Town 地图/场所；Agentopia 地点约束 | **需补**：v1 无空间与昼夜概念（被动 Agent 与空间无关） |
| **M6** | **对话与传播**（dialogue & spread） | Smallville 自主发起对话 + 信息/邀请传播；Project Sid 文化传播 | **部分保留**：v1 有公开板/DM/群组三通道与配额，**已具备传播载体**；缺「自然语言对话生成与记忆沉淀」 |
| **M7** | **目标与欲望**（goals & drives） | Smallville 计划；Agentopia「自主制定周计划 + 满足需求/目标」+ 生活奖励 | **需补**：v1 的驱动是「生存/货币」单一维度，缺内在目标/欲望层 |
| **M8** | **社会规范 / 文化浮现**（norms & culture emergence） | Smallville 派对/选举类突现；Project Sid 规则演变与文化传播 | **需补（观测层）**：v1 统计是经济/网络指标，无「规范/文化」观测口径 |

**必备模块的最小集（按实现优先级）**：
**M1 人格 + M2 记忆 + M4 日程 + M7 目标** 是「生活观察」能够自持的**最小可信内核**（对应 Smallville 三件套的可扩展版）；**M3 关系 + M5 场所 + M6 对话** 是「社会性」的载体；**M8 规范/文化** 是终极观测目标，依赖前述模块先立起来。

## 6. 与 v1 底座的对接建议（v1.1「AI 生活观察实验」重构）

> 总原则：**v1 的确定性内核不动摇**，把它的角色从「实验主角（受控经济验收）」改写为「**生活世界的物理法则 + 健康度护栏 + 可审计度量层**」；在此之上**新增人格生活层与涌现观测层**，将「成功判据」降级。

### 6.1 保留（继续作为地基，不推翻）
| v1 资产 | 保留理由 | 在 v1.1 中的新定位 |
|---|---|---|
| **确定性引擎**（回合制 / 事件驱动 / 中央裁决器 / 哈希链日志 / 规范 JSON 复现） | 「可复现、可审计」是科学实验底线；也是与 Agentopia「程序骨架 + LLM 环境引擎」分工同源的稳健选择 | **世界法则内核**：为生活层提供确定性时钟、状态校验、不可篡改记录 |
| **经济闭环**（货币发行/回收、撮合清算、税收再分配） | 经济是「成长激励」与「资源稀缺」的具体化；Agentopia 也把经济作为生活奖励维度之一 | **资源/激励子系统**：降为生活的一部分，而非实验唯一目的 |
| **死亡与续命**（净值判死、借贷负资产、惩罚 P1–P8、安全阀） | 用户已拍板「可续命」路线；提供戏剧张力与压力测试 | **健康度护栏 + 极端事件机制**：从「核心验收对象」变为「防崩溃护栏」 |
| **确定性统计程序**（只读日志、纯函数、逐位一致） | 「不依赖 LLM 主观判断」的度量是 v1 最大优势，**必须保留并扩展到生活指标** | **统一度量层**：在原有经济/网络指标外，新增生活/涌现指标（见 §6.3） |

### 6.2 需补（两个新层）
**A. 人格生活层（persona / life layer）** —— 对应 M1/M2/M3/M4/M5/M7：
- **人格定义**：为每个 Agent 定义结构化人格（性格维度、技能、背景、价值观、目标倾向）；**与引擎解耦、可批量配置**（借 AI Town `characters.ts` 思路）。
- **记忆系统**：引入 Smallville 式记忆流（recency/importance/relevance 检索 + 反思触发）；**复用 v1 的 append-only + 规范 JSON 机制**，避免重复造轮子；借鉴 Agentopia 的「压缩档案进 prompt + read-before-write」控成本。
- **日程与活动**：引入「日/周生活节律」与「活动」抽象（可参照 Agentopia 的 Plan/Contact/Activity/Review 四阶段），把 v1 的「回合」作为活动的底层 tick。
- **场所与昼夜**：引入最小空间（若干场所）+ 昼夜周期，作为活动与偶遇的载体。
- **关系与目标**：引入 Agent 视角的关系状态与内在目标/欲望（可映射为生活奖励的社会/主观维度）。

**B. 涌现观测层（emergence observation layer）** —— 对应 M8：
- **观测对象**：关系形成/破裂、信息与观点传播、群体/圈层涌现（如 Agentopia 的「社交建筑师被边缘化」）、规范形成、职业/身份转变。
- **观测方式**：**保持确定性可审计**——突现事件的「判定规则」尽量用日志可重算的确定性指标（如网络结构变化、传播链长度、语言/标签频次），LLM 只用于**生成与描述**，不用于**判定**（延续 v1「统计不依赖 LLM 判断」的铁律）。
- **标准实验范式**：复刻 Smallville「一个种子事件 → 自主传播」的范式（如「A 想办一场活动」），作为 v1.1 的核心测试场景。

### 6.3 定位改动：成功判据「降级为健康度护栏」
| v1 现状 | v1.1 建议 |
|---|---|
| 沙盒「通过」= 经济指标达标（存活率/基尼/坏账/通胀/成本…） | 这些指标**改称「健康度护栏」**：只要**不越界**即视为「世界未崩溃」，**不追求**「经济表现优秀」 |
| 「实验成功」= 经济闭环自持 | 「实验成功」= **观测到有意义的突现社会现象**（且全程可复现、无系统性观测偏差） |
| 经济是核心问题 | 经济是**背景条件**（提供稀缺与激励），核心问题变为「**在稀缺与规则下，Agent 社会会自发产生什么**」 |
| 死亡是核心机制 | 死亡是**护栏与极端压力源**（防止僵尸账户、提供张力），并须**打标以便统计剔除**，避免其主导叙事 |

### 6.4 与 v1 文档的最小回写建议（供 Leader/汇总人参考）
1. `05-v1-proposal.md` §1 目标/定位：**改写**为「AI 生活观察实验」，经济验收降级为护栏。
2. 新增分册建议：`06-life-layer.md`（人格生活层）、`07-emergence-observation.md`（涌现观测层）。
3. `03-engine-stats.md`：**扩展事件类型**（生活/活动/记忆/关系事件）与**统计指标**（新增生活与涌现指标），保持「只读日志纯函数」约束。
4. `04-sandbox-plan.md`：判据拆为「护栏判据（不越界）」+「观测判据（有突现）」两组；核心场景改为「种子事件传播」。
