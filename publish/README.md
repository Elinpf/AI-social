## 这是什么

一个「让 AI 居民像人一样聊天」的工程实验的可发布结果：把「一条条独立单发消息」改造成**可追溯的多轮对话线程**，并用**可复算的指标**说明它到底改变了什么、没改变什么。

**一句话结论**：结构改造**确实生效**（多轮线程 0→43.7%、回复指针 0→100%、对端称呼 0→51.0%、裸内部 ID 29.9%→0）；**措辞层只能表述为「形式与套路改善 + 两项确定代价 + 承接一项机制未定」**——**不得表述为「措辞改善」**，也**不宣称"更自然"**（judge 五维差 ≤0.21、无法区分）。

## 结论（可发布部分）

- **结构（v0-anchor → A0，16 agents × 84 回合、seed=42、真 LLM）**：多轮线程 **0 → 43.7%（90/206）**、回复指针完整率 **0 → 100%（480/480）**、对端称呼 **0 → 51.0%（318/623）**、裸内部 ID **29.9% → 0（0/686）**、`ctx` 快照覆盖 **686/686**。
- **旁证**：`PLACE_MOVE` 两批均 **406**（对话改造未扰动出行行为）；`WORLD_INIT` 四项指纹两臂逐字相同（配置零漂移）。
- **措辞（同窗口 前 34 回合、n=284×2）**：旁白 **−79.9pp**、含括号块 **−82.0pp**、8-gram 近重复 **−10.9pp**（均带外）；**代价**：具体性密度 **−9.5pp**、字数 p50 **−40.6%**；**承接**：词表口径 −10.5pp，但**真回指标记仅 −2.1pp（落带内、本规模无法判定）**，下降主体是语气/指示词（50.5%→37.9%）。

## 边界（必读，缩小字号的不是它）

1. **措辞层只有前 34 回合窗口**：完整 42/84 轮未取得，成因 **「起跑失败 + 准入拒绝」**（不得写"时间不够"）。
2. **幅度比较多处不可比**：结构改造使消息量 187→686（分母差 267%），措辞/F 系列多数指标被判「不可比（分母差>30%）」或「无可用带」。
3. **成本只能写调用数倍数**（**2.41 倍 = 2,905/1,207**），**不得写成金额倍数**；缓存冷热跨批差 3–7 倍。
4. **`max_turns` 只钳尾部**：`p90` 跟随上限、`p50` 卡在 1–2；抬上限到 6 反而让 ≥3 轮占比从 38.2% 降到 35.5%。
5. **措辞不可逐条复现**：同 seed 同提示词两批台词逐字节一致率仅 **21.30%**（49/230）。
