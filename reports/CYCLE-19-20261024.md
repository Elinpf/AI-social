## 四、改法设计与验收口径（**只写设计，不落地代码**）

> **总纪律（先写死）**：本维度的分母 `218` = **计划对端有向对实例数**。任何改法若靠**删 `participants`** 来提升比率，分母会从 218 塌到 16（= 双向互列数），比率变 87.5% 但样本几乎清零 —— 这是**分母缩水式假提升，一律判无效**。合规改法的判据是：**分母（`planned_pair_instances` = 218、`decidable` = 218）不变，只让 `place` 更常对上**。

### M-1（推荐，最小、不动分母）兜底落点向「同格邻居的计划落点」让路

- **改哪里（不实际改）**：`code/life/agent.py` → `_base_activity`（**594–607 行**）/ 其调用点 `_choose_activity`（**623–635 行**）。建议改法：保持 `_base_activity` 原语义作为**首选**；仅当（a）本格被门跳过、（b）存在同 `(day, slot)` 的邻居计划了**同伴活动**、且（c）该邻居的 `place` 对当前 `activity_type` 合法（复用 `_valid`，**609–611 行**）时，把落点让给该 `place`。
- **预期对指标的影响**：直接命中 **R-2 的 61 条（42.36%）**这一档的**上界**；实际兑现取决于「同格邻居计划落点是否合法」，**不承诺兑现比例**。分子上限 +61、分母仍 218 ⇒ 一致率上界 `(74+61)/218 = 61.9%`（**这是上界推算，不是实测**）。**不动 `participants`，不动门**，因此事件量纪律（CYCLE-18 D2.5 的 slot 配额问题）不受影响。
- **风险**：(a) 兜底不再是 `(day_type, slot)` 的纯函数，变成依赖**同格他人计划** ⇒ 回放稳定要求把遍历顺序钉死（`agent_id` 升序）并写进指纹；(b) 可能把多人挤向同一 `place`，加剧 CYCLE-16 已记录的「群聚形态单一（`GROUP_CREATED` 17 次全是 `market/afternoon/8 人`）」；(c) 与「`_base_activity` 是兜底」的设计意图冲突，需保留 `--override` 回退开关。
- **需补的验收口径**：跑前预登记 A/B 两臂；主判据 = `plan_pairs.consistency_rate` 分母**仍为 218**、缺口互斥主类求和 = 缺口总数；质量闸 = `GROUP_CREATED` 的 `place` 多样性不得退化（种类数不得下降）、F-2b 话题宽度与线程数跌幅 ≤ 10%；代价闸 = LLM 调用量增幅 ≤ +10%（本改法不新增 LLM 调用，应 ≈ 0）。

## 七、结论与下一步

**结论（事实层，全部可原地复算）**

1. P2 读数在既有 run 上**原样复现**：`74/218 = 33.94%`、缺口 `144/218 = 66.06%`、不可判 0、主类 `61/50/33/0` 求和 = 144。
2. 第二个独立 run（不同 `code_sha`、不同日志）给出**逐项相同**读数，但**计划流指纹相同** ⇒ 强度是「尺子确定性一致」，**不是**「跨计划独立复现」。
3. 缺口**不是类型不明**：42.36% 是「对端被 1/3 门跳过 ⇒ 固定兜底落点」（**61/61 逐条核验**），34.72% 是「对端在另一个多人模板」，22.92% 是「对端在单人模板（`bank` 27/33）」。
4. 骨架是**单向列名**：92.66% 的实例里「计划同伴」只有一方列名；双向互列（仅 16 条）一致率 87.50%，单方 29.70%。
5. 同处率随对端自身并行度单调上升（1 人 15.32% → 2 人 37.33% → 8 人组 90.62%）⇒ **「进同一个组/同一个 `place`」是唯一有效机制**。
6. **本维度不产生判据级页面证据**：截图为节律/落点层的真实旁证，`participants` 不在页面上 ⇒ 判据以数值为准（同 §5.1）。

**下一步（建议顺序，均需先预登记再跑）**

1. **M-1 先行**：兜底落点向同格邻居让路 —— 唯一**不动分母、不动门、不新增 LLM 调用**的改法，直接瞄准 42.36% 那一档。跑前必须预登记「分母仍为 218」与「`GROUP_CREATED` place 多样性不退化」两条闸。
2. **M-2 随后**：计划期同伴对齐（需先把 PLAN 阶段串行化并钉死顺序 + 双跑计划指纹一致）。
3. **M-3 永久否决**：任何靠删 `participants` 提升比率的做法。
4. 口径侧：本轮提出但**未处置**的两项留给下一轮 —— (a) 双向互列档需扩样本才有判据资格（当前 16）；(b) slot 级对齐低估共处（U-2）需 round 级在场重建才能量化，属新出数器工作量。
5. `reports/README.md` 的 CYCLE-19 索引行本轮**未改**（本轮按显式路径提交，避免动既有索引文件），由下一轮统一回填。
