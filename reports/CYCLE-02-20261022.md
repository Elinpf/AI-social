## 一之补充（标题级）：本轮最重要的一句

> **中位深度不是被「允许聊多长」卡住的，而是被「跟谁聊」卡住的。**

**六次尝试（全 mock、零成本）**：`max_turns` 2/4/6、`max_messages_per_slot` 2/3/4、`max_turns_per_round` 2/3/4、`reply_window_rounds` 2→4、「对未回对端不发起」——**前五个（"允许更多"思路）全部抬不动 `p50`**；第六个「**发起时选『欠我回复的对端』**」（**"换对象"思路**）第一次抬动：**`p50` 1→4**、单发 **52.26%→42.39%（−9.87pp）**、`≥3 轮` 绝对条数 **120→130**、总消息仅 **+3.4%**。

**判定：`部分有效`（不得改写为"有效"）**——预登记要求 `≥3 轮` 绝对条数 **+≥10%**，实测 **+8.3%**，**差 1.7pp 未达标**；但紧邻写出三条硬事实（`p50` 1→4、单发 −9.87pp、绝对条数 +10 条且消息仅 +3.4%），让读者同时看到"差一点没达标"与"这是真机制"。

**【事实 · 定义产物不等于行为差异】** `expired_unanswered_inbound` 两臂算出 **38 vs 22**，但**行为逐项相同** ⇒ 该差值属**定义/窗口口径产物**，不构成行为差异证据（已进 R1 边界 9）。

## 三、还有哪些问题

### 3.1 实验设计问题

1. **所有"效果"都被守卫或剂量挡住**：R13（L-13 击穿）、R14（L-7 击穿）、R15（F2 一票否决 + L-7 击穿）、R16（BELOW_BAND）、R17（剂量不足）—— **五个臂，零个"效果达成"**。这不是运气差，是设计层面的结构问题：机制方向与守卫方向常常同源冲突（R13 的"带话题 token"、R15 的"G-1b ≡ G-1 结构互斥"）。
2. **F2 与 F1 结构互斥（R15 登记）**：`G-1b ≡ G-1` ⇒ 按冻结判据 A1 **数学上不可能**被判"改善"；这类"判据自相矛盾"必须在预注册阶段就查出来，而不是跑完之后。
3. **剂量不足使统计功效≈0（R17）**：世界导演 `conservative` 曲线下，每回合总命中率 **115bp = 1.15%**，84 回合期望 **0.966 次**。这类"一百回合一次"的供给，任何效果设计都测不出来。
4. **窗口分母过小**：R17 窗口（rounds 30–35）只有 **48 条**消息（<68 判读下限），按纪律只能报条数不报比率。

### 3.2 实现与工程问题

1. **双重计数（R17 §3.5）**：`engine/world_params.py:44-59` 对两类世界事件都累加 `params`，`hooks/world_director.py:37,46-49` 又把同一 `directive_id` 写进两类 ⇒ 剂量虚高一倍。**已登记未修**，修复须开分支（与 `af1dffc` 不可对照）。
2. **记忆侧从未接入世界事件**：`_SALIENT_EVENTS`（`agent.py:111-115`）不含 `WORLD_DIRECTIVE`/`WORLD_GROUP_EVENT` ⇒ 世界事件进不了记忆，也就进不了"跨天记忆引用"（F-6 那条链）。**这是链路缺口，不是参数问题。**
3. **4 批缺 `meta.json`**（`run_worldline_c1_ctrl`、`run_g1_b0`、`run_l7struct_on`、`run_a1wording`）：按团队纪律"缺 meta 判批次不可用"，但目前它们仍在被引用做读数 ⇒ **需要 Leader 裁定统一处置口径**（要么补 meta，要么明确降级为"仅读数来源"）。
4. **`meta.code_sha` 语义漂移**（CYCLE-01 已登记）：跑批代码须 `code_sha_start` + landing 记录 + 期间无改动三件共同确定。

### 3.3 口径与证据问题

1. **跨批不可比是常态**：规模（16×60 vs 16×84）、天数（5 天 vs 7 天）、提示词版本、开关状态四者同时变。本周期所有横向读数都必须在表里带"规模"列，否则会被读成前后对照。
2. **F-1 跨时代含义变了**：v0/A0 两批 F-1 里 **64.6% / 81.8%** 是括号旁白；2026-10-20 之后所有批括号为 0 ⇒ 现在的 71–78% 是**纯台词闲聊**，不能与旧批当同一把尺子。
3. **噪声带：本轮补了三条，仍缺两条**（更新：本周期上游已产出 `recon/f2b-noiseband.md`）：已补 **F-2b**（dm / all 两口径，bootstrap B=5000 + Wilson）、**L-7**（相对同批对照臂 **+6.0pp**）、**L-13**（率 ≤1.42% 且绝对条数 ≤7）；**仍缺 F-1 与 F-5 的噪声带上界**（per-message / per-agent 不得借用消息级 B2 档）⇒ 这两个维度的跨批 Δ 仍只能写读数、不能写"带外"。
4. **同配置批间波动远小于抽样带（F-2b）**：16×60 九批极差 **1.75pp**、16×84 四批极差 **0.25pp**，而单批抽样半宽 ≈ **±7.2pp** ⇒ 单批 CI 就是主导不确定度，不必再叠批间方差；但也意味着**本规模的分辨率只有 ≈+7pp**。
