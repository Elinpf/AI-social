# D9 线收束一页纸（对外可发布）

> 用途：把 D9c / D9g / D9h / D9i / D9j 五条线的结论与**边界**汇成一页，供外部读者判断"这些数能用来做什么、不能用来做什么"。
> 文风约定：**每条只写"测得什么 + 边界"**；不写"改善/退化"这类评价词（本系列判据尚未定型处一律记"不可判"）。
> 脱敏：本页不含路径、主机名、密钥；所有实验均为离线/本地可复算。

---

## 0. 一页结论（先看这四行）

1. **参数层的三个方向（对话窗口、挑选顺序、对端选择）在既有语料上都没有产生可判定的收益**；其中挑选顺序一案在数据上有明显机制反应，但**预登记判据没有覆盖"机制触达而幅度未达线"这一档**，故只能判"不可判"，不得判"无效"。
2. **"负向话/冲突"这类语义指标目前不可作为质量判据**：旧词表在两批抽样上假阳性 **33/33 = 100%**；换成"指向性前置筛 + 形态排除"后，样本内假阳性降到 **1/33**，但对人工锚定的真负向话**召回 0/14**（零响应）。
3. **旁白（动作/神态）通道已验证可开关、且不付结构代价**：同代码对照下旁白率 **0% → 93.7%**、动作神态类占 **71.7%**，结构量（消息数/线程数/≥3 轮）**不变**，台词长度仅 **−2.7%**；表面上的"重复率上升"经同口径重算后**实际下降**。
4. **所有跨臂比较必须先过"配置同源"与"暴露面/同口径"两道闸**：本轮至少有一次结论因"两臂代码版本不同"而作废，一次因"新增内容抬高指标暴露面"而误判。

## 1. 五条线逐一（结论 + 边界）

### D9c · 挑选顺序（recent → oldest）
- **测得**：机制确实被触发 —— 回复滞后 `lag=2` 由 **7 → 257** 条、线程中位轮数 **1 → 3**、`≥3 轮` **120 → 127**。
- **结论**：**不可判（判据未覆盖）**。预登记把"有效"单点锚在"`lag≥3 > 0`"，而实测 `lag≥3 = 0`（两臂、两口径均 0）⇒ 四档皆不命中；按纪律**不得**改判为"有效"。
- **边界**：①预登记的反事实"若 `lag≥3` 恒 0 则方向作废、不再复测"**已触发**；②"上界由结构决定"这一因果说法**已撤回**（`lag_turn` 上界随顺序从 1 变 2）；③两臂为 mock，**不作语言质量证据**。

### D9g · 负向词表假阳性（第一层）
- **测得**：33 条分层抽样上，人工判"否" **33/33 = 100.00%**（两读者独立全否，一致率 33/33）。
- **结论**：旧词表判定**不可用于冲突维度**；错法可按形态归因 —— 关切（`累` 5/5）、转述他人冲突（`吵` 3/6）、生理/味觉（`疼`/`苦`）、顾虑句式（`怕` 5/6）、客套（`烦` 4/4）。
- **边界**：①**一致率 100% 无区分力**（两侧全否 ⇒ 分子恒等分母），**不得**写成"判据可靠"；②本批无"是"样本 ⇒ **无法估计假阴性**；③只能评价 7 个词（另 11 词在语料中零命中）；④"群体指称"按定义记否，但**确有 1/33 条真实负向话被该定义排除**（属定义设计问题）。

### D9h · 负向判定改法（第二层）
- **测得**：加"指向性前置筛 + 5 类形态排除、不删词"后，同一 33 条上假阳性 **33/33 → 1/33（3.0%）**；人工锚定的真负向话（9 条主用 / 14 条含调侃）**召回 0/9、0/14 = 0%**。
- **结论**：**仅降假阳性，且降幅为"样本内成绩"**（规则与抽样同批定型）；**召回为零 ⇒ 与"把词表删空"在本批数据上不可区分**。
- **边界**：①"A 闸（假阳性 ≤20%）**不能认定**"（无独立样本）；②不得写"灵敏度未知"（那是"未知"，本批是"已知为零"）；③`enabled=false` 只证"关闭态不可达"，**不得**写"等价性已验"；④未参与调参的旧命中上仍有 **43.2% / 40.0%** 被判是（保留率，非假阳性率）。

### D9i · 旁白（动作/神态）通道
- **测得**（同代码、只切一个环境开关的真 LLM 对照）：旁白率 **0/191 = 0.0% → 179/191 = 93.7%**；旁白内动作/神态类占 **147/205 = 71.7%**（非情绪标签）；结构量不变（191 消息 / 66 线程 / 28 条 ≥3 轮）；台词 **42.26 → 41.12 字（−2.7%）**。
- **结论**：**通道可恢复、无结构代价**（判 N-通道恢复）。表面 `L-7` 重复率 **+7.33pp** 经同口径重算后**为 −7.33pp**，属**指标构造的暴露面副作用**，非质量下降。
- **边界**：①**只证"通道回来"，不证"更像真人"**（须人工读样本）；②**R9 记录的"台词 −53%"未重现**（本批 −2.7%）⇒ 那个降幅不是旁白通道造成，**不得**用本结果推翻 R9；③结论仅限单 seed、单规模（16 agent × 24 轮）、单代码版本，**不外推**到其它配置。

### D9j · 可比性守卫（工具）
- **交付**：一个只读校验工具，输出两臂的**暴露面**（平均长度 / 8-gram 总数 / 候选池）＋**同口径重算**后的差异，并给出 `PASS / WARN-暴露面效应 / FAIL` 与退出码。
- **用途**：把"指标看起来退化、实为载体/口径造成"这一类误判**自动拦下来**；本线第一条实际产出即把一处 `+7.33pp` 的"退化"判为 `WARN-暴露面效应`。
- **边界**：①只支持剥"成对括号"一种载体，出现新载体须扩展；②**不做长度分层**（会引入不可审计的分桶边界，已裁定不加）；③**不给置信区间**，小样本下不得把 pp 差当显著；④它只回答"差异能否被口径解释"，**不判质量**。

## 2. 跨线共同的四条边界（引用任何一条线时都要带上）

1. **配置同源**：两臂若 `code_sha` 不同（含 prompt 差异），**任何差值都只是观测、不是因果**；本轮曾因此作废一条结论。
2. **暴露面/同口径**：重复率、命中率类指标在"新增内容"下会因暴露面变大而虚高；**必须先同口径重算**再下结论。
3. **"不可判"≠"无效"**：判据未覆盖、"零响应"、"全否一致"都只能支持"该口径不可用于该判断"，不能反推"该机制无用"。
4. **样本与语料**：本系列多为单 seed、单规模、小样本（n=12~191）；**一律不报点估计精度**（如 κ、精确率 CI），只报分子/分母与量级。

## 3. 若要继续，建议的三件事（按性价比排序）

1. **给判据补"部分起效"档**（主判据未达线但次级结构量显著变动）—— D9c 的教训，最便宜、最能止血；
2. **冲突维度换语料而非改词表**：本语料里"对具体人的负向话"极其稀有（人工严格口径 9/1372 ≈ 0.66%），**加词/改匹配的天花板由分母决定**；
3. **旁白通道先做人工读样本**（只判"读起来是否更像人"），再做真 LLM 的多 seed 复现；**不要**先用它去改别的判据。
