## 〇、一句话判定档

> **可判（分母满足 438/439 ≥ 68），但效应在 MDE≈2.75pp 以下无可检出差异，且方向随标记集选择翻转 ⇒ 本轮不产出方向性结论。**

配套的三条硬事实（本轮真正的产出，均为可复算读数）：

1. **尺子换了，线才可判**：机会分母从旧口径的 `28 / 22` 抬到 `439 / 438`（≥ `PROBE_MIN_DENOM=68`），F-3 第一次进入 `band = ok`。
2. **效果侧瓶颈被定位到具体一格**：机制侧给了 **107** 次机会，确定性自检只判 **7** 次「接住了」⇒ 采纳率 **7/107 = 6.5421%**；且瓶颈可进一步拆到 `has_cue`（**7/107**）而非指称（`has_ref` **45/107**）。
3. **engine 侧 judge 五维不能充当对话质量的两臂证据**（717/717 prompt 逐位相同），这是本轮对整个项目的方法论级发现，边界见 §5。

## 四、A 段（主结论之一）：采纳率瓶颈在 `has_cue`，不是「采纳率低」四个字

口径：`code/life/emotion_echo.py:349` 定义 `adopted = has_ref ∧ has_cue ∧ ¬ack_then_switch`。以下数字由本报告作者独立从 ON 臂 `run.jsonl` 的 `payload.ctx.echo.verify` 重算（**不引用** `arm_check.json`），OFF 臂 `ctx.echo` 为 0 条（字段不存在 ⇒ 机制确认关闭）：

| 量 | 值 | 率 | 含义 |
|---|---|---|---|
| 机制机会 `verify_present` | **107** | — | ON 臂拿到情绪呼应指令的消息数 |
| `has_ref`（点名指称对象） | **45** | **42.06%** | 模型**学会了**「先指称到那句话/那个人」 |
| `has_cue`（第一分句含情绪回应线索） | **7** | **6.54%** | 模型**没学会**「给出情绪回应线索」 |
| `ack_then_switch`（应一声就转话题） | **66** | **61.68%** | 主要**逃逸方式** |
| `verify_adopted`（结构合规） | **7** | **6.5421%** | 与 `has_cue` 逐行同集（见下） |

**关键结构事实**：`adopted` 与 `has_cue` 在 107 条上**逐行同集**——`adopted∧has_cue = 7`、`adopted∧¬has_cue = 0`、`has_cue∧¬adopted = 0`。
⇒ 采纳率的**唯一卡点就是 `has_cue`**；指称能力（45 条）已具备但被浪费。

**诊断段（可直接引用）**：

> **F-3 机制已接线、指称可达、情绪线索缺失、且以话题转移为主要逃逸方式。**
> 具体地：107 次机会里 45 次点名了指称对象（42.06%），但只有 7 次在第一分句给出情绪回应线索（6.54%），
> 66 次是「先应一声再转话题」（61.68%）；`adopted` 与 `has_cue` 逐行同集 ⇒ **失效点单一、可定位**。

**对下一轮的指令性含义（本轮不做）**：要提效果，应**修 `has_cue` 的生成约束**（例如把「第一分句必须含情绪回应线索」写成硬约束，或对着 66 条 `ack_then_switch` 反例做约束），**而不是加大 echo 强度**——加大强度只会把 107 抬到更多条，而 `has_cue` 率不变，文本层 P1 仍然动不了。
**纪律提醒**：本段**不参与两臂比较**（`ctx.echo` 只在 ON 臂存在，OFF 恒 0），不得据此写「ON 比 OFF 更会呼应」。

## 五、方法论小节：judge 的正确读法（证据用途失效 ≠ 设计使然 ≠ 完全无用）

这一节是本轮对整个项目最可复用的产物，**下一轮还会踩**，故单独成节。

### 5.1 三条必须分开说的事

| 命题 | 是否正确 | 依据 |
|---|---|---|
| ① engine 侧 judge 五维**不能**充当「两臂台词质量差异」的证据 | **正确** | judge 的 user prompt 不含任何台词正文（见 5.2），对措辞层干预**结构上不可见** |
| ② 两臂 judge `prompt_hash` 完全相同是**设计使然** | **正确** | 同左：prompt 只由 `question_ref/dimension/parties/envelope/rng_branch/context` 拼出，与台词无关 |
| ③ judge **完全无用 / 空转** | **错误** | judge 的 `decision` 经 `delta_from_frozen_label` 喂进 `RELATION_CHANGE`，对关系轨迹与后续对话有**间接因果** |

**准确说法（锁定）**：**engine 侧 judge「不作质量证据、但参与关系动力学」。**

### 5.2 结构证据（代码身份）

- judge prompt 构造：`code/freeze/llm_client.py:577-596` —— `system` = 软判定层说明；`user` = `canonical_json({question_ref, dimension, parties, envelope, rng_branch, context})`，**无任何 message body**。
- 调用点：`code/life/agent.py:817-880`（`_maybe_soft_judge` 传 `context={"dim","to","after"}`；`_maybe_social_appraisal` 传 `context={"dim","to"}`）、`code/life/soft.py:36`。
- 数值后果：`delta_from_frozen_label(payload.get("resolved", payload["decision"]))` → `INTENT_RELATION`（`agent.py:845-856`）⇒ judge 输出**确实**改变关系量。

### 9.1 独立复算器源码（可直接原样保存为 `/tmp/ev_indep_f3.py`）

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""evidence-verifier 独立复算器（不改仓内任何文件）。
按 v2/refs/P-F3-verdictable-r32.md §3.2/§4.1/§4.2/§4.3 的判定式，从 run.jsonl 自行实现，
不 import tools/metrics/f3_echo_rate.py，用于第三方对账。
用法: python3 ev_indep_f3.py <arm_dir> [lexicon_path]
"""
import json, sys, math, os, hashlib

NEUTRAL_MOOD = {"平和"}
EMPATHY = ("我懂", "我也", "别难过", "恭喜", "辛苦", "真惨", "太好了", "确实", "是啊", "可不是")
MOOD_WORDS = ("紧绷", "孤单", "疲惫", "饥饿")


def load_lexicon(path):
    emo = {}
    for line in open(path, encoding="utf-8"):
        line = line.rstrip("\n")
        if not line or line.startswith("#"):
            continue
        pol, w = line.split("\t")
        emo[w] = int(pol)
    return emo


def polarity(body, emo):
    body = body or ""
    pos = sum(1 for w, p in emo.items() if p > 0 and w in body)
    neg = sum(1 for w, p in emo.items() if p < 0 and w in body)
    return 1 if pos > neg else (-1 if neg > pos else 0)


def wilson(k, n, z=1.959963984540054):
    if n == 0:
        return None
    p = k / n
    d = 1 + z * z / n
    c = (p + z * z / (2 * n)) / d
    h = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / d
    return [round(max(0.0, c - h), 6), round(min(1.0, c + h), 6)]


def main():
    arm_dir = sys.argv[1]
    lex = sys.argv[2] if len(sys.argv) > 2 else "tools/d5/emotion_lexicon.txt"
    emo = load_lexicon(lex)
    log = os.path.join(arm_dir, "run.jsonl")
    msgs, order = {}, []
    for line in open(log, encoding="utf-8"):
        d = json.loads(line)
        if not str(d.get("type", "")).startswith("MSG_"):
            continue
        p = d.get("payload") or {}
        rec = {"uid": p.get("msg_uid"), "rt": p.get("reply_to"),
               "body": p.get("body") or "", "mood": (p.get("ctx") or {}).get("mood"),
               "thread": p.get("thread_id"), "round": d.get("round"), "seq": d.get("seq")}
        msgs[rec["uid"]] = rec
        order.append(rec)
    den = 0
    hits = {"H1": 0, "H2": 0, "P1": 0, "H3": 0, "S1": 0}
    exc = {"no_parent": 0, "no_affect_parent": 0, "dangling": 0}
    for m in order:
        if not m["rt"]:
            exc["no_parent"] += 1
            continue
        par = msgs.get(m["rt"])
        if par is None:
            exc["dangling"] += 1
            continue
        p_par = polarity(par["body"], emo)
        if not ((par["mood"] is not None and par["mood"] not in NEUTRAL_MOOD) or p_par != 0):
            exc["no_affect_parent"] += 1
            continue
        den += 1
        p_me = polarity(m["body"], emo)
        h1 = p_par != 0 and p_me == p_par
        h2 = any(w in m["body"] for w in EMPATHY)
        hits["H1"] += int(h1); hits["H2"] += int(h2); hits["P1"] += int(h1 or h2)
        hits["H3"] += int(par["mood"] in MOOD_WORDS and par["mood"] in m["body"])
        hits["S1"] += int(m["mood"] == par["mood"] and par["mood"] not in NEUTRAL_MOOD)
    print(json.dumps({"arm_dir": arm_dir,
                      "log_sha256": hashlib.sha256(open(log, "rb").read()).hexdigest(),
                      "n_msgs": len(order), "den_wide": den, "excluded": exc, "hits": hits,
                      "rate_P1": round(hits["P1"] / den, 6) if den else None,
                      "wilson_P1": wilson(hits["P1"], den)},
                     ensure_ascii=False, sort_keys=True, indent=1))


if __name__ == "__main__":
    main()
```

> 说明：上面是**产出 §2 与 §2.3 全部数字的同一份实现**（旧口径复现与三套标记集敏感性用到的是同一脚本的扩充版，规则见 §3 与 §2.2 表注，均为同一算法换标记集，不涉及新词表）。
