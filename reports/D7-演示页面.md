## 5. 「生活气息」前后对照（同一批人、同一 seed，只差对话结构改造）

下面每一行都能由 `threads.json` 直接统计（脚本可复算，不是主观描述）：

| 维度 | 改造前 `run_d2_before_n16_seed42-c1f86bf6` | 改造后 `run_d2_after_n16_seed42-643f13a5` | 口径 |
|---|---|---|---|
| 对话条数 | 187 | **686** | `stats.messages` |
| 线程数 | 187 | 206 | `stats.threads` |
| **多轮线程（≥2 轮）** | **0** | **104** | `stats.multi_turn_threads` |
| ≥3 轮线程 | 0 | 90 | `stats.threads_ge3_turns` |
| **最长线程** | **1 轮** | **6 轮（18 条消息）** | 轮数 = `turn_index` 去重；`stats.max_turns=18` 是**消息条数**口径，不是轮数 |
| 渠道分布（消息） | 私聊 132 / 公开 48 / 群聊 7 | 私聊 497 / 公开 63 / 群聊 126 | `msg.type` |
| 带地点的对话 | 139 | 623 | `messages[].place` |
| 走动（串门） | 406 次 / 16 人 | 406 次 / 16 人 | `PLACE_MOVE`（与对话解耦，两批一致=确定性旁证） |
| 天数 × 时段格 | 7 天 / 28 格 | 7 天 / 28 格 | `day`+`slot` |
| 生成时语境快照覆盖 | 0（改造前无 `ctx`） | **686 / 686** | `payload.ctx` |
| 转述引用 `refs` | 0 条可匹配边 | 0 | 日志真源 |

**读法**：改造前有 187 条消息却只有 187 条线程、多轮 0、最长 1 轮 ——
一天里有人在说话、有人在串门（406 次），但**没有一句话是接着上一个人说的**；
改造后同样 16 个人、同样 7 天、同样 406 次走动，消息变成 686 条、收进 206 条线程，
其中 **104 条是多轮往复**，最长一条 **18 轮**（如
`TH-P009-Gplace-hall-67`：8 位居民在大厅围绕 `contest` 你来我往 18 轮）。
这就是「生活气息」里最难伪造的那部分：**接话**。

两条旁证：
1. **串门行为没被扰动**：两批 `PLACE_MOVE` 都是 **406 次 / 16 人全动过**，与对话改造完全无关——
   说明改进只作用在对话层，没有顺手改动世界层行为（确定性旁证，也符合「冻结面不动」的约束）。
2. **语境快照全覆盖**：改造后 686/686 条都带 `payload.ctx`（relation/mood/need/topic/trigger），
   这是页面上「为什么这么聊」能逐条展开的证据基础；改造前这个字段不存在，面板只能靠 RELATION_CHANGE/NEED_UPDATE 回推。

## 10. 复现边界（重要）

产出 `threads.json` 的**复现单元**是：

```
(gen_threads.py 字节 sha + run.jsonl 字节 sha + personas.json 字节 sha + places.json 字节 sha + 参数)
   → 产出 threads.json 字节
```

`threads.json.source` 里已绑定：`generator_sha256`、`run_sha256`、`inputs.personas.sha256`、
`inputs.places.sha256`、`inputs.params`。**换脚本（哪怕只改注释）或换人格文件都会产出不同字节**，
这是特性不是缺陷——报告引用时必须把这几项一起带上。

另外一条实测事实（决定了必须用 `seq` 而不是 `msg_id` 定位）：
改造前日志（`run_d2_before_n16_seed42`，187 条消息）里只有 **74** 个不同 `msg_id`：
**19** 个 id 被复用，最严重的 `D-6-0` / `D-42-0` 各被 **12** 条不同消息复用。
因此页面一律用**全序 `seq`** 作唯一键，报告引用也用 `#seq`（按 `msg_id` 引用会产生歧义）。
复算一条命令：
```bash
python3 -c "import json,collections;\
c=collections.Counter((r['type'],r['payload'].get('msg_id')) for r in map(json.loads,open('v2/evidence/run_d2_before_n16_seed42/run.jsonl')) if r.get('type','').startswith('MSG_'));\
print('msgs',sum(c.values()),'unique',len(c),'dup_ids',sum(1 for v in c.values() if v>1),'worst',c.most_common(2))"
# → msgs 187 unique 74 dup_ids 19 worst [(('MSG_DM','D-6-0'),12), (('MSG_DM','D-42-0'),12)]
```
