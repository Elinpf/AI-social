## §二 · 本轮维度

**DEQUANT：台词的模板化同质感 —— 去量化词 / 去「上回·上次」回指起手式。**

- 病灶（S1 §7.1，样本 `v2/evidence/run_d12d_on_n16r60_seed42/run.jsonl`，510 条 `MSG_*`）：「上回」`407/510 = 79.8%`、「第三格」`152/510 = 29.8%`、「半指」`121/510 = 23.7%`，首 6 字高频全是 `（把…往…` → 台词像同一支笔写的；「记得」被固定句法冒充。
- 本轮做法：**只改两条 dialogue user prompt 的收尾指令**（默认 OFF，显式 `export LIFE_PROMPT_DEQUANT=1` 才追加），零 config、零结构、零调用链改动、零额外 LLM 调用。
- 为什么属于北极星：生活气息的一大反面是「所有居民说同一种腔调」。压掉固定量词与套路化回指起手式，是让台词回到「眼前这件事」的必要条件（**不是充分条件，本轮也未证明它更自然**）。

## §八 · 已知局限与风险

1. **单 seed**：两臂仅 `seed = 42`。所有 pp 差值都是**这一个种子**上的一次读数，**不作统计断言**。
2. **探针规模**：每臂 `MSG_*` = **67 条**（`n8r16`），1 条 = **1.49pp**；无区间估计、无显著性检验。要出效果结论须多 seed 重复或 `n16r60` 主尺度复跑。
3. **尺度不可比**：`reports/dequant-impl-20261028.md` 交付的 `n16r60` 基线读数（`上回 79.8%` / `第三格 29.8%` / `半指 23.7%` / `上次 6.9%` / `想起 10.2%` / `（把…往… 24.1%` / `骨架重复 22.2%`，日志 `v2/evidence/run_d12d_on_n16r60_seed42/run.jsonl`，`log_sha256 ad0c939f…44ca0`）**不得与本轮 `n8r16` 的 pp 放进同一张表做对比结论**，只能作「不同尺度的历史读数」并列。理由：同一脚本在不同尺度下基线本身就差一个量级（`上回`：`n8r16` OFF 6.0% vs `n16r60` 79.8%），探针批几乎全在最初几轮、未进入「回指/量化」密集区。**探针尺度下 `第三格` / `半指` 基线即为 0 ⇒ 这两个词在本尺度无区分力，`±0.0pp` 不代表无效，而代表测不出。**
4. **`prompt_hash` 零交集只证明「提示词变了」**，不证明「模型遵守了」。模型是否遵守由 §4.3 的台词度量承载，两者不可互换、不可互相替代。
5. **过度压制风险（本轮最需要如实告知的一条）**：本轮黑名单合计属「绝对归零级别」的压制方向（`上回 6.0% → 0.0%`、`上次 1.5% → 0.0%`）。历史参照：F-6 跨天记忆引用率的 v0/A0 基线仅 **6.4%**（出处 `reports/R4-life-texture.md:61`，`run_d2_after_n16_seed42`，`code_sha 884f4541`，**分母仅 187 条消息 ⇒ ≈12 条命中**，跨 `code_sha` 只作「历史参照，不可直接等同」）。若下一轮主尺度复跑时 **F-6 随黑名单一并归零**，那不是生活气息改善，而是「居民失忆」。**下轮建议：主尺度复跑时同时读 F-6 引用率，与黑名单命中率联看，任一方向异常都要先查是不是压过头。**
6. **换词现象（风险）**：ON 臂出现**换词**（`半袋 7.5%→1.5%`、`半勺 0.0%→3.0%`），词表内并非全面归零；总量下降但伴随新词进入，属 67 条小样本噪声区间，**不能表述为「套话已消除」**。「同质感」是否真被削弱，需看骨架重复度与 judge 维度（本轮后者未做）。
7. **协同时序（事实陈述，不做归因评价）**：本轮期间分支 HEAD 被其他工作线推进过（`2a53451`、`b4972fd` 两笔 D7 README），与 DEQUANT 无关，已在 `git diff` 与提交范围中排除；`code/` 下该两笔仅触及 `code/frontend/README.md`（+18 行，不参与运行时）。
8. **T2 报告的两处逐词行与本报告不一致**（见 §4.3 表下注），已同步 leader 与 run-verifier；本报告以产物 JSON + 现场复算为准。
9. **本轮未验证**：去量化指令是否伤到「人际温度 / 信息量」（需 judge 维度前后对比或人工盲评）；`（把…往…` 动作骨架（S1 §7.3 排序 #3）**不在本轮改动面内**，只被纳入度量输出。
