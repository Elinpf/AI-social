## 三条通用纪律（全族适用）

1. **每条结论绑来源文件 + sha256**；探针级读数一律原样标 `probe`。
2. **判定三件套**：`|Δ|` / 同分母噪声带上界或 CI / 分母条数——三者未同表出现时，该表必附表注。
3. **截图三件套**：来源 run 目录 + 渲染命令 + 日志 sha256；文件名 `<batch_id>-<视图>-<sha8>.png`。禁止拼图与跨批混拼；拿不到图就写「无图 + 渲染命令」，不替代。

## 关于「不吹」

本报告族不含「首次」「业界领先」这类表述。凡结论均限定在「本配置、本规模、本 seed」内；凡不可复现的部分（LLM 措辞层）明确说明不可复现，并给出可核验的替代形式（冻结快照 + sha）。
