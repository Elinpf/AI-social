**【判断】** 「5 次张力 0 次修复」比任何形容词都有力：它说明的不是"对话不够有生活味"，而是**关系张力产生之后没有任何修复动作**——吵架不会和好；情绪呼应也只有 1/6。两个关键机制**近乎缺席**。

## 1. 什么是「生活气息」：七个可度量的维度

**【事实】** 所有维度统一编号（F 系列），并固定统计单位与分母；本报告只引用编号，不另立口径。

| 编号 | 维度 | 定义式（分子/分母） | 统计单位 | 备注 |
|---|---|---|---|---|
| **F-1** | 非功能性闲聊占比 | 分子 = 非功能性消息（标签与任务标签无交集且正文不命中事务正则）；分母 = 全部消息 | per-message | "不为办事而说的话" |
| **F-2** | 话题漂移率 | 分子 = 相邻消息既无标签交集、字符二元组 Jaccard 又 < 0.10 的对数；分母 = 组内相邻对数 | per-adjacent-pair | 忽左忽右的闲扯程度 |
| **F-2b** | 多话题线程占比 | 分子 = 线程内标签去重数 ≥2 的线程数；分母 = 线程数 | per-thread | 一条对话里能不能扯到两件事 |
| **F-3** | 情绪呼应率 | 分母 = 上句情绪极性 ≠0 的相邻对；分子 = 下句极性相同**或**含共情标记的对数 | per-adjacent-pair | 有人接情绪 |
| **F-4** | 修复闭环率 | 分子 = 张力事件后 8 条同线程内出现修复词的事件数；分母 = 张力事件数（相邻极性相反或当句极性为负） | per-event | 吵了会不会和好 |
| **F-4b** | 修复时滞 | 张力→修复之间隔了多少条消息（均值） | per-event | 和好得多快 |
| **F-5** | 习惯强度 | 分子 = 某 `(时段, 场所)` 覆盖 ≥3 天的 agent 数；分母 = agent 总数 | per-agent | 有没有固定作息 |
| **F-5b** | 最大重复天数均值 | 每个 agent 的最大重复天数之均值 | per-agent | 习惯有多稳 |
| **F-6** | 跨天记忆引用率 | 分子 = 正文命中时间回指词表的消息数；分母 = 全部消息 | per-message | **只测"提到过去"，不测"引用是否正确"** |
| **F-7** | 越界编造率 | judge 拿到该线程时段内**真实发生的事件摘要**，判每条是否编造了日志中不存在的事件；率 = 编造条数 / 受检条数 | per-message | **本维度优先级最高**：出现即扣该批可信度 |

**【判断】** 把「生活气息」这样拆开的好处是每一维都能被证伪：读者可以自己数"张力事件之后 8 条内有没有修复词"，不需要相信作者的审美。坏处是七个数不会自己合成一个结论——所以本报告**不给总分**（R1 §1.2 已禁）。

## 3. 怎么度量（方法与陷阱）

### 3.1 判据

- **阈值只用 B2**（同分母重采样上界）：F-1/F-6 这类 per-message 指标可用消息级分母档；**F-2/F-3 是 per-adjacent-pair、F-2b 是 per-thread、F-4 是 per-event、F-5 是 per-agent** ——**这些单位的上界不能借用消息级档**。若该单位的上界未估计，一律写「**本规模下无法判定**」（R1 §2.5 纪律 4）。
- 每个维度必须给：值 + 分母 + 统计单位 + 证据级（`evidence`/`probe`）。

### 3.2 三个必须主动避开的陷阱

**【事实】** 以下三条在口径层已写死为"不算改善"：

1. **景物描写 ≠ 生活气息**：把生活气息写成旁白（"（窗外下着雨）"）会顶掉措辞层的旁白化改善——表现为 F-1/F-6 升高**同时**旁白率也升高 ⇒ 判为「用旁白换生活气息」，不算改善。
2. **每句塞"昨天/记得" = 套路**：F-6 升高时必须同时看重复率（措辞层 L-6/L-7）；重复率同步恶化则不算改善。
3. **编造未发生的事件 = 世界观污染**：F-7 单独报，**优先级高于 F-1…F-6 的任何好看读数**——一个会编造昨天发生过什么的居民，其"生活气息"是伪造的。

**【判断】** 第 3 条是本报告最不能让步的一条：如果为了让对话"有生活感"而让角色引用不存在的事件，那得到的是看起来更热闹、实际上更不可信的世界。

## 5. 人工质量抽检（A5 真臂 · n=12 线程 · 人读）

> **这是目前唯一能正面回答"像不像过日子"的证据**——但它是**人读、n=12、分层非随机**，只能回答"这 12 条里哪些像"，**不能**推广成"居民普遍有生活气息"。

### 5.1 方法

**【事实】** 数据：`v2/evidence/run_a5_real_n16r42_seed42/run.jsonl`（42 轮真 LLM，**523 条消息 / 140 线程 / 线程 `p50=5`、`max=6`**）。
**【事实】** 抽样：**按线程轮数分层**（4–6 轮池 77 条抽 8；2–3 轮池 8 条抽 4；1 轮单发 55 条**排除**，因目标是"对话抽检"），层内 `random.Random(42).shuffle` 取前 k ⇒ **共 12 条线程**，导出时按 `(round, seq)` 升序、线程内前后文完整未截断。
**【事实】** 评法：**两位评者盲评**（第一评先独立给出，再与第二评对账），三档定义：**A 有生活气息 / B 平凡但不假 / C 明显生硬**。

### 5.2 一致性（决定能写什么）

| 口径 | 值 | 处置（预注册纪律） |
|---|---|---|
| **三档 κ（未加权）** | **0.5862**（`Po=0.7500`、`Pe=0.3958`） | 落 0.4–0.6 ⇒ **只能作"方向参考"**，不得写"人工评可用" |
| **二值 κ（可用/生硬）** | **0.6250**（`Po=11/12`、`Pe=0.7778`） | ≥0.6 ⇒ **二分口径可用** |

**【事实 · A 档名单的两人差异】** 两人对 A 档的判定**差 1 个**：**#1 与 #10 互换**（一评把 #10 列入 A、#1 列入 B；另一评相反）。
⇒ **结论句固定为**：
> 「**约 5 条像过日子（量级可保留），但具体哪 5 条不完全一致**。」

**【事实 · 分歧的另一处】** #7 是 C 与 B 的唯一分歧，也是二值 κ 被压低的**唯一来源**（若 #7 归 C，二值一致率 12/12）⇒ 提二值 κ 前须先写清"复读 3 次是否足够判 C"。

### 5.3 三档分布（第一评）

| 档 | 条数 | 线程 |
