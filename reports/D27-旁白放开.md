### 2.1 Q3 `F-2_content_drift`（=F-2′）：**按字面从严判 ❌**

`63.3431% → 66.8675%（+3.5244pp）`。预登记判据「相对 C **升 ≤2.0pp**」⇒ **按字面从严判 ❌**。

**语义解读分歧（并列保留，不采用事后重解释）**：F-2′ 量的是"相邻消息 char-bigram Jaccard<0.10 记为换话头"的比例，其上升在"话题更活/更爱换话头"的语义下**对北极星未必是坏事**；但**幅度已越过预登记上限（+3.52pp vs ≤2.0pp，超出一倍多）**。判据以**事前文字**为准——预登记的作用就是不让事后解释去救一个越界的读数；这次救的是"通过"，下次就能救"失败"，规则一旦可商量整个体系就失效。

**分母 C=341 / B=332 的机制说明（不是"方向参考"三个字了事）**：

1. **分母定义**：`denominator_adjacent_pairs = pairs_cnt`，即**同一线程内相邻消息对**的总数——
   按 `mixed_key` 分组、组内按 `(round, seq)` 排序后，对每条线程累加 `len(thread)-1`
   （`tools/d5/dialogue_metrics.py:1062-1090`，累加语句在 `:1089-1090`）。等价式：
   **`pairs_cnt = Σ(线程长度 − 1) = 该批消息数 − 线程数`**（只对长度≥2 的线程有贡献）。
2. **两臂为何是该值**：C `510 − 169 = 341` ✅；B `502 − 170 = 332` ✅（与 `dialogue_metrics` 输出逐一吻合）。
3. **差的 9 个单元属于哪一类**（可逐项对账）：

| 线程长度 | C 线程数 | B 线程数 | Δ | 对相邻对的贡献 Δ×（len−1） |
|---|---|---|---|---|
| 1 | 81 | 81 | 0 | 0 |
| 2 | 11 | 15 | **+4** | **+4** |
| 3 | 7 | 8 | +1 | +2 |
| 4 | 16 | 13 | **−3** | **−9** |
| 5 | 2 | 3 | +1 | +4 |
| 6 | 52 | 50 | **−2** | **−10** |
| **合计** | 169 | 170 | +1 | **−9** |

   即 `Σ(len−1)`：C 341 → B 332，**−9**。分解为：**长度≥2 的消息数 429→421（−8）**、**长度≥2 的线程数 88→89（+1）** ⇒ `−8 −1 = −9`。
   **性质**：这是**线程结构的轻微扁平化**——6 轮长线程 52→50、4 轮 16→13 减少，2 轮 11→15、3 轮 7→8、5 轮 2→3 增加。**不是分母漏项**（`from` 为空的消息全部计入，全量线程 169/170 三方对账一致，见附录 C 第 4 条），故**不需要按 §3.119 重算**。
4. **它是否单向影响 F-2′？给一个敏感性分解**（把"分子增长"与"分母缩小"拆开）：
   - 漂移对**绝对数**：C **216** / B **222**（`0.633431×341` / `0.668675×332`）⇒ **+6 对**；
   - 若把 B 的分子放回 C 的分母：`222/341 = 65.10%` ⇒ 相对 C **+1.76pp**（纯分子效应）；
   - 剩余 `66.87 − 65.10 = +1.76pp` 来自**分母缩小**（341→332）。
   ⇒ 两个 +1.76pp 合成 +3.52pp：**约一半是"漂移对真的多了 6 对"，约一半是"参与统计的相邻对少了 9 对"**。方向不变（都是上升），但幅度有一半是结构性的。
   **判定不受影响**：即便只看纯分子效应（+1.76pp）也已在 ≤2.0pp 的边界内勉强通过、而字面 rate 指标 +3.52pp 明确越界——按预登记用的是 rate，故仍判 ❌；这一分解只用于说明**该读数的稳健性有限**，不作为改判依据。

   **⚠ 为什么不做"按 C 分母归一"（必须显式表态，防两种误用）**：

   > **分母缩小本身是处理效应的一部分。** 线程结构扁平化（len4 16→13、len6 52→50、长度≥2 的消息 429→421）是"旁白挤占台词"的下游后果，不是独立于处理的外部变量。用 downstream variable 去归一化，等于把处理的一部分效果从测量里减掉——这在因果推断里是把 post-treatment variable 当协变量调整，会引入偏倚。因此判定按各自 run 的真实 rate 取 ❌，敏感性分解仅作机制说明，不作为翻案依据。

   这一段同时防住两种误用：①别人拿 +1.76pp 来要求**翻案**（不行——那是对下游变量做归一）；②别人拿 +3.52pp 说"**结构性恶化**"（也不准确——约一半幅度来自分母缩小）。

## 7. 机制解释：为什么台词会变短（**推断，未验证**）

**可检验的推断**：收尾指令从"**禁旁白**"改成"**句首允许一个 ≤15 字的括号动作**"后，模型在**单次生成的表达预算**里把动作描写当成了"必须交付的组成部分"，于是把剩下的预算压给台词，台词被压到**功能性最低限度**（"饿得慌。""盛一碗。""冷馍顶不了账，周公文？"）。旁白越"到位"，台词越像"把意思说清楚就停"。

三条可复核的观察支持该推断（但**都不构成已证因果**）：
1. **总长也缩了**：B 整条消息 p50 = 36 字 < C 去括号台词 41 字 ⇒ 不是"总量守恒下的重新分配"，而是**总量与台词同时缩**；
2. **旁白自身并未失控**：旁白内字数 p50 8 / max 15，短旁白占比 99.40%，心理描写 0.00% ⇒ 模型**严格照做了旁白那半段指令**，问题不在旁白越界；
3. **三类质量闸没有同步恶化**：Q1 复述 −0.13pp（更好）、Q2 重复 +2.9959pp（擦线）、P2 第三人提及 +7.22pp（更好） ⇒ 不像"整体质量塌"，更像**表达预算的重新分配/收缩**。

## 附录 C：方法论沉淀（runbook 候选，本轮先以报告附录落盘）

1. **「换一棵树复现」不能假定读数等同，形态读数必须现算。** 实证：D2.5a 的 C 臂（`e2e7131`）与 D2.7 的 C 臂（`f2bf606`）`config_components` 完全一致、`code/` 无差异，但 **bodies 逐位置只有 20/510 条相同**，四项形态读数全部不同（L-7 20.59 vs 25.49、F-2′ 66.28 vs 63.34、L-15 4.12 vs 4.31、len_p50_excl 40 vs 41）。⇒ **只要有真 LLM 采样，就不能把别批的读数当本批基线**。
2. **Δ 必须用未四舍五入的原始分数求差。** 本轮实证：L-7 `28.4861−25.4902 = 2.9959pp`，若先各自取两位小数再相减会得 **3.00pp**，把"擦线过（余量 0.0041pp）"写成"正好 3pp"，是口径事故。
3. **"机制未生效"与"指标结构性为 0"必须分清。** mock provider 的对话池不含括号 ⇒ mock 的 `paren_rate` 恒 0，与提示词无关；用它判"接线失败"就是假阴性。正确做法是换一个**能判定的问题**（括号会不会被下游剥落）。
4. **处理效应会改变指标分母，禁止用下游变量归一化来"修正"读数。** 本轮实证：B 的线程结构扁平化（`Σ(len−1)` 341→332，−9）是"旁白挤占台词"的下游后果；若按 C 分母归一，`F-2′` 会从 +3.52pp 变成 +1.76pp 并"通过"阈值。但那等于把处理的一部分效果从测量里减掉（post-treatment variable 当协变量），会引入偏倚。**正确做法**：判定用各自 run 的真实 rate；分母差异只作机制说明与敏感性分析，**既可防"拿归一翻案"，也可防"把结构性变化全算成恶化"**。
5. **线程级比例分母 = 全部 `thread_id` 去重（含无 `from` 的匿名旁白线程）**（runbook §3.119）。本轮对账：C **169 = 169 = 169**（结构性 / `dialogue_metrics.meta` / `d12c`），B **170 = 170 = 170**。
   实测匿名旁白（`payload.from` 为空的 MSG，全部是 `MSG_PUBLIC`）：**C 55 条 = 55 个独立线程；B 53 条 = 53 个独立线程**。单条消息线程两臂均为 **81**；`MSG_DM` 线程数 C 114 / B 117。
   ⇒ 若只按"有 `from` 的线程"算分母，ge6 会从 **30.77%（52/169）虚高到 45.61%（52/114）**——C 臂这个坑本轮再次实测复现。
