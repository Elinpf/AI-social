### 0.3 结论（唯一允许的形态）

**结论一句话**：**机制侧存在性事实成立（G-1 `0.39% → 67.45%`，且提示词注入在 token 级可证）；但按冻结判据本轮判「失败」——`ΔG-1b_upper = +18.63pp > 0` 触发 F2 一票否决，叠加 L-7 击穿（`+11.18pp > +5.88`）⇒ 效果判失败、实现应回退；不得宣称改善。**

三条支撑（详见 §6.2–§6.5）：

1. **G-1 的带外判据只有一条**：`|ΔG-1| > band`，`band = [−5.69, +5.69]`（`p = max(p_b0, p_A1) = 0.6745`，n=510）。预注册写的 `±10.6pp` 是 **n=170 档的抽样噪声界限**，本轮分母 510 不适用 ⇒ 属「同一判据用了过时数值」。**带外 ≠ 改善**（§6.2）。
2. **F2 一票否决已触发**：`ΔG-1b_upper = 96/510 − 1/510 = +18.63pp > 0`。且因 **G-1b ≡ G-1**（结构互斥，§6.3），**A1 在任何读数下都不可能被判「改善」**——本轮数据把这个判据缺陷实证了。

### 1.2 为什么这算「生活气息」

「提到别人」是闲话的地基：真实小镇里，人不会只和眼前的人说话，会转述昨天谁家出了什么事、谁的手艺好、谁最近不对劲。**只有称呼（"老石，你尝尝"）而没有转述（"南边见了老周，他说今年雨水多"），对话就还停留在"两个 NPC 面对面念台词"**。

因此 G-1 的语义必须是「提到**不在场**的第三人」，而不是「正文里出现了人名」——后者只是称呼率，是最容易被误当成"生活气息"的假信号。本轮 §4.1 的口径缺陷正是这一区分被悄悄抹掉的实例。

### 1.3 本轮不做什么（边界，写死）

- **不改任何业务代码**：本轮 A1 只开一个**提示词开关**（默认 OFF，跑批时用 env 打开），`code/life`、`code/orchestration`、`code/config`、`code/engine` 均不改。
- **不做多维度**：不碰 F-1…F-6、不碰世界层、不碰经济参数。
- **不出因果结论**：单臂 ON/OFF 对照只能给"同代码、同 seed、仅提示词文本不同"的方向性对照，不能推「C15 导致居民更爱聊闲话」。
- **不认领历史遗留**：`v2/evidence/` 下的历史未跟踪产物不是本轮成果（见 §7.2）。

### 4.3 缺陷三：噪声带来源有已知缺陷（单池 vs 双池）

**缺陷位置**：`v2/evidence/d3_noiseband_bootstrap.py:70-75` —— `B_ = rows["t355"]` 被赋值但**从未使用**，两个伪臂都从 `t300` 池重采样。

### 6.1 双列噪声带与「逐指标取更严侧」判定伪代码

**规则（不是统一规则，必须逐指标各自取严侧）**：

```
# 带来源：主带 = 单池（保持与 R12/R13/R14 可比）；敏感性列 = 双池
# 取严侧：在"上升方向"比较两条带的上界，取更小的那个作闸门
for metric in [L-7, L-2, L-8]:
    upper_main = 单池上界[metric]
    upper_sens = 双池上界[metric]
    gate       = min(upper_main, upper_sens)      # ← 逐指标各自取严侧
    Δ          = A1[metric] - b0[metric]
    verdict    = 击穿 if Δ > gate else 带内

# 已知取值（n=510 档）：
#   L-7 : 单池 +5.88 / 双池 +7.45 ⇒ gate = +5.88（单池更严）
#   L-2 : 单池 +5.69 / 双池 +4.71 ⇒ gate = +4.71（双池更严）
#   L-8 : 单池 +5.88 / 双池 +5.10 ⇒ gate = +5.10（双池更严）

if 任一守卫 verdict == 击穿:
    效果结论 = "不可判"          # 不得写"带内""仅印象""趋势向好"
if 两条带结论不一致（一条带内 / 一条击穿）:
    取更严侧                   # 不得以主带单方面放行

if ΔG-1b_upper > 0:
    本轮判失败（F2 一票否决）   # 与 G-1 多好看无关
```

> **金句（单列，不埋进段落）**：**两条带结论不一致时，取更严侧，不以主带单方面放行。**

### 6.2 G-1 的带外判据：**只有一条**，而「带外」不等于「改善」

读者最容易卡住的地方：**预注册写的是 `±10.6pp`，噪声带算出来是 `±0.78pp`，到底听哪个？**
答案是**不存在「两套阈值」，只有一条判据用了过时的数值**——必须换代，而不是并存：

| 项 | 事实 | 依据 |
|---|---|---|
| `±10.6pp` 的真实身份 | **n=170 分母下的抽样噪声界限**，不是「改善门槛」 | `experiments/gossip-third-party/DESIGN-preregistration.md:53` 括号内自述「落在 n=170 档 B2 带内」；`v2/evidence/D3-noiseband-two-level.md:19,64` 定义 B2 用途为**判定阈值**；`:65` 明确 n=170 档**只适用于分母 150–190** |
| 本轮分母 | **510**，**不在** n=170 的适用区间 | b0 `meta.json::msg_counts` = 455 + 55 = 510 |
| 必须做什么 | 按 `:64` 的「同分母」规则**换算成 n=510 的带** | §4.3 已给出换算结果 |

**⇒ 唯一带外判据（含两臂异率时的带宽取法）**：

```
band  =  boot( p = max(p_b0, p_A1), n = 510, B = 2000, seed = 42 )
带外  ⇔  |ΔG-1| > band
```

- **为什么取 `max(p_b0, p_A1)`**：若用**基线窄带**去检验一个**高基率臂**，会把抽样波动误判成显著 ⇒ **取两臂观测率的较大者重算零假设带**。基线 `p_b0 = 2/510 = 0.0039`。
- 若 `p_A1 ≤ p_b0`，则 `band` 就是现成的 `[−0.78, +0.78]`（b0 标签重采样，`p = 0.0039`）。
- **本轮实际取值**：`p_A1 = 344/510 = 0.6745` ⇒ `p = max(0.0039, 0.6745) = 0.6745` ⇒ **`band = [−5.69, +5.69]`**（逐消息带放回重采样，B=2000, seed=42；由独立审计的权威脚本给出）。
  - **构造说明（防混用）**：该带用「每次迭代连续抽 `2n` 次、每次带放回取一条标签，前 n 条为伪臂 A、后 n 条为伪臂 B，各自求率后作差」的方式生成，等价于「每条消息独立 Bernoulli(p)」——即 `d3_noiseband_bootstrap.py` 重采样法的期望形式；**不是**把命中数固定成 `round(p·n)` 的构造（后者抹掉二项计数波动，会得到略窄且对称的带）。
  - ⚠️ 别混用：`[−6.08, +6.08]` 是 **A1 的 L-7 标签**带，不是 G-1 的带。
- ⚠️ **A1 落盘后必须先算 `p_A1` 再定 `band`，不得预设 `±0.78`**；定稿时必须写出 `p = max(p_b0, p_A1)` 的实际取值与对应 `band`。

**参考算例（逐消息 Bernoulli 构造，B=2000 seed=42，n=510；仅供读者预判量级）**：

| `p` | 对应 `band`（pp） |
|---|---|
| 0.39%（= b0 实测 2/510） | `[−0.78, +0.78]` |
| 2% | `[−1.57, +1.76]` |
| 5% | `[−2.55, +2.75]` |
| 10% | `[−3.73, +3.73]` |

> **解读声明（必须与本节同框）**：本报告采用「**取对本方声明更不利的带**」原则——宣称「可区分 / 改善」时用**更宽的带**（更难出带，防假阳性）；宣称「恶化 / 击穿」时用**更窄的带**（更难判退化，防漏判）。
> ⚠️ 该处理属**解读**：预注册与噪声带方法文档**均未规定**两臂异率时的取法。`D3-noiseband-two-level.md:64` 只写「**同分母**」，`:19` 的构造是「同配置两池重采样」（隐含两臂同率）⇒ 「同率」是由「零假设下两臂同分布」推出的**解读**，不是原文。

**⇒ 守卫带不适用本规则（重要区分）**：`L-2 / L-8 / L-7` 的带来自 `v2/evidence/d3_annotated_corpus.jsonl`（t300 / t355 语料池），按 §4.3 单池/双池给出 `[−5.69,+5.69]` / `[−5.49,+5.88]` / `[−5.88,+5.88]`，**与两臂观测率无关** ⇒「按哪个臂的率算带」**只存在于 G-1 的代理带**。守卫带一律按已冻结取值（含双池敏感性列），不随 A1 率变化。

**⇒ 但「带外」≠「改善」**——预注册全文**没有**「改善门槛」这一层，也不存在「超出噪声所以变好了」的推论。带外只说明「**这个差异不太可能只是抽样波动**」。

**⇒ 改善需同时满足三条**（缺一不可）：

| 条件 | 判据 |
|---|---|
| ① 带外 | `|ΔG-1| > band`，`band = boot(p=max(p_b0,p_A1), n=510, B=2000, seed=42)`（见上） |
| ② 守卫未退化 | `L-2 ≤ +4.71pp`（双池上界）、`L-8 ≤ +5.10pp`（双池上界）、`L-7 ≤ +5.88pp`（单池上界）——逐指标取更严侧，见 §6.1 |
| ③ 无新增越界提及 | `ΔG-1b_upper ≤ 0`（F2 一票否决） |

**⇒ 而因 G-1b ≡ G-1（结构互斥，见 §6.3），条件 ③ 事实上封闭了整条改善路径**：G-1 真涨 ⇒ 新增提及几乎必然是不在场的第三人 ⇒ 新增越界 ⇒ F2 判失败。
⇒ 因此本报告的结论只能是：**「机制侧存在性事实」+「效果判不可判」**。
**不设中间档**：本文早前版本曾设「可检测但不构成改善」的档 B，**该表述已作废**——预注册无此层，属过度解读。

**必须与本节同框披露的两条限定**：

1. **`[−0.78, +0.78]pp` 是代理带**：D3 标注语料（`v2/evidence/d3_annotated_corpus.jsonl` 的 t300/t355）**不含 G-1 指标**，无法用池间差换算，故本轮用**基线（b0）标签的单池有放回重采样**（B=2000, seed=42）作代理。它**不是** D3 语料带，精度上属「代理」而非「官方换算」。
2. **沿用旧数会放宽约 13 倍**：若仍用 `0.106 × 510 = 54.06`，等于要求**新增约 54 条命中**才算「出带」；而 n=510 档的带只要求**至少 5 条**——因为 `4/510 = 0.784pp` **恰好等于**带界（判据是严格 `> 0.78pp`，等号不算出带），`5/510 = 0.98pp` 才真正出带。`54 / 4 ≈ 13.6` ⇒ 这就是「继续用旧数值」实质等于**把判定阈值放宽一个数量级**的直接量化证据。

> ✅ **带宽取法已定稿**（不再留空）：见上方 `band = boot(p = max(p_b0, p_A1), n=510, B=2000, seed=42)`。A1 落盘后只需填 `p_A1`、`p = max(...)`、`band` 与判定，**规则本身不再变动**。

## 10. 下一步建议

> 本节**不含效果结论**，只列工程与判据层面的下一步。

### 10.1 判据层（优先级最高，影响未来所有轮次）

1. **重写 F1/F2 的互斥缺陷**：现判据把「第三方提及」与「越界提及」绑成互斥对 —— G-1b 判「提及者与说话人不同处一地」，而第三方提及**天然**是不在场的人 ⇒ `G-1b ≡ G-1`，于是「G-1 涨」几乎必然「F2 判失败」。本轮数据已实证（b0 `2 / 1`，A1 `344 / 96`）。
   建议二选一：① 把 G-1b 从"一票否决"降级为**披露项**；② 把越界重定义为「提及者位置明确不符 **且** 该对象当时正在做互斥活动」（需新的可审计字段，不能靠事后解释）。
2. **预注册写死「分母变化时如何换算噪声带」**，避免事后在两条带之间挑对自己有利的那条（本轮已遇到 187→510）。
3. **预注册补齐两个层级**：①「提及未实例化人物」是否计入、如何计入；②「G-1b 需全量人核」的操作化流程（本轮 96 条只做到抽样语义核）。

### 10.2 测量层

4. **修 `g_metrics.py` 本体**：`participants` 先 PID→主干名映射再比较（现为空操作，见 §4.1）。
5. **修 `d3_noiseband_bootstrap.py`**：`B_` 要么真正用起来（做池间差），要么删掉并改注释；并按各轮实际分母批量重算 B2 带。
6. **对「人名 = 常用词」的主干名加词边界/白名单**：本轮实测 `石头` 4 次名词误判（1.16%），同结构风险名另有 `月牙` / `小满` / `五味`（本轮抽样未见误判，但结构风险存在）。**注意**：改匹配方式会偏离 PREREG:73 ⇒ 必须在**下一轮预注册里先改判据**，不能本轮事后改。

### 10.3 机制层

7. **`LIFE_PROMPT_GOSSIP_G1` 本身不建议直接上线**：本轮它把 G-1 从 0.39% 抬到 67.45%，但同时把越界提及抬到 18.82%、8-gram 套路化抬到 47.65%（击穿）。若要继续，"提到别人"需要**与"少些套路化"联合约束**，而不是只开这一个开关。
8. **名单注入应与已实例化 agent 对齐**：本轮 16 人生成、名单含 20 个主干名（未实例化：书言/弦歌/石头/阿散）。虽然本轮 4 条误判与"未实例化"无关（是名词问题），但「名单 > 实例化集合」本身是结构性隐患，宜收敛。
