> 本文件**只放自检**，不参与报告正文。检查命令一律带 `--exclude=_selfcheck.md`。
> 目的：让"命中数"稳定、可被两个人跑出同一个数——即对拍成立。

```bash

grep -rn "fb832372\|7049c272" *.md --exclude=_selfcheck.md
```

## 2. 为什么本文件必须独立存在（自指污染，实测）

第一版把「命令 + 结果说明」写在 `README.md` 里，结果**下一次检查会被自己命中**：
- 撰写方（HEAD `ac7982f`）测得 **4 / 2 / 3**；
- 核验方（HEAD `69ce67c`）复跑测得 **6 / 5 / 4**；
- 差额 2 / 3 / 1 全部来自 README 里的**命令原文行**与**结果说明段**（它们复述了关键词）。

⇒ 同一份文档里放"检查命令 + 结果说明"，会让命中数随文档自身增长而漂移，**最终没人能说清"命中数为什么变"**。
修法：把自检段移出被检查的正文（本文件），命令加 `--exclude=_selfcheck.md`。迁移后两侧均测得 **4 / 2 / 3**。

## 4. 每处命中的"为什么必须在这里"

**G3 的 3 处**：

## 5. 可复用的判据设计经验（核验方建议，留档）

> **检查命令与结果说明，不得与被检查文本同处一个被扫描集合。**
>
> 否则命中数会随"说明文档自身"增长而漂移，导致两人跑出不同计数、且无法解释差异。正确做法二选一：① 自检段单独成文件 + 命令 `--exclude=<该文件>`；② 检查对象与说明对象物理分离。
> 补充：单用 `grep -v "grep -rn"` 挡不住"结果说明段复述关键词"这类污染——必须让说明文本不在被扫描集合内。
>
> 适用面：任何"自指检查"（对报告做检查、对规则做规则、对清单做清单）都同理。

## 6. 口径提醒（D9 轮新增，非自检计数的一部分）

> 以下为**口径事实登记**，不是 G1/G2/G3 的命中项；放在本文件是因为它同样属于「防止下一版口径漂移」的性质。

**`mono_ts` 不是墙钟。** 定义 `mono_ts = round * 1000 + 回合内序号`（`code/engine/ledger.py:18` `time_unit=1000`、`:29` 生成式；`code/engine/kernel.py:32-33` 全批**单个** `Ledger`），回合内序号在事件密集回合会超过 1000、溢进下一回合基数区间，**跨回合不单调**（实测 r4 达 `4000+1858=5858` > r5 基数 `5000`）。
⇒ **禁止**用它做耗时、s/round、吞吐或窗口/超时判定；逐回合耗时只能按 live 调用数 × 单位耗时折算，或取 side cache 文件 mtime。

**交叉引用**：`R5-datasets-and-demo.md:37` 已正确声明其「逻辑时间、非墙钟」语义；本条补充的是**「跨回合不单调」这一层**，两处不冲突。
**边界**：不建议因此改名——改名会动 `engine_version` 指纹并破坏既有证据可比性。

**`tools/d5/dialogue_metrics.py` 必须带 `--meta`。** 只给 `--log` 时，`admission.verdict` 会从 `ADMITTED` 掉到 `REJECTED`、`evidence_level` 从 `evidence` 掉到 `probe`（`B-7_files` / `B-9_event_count` / `B-2b_manifest_effective` / `B-10_provider` 因缺 meta 判 False），而**指标数值完全不变**。
⇒ 复核他人 d5 读数时必须带 `--meta <该臂 meta.json>`，否则会把可用证据误判成"不可用"；本条在 D9 轮由作者与独立复核方各踩过一次（`d9-readings.md` §1）。

**两臂对比时，"结构层逐项相同"与"措辞层有差异"可以同时成立。** 同 seed / 同 `engine_version` / 同 12 项 `config_components` 下，内核调度与线程形成是确定性的，只有正文受 LLM 采样影响。
⇒ 判"数据是否同一批"必须看**正文**（D9 轮实测：同位相同 35/686、唯一正文交集 34 条），**不能**看 `msg_uid`（构造式 `seed:seq`，同 seed 必然相同）或结构读数（必然相同）。

**`L-1_len` 有两个栏，禁止跨栏比较。** `all` = 原文全长；`excl_paren` = 去掉括号块后的"台词本体"。若一臂恰好零括号（如 A1 措辞臂 124 条全无括号块），则 `excl_paren ≡ all`，此时拿对端臂的 `all` 去比本臂的"唯一值"属**跨栏**。
⇒ 规则：**主对比一律同栏对同栏**；措辞类结论用 `excl_paren`（与 L-2/L-3 同口径），`all` 只作对照，并注明某臂两栏相等的原因（R9 措辞臂：−39.9% 为主口径、−52.8% 为对照口径）。
⇒ **子群拆分同样适用**：按 agent / topic / 渠道（DM·PUBLIC）/ 时段等任何子群拆 L-1 长度时，也必须同栏对同栏，**不得**一侧取 `all`、另一侧取自身唯一可取的那一栏（R9 措辞臂 §4.2 首版即犯此错，已由 `r9-erratum` 修正：按 agent 应为 `excl_paren` 22.4/16.5/27.3/62.7 → 16.9/17.3/18.2/52.3）。

**零事件只给上界，不给点估计。** 指标出现 0/n（如 L-2/L-3 = 0/124）时，用精确二项 `rule-of-three`：95% 上界 ≈ 3/n。禁止写"降到 0%""完全消除"（R9 §2.1）。

- **判据不是"计数为 0"**，而是"**每一处命中都能说明为什么必须在这里**"；把规则句删掉以凑 0 属于拆防线，不接受。
